## 0. 最终决定与完成定义

**G1 的最终交付**不是 L0 标签，也不是“每条反应一定找到 TS”，而是：针对每条通过 G1 v2 关卡的反应，生成、静态验证并冻结一个有限的 `scan_plan_v1` 候选树。树中包括选边、锚点、驱动/观察坐标、端点装配、参数、ORCA/xTB 输入、回退条件、预算和来源哈希。G2 只能按冻结树执行并报告结果；严格 TS/频率/双向 IRC 另行验证和记账。

完成时同时满足：

1. 上游 `v2-verify` 无问题且 `v2-gate.gate_pass=true`；失败关卡不向 G2 发布新计划。
2. 每个 `scan_ready` ID 恰有一个计划文档，状态为 `ready`、`manual_review` 或 `input_rejected`；所有状态和拒绝原因汇总闭合。`needs_review` 与 `excluded` 保持原有账本，不因扫描策略而放行。
3. 每个 `ready` 计划至少有一个**可构造、预算内、由 G1 预先排序**的候选；坐标/原子索引/端点/输入文件独立验证通过。没有适用原生扫描坐标时，必须显式转双端路径方法或给出拒绝原因。
4. 所有 G2 候选和结果沿用原始 R→P 身份、split、L0/L0u/L1；算法内部可选择反向扫描，但归档恢复原始方向。
5. 测试集只运行训练/验证阶段冻结的策略和阈值。计划输入中不得含 DFT TS/IRC 坐标、能量或反推得到的扫描范围。

## 2. 唯一的数据与方向语义

令 `E_R/E_P` 为映射图两侧的无向连接集合：

```text
F = |E_P \ E_R|   # 原始 R→P 新成键
B = |E_R \ E_P|   # 原始 R→P 断键 = 反向 P→R 新成键
O = 两侧均有连接但键级变化的数目，单独记录
```

| 算法成键方向 | 成键终点/锚点 | 从锚点拉伸的实际扫描方向 | 完整新键集合 |
| --- | --- | --- | --- |
| R→P | P | P→R | `F` 根 |
| P→R | R | R→P | `B` 根 |

**混合选边 v1，确定性预排序：**

1. `F=B=0`：不存在终点新键驱动；检查键级主导、角/二面角或双端路径，不生成零坐标扫描。
2. `F=B>0`：先比较映射与端点几何、组分装配和中心位置；若两侧均合格且分数相当，冻结双向候选。平局若 `F>3`，不尝试完整 4+ 键同步扫描。
3. `F≠B` 且 `max(F,B)≤3`：以多成键侧为默认锚点；少成键侧仅在 `min>0`、几何与装配合格时加入有限备选。实际执行能否改先后顺序，只按 G1 冻结的质量规则。
4. `max(F,B)>3` 且 `1≤min(F,B)≤3`：评估少成键侧能否安全装配、能否驱动所有目标编辑；通过才列为首选。否则从多成键侧选 ≤3 个代表性驱动键，或走 PATH/NEB。
5. `min=0,max>3` 或双侧均 `>3`：选 ≤3 个有因果解释的代表性坐标并观察其余编辑；无法验证时直接安排双端路径方法，不能为了满足语法上限任意删键。

“成键方向”是用来定义锚点的方向；**锚点拉伸方向与之相反**。这两个字段必须分别持久化。化学上的正反可逆不保证受限优化路径可逆；方向和扫描顺序可能改变实际得到的局部路径。[ORCA 6.1 Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)。

## 3. 从反应类别到扫描候选

现有七个规划族是静态入口，仍需逐条编辑图和几何检查；L0/L0u/L1 与规划族并存。它们在 `clean` 集合中的计数见[ORCA 扫描模式识别与计划](G1_v2_ORCA扫描模式识别与计划.md)。候选按以下规则具体化：

| 结构模式 | 第一层 1D 候选 | 观察项与回退 |
| --- | --- | --- |
| 单个局部成/断键、结合/解离 | 一个 B 距离；从键合侧拉伸，必要时有向该侧拉近候选 | 检查组分装配、另一侧端点和非目标碰撞；失败用双端路径 |
| 单一 H 伙伴转移 `A–H → B–H` | 优先从更好锚点拉伸该侧 H 键，一个 B 驱动 | 另一根 H 键做观察项；若不自发变化，用两个 B 同步或 PATH/NEB。H₂ 不套入此模板 |
| RPH 式两键协同、取代、消除、环合/开环 | 1–2 个主 B 或两个 B 同步同一步号 | 原断键、环拓扑、取向做观察项；异步证据触发少量预定早/晚时间表 |
| 三个相互独立的主成断键 | 最多三个 B 同步，先做约束几何与秩检查 | 几何冲突、分步通道或其他编辑不动时降为代表键或双端路径 |
| H₂、芳香/共轭、键级主导、密集耦合编辑 | 尝试 1–3 个有意义的 B/A/D，且明确观察其余编辑 | 若不能用可靠局部坐标表示，优先双端 xTB PATH 或 ORCA/xTB NEB |
| 多组分、构象主导或端点难对齐 | 几何可行时用 B/A/D；否则双端路径 | 必须先生成有限且可复算的端点装配；失败进入人工复核/输入拒绝 |

ORCA 6.1 支持 B/A/D 松弛扫描与至多三个同时扫描坐标；`Simul_Scan true` 让同一步号改变多个坐标，是**一个进度参数的路径**，不是 2D/3D 网格。每一步仍做受限几何优化。[ORCA 6.1 Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)。二维网格仅为试点证明增益且在预算内的歧义子集；xTB 降低单次成本，不能消除网格的点数乘法。可用具体方法仍需目标机器的 ORCA/xTB 版本能力测试。

## 4. G1 的实施包与顺序

| 关卡 | 实施内容 | 产物与验收 |

| **G1-1 能力注册** | 记录 ORCA/xTB 实际版本、B/A/D、1D、2/3 坐标同步、NEB/PATH 和关键输入组合的最小兼容样例；固定 GFN2-xTB 等方法与预算配置 | `orca_capabilities_v1.json`、可复算的小样例及版本拒绝码；未测组合不能生成 `ready` 输入 |

| **G1-3 双向选边与装配** | 对 R→P、P→R 均建候选；执行混合规则；按确定性种子做端点对齐和有限多组分摆放，检查原子顺序、电荷/多重度、碰撞 | 每个锚点有质量分项、拒绝码和排名；无零驱动键；平局和换向理由可解释 |
| **G1-4 驱动坐标与时间表** | 分别标记 `driver_pairs` / `observer_pairs`；对 B/A/D 检查端点差、几何独立性和冲突；先单键或同步 2–3 键，再有限早/晚时间表；配置 PATH/NEB 回退 | 同步候选 ≤3 坐标、共用点数；每个候选有有限扫描值列表、范围检查及全部目标编辑的观察定义 |
| **G1-5 输入与执行树编译** | 生成统一 map 升序的 R/P XYZ、ORCA 0 基索引、`.inp`、候选优先级、机器可判定 `run_if/pass_if`、资源上限、输入 SHA256 | 每条 `ready` 有有限无环候选树；G2 不得新选键、步数、装配或方法 |
| **G1-6 独立验证与冻结** | 独立读回 JSON/XYZ/INP 检查元素与索引、端点值、坐标上限、方法能力、总预算、触发树、truth 黑名单、split 与各哈希 | `scan_plan_v1`、summary/manifest；每条 ID 恰一终态；`plan_gate_pass=true` 才供 G2 消费 |
| **G1-7 Demo 与试点反馈后锁版** | 先用 24 条待复核样本（16 train + 8 valid）检查计划输入、路径与失败分类；再另取 200–1000 条分层样本，在相同核时预算下比较锚点/坐标/方法，仅用 train 调阈值、valid 检查 | 24 条形成逐例闭环，不用来估计总体成功率；独立试点后冻结策略版本与预算，测试集只用锁版计划，发布按族有效路径率和每个正确 TS 的总核时 |

建议 CLI 增加 `g1 v2-scan-plan`、`g1 v2-scan-verify`、`g1 v2-scan-freeze`；实现可拆模块，但外部 schema 统一。既有 `v2-gate.py` 中“G2 may choose its own scan method”的旧合同说明须同步更新为 G1 冻结方法、G2 执行。

## 6. 验收数字与实验判据

- **账目**：`n_scan_ready + n_needs_review + n_excluded = 199,217`；当前数分别为 183,460、7,688、8,069。计划状态之和必须等于当次通过 gate 的 `n_scan_ready`。
- **覆盖**：报告完整新键 1–3 根的数量上界 183,012/183,460，也报告几何/装配/方法能力过滤后的 `n_plan_ready`。这两个数不应混名。
- **输入**：`ready` 候选的 map→ORCA 索引、元素、XYZ 原子序、价态/电荷/多重度、坐标点列、正反方向、输入 SHA256 和总预算全部通过独立验证。
- **策略**：按 `F>B`、`B>F`、`F=B`，七规划族、H/H₂、芳香/非芳香、1/2/3/>3 键、单/多组分与 L0/L0u 分层；同反应配对比较多成键、少成键和混合规则。
- **G2 反馈**：分开报告输入通过率、方法完成率、目标端点路径率、有用 TS 初猜率、严格 TS/IRC 率及全部尝试的核时；失败、超时与回退都留在原始分母中。
