# G1 v2：多成键与少成键方向的扫描对比及混合规则

> 2026-09-27。比较两种**扫描方向的选边准则**，不改变原始数据 R/P 标签。数据为 `g1_v2_summary.parquet`、`inventory.parquet` 中 `audit_status=clean` 的 183,460 条。ORCA 6.1 `Simul_Scan` 一次最多三个 B/A/D 坐标；坐标数在范围内，只证明语法上可规划候选，不证明路径能到目标 TS。[ORCA Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)。

## 1. 两种方案的精确定义

令 `F=|E_P\E_R|` 为原始 R→P 新成键数，`B=|E_R\E_P|` 为原始 R→P 断键数；反向 P→R 的新成键数就是 `B`。`O`（键级变化）单列，不能当作新连接。

| 方案 | 选择的规范成键方向 | 键合锚点 | 从锚点拉伸时的完整新键数 |
| --- | --- | --- | ---: |
| **多成键优先** | `F>B` 选 R→P；`B>F` 选 P→R | 该方向的终点，即键连接较多的一侧 | `max(F,B)` |
| **少成键优先** | `0<F<B` 选 R→P；`0<B<F` 选 P→R | 该方向的终点，即相对另一侧新连接较少的一侧 | `min(F,B)` |

注意：这里“少成键方向”若 `min(F,B)=0`，**没有该方向的新键可从终点拉伸**。选零根约束虽然形式上不超 ORCA 上限，却不构成扫描。`F=B` 时两方案对键数的判定完全相同，仍需按端点几何选择或计划双向。

## 2. 当前数据的数量对比

| 指标 | 多成键优先 `max(F,B)` | 少成键优先 `min(F,B)` |
| --- | ---: | ---: |
| 0 根可拉伸键 | **0** | **10,694** |
| 1 根 | 14,364 | 74,083 |
| 2 根 | 103,154 | 87,714 |
| 3 根 | 60,567 | 10,715 |
| 超过 3 根 | 5,375 | 254 |
| **有 1–3 根完整新键** | **178,085（97.07%）** | **172,512（94.03%）** |

少成键优先把 `>3` 的情况从 5,375 降到 254，却因 10,694 条 `min=0`，反而使直接具有 1–3 根完整新键的反应数**少于**多成键优先。10,694 条零键由 `F=0` 的 5,761 条和 `B=0` 的 4,933 条组成；两侧同时为零的记录在当前 `clean` 集合里没有。两侧都超过三根的有 254 条，故“永远保证 ORCA 三坐标以内”不成立。

端点装配也是主要差异。在 `F≠B` 的 112,137 条中，若按多成键规则选择键合锚点，**86,416 条（77.1%）**锚点侧只有一个组分；按少成键规则，仅 **21,052 条（18.8%）**为单组分。少成键方向往往选择更碎的端点；从独立片段 XYZ 出发，即使只约束一根键，若相对取向不对，也可能走向错误通道。ORCA 文档对多片段约束优化特别强调片段连接和内部坐标设置。[ORCA Geometry Optimizations](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations.html)。

## 3. 化学与数值权衡

| 维度 | 多成键优先 | 少成键优先 |
| --- | --- | --- |
| ORCA 坐标上限 | 5,375 条需降维/换方法 | 254 条两方向都超限，另有 10,694 条零约束 |
| 起点几何 | 较常从连接完整的片段出发，起始几何有更多内部定位 | 更常从多组分侧出发，需人为装配与取向采样 |
| 约束强度 | 多键协同扫描可能过约束，设定先后关系有风险 | 少键扫描给其余键更多松弛自由，但目标反应可能不受控 |
| TS 候选 | 可保留 RPH 式双成键同步路径 | 可能得到更廉价的单键扫描，但高能峰未必属于目标编辑 |
| 失败机制 | 约束几何冲突、错过异步/分步通道 | 残余新键不自发变化、片段旋转/飘走、零键无扫描 |

所谓“可逆”属于同一基元通道的势能面事实；**局部约束优化不必可逆**。ORCA 手册明确说明扫描结果可依赖方向及坐标顺序。因此两个方向应作为可比较的算法候选，不以较少的坐标数预判哪一条会找到正确 TS。[ORCA Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)。

## 4. 推荐混合规则：先保住有效锚点，再减少约束

```text
if F == B:
    对 R/P 分别评估几何质量、反应中心是否处于已成键组分、装配成本；
    仍相当则 G1 冻结双向候选，优先顺序固定、失败时切换。
elif max(F,B) <= 3:
    以多成键侧作为默认键合锚点；
    同时为少成键侧生成有限候选（若 min>0 且装配合格），
    仅在几何评分更好或默认路径失败时执行。
elif 1 <= min(F,B) <= 3:
    先评估少成键侧是否可安全装配并能驱动全部目标编辑；
    合格则选少成键侧的 1–3 键扫描，
    否则仍从多成键侧挑 ≤3 个代表性驱动键或用 PATH/NEB。
else:
    不声称完整新键扫描能直接满足 ORCA 三坐标上限；
    G1 选代表性 ≤3 键并列出其余观察键，或编排 PATH/NEB。
```

此规则在**键数这一单一维度**上，能直接为 183,012/183,460 条（99.76%）挑到**非零且不超过三根的完整新键集合**：多成键数 ≤3 的 178,085 条，加上多成键数 >3 而少成键数为 1–3 的 4,927 条。剩余 **448 条**包括“少成键数为 0、多成键数 >3”的 194 条，以及“两侧都 >3”的 254 条。这个 99.76% 是**候选坐标覆盖率**，绝不可标成 ORCA 运行率、目标路径率或 TS 成功率。对任何一条，几何独立性、组分装配和未约束编辑仍须检查。

**少成键不是首要优化目标。** 更稳健的目标是：在目标编辑可被驱动、端点几何可用和总预算可接受的前提下，选最少的有效约束。G1 可以比较 `k=1,2,3` 的嵌套候选：若少键方案使其余目标键自发变化，即可省去多余约束；若不能，就追加约束或更换方向。每个候选与触发条件必须在 G1 冻结，G2 不临时挑键。

## 5. G1 评分与验收

每个方向生成 `direction_candidate`，至少记录：`n_formed_in_direction`、`n_components_anchor`、`n_components_origin`、`assembly_count`、`geometry_clash_status`、`driver_pairs`、`observer_pairs`、`estimated_scan_points`、`anchor_reason`。预筛选拒绝：零驱动键、端点映射/元素不一致、起点碰撞、构型退化、无法构造原子顺序一致的 XYZ、超预算。对可运行候选，路径质量判据与前述 G1 计划一致：未约束目标编辑是否完成、能量/帧连续、是否到达目标另一侧、TS 初猜与严格验证分别记账。

需要做**同反应配对试验**：在 `F>B`、`B>F`、`F=B` 三组，按 1/2/3/>3 键、单/多组分及 H 转移分层，比较多成键锚点、少成键锚点和上述混合规则。主要决策量是相同核时预算下的**正确目标路径率和每个严格 TS 的总核时**，同时报告零键、装配失败和未约束编辑失败。不要只比较每条扫描输入中写了几根键。
