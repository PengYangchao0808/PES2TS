成断键方向
如何决定扫描？

从原始反应 R→P 同时构造两个“成键方向”，比较可拉伸键数与端点质量。G1 冻结候选和回退条件；G2 按计划计算、记录并核验。

核心 成键端作为锚点首选 混合选边边界 最多 3 个同步坐标
99.76%当前 clean 集合中，混合规则在“完整新键集合为 1–3 根”这一单一条件上的候选覆盖率：183,012 / 183,460。仍需几何、装配与路径验证。

一条反应的决策链

原始 R/P 标签始终保留。这里选择的是扫描算法的方向和端点，不重写数据集的化学方向。

01 · 输入

映射的 R / P

端点几何、原子映射、组分和编辑图。

02 · 计数

求 F 与 B

F 是 R→P 新连接；B 是 R→P 断连接。

03 · 双向候选

比较 P 与 R 锚点

各自的新键数、几何质量与装配成本。

04 · G1 冻结

主方案 + 回退

驱动键、观察键、步数、预算和触发条件。

05 · G2 执行

计算与核验

运行预定候选，验证目标编辑与 TS 初猜。

F = |EP \ ER|原始正向 R→P 形成的新连接
B = |ER \ EP|原始正向断裂、反向 P→R 形成的连接
O 单独记录已有连接的键级变化不计入 F/B

输入 F / B，查看候选

这是“键数优先”的预选器；实际 G1 还要筛端点几何、组分装配与未约束编辑。

混合选边规则

下列分支会随上方输入高亮。它确定候选优先级，不声称扫描一定找到目标鞍点。

F = B

几何决定平局

1–3 根时比较两侧端点；仍相当则冻结双向候选。零键或双侧超限另走特殊路线。

max(F,B) ≤ 3

多成键为主

优先完整键合锚点；少成键侧在非零且装配合格时作为有限备选。

max > 3，1 ≤ min ≤ 3

评估少成键侧

少成键侧可降低坐标数；须验证它能驱动其余目标编辑。

其余情况

代表键 / PATH / NEB

一侧零键且另一侧超限，或双侧都超限；保留观察键与拒绝原因。

为何不固定选“更少的键”？

数据口径：2026-09-27 的 G1 v2 clean 快照，183,460 条。下图是新键坐标数量的统计，不是 ORCA 运行或 TS 成功统计。

完整新键集合的坐标数量

多成键优先178,085 · 97.07%
少成键优先172,512 · 94.03%
混合规则 · 坐标预选183,012 · 99.76%
1–3 根完整新键0 根超限 / 需其他路线

混合规则中的 448 条 = 一侧零键且另一侧 >3 的 194 条 + 两侧都 >3 的 254 条。

端点装配负担

77.1% vs 18.8%

在 F≠B 的 112,137 条反应中，多成键锚点为单组分的比例是 77.1%；少成键锚点仅 18.8%。组分数只是端点可用性的代理指标，最终仍需逐条几何检查。

  • 少成键策略有 10,694 条零驱动键，无法按“终点新键拉伸”生成扫描。
  • 两侧都超过三根的 254 条，不能靠换向直接满足 ORCA 的三坐标上限。
  • 协同的 2–3 根键可按共同步号扫描；这是一条同步路径，不是 2D/3D 网格。

一维路径的含义与边界

一个进度参数，最多三个受控键长

对同步候选，以同一步号推进 1–3 个 B 坐标；每一步松弛其他自由度。可选不同键的起止值或有限的早/晚时间表。它保留 RPH 的协同成键思路，同时避免 N×N×N 网格。

键数合格 ≠ 路径正确

未约束的成断键、H 迁移、芳香重排和片段取向必须逐帧检查。高能峰只是 TS 初猜；严格 TS 仍需优化、频率与双向 IRC 验证。

团队实现边界

G1 · 设计并冻结

  • 保留原始 R/P、F/B/O 和 L0/L0u 标签；构造两个方向候选。
  • 检查原子映射、端点几何、组分装配、碰撞与坐标独立性。
  • 冻结驱动键、观察键、起止值、步数、ORCA 索引、输入文件和 SHA256。
  • 冻结主备排序、触发条件、拒绝原因与预算；不使用 TS/IRC 真值设计输入。
→

G2 · 执行并验证

  • 按 G1 的计划和条件运行，不临时改方向、键集或预算。
  • 保存原始帧、能量、失败码与资源消耗。
  • 检查目标编辑、端点匹配、路径连续性与 TS 初猜质量。
  • 需要新策略时回到 G1 产生新版本计划；报告仍按原始 R→P 方向归一。
