## 1. 结论与当前代码现状

原训练方案覆盖算法流程，未完整规定按产品归属的文件范围、依赖方向和交付合同。此次把预测器作为独立所有权：本期所有新增业务代码归 `pes2ts_core/pesn/`；离线与在线在这个产品内隔离。测试、配置、依赖声明和真值守卫的最小登记是配套文件，业务实现仍在预测器。

## 3. 单一产品代码根与依赖方向

以下是目标文件树，全部为待创建；已有目录不迁移，不为未来任务先创建空头/空服务。

```text
pes2ts_core/pesn/
  __init__.py                    # 轻量产品标记，无offline/torch自动导入
  __main__.py                    # 显式子命令路由，延迟导入
  api.py                         # 运行时公共入口
  contracts/
    inputs.py                    # 目标图/当前观测/坐标只读输入
    predictions.py               # 教师输出与逐头availability
    artifacts.py                 # 数据/split/run/bundle声明及校验
  features/
    graph.py                     # 权威图到数值特征；不决定编辑/许可
    geometry.py                  # 描述坐标求值、空间邻域、单位/掩码
    normalization.py             # 应用冻结尺度与normalizer
  models/
    baselines.py                 # 同输入规则/MLP预测器基线
    encoder.py                   # 小图编码器
    heads.py                     # 本期progress/proximity/direction/activity
  inference/
    predictor.py                 # 单点/批量前向、支持域、能力拒绝
  bundle/
    reader.py                    # 白名单运行资产/权重/hash/兼容检查
  offline/
    cli.py                       # 显式离线入口与scope，不在运行导入链
    data/
      truth_source.py            # 唯一拟登记真值访问桥
      endpoint_adapter.py        # G1端点图/映射/坐标描述适配
      inventory.py               # 元数据join/来源/资格/typed拒绝
      dataset.py                 # 导出shard，sample/feature/label分视图
    splits/
      grouping.py                # canonical group/来源/污染/排除
      freeze.py                  # 父split约束+train子集/整族冻结
    labels/
      progress.py                # 配准/质量弧长/两侧定向/截短
      direction.py               # 低维朝TS导数/activity及缺失资格
    training/
      loader.py                  # 只读导出train分片，反应等权采样/collate
      losses.py                  # masked多任务loss、pair/对称语义
      trainer.py                 # 小试/扩量/早停/train内选择
      checkpoints.py             # 恢复、optimizer/RNG、依赖hash
    evaluation/
      metrics.py                 # 反应级定位/方向/覆盖/bootstrap
      benchmark.py               # 权重/门冻结后sealed评测，无fit调用
    experiments/
      runs.py                    # 配置/hash/资源/失败/版本/模型卡
    publishing/
      export.py                  # runtime白名单资产导出与检查
```

在线可达集 = api/contracts/features/models/inference/bundle；offline 依赖在线集，反向导入为违规。包初始化只声明版本/公共轻量符号；公开方法显式加载运行模型时才需要对应 backend。contracts/artifacts 只定义文件/字段校验，不导入 trainer/source。

允许 runtime 复用现有纯 utils/hashing、jsonio；路径读取限显式 load_bundle，不调用 source/网络/任务提交。G0/G1/coordinate_pool 等源模块只由 offline adapter 调用；它们在本仓中的转移依赖不进入runtime，外部调用者提供普通数据合同。

B0 的API可先定义合同，B6才交付模型前向实现；不以空壳返回值冒充可用。B1可在不读教师坐标的元数据上先行；B2以分裂冻结为前置。B3的可部署特征只接当前几何，即使数据来自IRC也不能访问其reference sidecar。

### 4.1 运行接口

- `load_bundle(path, *, expected_feature_spec=None) -> Predictor`：校验hash/schema/支持域/开放头；加载白名单运行资产。
- `Predictor.predict_point(PESNInput) -> TeacherPrediction`、`predict_batch(sequence[PESNInput]) -> sequence[TeacherPrediction]`：同语义/顺序，逐样本typed拒绝，不能因一条无效样本静默丢行。
- `Predictor.capabilities() -> capability_map`：research_only、支持输入/方法/坐标/头、证据与版本；STOP/成本/Q/production_control disabled。

PESNInput含当前X/元素/原子映射、端点任务图及来源、电子态/方法/单位、坐标描述/特征资格；不含参考TS/未来帧/标签。TeacherPrediction对应`pesn_teacher_prediction_v1`，含输入/model/feature hash、progress/path score/direction/activity及mask/reason，不含选中动作、执行结果或严格成功。

### 4.2 离线接口和配置

目标入口为 predictor 自有 `__main__` 路由的 inventory/split/build-teacher/train/evaluate/export/predict 子命令；本设计仅登记语义，不声明命令已存在。根cli后续只加延迟路由，不把实现内联到根cli；本期可先使用自有入口而无需修改根cli。

配置目标目录 `config/pesn/`，文件可按data/split/labels/features/model/train/eval/bundle区分；初期可一个完整g3_p1.yaml包含这些section，按实验需要再拆。每个section版本/hash和作用域显式，错误/未知键失败；路径参数不能让train读sealed或export打包teacher。`config/defaults.yaml`的Classic默认不改。

训练器独立环境/可选依赖；新增声明目标 `requirements-pesn-runtime.txt`、`requirements-pesn-training.txt`。基础requirements不强塞torch/训练框架，依赖版本在B4环境实测后锁定并入run/bundle；本次不安装或声称可用。运行时需backend而未安装时typed unsupported；数据盘点和既有Classic可继续工作。

## 6. 预测器内部真值与部署隔离

只有offline/data/truth_source拟导入G0审计访问器；它先校验data_version/split_hash/scope/allow_truth和读权限，再按selected IDs调用load_irc_frames/load_ts_geometry。已有全库stream若不能先限制访问范围，则本期不用于train构建；需要受限流式接口时提G0数据产品增量任务，不直接开原始HDF5第二通道。

source桥将已审计观测交给offline标签构建；source refs/TS/邻帧留在隔离标签/provenance分片。训练loader只读获准train导出文件和标签视图，不import truth_source；train_fit/dev/calibration以run权限校验。独立benchmark只读冻结模型及sealed导出视图，和train运行模式/路径/日志分开，没有fit/early-stop回路。

相同产品代码根不等于相同运行权限。runtime导出包含API、轻量合同、features/models/inference/bundle及白名单运行资产；不含offline、教师分片、样本参考TS、未来邻帧、训练checkpoint/optimizer状态、原始数据路径、HDF5/来源访问依赖。公开模型卡可包含来源摘要/hash，不含访问凭据或数据样本答案。

模型包中的LabelSpec仅为任务定义元数据，不能包含逐样本真值。在线代码能读取运行bundle，不因此拥有教师数据读取资格。模型本体的学习权重可来自隔离训练，推理输入始终是当前真实观测。

## 8. 版本、阶段与后续责任

此设计v1，G3-P1方案v1.1、教师合同草案v1.1、产品架构v1.1；只是实现边界细化，软件0.1.0、模型pesn-irc-v0.1.0、数据0.1.0及payload schema v1身份保持。新增研究输出schema是草案，不默认为正式发布。

G3.1的STOP头/校准/真实结果适配仍归预测器产品；它消费统一真实标签，不执行OptTS。G3.2的残差候选模型归预测器；合法性/Classic保留/显式选择及QC执行归控制器/拓扑/ACP。G4的Q模型和离线训练归预测器；实际rollout及全系统验收在宿主/评测产品，依协议回传只进入新train批次。

发布目标pesn-core为纯运行范围，pesn-training为离线开发工具范围，是同一预测器产品的不同分发内容；独立安装包的正式创建/依赖锁/入口在实现时验收，不另起工程阶段或复制模型体系。
