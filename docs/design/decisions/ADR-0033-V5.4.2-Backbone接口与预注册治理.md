## 2. 决策

### 2.1 统一接口：`BackboneOutput` 只有两个功能字段

- `BackboneOutput(frozen, slots)`：`z: [G,64]`（与 `batch["graph_index"]` 图序一致、`tanh` 饱和）+ `edge_msg: [E,48]`（与 `batch["edge_index"]` 列一一对应的**最后表示层**标量消息，带 autograd 图、平移/旋转不变、返回前 scatter 回输入边顺序）。不放 `u`（MOVE 由统一 Decoder 产生）、不放 `node_h`（诊断走单独 hook）。
- **`edge_msg` 而非 `node_h` 是唯一最小字段**：legacy Direct Head 消费边级最后层消息 `m_ij`；若 Decoder 只拿 `node_h` 再重算边 MLP，A0 数学即改变、parity 不成立。
- `DirectMoveDecoder` 是唯一共享 MOVE readout：参数只有 `w_v = Linear(48→1)`（**49 params**）；`a_ref=0.08 Å` 非学习常量；入参是 5 个张量 `edge_msg, pos, edge_index, key_index, degK`（结构上禁止读取监督键）；输出顺序严格等于 `key_index`；与 legacy 的 `+0.1` 分母、`clamp(min=1)`、`index_add` 逐字一致（CPU bitwise 前提）。
- PROCESS 原样复用 `ReactionProcessHeadV53MP`（**2,178 params**），只读 `z`；`order_score IS q`；模型外部输出保持 5 键 `{u, z, q, endpoint_logit, order_score}`，`forward_move` 保持 `{u, z}`，不新增外部键。
- 全候选共同宽度冻结：hidden 48、z 64、edge_msg 48、node 输入 21；参数硬上限 `N_backbone_active ≤ 70,000`、`N_decoder = 49`、`N_process = 2,178`、`N_joint ≤ 72,227`；**A0 joint = 57,619（55,392 active + 49 + 2,178）是迁移不变量**。禁止 `torch.compile`（hook/parity 失效）。

### 2.2 A0 迁移与「前向 parity / 训练可比性」双证书；重训 A0×3

- **不改 legacy 源文件**：`pes2ts_core/pesn/models/v542/` 新建 `A0LegacyBackbone(StarEGNNV3)`——子类只加 `message_mlp[-1]` forward hook 捕获 `edge_msg`（`finally` 移除、恰好一次、不 detach），核心循环 `super().forward` 原样；legacy 算出的 `u` compute-and-discard。
- **`w_v` 共享同一 module 对象**（`backbone.w_v is decoder.w_v`）：`named_parameters()` 去重、优化器不双更新；`state_dict` 双键指向同一 tensor，保存/加载断言 `torch.equal`。param-group **按 `id` 分组**（`core = backbone ∪ move_decoder`、`head = process_head`），禁止沿用 V541 名字前缀分类器（`move_decoder.*` 会触发 `PARAM_GROUP_UNCLASSIFIED`）。
- **显式映射 + strict audit**：source（R3 / V541 E0 / V53MP C）`payload["model"]` → 目标键的映射表冻结（identity + `w_v` 双写）；`missing/unexpected/shape_mismatch/dtype_mismatch` 全空；`strict=True`；逐键 `torch.equal`；禁止 `strict=False` 与运行时 shape 启发式。
- **前向 parity 证书**（6 checkpoint **全 required**：3 V541 E0 S17/S29/S43 主证据（`runs/` 37,900-update final）+ 3 V53MP C S17/S29/S43 辅助证据（`outputs/pesn/v53mp/` S3 formal 20k-tier 15,400-update；`source_tier`/`training_updates` 逐行钉死；path+SHA-256 已于 2026-10-30 由只读 lane 核实并钉入 config/template；smoke 与非钉死路径禁止）：strict-audit load → CPU bitwise（5 输出 + `forward_move`）→ ≥8 个真实 inner-val batch → GPU tolerance `atol=1e-6/rtol=1e-5` **硬上限**（关 TF32；run-to-run 地板仅作诊断，floor > cap ⇒ GPU parity inconclusive，CPU bitwise 仍为决定证据，不放宽容差）→ `q == order_score` → evaluator parity（V542 evaluator 重算 H2/H3 与 V541 存档比较）。**该证书只证明前向/评估迁移正确，不是 E0 复用证据。**
- **训练可比性 → 直接重训**：新接口、构造 RNG 隔离（`fork_rng` + process-head anchor + 训练前 `set_seed(run_seed)`）、按 id 的 param-group、新评估身份，使 V541 E0 训练复用不可直接签认；`a0_reuse_decision` 模板固定记录 `decision=retrain_a0_x3`，**不实现 shadow-run/reuse 分支**（避免额外复杂性）。V541 E0×3 仅 parity/历史参照；H2/H3 对照固定为 matched A0×3。附 **A0 sanity band**（A0×3 三 seed 均值 vs V541 E0×3 三 seed 均值：RMSE/zero ≤2% 相对、AUPRC/q ≤0.01 绝对；registry canonical gate `V542-A0-sanity-band`）只抓迁移大 bug；**T0 A0×3 formal + sanity band 必须在任何 T1 A1-A4 formal 前完成（硬前置）**，breach 时严格阻断 T1 并做迁移审计（parity 证书 / process-head anchor / R3 映射 / sampler / evaluator / code / data / initialization），若发现代码/数据/初始化缺陷则修复后 bump `source_tree_fingerprint` 并重跑 A0×3（旧 A0×3 记 `invalid_run` 不混比）；**不得带 breach 启动候选、不得签 sanity exception 继续**（fix-5 C5 移除旧 exception-continue 路径）。parity 资产分层（fix-5 C3）：V541 E0 = `runs/` 下 37,900-update final 主证据；V53MP C = `outputs/pesn/v53mp/` 下 S3 formal 20k-tier **15,400-update** 辅助证据（非 smoke、非 37,900、不在 `runs/`）；smoke 与非钉死 checkpoint 禁止；GPU 容差 1e-6/1e-5 为硬上限，run-to-run 地板仅作诊断（floor > cap ⇒ GPU parity inconclusive，CPU bitwise 仍是决定证据，不得放宽容差）。

### 2.3 候选 A1–A5 与共同初始化

- 候选按 Oracle §2 hidden48 配方冻结：**A1** 2L GeoEGNN（Star 同形消息 + 零初始化 `W_d(12→48)` 距离注入，~41.2k）；**A2** 新单帧 PaiNN-lite v32（标量 48 + 向量通道 32，`edge_msg` 在最终 `s^L` 上重算使向量通道作用于 MOVE，~54.9k，禁止复用 dual-* 代码）；**A3** A1 + 最后层 ReactionQuery 2×24（`W_o` 零初始化，init 时 == A1，~53.3k）；**A4** 2L sparse geometry transformer 4×12 + 每图 reaction token + Star 同形 edge readout（~55.8k，成本风险最高）；**A5** shared GRU T=4（~31.6k，容量 caveat：机制检验非容量匹配冠军）。参数量均标 `estimated`，构造后由断言给出精确值再登记，不作为实现前 exact 断言。A2 V0=0、φ_u/φ_g 最终输出零初始化、W_s/W_v 默认 seeded、W_g 零初始化在 WP0 冻结；A4/A5 backbone 内可用当前帧确定性几何量 `d/d²/r̂`（无参数、不更新坐标、禁绝对坐标）。
- **共同初始化**：warm-start 源只能是冻结 R3 checkpoint（SHA `a2e46b…0417f`，禁止 V541 E0 final——那会给候选多 37,900 update 预训练）；显式语义映射表逐键审计；**common process-head deterministic anchor**（`fork_rng` 内重放 legacy 构造序，算法 + SHA 记入 run identity，不强制二进制文件）；候选 fresh 参数 seeded `fork_rng`；整个构造包在 `fork_rng` 内、构造后 `set_seed(run_seed)` 再训练。
- **seed recipe（冻结）**：`seed_init = int(sha256("v542-init|{run_seed}|{init_source_id}").digest()[:8], "big") % 2147483647`；默认 `init_source_id = candidate_id`；**A1-C 的 `init_source_id=A1`、A5-C 的 `init_source_id=A5`**（depth/capacity 归因对照只差目标算子，不得引入初始化 nuisance）；构造顺序冻结为 fresh 模块（按 seed_init）→ R3 映射覆盖 → 特殊零初始化 → 共享 `w_v` decoder → anchor 加载 process head → `set_seed(run_seed)`。
- **per-candidate R3 语义映射表（冻结）**：A0 = 全部 37 键 identity；A1/A3 映射 `elem_emb, node_proj, z_head, message_mlp.0/1, node_mlp.0/1`（A3 query 全 fresh、`W_o` 零）；A1-C = A1 映射集 + 第 3 层 fresh（A1 init stream）；A2 = common 映射集 + 两层同形 `φ_s`；A4 = common 映射集 + `edge_readout = R3 message_mlp.2`（attention/token fresh、输出投影零）；A5 = common 映射集 + shared msg MLP = R3 `message_mlp.0`（GRU/W_g fresh、W_g 零）；A5-C = A5 映射集 + 第二 cell fresh（A5 init stream）。所有 `w_v` 来自 R3（49 params 同值）；process head 来自 deterministic anchor。

### 2.5 阈值签认为 frozen（2026-10-29；2026-10-30 统计合同细化）

方案建议值按原值签认，写入 config `thresholds` + `thresholds.signoff`（status `frozen`，signed_by `user_directive_20261029`）并镜像进 signoff 模板：H2（sign 0.01 / dead 0.01 / fixed-coverage 退化 2% / RMSE-zero **退化** 2%——H2 全部为非劣语义，措辞必须带「退化/degradation」方向词）、H3 MOVE（direction 相对 ≥3% 且绝对 +0.01；RMSE/zero 相对 ≥3%）、H3 PROCESS（ΔAUPRC ≥0.02 或 Δq ≥0.03；另一主指标非劣 0.01/0.02）、诊断粗筛（loss 降幅 <5% / dead > A0@2000+0.20 / RMSE/zero 退化 >10%）、GPU parity 1e-6/1e-5、`max_core_time_ratio=2.0`、bootstrap 10,000 draws、`bootstrap_seed_root=20261029`、参数上限 70,000/55,392/57,619/49/2,178、`top2_max_runs=4`、`a5_supplement_max_runs=2`、`t3_max_runs=6`。签认后不得按 seed17/dev 结果修改；改值须重走签认并同步 config/runplan/budget SHA。

**H3 统计合同冻结（2026-10-30，Oracle finding 3）**：

- `bootstrap_seed_root = 20261029`；每 endpoint/seed 用确定性子 seed `int(sha256(f"v542|{root}|{seed}|{endpoint}").hexdigest()[:16], 16) % 2147483647`（endpoint ∈ MOVE direction / MOVE RMSE / PROCESS AUPRC / PROCESS q）；final draws = 10,000；CI 与 p 用同一组 paired cluster bootstrap draws；frame-level 重采样禁止。
- p 值（one-sided improvement）：improvement = direction/AUPRC/q 的 candidate−A0，RMSE 的 A0−candidate；`p = (1 + #{seed-averaged paired bootstrap improvement ≤ 0}) / (10001)`。
- Holm family 冻结：MOVE direction 与 MOVE RMSE 两个 exit 各 α=0.025（出口间 Bonferroni），各自对 eligible candidate 集内做 Holm；PROCESS 单一 family，对 2 endpoints × eligible candidates 的 p 做 Holm，family α=0.025。eligible = 完成三 seed 且每 seed H2 无 breach 的 winner-eligible candidate（A5 仅当三 seed 完成）；diagnostic variants（A1-C/A5-C/A0）不入。
- 冠军须 adjusted p < 对应 α 且效应/非劣条件成立；报告同时给未校正与校正后结果。

**路线括号逻辑（route_logic，fix-5 C2 冻结）**：H3 判定与 `seed17_screen_pass` 显式复用同一结构化括号逻辑，消除任何「或」后条件悬空——MOVE pass = `(direction_pass AND rmse_non_inferior) OR (rmse_pass AND direction_non_inferior)`（`direction_pass` = direction 相对 ≥3% 且绝对 ≥0.01；`rmse_pass` = RMSE/zero 相对改善 ≥3%；`rmse_non_inferior` = RMSE/zero 退化 ≤2%；`direction_non_inferior` = direction 退化 ≤2%）；PROCESS pass = `(auprc_pass AND q_non_inferior) OR (q_pass AND auprc_non_inferior)`（`auprc_pass` = ΔAUPRC≥0.02；`q_pass` = Δq≥0.03；`auprc_non_inferior` = AUPRC 下降 ≤0.01；`q_non_inferior` = q 下降 ≤0.02）。非劣条件只约束所在支，两支各自括号闭合；结构化 block 见 config `evaluation_contract.route_logic`。

**最终 Backbone\* 选择规则（final_selection_rule，fix-5 C1 冻结）**：候选资格 = **H3-qualified only**（完成三 seed、每 seed H2 无 breach、adjusted p < 对应 α 且效应/非劣条件成立）；A0 与 diagnostic（A1-C/A5-C）不参加选择。恰 1 个 qualified ⇒ 选它；0 个 ⇒ A0 留任（`no_backbone_winner`）；多个 ⇒ 按冻结字典序：(1) route priority：MOVE-qualified 优先于 PROCESS-only；(2) qualifying 确认性 endpoint 的 Holm-adjusted p 最小值较小者；(3) qualifying endpoint 的 effect margin 最大值较大者（effect margin：MOVE direction = min(relative_effect/0.03, absolute_effect/0.01)；MOVE RMSE = relative_improvement/0.03；PROCESS AUPRC = delta/0.02；PROCESS q = delta/0.03）；(4) `core_time_ratio` 较小；(5) active backbone params 较小；(6) inner-val total loss 较小；(7) `candidate_id` 字典序较小。**不使用 dev**（dev 仅最终冻结后评估一次，永不参与选择）；报告须列出所有 H3-qualified 候选；完整 rule block 进 statistics/final-selection SHA 与 run identity；A5-C activation 仅用被选中的 candidate（`a5_selected_backbone`）。结构化 block 见 config `evaluation_contract.final_selection_rule`。

### 2.6 运行矩阵、激活规则与授权边界

- **run 三类分离**：nominal（T0 A0×3 重训 + T1 A1–A4 seed17）、conditional（T2 A5 full-dose、T3 top2 补种 + A5 supplement）、diagnostic（seed17 2,000 步诊断 A0–A5、A1-C/A5-C 归因对照）；diagnostic 永不计入主赢家；**winner 资格逐 run 判定**（run row `winner_eligible` 字段），nominal/conditional class 标记不自动授予 winner 资格。
- **诊断只做工程粗筛**：seed17 diagnostic 2,000 = 400 W0 + 1,600 W1，A0–A5 全做（含 A0@2000 同剂量对照），只按 §2.5 诊断带淘汰「不学习/破硬门/超预算」；**不得套用 full-dose H3 的 3% 效应量**；不参与排名。
- **top2（只属 A1–A4）**：预注册 A1–A4 × seeds {29,43} = 8 个稳定 `V542_A#_S##` 条件 run（`condition=activated_only_by_inner_val_top2`）；**eligibility = `seed17_screen_pass` predicate**（run done 且指标有限；H0/H1/diagnostic/cost≤2 全过；matched A0_S17 已完成；seed17 H2 全 guard 无 breach；point effect 至少一路，显式复用 route_logic 括号逻辑——PROCESS `(auprc_pass AND q_non_inferior) OR (q_pass AND auprc_non_inferior)`，或 MOVE `(direction_pass AND rmse_non_inferior) OR (rmse_pass AND direction_non_inferior)`）——**这是 seed17 筛选 predicate，不是三 seed H3 声明**；满足者按冻结 screen score 排序（tie = inner-val total loss 再 core-time），最多 2 个（可少于 2，不替补），**top2_max_runs = 4**；top2 freeze 需 A0_S17 complete **且 A0×3 sanity band pass（`V542-A0-sanity-band`）**；未激活 `gate_skipped` 计 0 新训练；checkpoint 始终仅按 inner-val total loss 选，禁止按 H3 指标挑 checkpoint。
- **A5 supplement（与 top2 完全拆分）**：A5 的 T3 行（S29/S43）**不属 top2**；条件 = `a5_full_dose_complete_and_seed17_screen_pass`（A5 seed17 full-dose run 完成 **且** A5 seed17_screen_pass）；**a5_supplement_max_runs = 2**；合计 T3 上限 `t3_max_runs = 6`。
- **A5 自动激活**：smoke/profile/diagnostic 先做；full-dose 需 diagnostic/cost/H0/H1 全过；仅当 A1–A4 top2 三 seed **最终 H3 无人合格**时自动激活，否则 `gate_skipped`；无裁量。
- **N_core（新训练 run 计数）**：`N_core = 3 + n_T1_seed17(≤4) + I(A5_full_dose) + n_diag2000(=6) + 2·n_top2_selected(≤2 candidates) + 2·I(A5_supplement) + I(A1C_activated) + I(A5C_activated)`；按公式计数，不按 listed runs 求和；**smoke/profile 是技术测量，不进 N_core**。
- **A1-C/A5-C 归因诊断（full-dose 诊断，均非 winner-eligible）**：激活前必须 H0 fixture、conditional smoke 200、40+40 profile、cost≤2、预算记录。A1-C（3L GeoEGNN seed17 full-dose）激活条件 = `a1_in_top2_supplement_set_OR_a1_selected_as_backbone`（进 top2 集**或**被选 Backbone\*；**不是仅 top-ranked**），skip reason = `a1_not_in_top2_and_not_selected`，负结果归因未解决、不事后补跑、不加入 C2。A5-C（2 个交替 GRUCell T4 hidden48，第二 cell 用 A5 init stream）激活条件 = `a5_selected_backbone` **仅此一项**，skip reason = `a5_not_selected_backbone`；若 A5 H3 合格但未被选为 Backbone\*，记 `capacity_caveat_unresolved`，不跑 A5-C。
- **授权位**：`implementation_authorized=true`、`formal_training_authorized=true`（用户 2026-10-29 指令），`t1_start_requires=[V542-H0-legality, V542-H1-resource, V542-WP1-interface-parity, V542-WP2-candidates, V542-smoke-200, V542-profile, V542-diagnostic-2000, V542-A0-sanity-band, V542-budget-signoff, runplan_pin_record]`（前 9 项为 registry canonical gate IDs，含 fix-5 C5 新增的 `V542-A0-sanity-band`；`runplan_pin_record` 是 record requirement，不是 gate alias）；`confirm_authorized=false`、`sealed_authorized=false`、`new_qc_calls=0`、`single_lane=true`、`swap_allowed=false`。
- **formal 阶段顺序（fix-5 C5）**：T0 `V542_A0_S17/S29/S43` formal + `V542-A0-sanity-band` pass 必须最先完成；之后才可启动 T1 A1–A4 seed17 formal；T2/T3（WP6）与 T-ATTR 随后；smoke/profile/diagnostic 可在 T0 前先行（技术测量，不属 formal）。
- **signoff 角色（fix-5 C4）**：`statistics_owner`/`evaluation_signoff` = `main_session_owner`（主会话，不是 Oracle）；`oracle_reviewer: oracle_gate0_reviewer`（reviewer 不是签认人）；parity/training/resource signoff 保持 pending（WP1–WP4 证据就绪后由 owner 签认并 re-affirm）；WP0 authoring complete，formal signoff pending owner re-affirm。
- **运行身份**：`source_manifest_sha256` 必填、`code_commit` 可选（`git_commit_authoritative=false`）；identity 还须含 config/common-protocol/environment/backbone_spec/init_mapping/process_head_anchor/statistics_contract SHA、`bootstrap_seed_root`、`plan_sha256`、`oracle_design_source_sha256`（设计源 SHA `4f13bfbd…ccccb`）。
- **成本门**：`core_time_ratio = candidate_core_time / V542 A0 同环境 profile ≤ 2.0`；分母必须是 V542 A0 实测（禁用 V541 存档表）；超限记 `gate_skipped_cost_ratio_exceeds_2`（科学结果保留、不晋级、不是 `resource_failure`）；**禁止**减帧/层/更新等事后绕行。budget 数值在 profile 前保持 `null`（prereg 通过、`--formal` typed block）。
- **outcome 六词**（`done/invalid_run/scientific_failure/resource_failure/budget_censored/gate_skipped`）与旧 ledger 状态机分开记录、互不改写；selection 只看 inner-val；dev 仅最终冻结的少数模型；confirm 永封；tau 不在 dev 重校；无生产 No-Move / verified TS / 部署声明。

## 4. 风险与未决

- **候选参数为估算**：A1–A5/A1-C/A5-C 的参数量是设计估算（`estimated: true`）；实现构造后由断言给出精确值并回填 registry/config，若超 70k 上限先简化（如 `W_v` 去 bias），不得在结果出来后裁。
- **预算未签认**：`budget.per_candidate_core_time=null` → `--formal` 持续 typed block（`V542_BUDGET_NULL`），须 WP4 同环境 40+40 profile 后回填并重哈希。
- **A2 `edge_msg` 重算语义**：A2 用同一 `φ_s` 在最终 `s^L` 上重算 `edge_msg`，使向量通道影响 MOVE——这是与 Star 语义的有意差异，必须写进 registry/报告，不得当作 bug「修」掉。
- **A1 负结果归因**：A1 未晋级时深度/算子归因未解决（A1-C `gate_skipped(a1_not_in_top2_and_not_selected)`）；C2（2L Star 无 `W_d`）不在本阶段预注册，不得事后补跑。
- **A5 容量混杂**：31.6k 容量明显低于 A0 55.4k；A5-C 仅在 A5 被选 Backbone\* 时跑；若 A5 H3 合格但未被选，记 `capacity_caveat_unresolved`（报告不得只按参数量声称「公平」），不事后补跑。
- **A0 sanity band**：`V542-A0-sanity-band` 为 T1/top2 硬前置（T0 A0×3 formal + band pass 先于任何 T1 formal）；breach 时严格阻断 T1 并审计 parity 证书/anchor/R3 映射/sampler/evaluator/code/data/initialization；若发现代码/数据/初始化缺陷 → 修复后 bump `source_tree_fingerprint` 并重跑 A0×3（旧 run 记 `invalid_run`）；band pass 后才可继续；**不得签 sanity exception 带 breach 继续**。
- **模板→实例化**：五个 JSON 为模板（含 `null` 占位与 `_template_note`）；正式实例落到 `outputs/pesn/v542_backbone_50k/plan/`，由后续 runner/plan 步骤生成，不在 WP0 范围内；**`a0_reuse_decision.json` 实例是 T1 前置**（`decision_record_instance_required=true`）。
