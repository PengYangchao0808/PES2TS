## 决策

1. 动作版本 `dual_ts_unbounded_displacement_v1`：主线直接回归 Å 位移，无 `0.1·tanh` 上限、无 inverse-tanh/log-Jacobian；旧头仅在 D0/D1 对照。取消头内上限不删除独立动作合法性检查。
2. H1 残差形式 `a_hat=a_phys+f_θ(X,g,G,H)`：a_phys 冻结不参与梯度，同时记录纯先验/残差/合成三套指标；H0/H1 输入一致（都含 g），差异只有 skip。
3. H2 辅助损失 `L=L_xyz+λ_dir L_dir+λ_mag L_mag`：L_dir 限 `‖a*‖≥0.01Å` 原子（1−cos，分母显式），L_mag 同集合 Huber(log 幅度比) δ=1；λ 由 fit45_train 32-batch 梯度范数中位数一次性校准（0.3/0.1 目标比）后冻结；不沿用旧 NLL 的 559.37；不加置信门/active BCE。
4. E1 特征 `pesn_dual_ts_features_v4`（边 4→7：三个梯度-方向内积，零范数 mask）；E2 关键对条件只来自部署可得的 changed_flag 白名单（独立 pair encoder + 节点广播 + FiLM）；V1 `dual_egnn_painn_v1` 16 向量通道（PaiNN 风格标量/向量耦合，无单叉积、空间轴无独立 LayerNorm）；V2 接触边只增不删（平滑 envelope 仅作用新增分支，确定性 16 近邻截断）。宽度 64/96/128 显式传参（light=False），融合宽度固定。
5. 训练协议 `campaign_v1`：AdamW 3e-4/wd 1e-5、warmup 5%、余弦至 1e-5、clip 1.0、batch 64、EMA 0.999（raw+EMA 同存）；检查点 u5000/u10000/u20000 独立路径；dev@5k/10k/20k；raw-vs-EMA 读取规则首夜一次冻结；完整断点恢复；非有限即停臂。D0/D1 用等价重建的 `legacy_v41` preset（Adam 1e-3），不改旧文件。
6. 评测三口径 legacy_full/common_unchanged/native_full 与 §9.1/§9.2 晋级/40k 门机械化实现；交集 hash 在看预测前冻结；新任务四门明示为新协议，不重写历史 G5。
7. 驱动器产物与预算删失、裁剪顺序按合同 §8；不能在看到 monitor 后延长训练。

## 证据边界

- 新 preset/E1/E2/V1/V2 是拟议起始值与预算内设计，非文献证明最优；PaiNN 参考实现不冒称完整复现。
- 头内无界不改变独立合法性检查语义；执行侧信任域另立方案。
- 内部 dev 晋级阈值是工程筛选规则，非显著性界限。
