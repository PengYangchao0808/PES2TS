# ADR-0027：V5.1 参考架 fallback 与双分母评估

> 状态：Proposed（研究门；不实现新 fallback）
> 日期：2026-10-20
> 层级：G3.P.0（数据/gauge）、G3.P.1（特征/标签）、G3.P.2（训练/评估）
> 取代关系：不取代 ADR-0026；落实 V5.1 方案 §1.3 的 ADR-0027 议题
> 上游依赖：[ADR-0026](ADR-0026-V5冲刺key-atom位移合同与OOF语义.md)、[V5.1a-R1 最终报告](../../../outputs/pesn/v5_1_r1/final_report.md)、[gauge 分析](../../../outputs/pesn/v5_1/diagnostics/gauge_analysis.json)
> 下游消费者：V5.1-R2 S1 数据质量门、V5.2 Key-Atom 合同、V6/V7 执行器

## 1. 背景

V5 的 d0=0.05 口径下，`gauge_unresolved` 为 **480/5568 = 8.6%**（8 个 branch-shard，6 个反应，两族占 720 行）。这些分支无法用冻结的 1–2 跳刚性参考块构造唯一参考架。

R1 已完成的 D4 可行性分析：

- 8/8 unresolved branch 都存在二跳候选；
- 但 **0/8** 能通过现有 scatter gate（λ2/λ1 共线）；
- 主惯性轴 fallback 被 ADR-0026 §2.2 明确禁止；
- 因此“纯二跳 fallback 在不放宽 gate 的前提下救不了任何 branch”。

## 2. 决策

1. **V5.1-R2 不实现任何新 fallback**；主分母维持原始 eligible 5,088 样本 / 49 簇。
2. 8.6% unresolved 只作为 S1 数据质量门的研究项；不得为了扩大分母而放宽 scatter gate。
3. 任何新 fallback 必须同时满足：
   - 新 ADR-0027 修订/替代；
   - G5.1 fixture 覆盖；
   - 双分母报告：原始 eligible 为**主分母**，gauge-resolved 扩展为**次分母**；
   - 次分母不得替代主分母结论；
   - 逐 branch 记录 fallback tier、参考原子集、散布特征值、失败原因。
4. 二跳 fallback 不再重复试验；若要继续，必须改变参考块构造或 gate 定义，而不是重复同一候选池。
5. 在 S1 门关闭前，V5.2 不得把 gauge-resolved 扩展样本混入主训练/主评估；可作为单独诊断切片。

## 3. 备选方案

| 方案 | 结论 | 理由 |
|---|---|---|
| 主惯性轴 fallback | 拒绝 | ADR-0026 §2.2 禁止；破坏参考架语义 |
| 纯二跳 fallback | 已证不可行 | 0/8 过 gate |
| 放宽 scatter gate | 拒绝 | 会把不可辨识样本伪装成可辨识 |
| 新参考块构造 + 双分母 | 唯一允许的研究方向 | 需新 ADR + fixture + 双分母 |

## 4. 后果

- V5.1-R2 的 R2 训练/评估分母不变；不得用 fallback 样本“补”指标。
- V5.2 新合同可以重新定义 K/参考架，但必须显式版本化；旧 V5.1 分母保留为历史。
- S1 报告必须列出 480 行 unresolved 的 branch/fold/family 分布与处置。
- 若 S1 判定新 fallback 不可行，V5.2 继续使用原始分母，并在模型卡中登记 8.6% 覆盖缺口。
