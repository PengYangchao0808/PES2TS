## 背景（Context）

G2-AB1 批次（WP-1…WP-7）在修复 strict 运行暴露的四个 P0/P1 阻塞（缓存身份、分支漂移、起点异常、验证未接通）时，产出/扩展了若干**版本化接口**。宪法 P1 要求：接口只以新版本变更、只固定**存在性与校验要求**（不冻结字段）、并登记 §9.6 + 台账。本 ADR 是该登记的决策记录；字段演进不要求新 ADR，语义破坏性变更要求。

## 决策（Decision）

以下接口按"存在性 + 校验"登记（实现落点以代码为准，均为离线 V0 已验证）：

1. **`pes2ts_execution_identity_v1`（评估身份命名空间；WP-1）**
   `evaluation_id := trial-<NNNN>/eval-<content16>`；`content = digest(canonical(geometry, constraints, targets, method_context, operation))`。receipt 目录按该身份内容寻址；同键不同 binding → typed `IDENTITY_CONFLICT`（含双 `request_sha256`），冲突拒绝永不删除或重算覆盖。`energy_gradient` 请求的 canonical JSON 序列化规则冻结于 `orca_gradient_request.canonical_request_json`（改任何一条即需新 schema 版本）。
2. **`endpoint_method_evidence_v1`（拟定；WP-3，已入宪法 §9.6）**
   存在性字段：`source_geometry_hash` / `prepared_geometry_hash` / `method_context_hash` / `stationarity_status` / `minimum_status`（未算曲率恒 `unknown`，不得 verified）/ `identity_status` / `gradient_ref` / `frequency_ref`（null+reason）/ `acp_receipt_ref` / `parent`。失败分型 `ORIGIN_CONNECTION_LOST / ORIGIN_OVERLAP_INPUT / ORIGIN_SCF_BRANCH / ORIGIN_BUDGET_EXHAUSTED`（+ `ORIGIN_PREPARED_COLLISION`）；重叠输入为终端无效起点。修补（overlap/torsion）只产出**新输入身份**（新 hash + provenance），永不覆盖端点。
3. **`pes2ts_gradient_seed_proposals_v1`（候选唯一来源；WP-4）**
   `rank_continuation_candidates` 为唯一候选来源；partial prefix 默认提名。正式链消费经 `continuation_path_bundle`（partial → usable 投影；`completed_interval` 为**报告字段**，路径完整性与候选验证分列）+ `seed_proposal_from_gradient_ranking`（几何 hash 必须逐字匹配 PathBundle 帧；无 `ranking.json` 兜底）。`ValidationResult` 增 `pes2ts.path_provenance.v1` 扩展：`completed_interval`（报告）、`preparation_layer_status = absent`（宪法 §8 诚实声明，落地前不得声称具备）。
4. **成本账本 / `label_state` / provenance / 分裂防火墙（WP-7；`pes2ts_core/flywheel.py`）**
   - 成本（R5/§9.4）：每次 attempt 写 `N_energy/N_gradient/N_Hessian/N_OptTS_trials`；`cpu_seconds`（实测）与 `allocated_core_seconds`（分配）分列；缺失 `null + reason`，不得写 0；数值 Hessian 内部梯度只计一次；父子账本聚合去重。
   - 标签（§9.2）：七态 `verified_target / verified_non_target / optimizer_failed / validation_incomplete / execution_failed / unattempted / censored_budget`；`unattempted` ≠ 失败；verified 标签必须携带 OptTS/frequency/IRC 证据引用（R2）。
   - 溯源（§9.3）：四层 `geometry / mapping / cohort_selection / development_exposure`；字段隔离 ≠ 来源独立，mapping 层必须声明 `truth_assisted_p1`。
   - 防火墙（R6/§11.2）：反应族整族同 split；逆反应/邻帧/映射副本/对称副本不跨划分；holdout 在看真值前冻结（`pes2ts_holdout_freeze_v1`）；禁止对 holdout 调参（typed 拒绝）。
5. **分支控制证据字段（WP-2；`state s_t`/`action a_t` 存在性登记，不冻结字段）**
   `BranchPolicy`（全部 TODO: calibrate）；接受帧记 `branch_reference_frame_id`、`convergence_mode ∈ {physical, biased_only}`、`landing_identity_scope/status`；`restraint_energy_added` 恒 false，数值锚定另记 `numeric_anchor_active`；`LOCALITY_*` 分型保持前缀兼容。

## 后果（Consequences）

- 上述接口的校验逻辑进入默认测试套件（`tests/test_execution_identity.py`、`test_branch_drift_fixture.py`、`test_origin_preparation.py`、`test_structure_identity.py`、`test_pesg_math_contracts.py`、`test_label_state_and_cost.py`、`test_split_firewall.py` 等）；放宽任何一条校验即测试失败。
- 不改变 R1–R6；不新增执行路径（测试替身已标注，不进生产）；Preparation Layer 缺口保持显式 `absent`。
- V2（真引擎重放）与 V3（科学评测）为 gated：通过前相关能力保持 `implemented`/`blocked`（宪法 §11.5）。
