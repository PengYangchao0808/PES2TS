# ADR-0019：IRC 20k 与 RL 2000 分阶段扩量

> 状态：**Proposed（详细规划已完成；接口实施/训练/真实计算未启动）**
> 层级：G3.P/G3.2/G4；G2.T/X 执行与评测；不新增工程阶段
> 取代关系：承接ADR-0018；局部取代其近期2–3轮小批的扩量节奏和预算，不改历史结论
> 上游依赖：[开发宪法](../../PES2TS_开发宪法_v1.md)、[ADR-0018](ADR-0018-RL纠错与动作支持研究计划.md)
> 下游消费者：[详细方案](../../plans/PES2TS_IRC20k与RL2000下一阶段详细方案_v1_20261008.md)、数据用途、支持registry、模型冻结与预算报告
> 当前版本：v1.0 @ 2026-10-08

## 1. 背景

用户提出IRC达到2万个、RL达到2000个，并要求下一阶段详细方案。现IRC为2000fit/250dev及259950帧；RL为258条旧转移/16episode。第一批模式纠错有效，但独立审核发现支持context混用、TD白名单绕过、训练/执行registry未绑定及审计缺源误通过。同反应registry不证明陌生反应可用；直接扩量不能替代修复和迁移证据。

## 2. 规划决策

1. 按独立canonical反应组计IRC20000fit与RL新2000主episode，帧、转移、重复采样/更新另报。运行失败计尝试，不替换为成功；未运行不计真实episode。
2. IRC采用2k→5k→10k→20k嵌套fit、固定dev和基线结构；RL累计50→200→500→1000→2000，权重/支持域在轮间冻结。
3. 先修四项审核缺陷、多episode后继与完整回放，再做真实配对；跨反应支持以新版本研究，不通过删除identity约束或放宽旧门来增加非零数。
4. IRC/RL共用全局组级用途与排除清单，sealed从两条训练线及校准中排除。旧教师暴露必须核验，Demo24只作开发回归。
5. 主采集500小时不是完整研究总预算；独立列开发、sealed、配对、冒烟及回归，主实验QC包络982小时15分/468360请求。训练/制备/严格验证/条件消融实测后另冻结并纳入总成本。
6. 20k/2k是数量目标；训练、能力、真实收益分别验收。跨反应支持无效或连续两档开发停滞时暂停RL扩量，IRC线可独立推进。

## 3. 接口、兼容与实施边界

沿ADR-0018拟定的快照、episode、配对、registry/bundle身份。在实现跨反应支持、惰性split读取和显式registry绑定时，正式版本、validator与宪法接口登记按既有审查完成；本次不发布新schema、不变更guard/受保护目录/默认预算。规划清单只有planning语义，不能被运行器当执行配置。

当前只登记规模与研究路径，不改R1–R6、正式阶段出口或默认方法，因此宪法内容v2.6保持；能力状态未升级。前版四份入口文档原字节及hash见[快照](../../archive/20261008_pre_scale20k_rl2k/README.md)。

## 4. 条件与不能声称的结论

库存候选不等于有效标签数量；IRC教师指标不等于控制收益；同反应支持不等于跨反应适用；全部fallback不证明Q有效；2000完整尝试不等于2000完整路径/严格TS。样本200只是独立评测预算起点，功效由开发方差和冻结效应门另计算，证据不足如实报告。
