## 背景

当前 continuation 调用 PES2TS 投影 BFGS，以 ACP OrcaGradient 返回的 ORCA/GFN2-xTB E/g 迭代坐标；driver 目标和分支锚定在 PES2TS 中执行。用户选择把完整几何优化交给 ORCA，让 PES2TS 只主动控制关键内坐标。

详细目标与实施建议唯一入口为[共同架构及迁移方案](../PES2TS_PES-C到PES-G架构与迁移方案_v1_20261004.md)。

## 拟议决策

1. 以 ACP→ORCA 原生约束优化作为拟议新主链的帧优化实现，先保持 GFN2-xTB 与旧关键目标。
2. PES2TS 拥有化学计划、ActionProposal、允许动作校验、帧接受、候选与目标身份；ACP 保持唯一生产 QC 执行责任。
3. PES-C 规则策略与 PES-G 学习策略共用动作/帧接口；学习器初期只决定关键坐标推进，不替代 QM 或改变验收器。
4. 旧数值优化器作为显式对照保留；没有自动静默回退。旧锚定/累计保护在新实现中的替代语义单独登记与消融。
5. 同一严格 preparation/OptTS/Freq/双向 IRC/端点身份链用于比较；实现与科学成功分别表述。

## 影响声明

- 涉及宪法 P1、P3、P4，§5–§6 和 §9.6 的计划/状态/动作/执行结果语义；正式合同以新版本登记。
- 维持 R1–R6；特别保持 ACP 唯一执行、真值隔离、全量成本与 reaction-family holdout。
- 本次仅写提案，不修改宪法规范、受保护配置、阶段或业务默认。正式落地时按宪法 §12 同步接口登记、规范引用与执行投影。
- 已有原生约束探测不等于 native continuation 已 smoke_passed。能力与迁移收益需要新证据。

## 备选与取舍

| 方案 | 取舍 |
|---|---|
| 保持自研投影 BFGS | 内循环可控，但持续维护优化、保护、预算及 QC 多次调用 |
| 复用 SCINE 等外部优化库 | 适合自定义逐迭代梯度/人工力；引入依赖与适配成本 |
| ORCA 原生约束优化（本提案） | 适合关键内坐标目标控制；分支累计保护转为独立验收/明确辅助约束 |

本提案借鉴 NT2 的原子对/事件表示，不称为 NT2 严格复现；原生优化器与 Native-GFN2-xTB 方法切换分开。

## 证据与转为正式实施的条件

依次取得 ACP 请求/结果合同与 fixture、真实约束优化和失败冒烟、四例/24 例固定协议 native/legacy 对照、完整成本/恢复证据及严格验证链结果。默认切换判据在实验前冻结；结果不足时保留旧默认。

不承诺轨迹相同、全局收敛、消除分岔、固定加速比或目标 TS 必然存在。写入设计不改变能力状态。

## 回滚

新 backend/policy 使用独立 manifest、schema/operation 身份与输出根。显式选择 legacy 可复跑旧基线；禁止覆盖旧输出或把 native 结果重标为 legacy。正式退役旧实现以持续基线证据与历史读取/回放能力为前提。
