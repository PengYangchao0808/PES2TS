# ADR-0014：预测器产品归属与 G3 代码范围

> 状态：Accepted（用户授权按产品细分开发范围；设计生效，代码/包/权限未实施）

> 取代关系：部分取代 ADR-0013 将教师构建放在 evaluation/pesn_irc 的目录安排；细化 ADR-0011 三模块视图中的预测器所有权，保留阶段/标签/模型路线

## 1. 背景与范围声明

用户要求本期代码属于预测器，并要求所有代码按产品内容详细划分。原方案覆盖算法、标签、训练和验收，但只给目录级归属；教师构建/独立评测在 evaluation，训练在 pesn/training，产品代码范围、接口、依赖和交付未完整登记。

源码定位确认：pesn 目录尚不存在；ranking 为 PathBundle 上的规则排序；evaluation 仅包标记；G1 图/映射、G0 审计访问器和分裂、G2 坐标/控制/ACP 接缝已有实现。现有根 requirements 未声明 ML 框架，不能把训练依赖强行加载到 Classic 入口。

本变更触及宪法 §2.3/2.5、产品布局/依赖、§9.6 新研究预测合同（P1/R1/R3/R6）。不迁移已有目录、不修改 G2 配方或数据含义，不改 G3.P 与 G2 并行关系；模型目标仍 pesn-irc-v0.1.0。

## 2. 决策

1. **预测器产品唯一代码根为 `pes2ts_core/pesn/`**。本期新增业务代码都在这里，包括模型、特征、推理，以及 `offline/` 内的来源适配/标签/分裂/训练/模型评测/发布。取消尚未实施的 `evaluation/pesn_irc/` 和顶层 `pesn/training/` 计划；无已存在代码需要迁移。
2. 预测器是一项独立代码所有权，控制器通过 API 消费估计。运行时三模块视图仍可将“调用预测器”作为控制器功能；代码审查细分拓扑、预测器、控制器、ACP 接缝四项责任，UI/验证证据/公共工具另有所属，不混进预测器。
3. `pesn` 在线可达集限定为 API、研究输入/输出合同、features/models/inference/bundle。它不依赖 offline、G0/G1 构建器、generation/ranking/evaluation、ACP/QC 或作业调度。离线可调用在线特征/模型，在线不能反向调用；包初始化不导入离线或可选训练框架。
4. 新 `pesn/offline/data/truth_source.py` 是本期唯一拟允许调用现有 G0 truth_reader 的桥；保留 allow_truth、审计和先冻结分裂/作用域。未来守卫仅窄登记该文件，不给整个 pesn/offline 或 pesn 包真值例外；本次未扩权限。loader/train/evaluation 不直接打开原始真值 HDF5。
5. G1 图、G2 坐标合同和 G0 父清单在预测器离线适配器处读取/转换，线上只接收普通版本化数据对象。复用当前 authority，不复制反应编辑/角色/合法性规则，也不让学习模型定义新的 driver 或绕过 Shield。
6. 开发文件、接口和测试按产品矩阵登记，当前阶段只实现预测器工作包；G2 控制/执行、规则 ranker、UI、通用验证器的改造分别留在自己的批次。支持文件限 tests/pesn、config/pesn、独立依赖清单及必要的单点守卫登记；不是把业务逻辑放到这些目录。
7. G3-P1 方案升 v1.1，教师合同草案升 v1.1；纯运行包目标 pesn-core、离线工具目标 pesn-training，均为同一预测器产品的不同安装/分发范围，不增加用户产品或阶段。包/依赖锁/CLI 尚未创建，模型和数据版本不因本次代码范围细化 bump。

## 3. 接口与验收

研究输入以 `pesn_feature_spec_v1` 为基准，补登记输出草案 `pesn_teacher_prediction_v1`；由结构、任务图、坐标描述和可用性得到研究进度/路径分数/方向/协同及逐头资格。输出不包含已执行动作或严格成功结论。

文件级方案登记 `load_bundle / predict_point / predict_batch / capabilities` 纯运行接口，以及隔离构建/训练/评测/导出入口。实际 schema/签名/CLI/fixture 在实现批次验收，不提供尚不存在的可执行命令。

产品边界门包含新文件改动清单、静态依赖与可达性检查、包导入无训练副作用、真值窄桥/未来特征检查、ML 缺依赖诚实拒绝、导出无教师数据、旧 Classic 回归。模型科研门保持 G3-P1 原定义，文档核验不升级训练能力。

## 4. 同步、证据与回退

设计依据为当前源文件/公共函数定位及用户授权；更新宪法 v2.3、AGENT v3.3、阶段 v4.2、PES-N 计划 v2.3、发布 v3.3、流程 v2.2、产品设计 v1.1、G3-P1/合同 v1.1、索引/台账 v2.4。

改版前13份文档及376份业务/测试/配置/脚本/清单哈希见[快照](../../archive/20261007_pre_predictor_scope/README.md)。本轮只改文档，不创建空模型实现、不安装依赖、不修改 truth_guard、不启动训练/QC，也不撤销工作区其他未提交工作。

若后续发现某个复用函数带入不可接受依赖，保持该调用在离线适配器或停用该输入资格，不向 runtime 扩大依赖。真实跨产品能力缺口登记对应产品任务，不用当前预测器批次重写其他产品；旧默认和数据链按原证据继续。
