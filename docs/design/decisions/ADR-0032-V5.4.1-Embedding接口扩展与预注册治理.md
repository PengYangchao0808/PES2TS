## 1. 背景

1. **方案已冻结、代码未落地**：V5.4.1 方案 v1.0（含 v1.1/v1.1.1 增量）定义了单臂双功能头 50K Embedding 基准的 WP0–WP7，但仓库中没有 V5.4.1 的 config、schema validator、registry 条目或 ADR；方案 §3 要求 WP0 先完成这些治理产物。
2. **用户已授权 implementation + formal training**：2026-10-27 用户明确要求「完成5.4.1的代码生成和训练工作」。该指令构成按既有方案开展实现与正式训练的授权，并使方案 §11.2 的「建议阈值」就地签认为 **frozen** 值（签认记录见 `config/campaigns/v541_templates/preregistration_signoff.template.json`）。
3. **授权不等于免门**：方案 §17 的启动前签认清单仍然有效——实际 T1 启动仍须 H0（legality）、H1（resource）、单路 smoke、预算签认、formal SHA 冻结全部通过；`confirm` / `sealed` / 新增 QC 调用恒为 false/0；单路、无 swap。
4. **旧账本不动**：V5.3-MP 的 ledger 状态机（`planned/running/done/failed/killed/skipped/interrupted`）与旧 V5.4 from-any-point 条目保持原样；V5.4.1 的 run 结果使用方案 §7.4 的独立 outcome 词表，两者不得混写。
5. **G–V registry 是唯一机器可读源**：新增战役必须登记进 `config/registry/g_v_map.yaml` 并重渲染映射文档，避免文档表与注册表漂移（ADR-0025 纪律）。

## 2. 决策

### 2.1 任务语义不变，只扩展 Embedding 接口

- MoveProcessContract v1 的 MOVE+PROCESS 任务语义、输入合法性、No-Move 化学语义**完全不变**；V5.4.1 只在 `h_legacy` 之上增加残差分支 `h = h_legacy + α·W·f_φ(h_legacy, V_legal)`（`α₀=0`，`W` 非零初始化投影到 48）。
- 输出给固定 core 的 `edge_scalar [E,22]` 始终是 legacy 原通道及顺序；**本阶段 core 不消费 `node_vector`，不引入 EdgeAdapter 式边/向量消费**；E6 只允许声明 scalar-projected 诊断，不进核心矩阵。
- `objective=unified_move_process` 是唯一外部任务名；过渡实现可在 runner 内部映射旧 `arm="C"`，但**新配置、日志、报表与 run_id 不暴露三臂矩阵**。run_id 统一 `V541_*` 命名空间（D05），与历史 30h 计划同名 E0–E6 隔离。

### 2.2 独立 schema 与 typed rejection

新增独立 schema `pes2ts_v541_campaign_v1`（不复用 `pes2ts_v53mp_campaign_v1`）与独立 validator `scripts/agent_ops/v541_config_schema.py`。以下情形一律 typed rejection，runner 拒绝启动：

| code | 拒绝条件 |
|---|---|
| `V541_SCHEMA` / `V541_MISSING_FIELD` | schema id / campaign_id 不符，或必填字段缺失/None |
| `V541_OBJECTIVE` / `V541_ARM_MATRIX` | objective 非 `unified_move_process`，或重新暴露三臂矩阵字段 |
| `V541_EMBEDDING_UNKNOWN` | embedding id 超出冻结 E0–E6 注册表、family/in_main_matrix 漂移、E6 被排进 run matrix、或 run 缺 embedding 身份（`null`） |
| `V541_FORWARD_KEY` | forward key 不在 `FORWARD_VIEW_KEYS_V3` 白名单（含 forbidden input class） |
| `V541_EDGE_ADAPTER` / `V541_NODE_VECTOR` | 声明 EdgeAdapter 或 node_vector 消费，或 edge 非 legacy 22 通道 |
| `V541_CONFIRM` | `confirm_authorized` / `sealed_authorized` 非 false，或 `new_qc_calls ≠ 0` |
| `V541_RESOURCE` | 非单路、`swap_max ≠ 0` |
| `V541_THRESHOLD_NULL` | `--formal` 下任一 §11.2 阈值为 null、signoff 非 frozen、或 signoff 与 config 阈值不镜像 |
| `V541_GV_MISMATCH` | `gv` 块与 `config/registry/g_v_map.yaml` 不一致 |
| `V541_RUN_MATRIX` | run_id 非 `V541_` 前缀、含 `TOP2` 占位、class/seed 越界、diagnostic 被标 winner-eligible、T3 预注册集不等于 E1–E5×{29,43} 或激活/计数字段违反 §9.1、outcome 词表漂移、旧 ledger 状态机被标记为已修改 |

阈值未签认时保持 `null` 并**阻断 T1**（prereg 模式报告 `t1_blocked`），runner 不得填默认值（§3.3）。

### 2.3 阈值签认为 frozen（2026-10-27）

方案 §11.2 建议值按原值签认，写入 config `thresholds` + `thresholds.signoff`（status `frozen`，signed_by `user_directive_20261027`）并镜像进 signoff 模板：`sign_drop_abs_max=0.01`、`dead_fraction_increase_abs_max=0.01`、`fixed_coverage_direction_regression_rel_max_pct=2.0`、`other_endpoint_auprc_drop_abs_max=0.01`、`other_q_corr_drop_abs_max=0.02`、`gpu_parity_atol=1e-6`、`gpu_parity_rtol=1e-5`、`max_core_time_ratio=2.0`（hard_ratio 成本接受规则）、`final_bootstrap_draws=10000`、`rollout_large_subset_curves=96`；H2 2% guard、H3 `+0.02 AUPRC / +0.03 q corr` 与 dev 否决规则、T4 对照策略、rollout 名单生成规则同单一并签认。签认后不得按 seed17/dev 结果修改；改值须重走签认并同步 config/runplan/budget SHA。

### 2.4 运行矩阵三类分离 + 授权边界

- runplan 区分 **nominal**（T1 E1–E4 seed17）、**conditional**（T0-R E0×3、T2 E5、T3 预注册候选集）、**diagnostic**（T4 容量/深度对照）；diagnostic 永不计入主赢家数（§9.1）。
- **T3 预注册（v1.1 修正）**：T3 不使用含混的 `TOP2` 占位 run，而是**预注册全部可能被初筛选中的候选** E1–E5 × seeds {29,43} = 10 个稳定 `V541_E#_S##` 条件 run，`condition=activated_only_by_inner_val_top2`、`winner_eligible=true`、`new_training_if_activated=1`。仅 inner-val top-2 冻结后激活，**实际激活满额 4 个**（2 候选 × 2 seed）；未激活记 `gate_skipped` 且贡献 0 次新训练；`N_core` 按 §9.1 公式计数，**不按 listed runs 求和**。E5 的 T3 行必须在选择门之上**叠加** `parent_gate`（E1/E4 父门 + 预算），两门皆过才激活；E1–E4 行禁止携带 `parent_gate`。
- 授权位：`implementation_authorized=true`、`formal_training_authorized=true`（用户 2026-10-27 指令），`t1_start_requires=[H0, H1, smoke, budget, runplan_pin]`；`confirm_authorized=false`、`sealed_authorized=false`、`new_qc_calls=0`、`single_lane=true`、`swap_allowed=false`。
- run outcome 使用 §7.4 六词表（`done/invalid_run/scientific_failure/resource_failure/budget_censored/gate_skipped`），与旧 ledger 状态机**分开记录、互不改写**。

## 4. 风险与未决

> （2026-10-29 注：本节为 2026-10-27 签认时点的风险清单，保留原文；逐项执行裁决见 §6.2。）

- **E0 复用状态仍为 `unknown`**：loader-v2 50K 训练路径位级证书 SKIP，WP5-CERT 补证或 E0×3 重训分支未决；`e0_reuse_decision.json` 未生成前不得按复用启动 T1。
- **采样分层声明与实现差异（已核实事实，待 WP5 裁决）**：代码核查确认旧 V53MP 训练器的 `_curve_batch_positions`（`pes2ts_core/pesn/offline/training/key_atom_v53mp_train_v3.py:883-926`，及 v52 同源实现 `key_atom_v52_train_v3.py:424`）只按 `(curve_id, direction)` 池做 8×4 曲线均衡 `rng.choice`，**不存在** `start/pre_TS/post_TS/endpoint` 四分层实现；而 `config/campaigns/pes2ts_v53mp_{20261021,50k_20261026}.yaml` 与本阶段冻结 config 均按方案 §7.2 **声明** `strata: [start, pre_TS, post_TS, endpoint]`。不得静默把旧采样当作与声明等价：V541 runner 必须实现或以证书证明配置所声明的共同 sampler；若 WP5 审计确认二者不成立（声明分层未实现或实现不一致），触发 §8.1「sampler/RNG 等价失败 → 重训 E0×3」分支。本裁决不改 config 的 `strata` 字段、不改方案文件、不改训练剂量。
- **pair evaluator 未修**：WP1 未完成前，绝对 sign/方向结论与 R3 H2 参照阻断。
- **预算未签认**：`budget.per_candidate_core_time=null` → validator 持续报告 T1 config 未就绪，须 WP5 W0/W1 分项 profiling 后回填并重哈希。
- **T3 预注册集 ≠ 激活集**：run matrix 列出 10 个 T3 条件 run 仅用于预注册可能的初筛结果；实际训练次数由 `N_core` 公式与激活决定（满额 4），账本/报告不得把 listed runs 求和当作训练次数。
- **T4 对照为 E0-MLP + E0-deeper**（方案 §9.4 建议优先 MLP 替代 E0-wide）；实际配置在 T4 前、任何 candidate dev 访问前 pin。
- **模板→实例化**：三个 JSON 为模板（含 `null` 占位与 `_template_note`）；正式实例落到 `outputs/pesn/v541_embed_50k/plan/`，由后续 runner/plan 步骤生成，不在 WP0 范围内。

### 6.2 §4 风险的执行裁决

- **E0 复用 → 重训**：loader 训练路径证书单次 `EVIDENCE_MISSING`（probe sid 不在 label cache，§8.1 一轮补证不重试）+ sampler/RNG 不等价（legacy curve+direction vs 冻结 config 的 start/pre_TS/post_TS/endpoint 分层）→ `e0_reuse_decision.json` 判 **retrain_e0_x3**；T0-R E0×3 已完成，历史 C×3 仅 auxiliary reference。§4 的采样分层风险就此闭合为预注册分支的实现，**未**静默等价。
- **T3 预注册 ≠ 激活集**：实际 T3 激活 0 次（无候选过 H2+成本门），报告未把 listed runs 当训练次数。
- **预算**：W0/W1 分项 profiling 后 E4 ratio 3.6455>2.0 → `gate_skipped`；该门按 §11.2 执行。
- **T4**：`no_new_embedding_gain` → `gate_skipped`；容量/深度混杂未闭合，E0 留任的归因声明相应收窄。
- **模板→实例化**：三个模板已在 `outputs/pesn/v541_embed_50k/plan/` 实例化并 SHA 冻结。

### 6.3 最终裁决

**E*=E0 留任**（无新 Embedding 通过 H2 硬门；E1–E3 `scientific_failure`、E4/E5/T3/T4 `gate_skipped`）。V5.4.1 registry 状态转 `executed`，`plan_revision: 2026-10-29.1`；旧 V5.4 条目不动。无生产 No-Move、无 verified TS、无部署资格声明；`joint-finetune-E*` 留给 V5.4.2 另立预注册。
