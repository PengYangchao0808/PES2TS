# ADR-0015：G2 稳定底座与轻量 RL 研究入口

> 状态：Accepted（用户授权简化近期路线；规划生效，策略/RL 能力待实现验收）

> 取代关系：部分调整 ADR-0010 的研究原型启动顺序；保留正式学习能力、科学出口、产品归属与历史证据

> 当前版本：v1 @ 2026-10-07

## 1. 背景及影响面

原生 xTB 扫描已提供 24 例真实动作响应，用户确认 G3 实施正在进行，要求保持简单快速，优先通过学习控制进一步优化 G2。继续把 IRC 驻定性、完整物理特征或全部正式 STOP 里程碑作为研究原型的前置，会扩大 G2 并重复 G3 工作。

本次调整 P5/§6.5 的研究启动条件、近期开发顺序和 §9.6 合同草案登记。R1–R6 原文与正式 G2/G3/G4 出口保持；当前 validated=0，不把运行闭环当科学成功或 RL 收益证据。

## 2. 决策

1. 固定 AB3 原生执行器作为研究环境与基线；G2 近期限真实缺陷、兼容、证据/成本和严格验证接缝。IRC 横向驻定性等复杂研究按收益后置。
2. G3-P1 沿原范围持续交付，不新建教师数据/编码器/训练器。其表示供后续小策略可选复用，未通过迁移不阻塞从零基线。
3. 在既有控制器提取单步策略接缝，共用 ACP/QC、状态接受、Shield、回退与费用；首版只选择有限步长/候选提交，不输出全原子位移或优化器参数。
4. G4 研究原型的接口、转移和代理奖励可与 G3-P1、人工 gate 并行；不等正式 1000 漏斗或 IRC 驻定性改造。真实试点需能力/身份/动作 mask/全费用/风险回退门，限 train 且单轮冻结。更新在轮次间离线完成。
5. 先规则/BC，再一个小型保守离散 Q；奖励区分候选效率代理和严格成功，数据不足不虚填动作价值。正式 p/C/Q 能力和默认切换继续走原阶段与基线门。
6. 登记 `pes2ts_control_action_v1`、`pes2ts_control_transition_v1`、`pes2ts_policy_reward_spec_v1` 草案，沿 Action/Transition、DecisionTrace、PESNModelBundle 既有族扩展；新变步长 recipe 与旧固定网格完整性分开报告。正式 payload/validator 后续实现，不改历史字段含义。

## 3. 证据、兼容与回退

依据为用户最新授权、当前原生代码/24 例产物和 G3 目录存在；未在本轮复跑 QC 或训练。单一路径、真值隔离、失败/删失、计费和旧 Classic 回归在接入批次验收；科学成功仍由严格验证给出。
