> 层级：G3.P / 工作流 R；取代关系：不取代 ADR-0021/0022 与历史冻结数据，只新增旁车数据版本

> 下游消费者：[实施合同 v1](../../contracts/PES2TS_V4.2-V4.7_实施合同与战役冻结_v1.md)、Lane A/D 实现、V4.2–V4.7 战役

## 决策

1. 新增数据版本 `pesn_dual_ts_features_native_v1`：按 gaps registry 的 `inserted_state_id`（fit 399 / monitor 以实数为准）剔除插入节点、跨插入重连原生转移，`action_delta=X_next−X` 沿用已配准坐标与 E/g 收据（不重新配准、不重算 QC）。逐态特征从 v3 npz 原样继承；s_g/s_delta_e 沿用 v3 冻结值（同一批几何与收据，逐态 g 不因重连改变；避免把缩放重拟合混入 D2↔D3 归因）。
2. 新增内部开发划分 `pesn_dual_ts_dev_split_v42_v1`：身份簇为单元（簇不跨 train/dev）、确定性规则与 hash 在首跑前冻结（合同 §3）；fit5_dev 只用于 V4.2–V4.6 配置筛选，不参与 V4.7 checkpoint 选择。
3. 新增物理先验 `pesn_dual_ts_physical_prior_v1`：`b_i=(g_i/m_i)/sqrt(Σ‖g_j‖²/m_j+eps_g²)`、`a_phys=Δs_fit·b_i`，Δs_fit 为 fit45_train 上与 L_xyz 同权重非负最小二乘；eps_g/tau_g/a_s 只由 fit 冻结（合同 §4）；V4.7 在完整 fit50 按同规则重估为 @fit50 变体。
4. E/g 来源硬门按证据登记：method=GFN2-xTB（ORCA EnGrad 包装）、basis=""（xTB 无基组，显式语义非缺字段）、charge=0、multiplicity=1、dE/dX 约定（力=−g）、solvent=未记录；**不得默认与教师 DFT IRC 势能面同源**，弱先验只影响 H1 优先级（prior_not_supported 时 H2 以 H0 为父臂）。
5. 395 exceedances 与 399 inserted 的差额必须在 `native_reconnect_audit.json` 逐条解释，不可解释即 hard fail。

## 证据边界（不能声称什么）

- 原生重连不改变任何历史冻结件；旧细分数据与 v4.1 run 收据保持原身份。
- xTB 梯度先验的放行只控制 H1 是否入夜，不证明物理先验普适，也不证明数据无错。
- 内部 dev 仅五组，任何筛选结论不构成显著性或外部门通过。

## 后果

数据侧新增三个冻结产物（native_features、dev_split、physical_prior_spec）+ 两份审计（reconnect、gradient_baseline）；Lane A/D 按合同 §2–§4、§7 实现。
