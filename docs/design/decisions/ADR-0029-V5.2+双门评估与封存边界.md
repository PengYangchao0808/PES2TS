# ADR-0029：V5.2+ 双门评估与封存边界

> 状态：Proposed（评估设计冻结；阈值待 V5.2 数据校准后预注册）
> 日期：2026-10-20
> 层级：G3.P.3（监督门）、G2.T/G4.1（物理搜索门）、G4.2（发布门不变）
> 取代关系：不取代 G5.2/G5.3/G5.4；新增独立门，旧门保留
> 上游依赖：[ADR-0026](ADR-0026-V5冲刺key-atom位移合同与OOF语义.md)、[ADR-0028](ADR-0028-关键原子几何策略合同与V5-V7任务拆分.md)、[V5–V7 v2.0](../../plans/PES2TS_V5-V7_三阶段研究与架构修订方案_v2.0_20261020.md)
> 下游消费者：V5.2–V5.4、V6.1–V6.3、V7.1–V7.3

## 1. 背景

V5.1a/R1 的旧门 G5.2/G5.3/G5.4 是为旧 key-atom 位移任务定义的。新合同增加了：

- 仅关键原子输出；
- Move/No-Move 的曲线停止位置语义；
- 多尺度 IRC 教师与路径一致性；
- V6 的 xTB 物理修正；
- V7 的真实执行/成本。

如果直接把旧门套到新任务，会出现两个问题：

1. 旧 RMSE/zero 0.824 被误当成新任务唯一门槛；
2. Stop、路径一致性、真实后继、验证 TS 成功率、计算成本没有正式门。

因此需要新增两套研究门，同时保留旧门作为历史/旧任务评估。

## 2. 决策

### 2.1 旧门保留

- **G5.1** fixture：继续作为所有新损失/新头/新 fallback 的前置。
- **G5.2/G5.3/G5.4**：保留为旧 key-atom 任务的冻结评估；不得覆盖、改名或事后放宽。
- 旧 V5 OOF 的 RMSE/zero 0.824、cos 0.780、α 0.6757 只作历史参照。
- 任何新任务结论不得用旧门分数直接替代；必须报告新门 + 旧门对照。

### 2.2 第一套：模型监督门（Supervision Gate）

适用于 V5.3–V5.4、V6.1–V6.2。

| 维度 | 指标 | 预注册要求 |
|---|---|---|
| Key Move | key-atom RMSE/zero、方向 cos | 相对匹配基线（zero/Classic/MLP/EGNN/PaiNN）有配对改善 |
| 键长变化 | 关键成断键 `Δd` 误差、sign | strong/dead 分桶报告；不得只报 pooled |
| Stop | precision、recall、PR-AUC、停止位置误差 | 预注册窗口；Mask 不计入硬二分类分子 |
| 路径一致性 | 单点场沿 IRC 的变化误差 | 与 T0/T1/T2 教师对照 |
| 泛化 | 新反应簇/族的配对改善 | cluster-level bootstrap，不以帧为独立单位 |
| 稳定性 | ≥2/3 seed、跨折方向一致 | 单折/单 seed 不得晋级 |

**通过规则（待 V5.2 校准后冻结）**：

- 至少 2/3 seed 在 ≥3/5 fold 上方向正向；
- cluster-level 95% bootstrap 下界 >0（或预注册的非劣界）；
- 关键 sign/dead-zone 不得相对基线退化超过预注册容差；
- Stop 的 PR-AUC/位置误差必须达到预注册工程阈值，不能只看 accuracy。

### 2.3 第二套：物理搜索门（Physical Search Gate）

适用于 V6.3、V7.1–V7.3。

| 维度 | 指标 | 预注册要求 |
|---|---|---|
| 真实后继 | 受限拉伸执行后几何有效率 | 与 Classic/简单扫描同预算对照 |
| 停止位置 | 提交 OptTS 的候选质量 | 停止位置误差 + 候选 TS 距离 |
| 验证 TS | verified TS 成功率 | 独立 OptTS/Freq/IRC 验证，不用模型自报 |
| 成本 | xTB/DFT 调用数、core-hours、失败成本 | 同成功率下的总成本；计入 V6 探测成本 |
| 稳健性 | 失败类型分布、超时/删失 | 不把失败尝试从分母抹掉 |
| 对照 | Classic、固定控制器、BC、RL | 同约束、同预算、同验证协议 |

**通过规则（待 V6.1/V7.1 校准后冻结）**：

- 同约束、同计算预算下，verified TS 成功率或总成本有预注册的实质改善；
- 不允许“成功率略高但成本高一个量级”；
- 不允许用未验证的“接近 TS”替代 verified TS；
- 所有失败/尝试/成本保留在分母。

### 2.4 封存边界

- Confirm/OOD/sealed 继续关闭；V5.1b 不启动。
- 新门不解除旧封存协议；任何解封必须独立审批 + hash 冻结 + 一次性开启。
- Fit150+ 仍需 S1–S3 全过；新架构不自动获得扩量资格。
- 封存数据的任何 peeking 都视为违规；开发/确认/封存的分工不变。

### 2.5 评估分母与统计单位

- 训练/评估的独立单位是**反应簇**，不是 IRC 帧；
- 主要报告 cluster-level 中位/配对 bootstrap；
- 帧级指标只作诊断，不用于晋级；
- 旧 V5.1a/R1 的分母保留；新任务另建分母，不混算；
- 任何分母变更必须预注册并双分母报告。

## 3. 备选方案

| 方案 | 结论 | 理由 |
|---|---|---|
| 直接用旧 G5.2/G5.3/G5.4 套新任务 | 拒绝 | 任务/标签/分母不同；Stop/成本无定义 |
| 只做单步指标，不做 rollout | 拒绝 | 无法证明几何导航可持续 |
| 只用模型自报“接近 TS” | 拒绝 | 必须独立 OptTS/Freq/IRC 验证 |
| 只报成功率，不报成本 | 拒绝 | 可能用大量 xTB 探测换成功率 |
| 旧门保留 + 新双门 | 采用 | 历史可比 + 新任务可归因 |

## 4. 后果

- V5.2 必须同时维护旧门（历史对照）和新门（新任务）。
- V5.3–V5.4 的报告需要新增 Stop/路径一致性/rollout 字段。
- V6/V7 的报告需要新增 xTB/DFT 成本、失败类型、verified TS 字段。
- 任何新门阈值在 V5.2 数据校准后预注册；本 ADR 不预先声称阈值已定。
- 旧 G5.2/G5.3/G5.4 的冻结结论不受影响；新门不能追认旧结果为通过。
