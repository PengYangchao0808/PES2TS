## 1. 触发与范围声明

用户要求先接通 RL 再扩数据，采用一个统一模型，并明确动作价值、MDP 与注意力；进一步要求把 AB4 的 ORCA/xTB 有限回退纳入同一轮 G2 改造。影响宪法 §6.5 的近期研究顺序、§9.6 接口登记及 G2 共享单步/费用语义，正式阶段出口和 R1–R6 原文保持。

## 2. 决策

1. 在现有反应规模上优先交付真实采集→离线更新→冻结新包→新运行；新增当前反应的动作响应是 RL 所需，数据集反应数扩量后置。IRC 邻帧只作隔离辅助标签。
2. 统一 PES-N 网络复用编码器，新增逐坐标有界残差头及动作条件化 Q_proxy 头；一个模型版本与 bundle，独立 MLP/从零初始化仅作对照。初始 Q 未训练时由明确行为策略采集，不能宣称学习决策已可用。
3. 采用有限预算、合法动作约束的 MDP 近似；执行上下文、恢复/pending target、预算与回退配额显式入状态。保留部分观测边界；注意力不证明 Markov性。坐标注意力可切换，首版汇总基线先接通。
4. 残差候选可独立改变 k 个距离 driver，由 G2 构造和选择合法动作；步长分类不成为前置。首轮有限候选集＋保守 Q，之后对真实支持的较优命令做受限模仿微调。STOP 候选提交和优化器回退均先沿冻结规则，模型不选择优化器。
5. G2 只提取一个公共单步/宏步恢复接缝，Classic、学习策略、原生与 AB4 回退共享接受/预算/质量/费用链。零残差保持原基准目标；残差实际 q 与名义 lambda 分开，不冒报网格覆盖。
6. 保留 AB4 三失败点/一正常点、每引擎每点60秒、正常点合格且救回至少2/3、4例路径对照、每逻辑目标一次/每例两次回退和原900秒/120请求等预算。学习目标用稳定 target ID 延续内部细分配额。四点工程资格不自动成为 RL train。
7. E_native 和 E_hybrid 分别冻结，RL 先在可用原生环境跑通；混合门未过救援不启用。比较策略时使用同环境；跨环境数据不无条件混合 Bellman 拟合。宏步含所有内部恢复费用和部分接受结果。
8. 网络权重在运行轮内冻结，更新在轮次间离线；研究 Q_proxy 不冒充正式 Q_MOVE/成功概率，正式默认仍走既有基线和严格物理门。

## 3. 接口存在性、兼容与所有权

新增草案：`pesn_control_input_v1`、`pesn_control_prediction_v1`、`pes2ts_control_action_v2`、`pes2ts_control_transition_v2`、`pes2ts_policy_reward_spec_v2`、`pesn_model_bundle_v2`、`pes2ts_native_scan_result_v3`/`trace_v3`。字段及成立条件见[实施方案§2–6](../../plans/PES2TS_统一残差决策与G2有限回退实施方案_v1_20261007.md#6-合同草案与代码所有权)。旧 TeacherPrediction、bundle v1、AB4 混合固定网格 v2 及历史产物不改义；正式 schema/validator 在实施时冻结。

控制预测/训练归 pesn runtime/offline；坐标authority和合法性、显式选择、宏步、恢复与费用归 G2；实际程序及公开 OrcaXtbConstrainedOpt 基元归 ACP。ACP 不在当前 workspace，不用 PES2TS 直启程序作为替代。没有迁移受保护目录或增宽真值/执行 allowlist。

## 4. 证据、验证和回退

证据来自用户本轮授权、当前编码器/教师包、G2 整段扫描/初猜源码及 AB4 冻结方案，不表示新业务能力已实现。本次保存文档快照、业务哈希并校验链接/版本/指针；真实四点、路径、RL采集、模型训练及系统收益待实施。统计/泛化和严格TS门分开。

规划同步宪法内容v2.6、AGENT v3.6、轻量计划v1.2、AB4 v1.1、未来计划v2.5、阶段v4.4、台账v2.7及索引。快照见[归档](../../archive/20261007_pre_unified_residual_rl/README.md)。无动作支持、ACP缺能力、方法不相容、救援未达门或预算不足时明确回退/停止；默认保持已验收基线。
