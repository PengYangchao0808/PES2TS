# ADR-0016：ORCA 驱动 xTB 硬约束优化试点

> 状态：Accepted（用户授权尝试并要求优化方案；设计生效，实现/真实能力待验收）
> 层级：G2 R/X；备选优化器与接口草案
> 取代关系：补充ADR-0012/0015；保留原生xTB基线、正式阶段出口和G3范围
> 上游依赖：[开发宪法](../../PES2TS_开发宪法_v1.md)、[ADR-0012](ADR-0012-Classic图论驱动与xTB原生约束扫描.md)、[ADR-0015](ADR-0015-G2稳定底座与轻量RL研究入口.md)
> 下游消费者：[G2-AB4方案](../../plans/PES2TS_G2_AB4_ORCA驱动xTB约束优化试点方案_20261007.md)、ACP公开工作流、扫描接缝/报告与文档治理
> 当前版本：v1 @ 2026-10-07

## 1. 依据与影响面

用户同意试验ORCA驱动xTB，并要求方案。AB3收据中7例45次几何未收敛、未检出SCC失败；ORCA外部xTB可结合硬内坐标约束，但稳定性收益尚无本仓实测。本次触及优化器/约束协议、请求/收据、缓存身份和混合路径字段，不改变ACP唯一后端、真值/标签和正式科学出口。

## 2. 决策

1. 增量归G2-AB4；原生xTB保留为基线/快速路径。首轮外部GFN2-xTB、气相、距离driver，ORCA原生xTB及其他能力不同时引入。
2. ACP薄公开工作流拟名OrcaXtbConstrainedOpt，复用既有ORCA后端、xTB单点和资源管理。PES2TS只提交/核验/选择，不调用底层QC或复制优化器；默认不启昂贵补救和Hessian计算。
3. 新请求/收据v1区分硬/软约束、实际有效方法、几何收敛、优化能量与裸单点物理能量，父几何/请求hash分开。混合结果/trace升v2，旧v1及报告不改义；新产物独立目录。
4. 先冻结3失败点+1正常点并做同初猜/预算对照；再接有限备选，每原target一次、每例最多两次、共享原总预算，仅几何不收敛触发。质量/身份拒绝及SCC失败不靠换优化器绕过。
5. 共用既有父帧、网格、细分、质量和费用循环；RL不增加选优化器动作。混合environment_id冻结并留存，不当作与旧环境相容的无条件转移。
6. 科学成功仍按OptTS/Freq/双向IRC/身份；能量峰/局部收敛/救回前缀不替代该链。硬约束与软约束是不同配方，结果不能全归因于ORCA优化器。

## 3. 登记、证据与回退

登记草案 `pes2ts_orca_xtb_constrained_opt_request_v1`、`pes2ts_orca_xtb_constrained_opt_evidence_v1`、混合`pes2ts_native_scan_result_v2`及trace v2；具体字段/validator/CLI在实施批次验收，不宣称当前已发布接口。

当前证据仅代码/收据核验、官方手册和冻结4点选择。方案未执行QC或训练，不修改ACP/PES2TS业务代码、模型、guard、依赖或默认。后续真实能力按implemented/fixture_passed/smoke_passed分层；方法/身份/成本门不满足即保留原生分支并typed停止。

同步宪法内容v2.5（仅登记接口/设计）、AGENTv3.5、轻量计划v1.1、索引和台账v2.6。改版前6份文档见[快照](../../archive/20261007_pre_orca_xtb_pilot/README.md)；R1–R6原文、阶段出口和正在实施的G3计划不改。
