# G1 v2：方向无关的成键锚点与双向扫描策略

> 2026-09-27。此文取代“总是从原始产物 P 逆向拉伸”的固定方向规则。数据集 R/P 是**参考反应方向**，不是扫描算法必须采用的方向。G1 先从两端选择更合适的**成键终点/键合锚点**，再预先编排“从锚点拉伸解离”和“向锚点拉近成键”两条候选；G2 仅执行、记录和按冻结判据切换。

“多成键锚点”与“少成键锚点”的定量比较及当前建议的混合选边规则见 [G1 v2：多成键与少成键方向对比](G1_v2_多成键与少成键方向对比.md)。本文件的 `max(F,B)` 规则保留为基线候选。

## 1. 化学前提及边界

对**同一电子态/电荷/环境、同一个基元反应通道**，R→P 与 P→R 描述同一势能面上的相反方向；目标一阶鞍点不因路径方向改名。微观可逆性不能推出“任意受限扫描从两端都会找到同一 TS”：松弛扫描的局部优化可能跳到不同构象或反应分支，路径也可能含中间体和多个鞍点。ORCA 手册明确提醒多坐标扫描结果依赖扫描方向和坐标顺序。[微观可逆性的原始分析](https://pubs.rsc.org/en/content/articlelanding/1966/tf/tf9666202754)、[IUPAC 定义](https://goldbook.iupac.org/terms/view/M03916)、[ORCA Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)。

因此算法可以**交换扫描方向**，但不能修改原始 R/P 的化学身份、数据划分、G1 v2 定向 L0 或参考 IRC 方向。扫描后输出要恢复并标明原始 R→P 顺序；方向无关 L0u 可供同族统计，不能替代原始方向标签。

## 2. 对每条反应定义两个方向的成键数

在原始 R→P 映射图上：

```text
F = |E_P \ E_R|       # 原始正向新形成的连接
B = |E_R \ E_P|       # 原始正向断裂、反向新形成的连接
O = 两侧均存在但键级变化的连接数，另行记录，不算 F/B

若 F > B：规范成键方向 R→P；成键终点/键合锚点 T=P；成键起点 S=R
若 B > F：规范成键方向 P→R；成键终点/键合锚点 T=R；成键起点 S=P
若 F = B：成键计数无法选边，进入平局判定；必要时两方向都规划
```

这里“键合锚点”只表示**相对于另一侧含更多新连接的端点**，并不按总键级、热力学稳定性或实验产率评判。`F-B` 是连接数净变化；键级变化 `O` 仍需作为拓扑质量目标。芳香区域的若干键级重排不能被误判为若干独立成键扫描坐标。

对每个已选 `T`，G1 至少编排两个方向不同但目标一致的**候选**：

1. **锚点解离扫描**：从 T 的真实成键几何出发，把 `E_T \ E_S` 中选定的 1–3 根锚点特征键逐渐**拉长**，其余坐标逐步松弛；这保留 RPH“从成键端向 TS 回退”的优势。
2. **向锚点成键扫描**：从 S 的合格组分装配出发，把相同特征键逐渐**拉近**至 T；用于检验解离扫描是否因构象、滞后或错误路径而失效。

两者共用 map 原子、关键键集合和目标拓扑，但需要各自的端点装配、起止值、计算预算和失败触发条件。若第一条已得到可信 TS 初猜，第二条可在试点外按冻结策略跳过；科学验证子集须双向运行以估计方向偏差。

## 3. 现有 G1 v2 数据给出的规模

静态口径：`g1_v2_summary.parquet`，`audit_status=clean`，共 183,460 条。最终 G2 人群仍以 `g2_scan_ready.json` 为准。

| 原始 R→P 的连接变化 | 反应数 | 规范成键终点 |
| --- | ---: | --- |
| `F > B` | 55,350 | P |
| `B > F` | 56,787 | R |
| `F = B` | 71,323 | 需平局策略，不能自动指定 P |
| **合计** | **183,460** | 每条都保留原始方向及规范扫描方向 |

`max(F,B)≤3` 有 **178,085 条（97.07%）**，在“坐标数量”上可考虑 ORCA 最多三个同时扫描坐标；余下 5,375 条要选少数代表性键或用其他路径方法。这个比例不是可执行率：同一方向的多个形成键可能几何冲突，反应中心取向、独立片段装配和键级重排仍需核验。

例如之前固定 P 侧规则遇到的 5,761 条 `F=0` 记录，全部有 `B>0`；按新规范方向，`T=R`，可从**原始反应物 R**拉长其将断裂的键。这些记录无需被当作“无成键策略”的例外，而是扫描方向原先选错了。

## 4. `F=B` 的平局规则

71,323 条平局反应中，35,912 条带 H 转移。相同成键数不表示两个端点作为扫描锚点等价。G1 的确定性优先级建议为：

1. **端点几何可用性**：完整映射、合理电荷/多重度、有限坐标、无显著碰撞；不合格侧不能作为锚点。
2. **组分装配负担**：优先选反应中心位于一个已成键组分、且不需人为拼接多个独立 XYZ 的侧；用 `n_reactant_components` / `n_product_components` 及中心跨组分关系记录原因。组分数少只是代理指标，不是决定性化学事实。
3. **单主键可表达性**：尤其对唯一 A–H→B–H 转移，分别构造“从 A–H 拉伸”和“从 B–H 拉伸”的单键候选；若两侧几何均好，不靠原始 R/P 名称拍板。
4. **剩余平局**：规划**双向扫描**，用固定顺序排作业以保证可重复，记录 `tie_bidirectional`，不宣称有唯一物理优先侧。

平局评分仅用端点几何、映射和编辑图；**不能**用 DFT TS/IRC 距离、能量峰位置或测试集结果决定锚点。若某侧有独立碎片，还必须输出相对摆放的有限候选；单靠“组分数更少”并不能保证该侧路径正确。

## 5. 按规范成键数规划坐标

| `k = max(F,B)` | G1 第一层计划 | 特殊处理 |
| --- | --- | --- |
| 1 | 从 T 拉长一根锚点新键，或从 S 拉近同一键 | H 转移先只扫受体侧 H 键，观察另一 H 键是否自发形成 |
| 2 | 两根锚点新键共用一个进度参数，同速为首候选 | RPH 式双成键；失败时才尝试有限早/晚时间表或单主键 |
| 3 | 三根锚点新键同步；先检查几何独立性和约束可行性 | 若一根是冗余的 H/芳香联动事件，可降到 1–2 根 |
| >3 | 编辑耦合图选 ≤3 根代表性主键；其余列为每帧验证目标 | 若无法证明降维方案，使用 xTB PATH/NEB，或经版本测试的 xTB concerted 模式 |

化学标签仍影响约束选择：H₂ 需要观察 H–H 与原 H–供体键；芳香区域不逐键设约束；取代可能先拉长锚点新键，观察另一侧旧键是否自发重建；环反应需要检查片段朝向和环拓扑。`k` 是规划入口，不是所有新键必需同时硬约束的命令。

## 6. G1 计划字段与执行语义

`scan_plan_v1` 在原有字段之外至少包含：

```text
source_reaction_direction = R_to_P                  # 永不修改原始标签
forward_formed_count = F
reverse_formed_count = B
canonical_formation_direction = R_to_P | P_to_R | tie_bidirectional
formation_origin_side = R | P | both
bonded_anchor_side = P | R | both
anchor_selection_reason = more_new_bonds | endpoint_geometry | fewer_assembly_steps | tie_bidirectional
anchor_new_bonds = map-space unordered pairs, original edit kind, priority
scan_candidates = [anchor_stretch, approach_form, optional schedule variants, PATH/NEB]
report_direction = original_R_to_P
```

每个候选仍需冻结 `map→ORCA 0 基下标`、装配方案、约束点列、正/逆方向、允许的最大拉伸/拉近范围、步数、失败触发码、资源预算和输入文件 SHA256。G2 输出原始运行帧序列；标准化层将反向帧重排到原始 R→P，保留 `raw_scan_direction`，不把扫描起点能量误当成数据集反应物能量。对于可能相同反应的 R/P 倒置记录，沿用既有冻结 split/近重复分组，避免方向变换造成训练测试泄漏。

## 7. 如何证明方向重选有益

在相同反应、装配质量、计算级别和总核时下，配对比较：

- 原固定 P 侧逆向拉伸；
- 按 `max(F,B)` 选择锚点的逆向拉伸；
- 同一锚点键集的向前拉近；
- 对平局及科学验证子集两方向都运行。

分层报告 `F>B`、`B>F`、`F=B`，再切 H 转移、成键数 1/2/3/>3、R/P 多组分和 L0u。指标分开为 `barrier_bracketed`、目标编辑进展、R/P 端点匹配、有用 TS 初猜、严格 OptTS+频率+双向 IRC 成功率，以及每个正确 TS 的全部核时。若锚点拉伸只给出高能帧但未抵达另一端，可计入初猜候选，不计入完整目标路径。优化和选边仅用训练/验证集，测试集使用冻结策略。

## 8. 决策

**把 R/P 当作可交换的扫描端点，把“哪侧在选定规范方向形成更多新连接”作为第一选边规则；从该键合侧拉伸是首选，向该侧拉近是方向互证和有限回退。** 71,323 条连接数平局必须使用几何/装配规则或双向计划。只在相同基元通道上，正反计算才有应指向同一目标 TS 的物理期望；受限松弛扫描是否做到这一点，需由实际路径与双向 IRC 验证。
