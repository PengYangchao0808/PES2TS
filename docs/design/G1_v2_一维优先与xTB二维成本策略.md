# G1 v2：一维优先、xTB 与二维扫描的成本策略

> 已并入图谱选择器 P0–P3 (见 docs/design/PES_GENERATION_图论扫描策略选择器设计_v1.md 与 .omo/plans/pes-generation-graph-scan-strategy.md)

> 2026-09-27。配套 [G1 v2 ORCA 扫描模式识别与逐反应计划](G1_v2_ORCA扫描模式识别与计划.md)。G1 负责冻结方法和回退树；G2 只执行。这里的目标是为每条合格反应争取一条有能量、几何、拓扑检验的**一维路径剖面**，不是要求所有反应都可由**单个 B/A/D 几何坐标**正确表达。

## 1. “全部一维”有三个不同含义

| 说法 | 能否对全部 `scan_ready` 先规划 | 物理含义与风险 |
| --- | --- | --- |
| 单个键长/键角/二面角的 ORCA 1D 松弛扫描 | **不能保证** | 一个 B/A/D 坐标可能遗漏协同成断键、H 转移第二键长、组分取向和环重排。强行扫描可得到平滑但离题的曲线。 |
| 多个坐标随同一进度参数同步变化 | 可以作为候选，但须逐条检查坐标和耦合 | ORCA `Simul_Scan` 最多三个坐标；独立 xTB 的 `mode=concerted` 也能让多约束同一步变化。结果仍是一条一维路径，而不是二维 PES；设定的同步关系可能错。 |
| 双端生成路径，以弧长/图像序号作为一维参数 | 可作为复杂反应的默认候选，但不能保证成功 | GFN2-xTB PATH 或 xTB/ORCA NEB 可输出能量随路径进度变化的曲线。曲线是否连接目标 R/P 必须逐条验证。 |

因此可以对所有合格记录统一**输出合同**：`frame_index, reaction_progress, E_xTB, xyz, changed_bond_distances, topology_checks`，并赋予 `valid_path` 或明确失败码；不能承诺每条记录都有有效的一维 PES 曲线。全部 199,217 条都应留在账本，但现有 v2 审计只有 183,460 条 `clean`，另有 7,688 条待复核及 8,069 条排除，后两组不得靠强制扫描绕过 G1 gate。

当前 `clean` 集合中，仅 180 条落在“单个重原子成/断键且无其他优先特殊事件”的严格初步族；这**不是**一维扫描可行总数，其余反应可能通过几何验证找到有效单坐标。173,609/183,460 条有至少四项 `F+B+O` 编辑，142,446 条涉及多组分。这说明“一条编辑 = 一维坐标”的捷径不成立，但不证明其真实反应通道必然高维。

## 2. 点数与时间：xTB 能省单点成本，不能消除网格乘法

设一维 N 个点、二维网格每维 N 个点，每次松弛优化的实测中位成本分别为 `t_1D` 和 `t_2D`：

```text
ORCA/DFT 1D：约 N × t_DFT
ORCA/DFT 2D 网格：约 N² × t_DFT
xTB 2D 网格：约 N² × t_xTB
双坐标同步扫描：约 N × t_method
```

例如每维 20 点：一维 20 次约束优化，二维网格 400 次，三维网格 8,000 次；这只是**点数**，不是可靠的实际小时数。不同结构、电子收敛、起始几何和并行设置会改变单点成本。若要让 20×20 xTB 网格的粗略优化工作量不超过 20 点 DFT 一维扫描，需要 `t_xTB/t_DFT ≤ 1/20`；是否达到必须在同一硬件、同一代表性反应上测量。还要另计端点装配、重启和失败作业成本。ORCA 手册明确指出三坐标网格的约束优化次数会立方增长，而 `Simul_Scan` 使多个坐标沿同一序列变化。[ORCA Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)。

独立 xTB 的 `$scan` 支持距离、角度、二面角的松弛扫描，以及 `mode=concerted` 和顺序扫描；其约束是弹簧势，实际几何可能偏离目标值。xTB 文档明确说不提供原生的完整多维扫描，网格可通过重复调用构建，因此 xTB **降低每格成本，不把二维网格变成一维工作量**。[xTB PES Scan](https://xtb-docs.readthedocs.io/en/latest/scan.html)。ORCA 的 GFN2-xTB 接口支持松弛扫描和 NEB。[ORCA Semiempirical Methods](https://www.faccts.de/docs/orca/6.1/manual/contents/modelchemistries/semiempirical.html)。

## 3. 推荐的分层方法策略

| 层 | G1 冻结的候选 | 适用条件 | G2 保存与判定 |
| --- | --- | --- | --- |
| A：单原生坐标 | GFN2-xTB 的 ORCA `B/A/D` 1D；正反两个方向按预算 | 一个坐标覆盖主要变化且几何非退化；其他编辑能随松弛自动完成 | 全部帧的目标编辑、非目标拓扑、碰撞、能量与端点 |
| B：协同一维（优先验证） | ORCA `Simul_Scan` 2–3 坐标或独立 xTB concerted scan | 关键事件能由 2–3 个可验证的驱动坐标表达；H 转移用供体–H/受体–H 等组合 | 同步约束是否达到、路径方向、是否错误同步/跳支 |
| C：双端一维剖面 | GFN2-xTB PATH，或 ORCA/xTB NEB | 密集编辑、芳香/H₂、组分复杂、A/B 不适用或 A/B 失败 | 路径弧长、逐帧能量、图像收敛、终点与全部编辑 |
| D：选择性二维 xTB | 小规模 2D 网格或多条不同同步路径 | A–C 显示不同通道/不同先后次序、关键双坐标耦合仍不确定，且预计收益足以支付成本 | 网格与一维最佳路径比较；同一预算下的增益 |
| E：高层级复核 | 对分层样本的完整有效帧做 B97-3c/目标级别单点或进一步 TS 验证 | 训练标签和物理验证子集 | 与 xTB 路径结果分开报告，不能只选峰值帧补能量来伪造曲线对照 |

推荐**不把 2D 网格当作 G2 全量默认**。G1 为所有 `scan_ready` 反应生成 A/B/C 中适用的有限候选及触发树；D 仅为试点确认有价值的少量歧义子集保留预算。若目标是“所有反应同一种输入格式”，应统一路径**输出 schema**，而非强迫同一原生扫描坐标。

### 3.1 把 RPH 双成键经验推广为“单参数、多约束”

RPH 的两根键同步形成说明：对具有明确协同关系的一类反应，用两个键长随同一进度参数变化、其余几何在每一点优化，可能得到有用的 TS 初猜。PES2TS 可以把它作为**模板先验**，不能据此断言所有反应都适用同一组等速约束。数学上，对第 `j` 个关键坐标定义端点值 `q_j^R, q_j^P`，由同一个 `t∈[0,1]` 驱动：

```text
q_j(t) = q_j^R + s_j(t) × (q_j^P - q_j^R)
E_path(t) ≈ local_min_x E(x), subject to q_j(x) = q_j(t) for all selected j
```

`s_j(t)` 是 G1 冻结的时间表：基础版所有坐标同速线性变化；第二版提供少量预定义的“先成键后断键”“先断键后成键”“H 转移偏早/偏晚”时间表。每条时间表都从 R 的端点值开始、在 P 的端点值结束，并使用相同的离散点数。G1 可以用分段平滑函数生成各点的显式坐标值：令 `u_j=clip((t-a_j)/(b_j-a_j),0,1)`，取 `s_j=3u_j²-2u_j³`；`[a_j,b_j]` 决定某一坐标何时主要变化。ORCA 手册给出 B 坐标的自定义扫描值列表和 `Simul_Scan`，但**非线性列表与同步组合在目标 ORCA 版本上需先做小型输入兼容测试**；若不可用，G1 可把曲线编译成固定数量的连续多约束优化作业，并保留同一 `t` 索引。ORCA 官方文档明确支持同一优化作业中的多个 B/A/D 约束。[ORCA Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)、[ORCA Constrained Optimizations](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations.html)。

这仍是一条**预设**的约束路径，不是自动找到最低能通道。`k` 个坐标需要 `N` 次松弛优化而不是 `N^k` 个网格点，但可能因时间表错误、过约束或多组分摆放不合理而穿过人工高能区。若试 `K` 个时间表，粗略成本变为 `K×N` 次优化。G1 需冻结 `K` 的上限，不能对每条反应无限试探。

### 3.2 反应类型到 1–3 个驱动坐标

| 化学模式 | G1 首选驱动坐标 | 何时不应硬套 |
| --- | --- | --- |
| 类 RPH 的双键协同形成、双键同步断裂 | 两个关键 B；先同速，再测试少量早/晚时间表 | 两成键实际分步、有稳定中间体、不同取向形成不同通道 |
| 取代/加成消除 | 形成键 B + 断裂键 B；第三个 B 仅在有独立 H 转移或额外主事件时加入 | 电子重排/组分转动主导而两距离无法描述通道 |
| H 迁移/夺取 | 供体–H B + 受体–H B；若同时形成/断裂一个重原子键，可作为第三 B | H₂ 事件、游离 H、多个可能供受体未消歧 |
| 环合/开环 | 关键闭合/开裂 B；必要时加第二个 B 或一个 A/D 调整进攻方向 | 芳香区域重排或多个环键必须协同变化 |
| H₂ 生成/消耗 | H–H B + 1–2 个 H–供体 B | 涉及更多独立反应中心、端点碎片无法一致装配 |
| 芳香重排、密集键级变化 | 先寻找 1–3 个独立的几何驱动坐标，并以其余编辑为**验证目标** | 若键级变化主要是离域重排，局部 B 约束无法覆盖时转双端 PATH/NEB |

**不要把每个 `formed/broken/order_changed` 都约束一次。** L0 签名中的多项编辑常由同一几何运动造成。G1 应用编辑耦合图、共享原子、环区域、端点距离变化和几何独立性选出最多三个关键坐标；其余编辑作为每帧的目标拓扑检查。坐标选择必须可重算，并拒绝重复原子、退化角/二面角、彼此冲突或会造成明显碰撞的约束。特别是多组分反应，G1 先生成合理的有限端点装配；两三根键的距离约束本身不能确定片段的相对朝向。

### 3.3 约束也是优化的一部分，但必须测量其偏离和副作用

在每个 `t` 点，未选的内部自由度松弛，所以同步扫描并非刚性 Cartesian 插值。不同计算引擎约束实现不同：xTB 文档明确说明其扫描约束用力常数，实际几何可能偏离指定值，因此输出要记录**目标值与实际值之差**；ORCA 输入则按所选 Scan 设置逐点执行约束优化。[xTB PES Scan](https://xtb-docs.readthedocs.io/en/latest/scan.html)、[ORCA Surface Scans](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_scans.html)。

每个候选的通过条件至少包括：每点优化/能量完整、实际约束误差低于冻结阈值、帧间连续、非中心无严重碰撞、全部目标编辑按预期方向实现、终点匹配 P、正反方向无无法解释的分叉。高能峰若在端点、路径突跳、出现错误拓扑或中间稳定体，应分别标记；不能把平滑曲线自动视作正确反应路径。阈值须用分层试点确定并锁定，不从 DFT TS/IRC 真值反推扫描时间表。

### 3.4 G1 如何决定 1、2、3 根键及回退

1. **先找物理上不可省的驱动模式**：例如 H 的两个伙伴是一对，协同环加成的两成键是一对；仅凭编辑总数不决定 `k`。
2. **对候选坐标做几何独立性检查**：端点距离差足够、坐标无退化，约束雅可比不显著秩亏；选择最少的 `k≤3`，其余变化交给松弛优化。
3. **优先一条同速时间表**；对已知可能异步的模板增加有限的早/晚时间表。RPH 双键经验可作为双成键模板的第一候选。
4. **三坐标仍无法表达、或试点显示目标路径率不足时**，G1 在冻结计划中安排 xTB PATH/NEB；少量歧义案例再升级二维 xTB 网格。G2 不能临时创造第四个 ORCA `Scan` 坐标。

ORCA `ScanTS` 是扫描后直接做 TS 优化的特殊流程，官方明确用于较局部、无多原子协同移动的模式。多约束路径得到的高能帧应交给独立的 TS 优化与频率/IRC 核验，不将其冒充适合 `ScanTS` 的情形。[ORCA Transition State Searches](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations_TS.html)。

对复杂反应可在 G1 候选中包含双端 xTB PATH：官方 xTB 文档给出从 R/P XYZ 运行 GFN2-xTB PATH 的接口，也明确其推拉偏置参数依赖体系、困难路径可能需要其他方法。[xTB Reaction Path Methods](https://xtb-docs.readthedocs.io/en/latest/path.html)。它能提供一维路径剖面，但不是严格的一维受限坐标扫描，也不能保证最小能量路径。

## 4. 决定何时升级二维，而不是仅凭 L0

G1 预先写入以下机器可判定触发条件，G2 不临时选择方法：

1. 两个关键坐标在同步扫描中不能同时达到目标，或路径出现明显跳支；
2. 正反扫描得到不相容的路径或能量峰，且几何/拓扑核对显示可能有两条通道；
3. xTB PATH/NEB 到达错误终点，或出现稳定中间体，需要拆分为多步假设；
4. 多装配试验提示组分相对取向显著改变结果；
5. 该反应属于预先指定的分层验证子集，且二维工作量未超过冻结预算。

若二维网格不可承受，优先比较**多条一维候选路径**（不同装配、方向或同步关系），而不是无条件扩大网格。需要明确记录二维网格找到的新通道是否在同预算一维集合中缺失。二维扫描的收益指标是“每增加一个正确目标路径/有用 TS 初猜付出的总核时”，不是仅看收敛率。

## 5. 试点需要测量什么

从七个 G1 规划族、L0 高频与稀有类、单/多组分中分层抽取同一批反应，固定硬件、xTB/ORCA 版本、核数、超时和总核时。每条记录在 A、B、C 的适用方案上运行；D 只在预先冻结的子集运行。报告：

- `n_input_valid / n_scan_ready`、`n_method_finished / n_attempted`、`n_valid_target_path / n_scan_ready`、`n_useful_seed / n_scan_ready`，分母逐项保留失败和超时；
- 每个模式的中位数、P90 核时与重试成本，按原子数、组分数、编辑耦合族分层；
- 同一反应的“单坐标 vs 同步一维 vs 双端一维 vs 二维 xTB”配对有效率、额外正确路径数和额外成本；
- xTB 路径对高层级的方向、峰位、拓扑是否稳定；这些是经验结果，不能用“xTB 比 DFT 快”替代验证。

第一阶段不需要宣称全量成本：先用 100–200 条检查输入正确性，再用约 1,000 条估算成功率与实测每帧成本；完成后冻结各规划族的预算和二维升级条件。对测试集只运行冻结策略。

## 6. 决策

**建议采用“一维路径剖面全量优先、严格单坐标仅在适用子集、二维 xTB 作为预算内补救”的架构。** 这使 G1 能为每条合格反应准备完整且可执行的候选树，也保留物理上可能需要多坐标或分步路径的事实。最终能否得到有效剖面必须由 G2 的端点、拓扑、能量和几何检查实测；得到剖面仍不等于找到正确 TS。
