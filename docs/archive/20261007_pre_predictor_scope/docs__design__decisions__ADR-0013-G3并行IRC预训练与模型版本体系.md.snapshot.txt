# ADR-0013：G3 并行 IRC 预训练与模型版本体系

> 状态：Accepted（用户授权调整阶段规划；设计生效，训练实现与权重未交付）
> 层级：G3.P；批次 G3-P1；关联 G0/G1 数据资格、G2/G3/G4 交接
> 取代关系：部分取代 ADR-0010 的全串行训练安排，增加 G3 内可提前启动的教师预训练；保留 STOP→真实动作残差→离线 Q→冻结闭环的接入顺序
> 上游依赖：[开发宪法](../../PES2TS_开发宪法_v1.md)、[阶段定义](../../plans/PES2TS_阶段定义_G0-G3.md)、[ADR-0010](ADR-0010-PES-N反应状态价值与STOP-MOVE统一决策.md)、[ADR-0012](ADR-0012-Classic图论驱动与xTB原生约束扫描.md)
> 下游消费者：[G3-P1 训练方案](../../plans/PES2TS_G3_P1_IRC教师预训练与模型版本计划_v1_20261006.md)、[教师合同草案](../../contracts/PES2TS_PESN_IRC教师数据与模型包合同_v1.md)、阶段/发布/开发流、离线构建器及共享内核
> 当前版本：v1 @ 2026-10-06

## 1. 变更声明与理由

用户确认第一轮 IRC 教师学习可先于 G2 调教，明确授权调整阶段规划并建立整体版本及训练方案。变更触及宪法 §6.5、§7.3、§9.6、§10 的阶段依赖、离线教师资格与新合同族（P1/R1/R6）；科学成功含义、ACP 边界与已有生产默认继续按原规范。

现有 G3.0–G3.2 围绕真实 STOP 标签和 Classic 转移展开，不能覆盖“已有 IRC 提供路径表示/理想方向监督”的独立入口。将整个 G3 阻塞于 G2 闭环，会使已有专家数据无法提前用于表示学习。

## 2. 决策

1. 在 G3 内登记 **G3.P（IRC 教师预训练支线）**，细分 G3.P.0 数据与分裂、G3.P.1 标签与基线、G3.P.2 共享编码器训练、G3.P.3 冻结与交接；实施批次为 **G3-P1**。它不是新增 G5 或独立字母阶梯。
2. G3.P 的启动依赖来源、原子/图映射、冻结分裂、离线访问权限及坐标合同，不依赖 G2 步长/约束优化调教或 G2 科学出口。G3.0 的正式 1000 输入漏斗仍经 G2 闭环，G3.1 的真实 STOP 门、G3.2/G4 的动作与接入门继续有效。
3. 先学习 reaction progress、参考 IRC 路径接近度、低维趋近 TS 的教师方向与坐标协同。参考 TS 是隔离标签锚点；这些输出不叫 p_seed、Q_STOP、Q_MOVE 或成功标签。
4. 显式区分离线 TeacherState 与生产 ReactiveState。IRC 当前帧可作为隔离训练样本，未来帧/参考 TS 只参与标签；在线特征从真实观测重建，不能读取教师轨迹或答案。参考评测在权重/门冻结后独立执行，不参与拟合或选模型。
5. IRC 位移/导数仅提供 `teacher_direction`，不伪装为 ACP 约束优化的 Action/Transition。与 Classic 的差值可在绑定其版本后做离线候选研究；真实可执行残差与 MOVE-Q 仍依赖相容动作/响应数据及接入验收。
6. 首轮模型目标身份为 **`pesn-irc-v0.1.0`**；文档方案 v1、数据/特征/标签/分裂/模型包合同及实验 run_id 分别版本化。仓库软件 `pes2ts_core/version.py` 的 `0.1.0` 不因模型规划而修改。后续模型里程碑见发布方案及 G3-P1 版本表，不用编号代替能力证据。
7. 优先用几何/目标图特征建立低维基线和小图编码器，E/g 后置消融；第一批约 2,000 个 train 反应跑通，再按冻结规则扩至 20,000、50,000 及合格 train 全量。数量为上限/目标，不承诺有效数据或硬件吞吐。
8. 第一期可发布研究用编码器及教师头。其 capability manifest 禁用 STOP/MOVE-Q/在线控制，不能由宿主自动切换为默认策略。G3.1 扩头时比较从零训练与预训练，并复核负迁移及校准。

## 3. 数据与数学边界

当前 `truth_manifest.json` 登记 B3LYPD3_TZVP TS/IRC；不能因另有 GFN2_xTB 文件而宣称全部是 xTB IRC 或逐帧方法匹配。G3.P.0 先对账来源、有效反应/轨迹/帧、方法/单位及配对关系。本次只读取清单元数据，未读取教师真值坐标。

教师进度使用原子身份一致、去刚体后的质量加权累计弧长，两侧分别归一化。图定义的尺度化坐标方向仅是已选坐标中的投影，坐标不完备或局部退化时不保证实际优化轨迹。TS/零方向/无法定向样本记录缺失掩码。沿 IRC 朝 TS 的反向示范不等同于逆向 IRC 积分方程或生产动力学。

分裂保持既有排除与开发污染记录，正逆/映射/构象/对称副本同组；整反应族留出前冻结，隔离 valid/test/holdout 不用于训练和模型选择，train 内另设 development/calibration 子集。新分裂单独身份与哈希，旧清单不覆盖。

## 4. 接口登记与兼容

新增待实现草案：`pesn_irc_teacher_dataset_v1`、`pesn_irc_teacher_labels_v1`、`pesn_irc_split_v1`、`pesn_feature_spec_v1`、`pesn_training_run_v1`、`pesn_model_bundle_v1`；字段与哈希关系见教师合同草案。TeacherState/TeacherLabel 存储与在线 FeatureSpec 分开，沿用已登记 PESNModelBundle 家族。

离线构建器预定置于 `evaluation/pesn_irc/`，推理/模型位于已登记的 `pes2ts_core/pesn/`；实际目录、guard 窄权限、validator/fixture 在实现批次审查。本次没有更改 truth allowlist、生产 schema、运行配置或任何数据产物。

## 5. 证据、同步与回退

设计证据为用户授权、现行规范/计划/清单元数据及源码边界。改版前九份入口文件的精确快照含现有未提交编辑，见[归档](../../archive/20261006_pre_g3p/README.md)。文档范围校验不充当模型或 QC 冒烟。

同步宪法内容 v2.2、阶段 v4.1、AGENT v3.2、PES-N 计划 v2.2、发布 v3.2、总纲 v2.1、台账 v2.3、README/索引。训练、硬件测量、独立评测与在线收益均未启动/未验收。

若教师泛化或后续迁移无增益，保留报告和失败记录，G3.1 从零训练基线继续；G2 和正式 STOP/闭环路径不被 G3.P 阻塞。不同标签/坐标/Classic 版本的新实验写新身份，不覆盖旧 bundle 或冻结分裂。
