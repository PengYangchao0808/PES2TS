## 1. 路线与当前事实

**图论定义允许范围 → 策略选择下一步 → 现有 ACP/xTB 约束优化 → 实际结构/物理能量与费用 → 再决策。** G2 提供稳定环境，G3 提供可选表示，RL 改进有限动作的选择。把复杂度留在已有计算器和质量检查内，首版只学习步长与提交时机，不重新实现几何优化器。

AB3 的 24 例真实产物为 13 complete_path / 9 partial_prefix / 2 rejected_typed，严格 validated=0；9 例部分路径由 7 个不收敛硬点和 2 个旁观键窗终止组成。22 个实际扫描配对的逐例耗时比中位数约 61.4×；这是开发集工程对照。证据见 [24 例报告](../../outputs/g2_ab3_native_xtb_run1_20261007/native_comparison_report_v1.json)。342 个接受的非 origin 帧有物理单点能量，不据此声称完整梯度或成功 TS。报告路径/候选数/计费口径先对账，旧报告保留，修订写旁车。

用户确认 G3 改造正在实施；沿用 G3-P1 的 B0–B7、数据/分裂及模型目标，不新建第二套教师数据、编码器或训练器。具体权重、硬件和评测状态由该任务的证据确认。

能跑通说明已有可接学习控制的物理执行基础；可训练 RL 还取决于动作记录、奖励与真实响应覆盖，收益由冻结策略的同预算对照验证。

## 2. G2 的稳定范围

冻结一份原生 Classic 配方作为基线：关键原子初猜、现有 driver/guard、xTB 原生约束松弛、同几何无约束势单点、接受父帧、有限细分、身份/缓存、typed 终态及全量费用。关键原子只约束初猜主动位移，未冻结原子仍由 xTB 松弛。

近期 G2 工作限于真实缺陷、兼容、收据/成本完整性和严格验证接缝。约束强度、最大优化周期和细分上限固定；策略不能通过改预算赢得对照。freeze_environment 等未全路径验收能力保持独立任务，不成为首轮研究动作。

IRC 横向驻定性、完整 Hessian、路径重参数化、NEB/GSM、多维扫描和动态增删驱动坐标列为按收益启动的后续研究。IRC 近似目标保留作隔离评估方向；既有扫描仍称受约束松弛扫描，不把路径峰或完成区间叫作 IRC/TS。

## 3. 只增加一个策略接缝

计划接缝为 `choose(state, allowed_actions) -> action`。规则策略与学习策略共享同一个状态接受、动作执行、质量和计费循环；先提取可复用单步执行，保留 Classic 回归，避免复制完整扫描器。

| 所有权 | 增量范围 |
|---|---|
| generation/planning | 策略适配、动作 mask、单步推进、预算/回退与 trace；复用现有扫描/候选逻辑 |
| pes2ts_core/pesn runtime | 小策略/价值模型推理与能力声明；不导入 QC、控制器或离线真值 |
| pes2ts_core/pesn offline | 真实转移适配、行为模仿/离线 Q、冻结模型包与模型评测 |
| integration/acp | 沿用请求、收据、归一；不新造计算通道 |
| 宿主评测 | 严格 TS 标签、全输入费用与独立系统对照 |

首版动作最多四个：`MOVE_FINE`（基准步长一半）、`MOVE_BASE`（基准步长）、`MOVE_COARSE`（基准步长两倍）、`STOP_CANDIDATE`。基准取冻结配方的 Δλ；区间端点截断，跨度和方向受 mask 限制。STOP 仅在已有接受帧形成合格物理能量夹峰、化学检查通过且提交能力可用时开放；它提交候选，不声明成功。拒绝后的有限细分仍由现有规则处理，未接受结构不成为父帧；预算、硬拒绝、ABORT 由环境终止。

策略不输出 3N 原子坐标、力常数、电荷/自旋或优化器参数。变步长使用新的计划/协议身份：Classic 的固定网格仍按原完整性口径验收；学习路径单列采样间距、区间覆盖和提前提交。跳过网格点不记作完成旧网格；达到端点也不称完整势能面扫描。

输入只含当前完整几何/目标图、坐标/残差、已接受历史的相对物理能量、失败原因、剩余预算、方法与 mask。缺失梯度显式缺失，不追加 Hessian 来填特征。参考 TS/IRC、未来帧与未来验证结果不进入在线状态；有限历史的 Markov 近似边界显式记录。

## 4. 最小训练数据与奖励

先从原生 trace 构建有资格的 `(s, a, response, s_next, terminal, cost)`，保留所有失败、恢复、拒绝、删失及真实调用。记录命令目标和实际响应的区别、接受父帧、动作 mask、行为策略/概率（未知注明）、配方/输入/方法/策略哈希。原有轨迹只支持实际执行过的动作，不能补造跳步的反事实响应；IRC 邻帧不当环境转移。

拟合只导出冻结split中有资格的train轨迹，继承历史禁入组和反应/方向/邻帧分组；未确认split的产物先用于排错，不能因已看过或名为Demo而改标train。

登记三份 Action/Transition 合同族草案：`pes2ts_control_action_v1`、`pes2ts_control_transition_v1`、`pes2ts_policy_reward_spec_v1`。模型复用 PESNModelBundle 的版本/能力表，以研究策略能力发布；不借用正式 p_seed/Q_STOP 名称。正式 schema/validator 随接入实现，历史 payload 不改义。

首轮研究奖励保持简单：

`R_proxy = B · I(合格候选已提交) − 全量实际费用/C_ref − κ · I(已知硬失败或主动放弃)`。

候选资格沿用冻结的原生夹峰和质量谓词；B、κ、C_ref 只在 train 内确定后冻结。每次尝试计费，候选奖每条 episode 仅一次；无候选 STOP 被 mask，不能靠立即结束拿高分。这个奖励衡量工程候选效率，不是 TS 成功、IRC 一致性或 seedability。人工 gate、任务中断和未知终态记删失/未标注，不能自动当严格失败；不明回报不当完整 episode 拟合。

B、κ和C_ref取正值；逐步奖励只扣该步增量费用，候选奖/失败惩罚在对应终态结算，使累计回报等于上述episode目标。原生优化内周期、单点、恢复和推理成本各留明细，避免漏记或重复计费。

后续有同协议严格标签才使用成功/总费用目标，成功 Y 仍来自 OptTS/Freq/双向 IRC/端点身份。未验证候选的 Y 缺失，不压成 0；验证实际执行时费用进入系统账本。代理指标改善之后再做小批候选严格验证，不为首个原型跑全量昂贵验证。

学习顺序：规则基线 → 同动作集合的简单规则/行为模仿 → 一个小型离散保守 Q。优先 MLP；G3 encoder 可选复用并与从零比较，不为策略研究重启 G3。首轮不同时建设 PPO/SAC、世界模型、连续坐标策略或复杂 ensemble。离线 Q 限制数据外动作；单一行为轨迹覆盖不足时先补少量 train 内合法动作响应，不把离线评分当真实收益。[CQL 原论文](https://arxiv.org/abs/2006.04779)

## 5. 按小批交付，不等待物理算法堆满

| 次序 | 交付 | 放行证据 |
|---|---|---|
| A：现在 | 冻结 AB3 基线与费用口径；继续正在做的 G3-P1 | 配方/代码/方法 hash、24 全终态对账；G3 按原任务交付 |
| B：可并行 | 单步策略接缝、动作/转移/奖励草案、trace 适配和规则回放 | 同一执行循环；旧 Classic 回归；失败/删失和防泄漏 fixture；不增加 QC |
| C：数据合格后 | 一个 BC 基线和一个小 Q 研究包 | 动作支持/训练分裂/冻结参数与能力表；未覆盖动作拒答/回退 |
| D：首轮真实试点 | 4 个开发反应上规则与一个冻结研究策略成对运行；每例预算预注册 | 质量/候选率、全尝试费用、完整路径与提前提交分列；失败也计入。先单 seed 排错，再扩反应族/seed |
| E：有工程收益后 | 小批严格验证、独立反应族评测与默认切换判定 | 正式阶段/科学门与基线门；同先验/QC/验证预算，质量不降才比较费用 |

当前 Demo24 已用于开发，只能做回归与试点，不能再称独立测试集。试点样本兼顾能跑通和困难模式；正式泛化使用另行冻结的整反应族留出，train 内选择，sealed 集冻结后评测。规则、BC 和 Q 的真实比较逐步增加，先完成两策略的小试点，不预设一次多算法大扫参。

采集/拟合试点只从允许开发的train队列选；原有sealed/禁入组保持原资格，Demo24的开发暴露单独披露。逐步评估先读已有trace的费用、接受/拒绝、残差与物理能量；G3教师分数或IRC对齐可在隔离侧补诊断，复用现有工具，不为这些指标追加在线QC，也不把教师接近度称为IRC驻定性。

G4 研究原型可与 G3-P1、人工复核并行；不等待 1000 输入漏斗、完整梯度/Hessian 或 IRC 驻定性改造。受控真实试点仍需所用 ACP 能力、化学 mask、费用、风险拒答/Classic 回退验收；一轮内模型冻结，采集只在 train，更新在轮次之间离线完成。正式 G3.0–G4 出口按阶段文件执行。

## 6. 长期保持简单快速

默认保留收益已证实的最简单策略；Q 不优于规则/BC 就保留后者，不能为“实现 RL”扩预算。预算同时记录 QC、特征/推理/Shield 和冷启动；推理开销目标不超过扫描墙钟的 1%，先实测，不据参数量宣称达标。重复计算只在身份完整时复用缓存，训练成本与运行成本分开报告。

每次增量只检验一个决策因素；新增物理能力需要明确失败机制和同预算收益证据。严格验证持续补齐，复杂物理研究按需启动。每个研究包保留 Classic 回退与配置开关；本轮仅交付计划及规范同步，不改正在实施的业务代码、旧结果或运行默认。
