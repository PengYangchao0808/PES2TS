## 2. 双轨与三工作流（与主干正交）

```
PES-G（generation）            PES-R（ranking）
  G2 Classic → G4 生长             G3.1–3.2 学习排序
        └──────── 共用 ACP + 共用 PathBundle / SeedProposal 合同 ────────┘
```

### 3.5 G4 · 机理驱动的定向生长（Topologically Constrained Path Growth）🆕
> 本版新增定义。G4 = 原路线 `Gen` 的正式化；其概念内核是"化学先验驱动的定向流形生长"。

**本质**：**不是**用神经网络泛化势能面，而是把有机化学家先验（反应中心、轨道相互作用方向、惰性骨架守恒）形式化为**图论与微分几何的边界条件**，从端点定向"拉伸/生长"出高置信反应通道，每步由第一性原理（xTB/ORCA）落地。

**生态位**：带完备化学拓扑约束的**单/双端路径生长方法**，针对传统方法的两个几何陷阱——
- NEB/弹性带的**初猜黑洞**：复杂环系/多中心重排的初始插值在笛卡尔直线上穿插，需耗费大量 DFT 整体迭代拉直。
- AFIR/无向扫描的**自由度灾难**：在高维切空间中沿外围 C–H 键或柔性链滑移，产生大量非目标裂解。

**机制闭环**：`图论提议 → 构象拉伸 → 真实 QC 投影松弛 → 鞍区逼近`。
**两阶段生长（Two-Tier Growing）**：Stage 1 以 xTB 小步长受限拉伸生长 → 事件邻域峰（Event Peak）；Stage 2 仅对 3–5 个候选切换 ORCA 精修，递交标准虚频与 IRC 闭环。

**数据协议（拟定）**：`ReactionTopologyPrior`（`active_bonds` 带 forming/breaking + target_dist；`frozen_invariants` 如 spectator_ring_topology / chiral_centers；`qc_engine`；`level_of_theory`）。

**与 G2/G3 的边界（必须显式冻结）**：
| | 驱动方式 | 帧资格 | 学习 |
|---|---|---|---|
| **G2 Classic** | 规则（图论选择器 + 约束分支延续） | 物理 KKT 约束驻点 | 无 |
| **G3 Rank** | 固定 generation | — | 只学排序 |
| **G4 生长** | 机理先验 + 学习型 driver/guard/方向/时序 | 按方法定义的连续性（受驱动轨迹不强制逐帧 KKT） | 学生成决策 |

**依赖**：G2 闭环 + G3 标签/划分 + ACP **原生键级产品及其导数覆盖** + 曲率探针能力（ACP-G2-08）。

**入口门（承袭 G2 收紧方案的严谨边界）**：
- 不宣称目标 TS 的**存在性 / 唯一性 / 全局收敛**。
- **路径峰 ≠ TS**；三类路径方法（约束分支延续 / 受驱动轨迹 / 链式多图像）分开，各自定义帧资格。
- 文献适配 ≠ 严格复现（RMSD-PP 89/100 是六次运行合并覆盖）。
- 有限势垒构象运动（甲基旋转/胺反转）保留物理轨迹，不硬镜像。

**出口**：固定 ranker 与验证器下，比较**全流程成本与覆盖**；有独立增益证据再扩大范围。

### 4.2 理论主线（收紧后表述）
```
输入与化学假设 → 尺度化约束 → 分支预测
→ 局部校正与辅助项释放 → 物理驻点/事件检查
→ 候选 → ACP 严格验证
```
- 分支理论以**物理 KKT 方程**为主线；约束满秩、约化 Lagrangian Hessian 正定时，才能建立局部光滑分支。
- 分支锚定是**数值辅助**，接受前必须检查**释放后的物理驻点**；不能靠罚项制造"收敛"。
- 图保护显式管理保护边/禁止边/核心—旁观者接口；**谱只作辅助**；原生键级无导数时只用于监测。
- 对称性用于模式解释/候选扰动/可选软先验；**不能强行删掉其他模式**。

### 4.3 三类路径方法必须分开
1. **约束分支延续**：追踪满足物理 KKT 的局部约束极小点。
2. **受驱动轨迹**：RMSD-PP 偏置优化、NT2 式梯度改写；**不要求每帧达到约束极小点**。
3. **链式多图像**：NEB/string，显式耦合多图像。

RMSD-PP/NT2 **不是**第三类。**路径候选 / 局部约束驻点 / 无约束 TS / IRC 是四个不同对象。**

### 4.4 工作包 A–I（非新阶段，与用户草案对照）

| 包 | 主干/优先级 | 内容与依赖 | 完成门 |
|---|---|---|---|
| A 地基 | G2.1/X，P0 | 请求身份/缓存命名空间、边界旁车、能力收据；ACP-01/03 | 同键冲突拒绝；新几何不串缓存 |
| B 分支 | G2.2/R0–R1，P0 | 复用 SVD/校正，统一度规；预测/释放/逐项局部性；ACP-03/04 | 零/微推进/反向回放；物理驻点改善且化学质量不降 |
| C 化学门 | G2.2/R2，P0→P1 | map 保护/禁止边、接口边、几何代理；Wiberg 原生证据 | 禁止边可回放；空 spectator 不误报；代理不冒充原生 |
| D 时序方向 | G2.2/R3，P1 | 事件检测、坐标级相位、有限家族方向/guards | 对照只改一个因素；不用真值相位在线调度 |

### 4.5 留数三层与标签
- **不可变物理帧 + 执行证据 + 隔离标签**三层分离。
- `label_state` 七态：`verified_target / verified_non_target / optimizer_failed / validation_incomplete / execution_failed / unattempted / censored_budget`。
- **未运行 ≠ 失败**；真值只进隔离构建器导出 **train** 分区；`ValidationResult` 不得回流当前推理或 valid/test 调参。

## 5. G1→G2 边界 v2 与六项补齐任务

**审计结论**：183,460 数量与 gate 一致，但**字段隔离 ≠ 端到端真值独立**——映射用 `truth_assisted_p1`，队列筛选还参考 IRC 证据。故：
- **两条评测路线**：① 现有 `truth_assisted_development`（工程回归 + 条件化对照，不得声称无真值泛化）；② **新独立队列**（只用端点 + 可部署映射构建，冻结后 TS/IRC 仅用于评价）。
- 45 条 unassigned **不得**流入 train/test。

### 5.1 五条边界保证（修订审计）
1. 白名单输入完整 → 端点/原子序/F/B/O/H 变化/分类具备；**全图/立体权威需补旁车**。
2. 活动编辑视图 → 有 `edit_kind`，**无显式活动视图版本**；需唯一规范适配器 + 摘要，禁止各消费者自行推断。
3. 电子态一致 → 有组件 charge/multiplicity；当前装配仅接受总 Q=0/M=1，**不能推广为任意多组分总自旋已确定**。
4. 工作方法一致性 → **缺带方法/几何/证据的结论**；G1 交来源与 `unknown`，G2 origin preparation 经 ACP 产生证明。
5. 真值无关与可复现 → **严格端到端 truth-free 不满足**；需分层 provenance。

### 5.2 六项补齐任务
| ID | 优先级 | 交付 | 验收 |
|---|---|---|---|
| G1G2-01 活动视图 | P0 | 规范适配器 + 旁车（F/B active、O archived 单一政策） | O 不流入 driver/guard；重排 map 结果一致 |

| G1G2-04 全图与立体 authority | P0（严格验证） | 洁净全图旁车；立体/芳香/质子化/电子态身份 | 图冲突/立体不确定显式拒绝或 `unknown` |
