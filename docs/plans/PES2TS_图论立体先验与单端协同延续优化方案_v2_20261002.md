## 2. 三种运行模式与信息边界

1. `endpoint_informed_single_ended`：已知 R/P 的图，至少有一个有效完整几何。可从 P 起步，沿反向事件推进；另一端几何若存在只用于几何先验、候选判读或对照，不强制执行路径终点。
2. `event_informed_discovery`：只给一个有效起点和局部事件，未知另一端。不能要求完整 ΔB、另一端目标角度或双端几何见证；用在线投影和释放约束探针生成新极小值候选。
3. `reference_guided_diagnostic`：使用已知 TS/IRC/参考目标表，专门验证执行算法。保留教师来源和隔离审计，不能宣称未知机理发现。

既有固定完整双端模式保留独立合同与验收。若驱动来自 P 的图编辑，即使不提供 P 坐标，仍是端点图知情搜索，不是反应事件盲发现。

从 P 出发得到的分离反应物复合物，与原始 R 的相对取向和构象可能不同。验证“化学身份相符”和“完整几何逐分量等于原始 R”是不同任务，不应强行拼回原始 R，也不能通过取消该要求直接宣称旧合同成功率提升。

## 3. 图论引擎：先分清事件，再派生少量立体候选

### 3.1 成断键与键级变化分开

在原子映射、显式 H、电荷和芳香表示一致的图上，定义边存在性 \(A_{ij}=1[B_{ij}>0]\)。

- `formed`：\(A_R=0,A_P=1\)，自然距离驱动候选；
- `broken`：\(A_R=1,A_P=0\)，自然距离驱动候选；
- `order_changed`：\(A_R=A_P=1,B_R\ne B_P\)，默认监控，必要时有证据地指定几何驱动；
- 氢迁移：供体–H 与受体–H 两个独立距离，配合 D–H–A 角监控或辅助控制。

不能将所有 ΔB>0 判成新成键，或所有 ΔB<0 判成断裂。例如双键变单键不等于键断裂。芳香/Kekulé 表示差异也不能当作真实编辑。现有 `coordinate_pool._emit_edit_coordinates` 已正确区分这些类别，应保持。

对于 R-only 模式，事件由规则/用户/模型提出，并附来源与置信度；不要用不存在的 P 计算 ΔB。

### 3.2 事件区域与立体支持原子

对编辑子图聚类，结合已有 `event_coupling` 识别共同反应中心、环闭合、共轭链、氢迁移和可能的多步区域。新增派生特征：重原子/显式 H 邻居变化、局部键级和、环成员、可旋转键、手性支持原子及几何平面性。

配位数变化和图杂化标签用于候选提名，不是轨道重构的直接测量。反应中心选点需兼顾失去/新出现邻居与稳定支持原子，避免把将要断裂的键当作唯一立体锚点。

### 3.3 坐标角色与逐级启用

沿用现有四角色：

| 角色 | 用途 | 是否硬约束 |
|---|---|---|
| `driver` | 明确驱动化学事件 | 是 |
| `monitor` | 平面性、环形态、键级代理、自旋和新事件监测 | 否 |
| `guard` | 稳定特定立体分支的少量辅助几何 | 首版使用已验证 B/A/D，按窗口或明确目标施加 |
| `target_test` | 事件/终点化学身份判读 | 否 |

新增立体候选默认进入 monitor，具有明确反应面/构象先验、稳定几何定义、必要独立秩和共同见证时才提升为 guard。首轮从每个局部事件 0–2 个独立 guard 起测，这只是预算起点，不是普适化学上限。每次提升必须记录来源、保护目的、作用区间和释放规则。

现有环坐标生成会直接把局部 A/D 提名为 driver，且支持邻居通常按映射顺序选择。升级应区分化学驱动和立体伴随控制，增加几何稳定性评分；相等候选再用固定映射排序保证可复现，而不是用最小 map ID 代表最佳锚点。

### 3.4 外平面与环形态

外平面监控优先定义为具有固定有序支持原子的平面高度或有符号体积。三个支持原子为 a,b,c，中心为 o，例如：

\[
h_o=\frac{(r_o-r_a)\cdot[(r_b-r_a)\times(r_c-r_a)]}{\|(r_b-r_a)\times(r_c-r_a)\|}.
\]

该量是平面性/朝向几何代理；严格手性判读还需完整四取代基与固定有序定义。支持平面退化时禁止使用其符号。

首版硬约束可采用适当原子顺序的 improper-like D，但需核查其与所需面侧的对应、非线性响应、周期展开和近线性退化。任意普通二面角不等于金字塔化角；自定义高度/体积目前不能假定直接编译为 ORCA `%geom Constraints`。

从 sp3 向平面化推进时，h 接近零是允许的；不能设置始终固定符号/幅度的 guard 来阻止反应必需的平面化。在近零区域标注面侧不可判读，而不是误报立体翻转。

环形态可先用稳定、独立的 1–2 个局部 D 描述特定分支，并把更完整的环起伏作为 monitor。允许与反应必要运动一致的变化；不要固定所有环扭转。椅/船/信封不是单个二面角的普适编码。

## 4. 方向选择：环加成偏向 P，但质量优先

为每个可用起点生成可解释 profile，先做物理和电子态硬门，再进行方向偏好比较：

1. 完整结构无严重重叠，原子身份明确，charge/multiplicity 和计算方法适用；预优化保留化学身份；
2. 驱动所涉及的反应片段是否共价连接、关键距离是否已成键；
3. 需要额外安排的反应片段相对位置/朝向自由度是否更少；只计算反应相关组分，不受旁观离子数量误导；
4. 支持几何、立体身份和起点柔性是否更利于该事件；
5. 同方法低能构象作为补充候选依据，不单独决定方向。

双分子环加成且有有效 P：默认优先产品侧单端逆向延续。单分子重排：比较事件局部几何和柔性，而非固定“最低能端”。若两个方向证据相近，预算内保留备选方向；先执行优选，再按冻结失败规则启用备用，不必全部并行算。

P 的一个构象只代表一个通道假说。需要探索 endo/exo 或多个构象时，每个起点各自保存 conformer/channel ID，并做有限候选选择。禁止把某个产品骨架先验宣称为所有可能 TS 通道。

既有 `direction_assembly.compare_directions` 已将起点成键和减少组分自由度放在高优先级，可扩展其 profile。它目前强制 R/P 均有可用 target definition；开放终点模式需要单独入口，不能简单调用后放宽异常。

若从 P 逆向推进，计划中记录 `execution_direction=P_to_R`、`origin_endpoint=P` 和方向无关的事件身份。执行 lambda 从 0 递增；可另存显示反应进度 \(\xi=1-\lambda\)，不得将显示坐标当作执行节点身份。

## 5. 协同调度：区分采样变换与反应通道假说

所有驱动共享一个 lambda，但需要冻结可在任意新 lambda 求值的目标函数，而非仅保存 20–40 点表。

### 5.1 共同 S 型不一定改变路径

如果所有坐标都用同一单调函数 S，则

\[
c_k(\lambda)=c_{0,k}+(c_{1,k}-c_{0,k})S(\lambda)
\]

在约束空间中仍是同一条直线，只改变采样参数。理想连续极限下没有引入异步通道。只有不同坐标相对进度改变，才构成新的曲线路径假说；实际分支/有限步差异仍需对照。

lambda 不是物理时间；0.4/0.6 相位只是“先后程度”候选，不是从极性或图结构直接得到的真实机理。异步协同与分步反应的区别要由稳定中间体和 TS 连接证据判定。

### 5.2 修正 Sigmoid 的端点

建议保留线性基线、已有 windowed smoothstep，并新增端点归一化 sigmoid：

\[
L_k(\lambda)=\frac1{1+\exp[-(\lambda-\lambda_{0,k})/\sigma_k]},\quad
S_k(\lambda)=\frac{L_k(\lambda)-L_k(0)}{L_k(1)-L_k(0)}.
\]

原始 logistic 在有限 0/1 处通常不等于 0/1，会破坏准确边界。要求 sigma>0、分母远离数值退化、稳定数值求值，并限制最大 \(|c'_k|\) 或每步目标增量。

若需窗口拼接的二阶平滑，可以增加 quintic smoothstep \(10u^3-15u^4+6u^5\)。现有 cubic smoothstep 已可作为首版，不必为了引入 sigmoid 全部替换。

初始有限候选族：同步；事件组 A 适度领先；事件组 B 适度领先。事件分组来自耦合图；不对所有键进行全排列。不在第一版同时搜索相位、陡峭度、所有 guard 和起点构象的完整笛卡尔积。

驱动分成三个调度类别：主事件距离；有证据的协同事件距离；立体 guards。guard 的目标优先来自几何见证或有限分支跟踪规则，不能给所有扭转任意相位。

### 5.3 P 起点反向参数化

已有正向目标函数 f 时，反向先定义 \(c^{rev}(\lambda)=f(1-\lambda)\)。使用归一化 sigmoid 时相位对应变为 \(1-\lambda_0\)。不能只交换起终距离而保持原相位，否则并未沿原约束通道反向。

即使目标曲线精确反转，局部极小值可能存在滞回，R/P 两侧追踪也可能得到不同分支。两方向都需独立验收，不预设相同。

## 6. 共同几何见证：保可实现性，不冒充正确 PES

已知双端几何时，可选 geodesic 等方法构建完整几何种子，再测量所有目标值。geodesic 文献支持其作为反应路径初猜，但并不等于经过能量验证的 MEP。[Zhu, Thompson, Martínez, 2019](https://pubmed.ncbi.nlm.nih.gov/31042909/)，[作者实现](https://github.com/virtualzx-nad/geodesic-interpolate)。LST 或笛卡尔插值只能作为候选初猜，仍需碰撞、立体和投影检查。

即使各个离散节点具有共同见证，对各个 q 独立拟合 spline/sigmoid 后，中间新节点仍可能不可实现。自适应折半时，必须对新 lambda 重新进行联合投影/见证验证。

给定意图目标 \(\hat c(\lambda)\)，首版按以下方式处理：

1. 从上一已接受完整几何预测；
2. 联合回代所有活动 hard driver/guard，检查归一化残差、秩、条件数和碰撞；
3. 通过后记录当前预测几何为局部可实现见证，再进行物理约束松弛；
4. 不可实现则缩步、失败分类；若需要修改目标或添加控制，形成明确的新计划版本。

若允许软化辅助意图，应在合同中规定哪些 guard 可软化、幅度和成本；保存 proposed/effective targets 及偏差，不能事后把 projected values 宣称为原指定曲线。只有 R/P 图而无第二端几何时，不编造第二端几何见证；只做单端局部投影。

几何存在性、连续可达性、当前分支稳定性、化学正确性是四个独立层次。一个满足距离/角度的 3D 构型只能证明第一层。

## 7. GENERATION：在线闭环与有限分支预算

沿用上一报告的关键流程：有效起点准备 → 预测 → 非线性投影 → ORCA 硬约束校正 → 质量门 → 接受或分类重试/折半。

- 当前帧仅取上一 accepted checkpoint；禁止参考表默默覆盖；
- 用新目标减当前实测 q 的残差，避免误差累积；
- 整体 proper-Kabsch RMSD≤0.30 Å；同一次对齐下最大原子位移≤0.60 Å；输出反应中心和重原子诊断；
- 同时要求有限物理能量、正确电子态、收敛和全部约束残差；
- 两次连续平滑且校正温和后才放大步长；失败后清零计数；
- 最小步长与每点/总 attempts、总时间、帧数均有显式终止；
- 保护旁观骨架，探索区域意外事件存为分支证据，不能用“所有非驱动键绝不改变”关闭级联发现；
- guard 释放会改变约束流形，按冻结窗口/分段规则释放并检查松弛，不能静默删约束；
- λ 上限只说明事件窗口结束；新中间体由独立释放约束探针判定。

输出可以是完整合格分支、部分有效分支或失败证据。有效曲线只包括 accepted frames；拒绝尝试全部保留和计费。不保证始终产出一条全程光滑曲线。

AFIR 可作为以后驱动不足/分支停滞时的独立预算候选，而非本版必需依赖。AFIR 人工势与硬约束扫描不是同一算法；若接入，原始物理 E、偏置项和总目标分别保存，排名使用指定物理通道，不混用偏置势峰。[AFIR 作者技术介绍](https://pubmed.ncbi.nlm.nih.gov/27258568/)。

图论与几何应协作：图筛化学事件，几何筛取向和可行性。不要把“不能仅按距离猜反应”解释成“几何距离不得参与候选筛选”。反应发现框架仍需处理三维反应物摆放。[Zimmerman 组的方法介绍](https://pubs.rsc.org/en/content/articlehtml/2017/ob/c6ob02183b)。

## 8. 物理证据字段与 RANKING 改进

### 8.1 未约束受力是质量门

固定欧氏笛卡尔度量，且梯度、坐标导数单位一致时，令

\[
P_\perp=I-J^T(JJ^T)^+J,\qquad g_\perp=P_\perp g_{phys}.
\]

在收敛的约束极小值处，\(g_\perp\approx0\) 是应满足的条件，既可能出现在势垒前、峰顶，也可能在势垒后。因此 \(\|g_\perp\|\) 主要用来排除校正不足，不应充当 TS 主评分。

在 \(\mathcal L=E+\nu^T(q-c)\) 约定下，\(g_{phys}\approx-J^T\nu\)。如果 gradient API 可提供真正的未投影物理梯度，可以求最小范数乘子估计，并保存 KKT 残差。冗余约束下乘子不唯一；不同坐标单位下 ν 的范数也不可直接比较。可比较的是统一笛卡尔单位的梯度和 \(J^T\nu\)。

不得把 ORCA 输出的投影/约束优化梯度直接称为无约束物理梯度。现有接口能量与结构证据已贯通，物理梯度和乘子端到端能力尚需真实探针验证。缺失值用 null/unknown；必要时对少量排名候选追加同方法物理梯度计算，并计入验证/证据补充预算。

### 8.2 lambda 斜率的两个陷阱

多驱动时 \(dE/d\lambda=-\nu^Tc'\) 为零可以是贡献抵消，而非物理驻点。smoothstep 的端点或平台 \(c'=0\) 也会产生零斜率，但不表示 TS。

候选识别应聚焦有足够实际位移的内部 accepted 节点：使用实际非均匀节点有限差分/局部峰拟合，并用共同对齐后的几何弧长 s 检查 \(dE/ds\)。若弧长增量接近零，标注停滞而不求导。不能将不同参数化下的 \(|dE/d\lambda|\) 数值直接作统一分数。

### 8.3 排名顺序

建议采用可解释的分层排序，首版不训练黑箱总分：

1. 硬资格门：accepted、完整局部连续性、有限同方法能量、约束残差、电子态和输入有效；
2. 各独立局部峰区间提名候选，允许多峰、无峰和边界未包围的状态；
3. 排除辅助 guard 驱动异常、强应变和不相关拓扑；检查 \(\|g_\perp\|\) 是否满足松弛质量；
4. 在局部峰区间内结合未约束 \(\|g_{phys}\|\)、峰值包围质量、可用的负曲率/反应模相关性和立体通道判读排序；
5. 按几何/通道去重，保留少量不同峰与不同异步方向，输出理由和缺失证据；
6. 有限候选进入 OptTS 和验证，不保证排名首位一定成功。

未约束梯度小也可能是极小值或高阶鞍点，必须结合峰区间和曲率验证。不要简单按不同路径的最高绝对能量排序；不同构象/参考端点的相对势垒与计算方法需一致。不同片段取向的关联态能量也不能直接冒充标准态自由能势垒。

建议每个 frame 保存：lambda、弧长、X、物理 E、method/state、frame_role、全部 targets/actual/residuals、活动 driver/guard IDs、接受质量、物理梯度及来源/单位、projected-gradient norm、乘子估计及可信度、父节点与 attempt 身份。扩展 PathBundle 时版本化校验和可选证据字段；旧能量排名保留作为基线。

## 9. 责任边界与验证

```text
PLANNING
  图/事件 → 起点与方向 → driver/monitor/guard → 可求值调度与预算冻结
      ↓
GENERATION
  预测/投影/校正 → 质量验收 → checkpoint/折半/终止 → PathBundle
      ↓
RANKING
  冻结 PathBundle → 局部峰与物理证据 → 去重候选 → SeedProposal
      ↓
VALIDATION
  OptTS → 频率与反应模 → 双向 IRC → 端点优化与身份确认
      ↓
INTERMEDIATE STAGING
  已验证中间体/分支证据 → 新计划版本 → 下一基元步
```

GENERATION 可以依据冻结规则触发峰附近加密和 landing probe，以满足搜索停止逻辑；它不能据此宣布 TS 正确。RANKING 不重新生成路径、不静默改 guard/schedule；所需新计算由验证/编排层形成有版本、有预算的派生请求。

TS 正式证据：无约束驻点、恰有一个有意义的相关虚频、双向 IRC 与相邻势阱身份。中间体正式证据：无约束局部极小值、电子态与身份确认，频率排除有意义的虚频；数值近零模单独处理。[ORCA TS 搜索](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/optimizations_TS.html)，[ORCA IRC](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/irc.html)。

## 11. 下一轮实验与验收顺序

### M0：合同和起点基线

冻结三模式、方向、构象、事件来源、guard 规则、预算与终止状态。以同方法准备有效起点；保留原始结构。RXN_0000155302 原始 R/P 的 C/Cl 组分重叠列为输入异常负例，不参与合格搜索分母。

### M1：先证明在线执行收益

相同目标函数、同方法和预算下比较参考逐点启动、上一帧固定步长、预测/投影/自适应步长。先不新增 guard 和相位。选 RXN_0000007104 为已通过基线，RXN_0000017762、RXN_0000187964 为多坐标压力例，RXN_0000026256、RXN_0000077619 为单驱动压力例。

验收：无无限循环、无拒绝点污染、恢复无重复执行；全部接受帧满足冻结门，并报告完整区间覆盖与部分停止，不能用提前终止取得虚假的连续成功。

### M2：隔离方向/调度/guard 收益

先按图核实选出环加成或环闭合实例，不能仅凭 RXN ID 指定反应类别。分阶段做小规模消融：

- 同一事件/调度，比较 R/P 起点；
- 同一起点与 guard，比较同步、A 领先、B 领先；
- 同一起点/调度，比较无 guard 与少量有证据 guard；
- 保留线性/共同 smoothstep，检验采样改善与通道改变的差别。

采用匹配预算；不要一次计算完整“方向×构象×相位×陡峭度×guard”组合。统计失稳位置、实际覆盖、辅助控制应力、所有尝试成本，记录未执行候选的剪枝理由。

### M3：RANKING 和真实 TS 验证

先真实验证能读取未投影物理梯度、单位正确、乘子估计 KKT 残差合理。然后比较现有能量排名与新证据排序的少量候选 OptTS 成功率。正式比较指标为相关一级鞍点与 IRC 连接成功率，而非已知 TS 几何邻近。

### M4：未知中间体与扩展

只给有效单端结构和事件，触发独立 landing probes；区分回到起点、新势阱、新分支和计算失败。稳定新中间体经证据处理后再启动下一段。代表例门槛通过后再扩批，GFN2-xTB 与高层级验证分别统计。

必要负例包括：键级下降被误报断键、芳香表示漂移、支持平面退化、扭转跨周期、必要平面化被 guard 阻断、sigmoid 端点误差、共同重参数化误判异步、反向相位错误、独立插值中点不可实现、c'=0 伪峰、g_perp 小但 g_phys 大、未知梯度冒充零、步长耗尽、无势垒、多峰、landing 回到起点、跨自旋面、真值回流与断点恢复污染。

最终报告分开给出：执行完成率、完整区间连续性、部分路径比例、约束与电子结构质量、TS 候选精化成功率、IRC 连接成功率、中间体确认率、总计算成本。所有失败尝试、起点准备、梯度补充、landing 和科学验证均计入预算。

## 12. 推荐实施顺序

M0/M1 是最高优先级；随后 M2 中先做产品侧优先与最少立体 guard 的消融，再扩大协同调度假说。M3 的物理梯度接口应尽早探针验证，但不阻塞已有能量基线；M4 在稳定在线执行之后开展。

本版不废弃线性对照，不将所有键级编辑硬约束，不默认锁死环构象，不用零路径导数或零投影梯度宣布 TS。通过明确先验、完整质量证据和独立验证，把产品侧经验转化为可复现、可比较的 PES2TS 搜索策略。
