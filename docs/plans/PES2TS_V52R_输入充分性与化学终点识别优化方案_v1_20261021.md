**核心立场**：PES2TS 要学的是**化学终点区域识别**（task-chem），不是**参考构象重现**（task-ref）。当前 `d_end ≤ 0.10 Å` 标签是 task-ref 的监督代理，必须先用实验判断它与 task-chem 的一致性，再决定是否值得训练。

## 1. 两个任务的严格区分

| | task-ref：参考构象重现 | task-chem：化学终点区域识别 |
|---|---|---|
| 问题 | 当前结构是否距数据集中**某一个指定端点构象** < 0.10 Å | 当前结构是否已到达目标反应的**另一端点区域** |
| 标签 | `d_end = RMSD_K(X, X_ref)` | 目标拓扑完成 + 处于合法终点构象集合 |
| 输入 | 当前几何 + 拓扑；参考坐标**不在**前向输入 | 当前几何 + 拓扑；不依赖单一参考构象 |
| 失败模式 | 同一产物的另一稳定构象被判为负例 | 需要定义“合法终点构象集合”，存在过宽风险 |
| PES2TS 目标 | 否 | **是** |

当前合同的 `d_end` 标签属于 task-ref；推理输入按合同 §5.1 禁止参考端点坐标。因此：

- task-ref 在**当前输入下不可完全辨识**（这是标签依赖隐藏参考的直接后果）；
- task-chem 是否可从合法单帧输入学习，**尚未被 D1 回答**；
- 不能从“task-ref 缺参考”直接推出“必须修改输入合同”。

## 3. D0.1 — 标签与数据审计补强（CPU）

### 3.1 22 个拓扑异常行（必做）

D0 已列出 22/1781 个正例存在某个 CV pair 距离偏离参考 >0.25 Å（最大 0.35 Å）。逐行分类：

| 类别 | 判据 | 处置 |
|---|---|---|
| S：对称等价映射 | 图自同构下 RMSD 显著下降 | 用自同构最小 RMSD 重算标签；若翻正→保留，翻负→Mask |
| T：目标键编辑未完成 | target bond-edit completion 未满足 | 按合同 §5.3 规则 5 进 Mask，**不得**作正例 |
| D：数据/映射错误 | 原子序、坐标或索引不一致 | 上游修复；该行进 Mask 并记录 |

产出：`outputs/pesn/v52r/d0_1/topology_anomaly_audit.json` + 人类可读表。**未分类清零前，D2 的 P5 不得启动。**

### 3.2 对称性重算 `d_end`（高优先级）

当前 `d_end` 使用固定原子对应。对对称等价原子（羧酸氧、甲基氢、等价卤素等），同一化学终点可能因映射不同而被判为远。

- 构建 K 原子/全分子的图自同构集合；
- 重算 `d_end_sym = min_{π ∈ Aut(G)} RMSD_K(X, π(X_ref))`（proper-rotation Kabsch）；
- 报告：1781 个正例中标签翻转数、22 个异常行中翻转数、翻转后的 prevalence；
- 若翻转显著（>2% 正例），**D0 的标签统计需以 `d_end_sym` 重述**，并作为 P5 的基线之一。

### 3.3 terminal provenance（必做）

- 复核 1123/1781 = **63.1%** 的正例来自 `terminal`（本地证据包已确认）；
- 确认 `move_status` / `terminal` / `stop_status` **不在** `FORWARD_VIEW_KEYS_V3`（已有结构性拒绝，补一条负向测试）；
- 比较 terminal 与 non-terminal 正例的几何分布（K 距离、角度、d_end 分布），判断是否存在“terminal 代理”分布偏移；
- 报告：若 terminal 正例系统性更“平坦/更产物化”，在自由 rollout 上单独分层报告，不得混算。

### 3.4 数据规模披露

- 30 条 dev 曲线、28 条有 ok 行；每折 10 条；正例 1781；
- 明确写出：所有 D2 结论的统计单位是**曲线**（n=30），不是行（n=7010）；行级显著性不得单独使用。

## 4. D2 — 输入充分性探针 P0–P5（CPU，冻结 R3 编码器）

### 4.0 共同协议

- 数据：dev folds 0–2 only；folds 3/4 只计数，不编码、不探针；
- 编码器：9 个 fold-matched R3 winner（3 折 × 3 seed），strict load，eval 折未见；
- 划分：train = 另外两折，eval = 当前折；按曲线分组；
- 模型容量：同一模型族、同一超参预算、同一 seed 集；
- 阈值：预注册规则（inner-train 曲线分组，precision ≥0.80 的最小阈值；达不到则 thr=∅）；
- 指标：AUPRC（主）、AUROC（次）、prevalence 同报；operating point（recall@precision≥0.80、start FP、TS FP）；
- 统计：曲线级 cluster bootstrap 1000 次；配对比较（同折同 seed）；
- 禁止：任何 sealed fold、任何目标坐标进入前向、任何按 AUPRC 事后挑窗。

### 4.1 P0 — No-goal 基线（已有 D1，保留）

- 输入：当前 K 两两距离（28）+ intent one-hot；
- 模型：constant / logistic / HGB；另报冻结 z、key-pooled h；
- 定位：**no-goal 参照**，不是“单帧模型的理论上限”。

### 4.2 P1 — Goal-oracle（诊断，不部署）

- 输入：P0 + 目标端点 K 距离向量 + (当前−目标) 差值 + |差值|；
- **P1c**：P1 + 当前/目标的手性特征（signed tetrahedral volume、improper dihedral）；
- 目的：估计“目标几何信息”的价值；
- **解释边界**：距离向量对镜像不敏感，而标签使用 proper-rotation Kabsch；因此 P1 是目标信息价值的**下界**，不是上限。P1c 用于分离镜像歧义。
- **P1 胜出不授权修改合同**；它只回答“如果知道目标，能好多少”。

### 4.3 P2 — Label-oracle（自检）

- 输入：P1 + 真实 `d_end`；
- 目的：检查标签、Mask、评估实现；
- 判据：AUPRC 应 ≥0.99；否则**探针管线有 bug，停止一切解释**；
- 定位：自检，不是可部署上限研究。

### 4.4 P3 — Topology-only（泄漏/记忆检查）

- 输入：目标拓扑 + intent，无当前坐标（或常量几何占位）；
- 目的：测量“只靠反应身份”能预测多少；
- 判据：若 P3 AUPRC 接近 P4，说明模型在背反应而非判断几何；P4/P5 的解释作废，先修特征。

### 4.5 P4 — 完整合法单帧几何（无目标）

- 输入：当前 K 距离 + K 角度 + K 二面角 + 局部立体化学（signed volume、cis/trans）+ 冻结 z/h + intent；
- 目的：回答“P0 的 28 维距离是否太弱，遗漏了终点识别所需的三维信息”；
- 模型：HGB（工程特征）与 MLP（z/h/拼接）同容量对照；
- **不含**：目标端点坐标、目标距离向量、`d_end`、q、历史、能量/梯度；
- 解释：P4 是**当前帧信息**的更强表达，不含目标；P4 强于 P0 说明特征/表征是瓶颈，不说明目标不必要。

### 4.6 P5 — 化学终点监督（候选标签）

- 输入：同 P4（无目标）；
- 标签：`d_basin(X) = min_{Y ∈ B_target} RMSD_K^sym(X, Y)`，并附目标键编辑完成与结构有效性；
- `B_target` 构造（预注册，按顺序）：
  1. IRC 参考端点（必含）；
  2. 图自同构等价映射；
  3. 端点构象生成 + 受约束优化（xtb GFN-2，小样本：10 曲线 × 3–5 构象，≤50 次单点/短优化）；
  4. 若有独立 IRC 端点，追加（本数据集暂无）。
- 有效性检查（全部通过才可用）：
  - 参考端点在 `B_target` 内；
  - 反应物 A 与 TS 不在 `B_target`（`d_basin > w_neg`）；
  - 硬负例（产物拓扑但键编辑未完成/关键几何错误）不在 `B_target`；
  - 构造 seed 变化导致标签翻转 <5%；
  - xtb 能量窗口（子集）与参考端点差在预注册范围内；
  - 正例率落在 15–35% 的预注册观察带（越界需重新定义，不得直接训练）。
- **定位**：候选监督定义，不等于势能面局部极小；未通过有效性检查前不得用于 T1。

### 4.7 探针矩阵总表

| 探针 | 当前几何 | 目标信息 | 标签 | 回答 |
|---|:--:|:--:|---|---|
| P0 | ✓ | ✗ | d_end | no-goal 参照 |
| P1 | ✓ | ✓（距离） | d_end | 目标信息的价值（下界） |
| P1c | ✓ | ✓（距离+手性） | d_end | 镜像歧义分离 |
| P2 | ✓ | ✓ + d_end | d_end | 管线自检 |
| P3 | ✗ | ✗（仅拓扑） | d_end | 反应身份泄漏 |
| P4 | ✓（全几何） | ✗ | d_end | 当前帧信息是否足够 |
| P5 | ✓（全几何） | ✗ | d_basin | 化学终点监督是否可学 |

## 5. 统计与预注册

### 5.1 主比较（每个问题一个，避免多重比较）

| 问题 | 主比较 | 预注册最小有意义效应（MME） |
|---|---|---|
| 目标信息价值 | P1 − P0 | ΔAUPRC ≥ +0.10 且配对 CI 下界 > 0 |
| 当前帧信息是否足够 | P4 − P0 | ΔAUPRC ≥ +0.05 且配对 CI 下界 > 0 |
| 化学终点监督 | P5 − P0 | ΔAUPRC ≥ +0.10 且配对 CI 下界 > 0 |

- **不使用“5× prevalence”作为定理**；它只作为描述性里程碑（AUPRC 0.925）报告；
- 所有比较同折、同 seed、同模型容量；报告配对 Δ 与 95% CI；
- 次要比较（P1c、P3、P4 内部消融）全部标 exploratory，不参与门控；
- 同时报告 operating point（recall@precision≥0.80、start FP、TS FP）与每曲线散点。

### 5.2 解释规则

- P2 < 0.99 → 管线 bug，停止解释；
- P3 ≥ P4 − 0.05 → 反应身份泄漏，P4/P5 解释作废；
- P1 高而 P4/P5 低 → 目标信息有价值，但**当前合同输入不足**；**不得**据此直接改合同，转入 task-ref/task-chem 的独立决策；
- P4 高而 P1 不高 → 当前帧信息已足够，目标信息边际价值低；优先表征；
- P5 高 → 监督定义是瓶颈；先修标签，再谈 GPU。

## 7. T1 条件协议（仅 D2-G 通过后）

### 7.1 输入与标签

- 输入：**合法单帧**（P4/P5 胜出的特征集；不含目标坐标）；
- 标签：D2-G 冻结的标签（`d_end` 或 P5 `d_basin`，二选一，不得混用）；
- 初始化：R3 winner（F2-bidir），strict load；
- 分阶段：冻结编码器 head warmup → Endpoint/Ordering 独立（编码器可更新）→ 联合加入 Move → 可选 q（λ_q 默认 0）。

### 7.2 规模与预算

- 9 主 runs（3 折 × 3 seed）+ 2 消融（`ts_stop_legacy`、intent-off）+ 1 个 goal-off 对照（若使用 goal 诊断）= **≤12 runs**；
- 硬上限：**2 GPU-h**、4 h wall；超限即停，记录已完成的 run；
- 预注册：数据/标签/split/config 哈希、seed 集、时间上限、比较集，全部在启动前冻结。

### 7.3 门与失败分类

| 门 | 判据 |
|---|---|
| Move 非退化 | RMSE/zero 相对匹配 R3 基线退化 ≤2% |
| Endpoint | AUPRC CI 下界 > prevalence **且** 配对 Δ vs D2 最佳 ≥ MME |
| Ordering | mean >0.65，跨 TS >0.6 |
| 误停 | 起点 FP ≤2%，TS FP ≤2%（冻结 operating point） |

**失败分类（对母计划的修订）**：

- `invalid_run`：数据泄漏、协议违规、哈希不符、运行时错误——**只保留给这些**；
- `scientific_failure`：训练有效但 Move 退化 >2%、Endpoint 未达门、Ordering 未达门——**记录并分析，不得丢弃，也不得标为 invalid**。

> 该修订需在母计划 v1.1 中显式落笔，并同步合同/验收表措辞。

## 11. 风险与缓解

| 风险 | 缓解 |
|---|---|
| P1 距离特征镜像歧义 | P1c/P4 加手性特征；解释时声明 P1 为下界 |
| P5 `B_target` 过宽 → 标签失去判别力 | 硬负例 + 正例率 15–35% 观察带 + 能量窗口；越界重新定义 |
| terminal 成为隐式前向特征 | 结构性 `FORWARD_VIEW_KEYS_V3` 拒绝 + 负向测试 + 分布分层报告 |
| 22 个拓扑异常污染 P5 | D0.1 未清零前不启动 P5 |
