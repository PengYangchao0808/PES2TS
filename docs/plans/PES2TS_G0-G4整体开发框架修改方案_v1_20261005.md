## 1. 总体裁决与变更范围

**保留 G0–G4 阶段体系，将后续主线调整为：数据与真值隔离 → 化学先验编译 → Classic 物理闭环 → 统一模型离线学习 → 统一模型闭环导航与泛化。**

统一模型读取完整体系的几何及当前计算信息，共享化学与几何表征，输出：

- 整体结构对目标 TS 的接近度 d；
- 图论先验允许的关键反应内坐标增量 Δq。

PES-G 使用两个输出推进与选点；PES-R 对外部候选调用同一接近度输出，必要时也可继续导航。PES-C 是规则控制和真实数据生成基线。G/R 是使用模式，默认不分别建设两套独立模型。

| 现行组织 | 拟修改为 | 保留内容 |
|---|---|---|
| G1 主要交付图审计、分类与白名单 | 化学先验编译：反应原子、上下文、事件、驱动坐标与合法动作模板 | 既有图/映射审计、放行范围、来源与身份合同 |
| PES2TS 内部数值校正 | 控制器提目标，ACP/ORCA 执行完整原生约束优化 | 旧投影 BFGS 冻结为回放/对照基线 |
| G3 只训练独立 Rank | G3 构建共享双输出模型的离线训练与评测 | 同候选池排序诊断、严格标签及成本指标 |
| G4 才开始模型化的生成研究 | G4 部署 G3 模型、收集真实反馈并验证闭环收益 | 机理条件、反应族留出、全流程成本比较 |
| 内部生成结束后固定独立排序 | 搜索过程中用同一 d 保留候选并按冻结门交接 | 历史规则后排序作为基线；外部 rank 入口 |
| 模型输出与最终科学成功容易混称 | 预测、真实响应、候选资格、严格成功分别记录 | OptTS/目标模态/双向 IRC/端点身份验证 |

“一个模型”指共享编码器、配套输出头、共同特征定义及一个版本化模型包；不要求所有输出最后一层相同，也不要求每个训练样本拥有全部标签。

### 3.1 原子分工与自由度分工

图论层确定“重要反应原子”是必要的，但实现采用两类信息，避免把原子角色直接等同于冻结状态：

| 层面 | 拟议表示 | 含义 |
|---|---|---|
| 化学角色 | reaction core / geometric support / environment | 参与事件的反应原子、定义方向或配位的支持原子、其余环境原子 |
| 坐标控制 | driver / monitor / guard / target_test | 哪些坐标主动提目标、哪些只观察、哪些保护、哪些用于目标判定 |
| 当前优化自由度 | 实际硬约束及其支持原子 + 剩余自由度 | 由本帧已启用约束确定，不由“重要/非重要”二分直接推出 |

自由松弛原子仍进入模型的结构上下文，并影响 d 与 Δq；“不由模型直接驱动”不等于“不重要”或“位移为零”。反应原子未被约束的自由度同样由 ORCA 松弛。若 guard 或方向坐标涉及环境原子，约束参与关系单独记录，不继续把相关自由度称为完全自由。

G1 给出端点可推导的静态模板与来源，G2 按已冻结的相位/状态实例化当前动作集合。初版模型只能在已允许集合内选择，不能自行新增反应原子、改变氢伙伴或扩大事件种类。确需新假设时输出显式原因，并以新 H/计划启动新的尝试。

### 3.2 共享模型及双输出

\[
Z_t=\operatorname{Encoder}_\theta(X_t,\mathcal O_t,H),
\qquad
\widehat d_t=f_d(\operatorname{Pool}_H Z_t),
\]
\[
\Delta q_t=\operatorname{Decode}_{\mathcal A_H(s_t)}
\left[f_a(Z_{t,\mathrm{events}},\operatorname{Pool}_H Z_t,h_t)\right].
\]

共享编码器观察完整体系；距离头作反应条件的整体汇总；动作头读取事件/驱动坐标表征和必要历史。图掩码限制可输出坐标，成员检查覆盖耦合、尺度和相位等掩码不能表达的条件。没有合法动作时输出拒绝原因，不用非法零填充冒充成功动作。

建议首版 d 为冻结定义的几何/描述符接近度，记录目标方法与尺度，保持同一结构、目标和方法下的语义一致；不因为预算或路径步数改变而重定义距离。预算、历史、交接校准与不确定性可影响决策，不能把它们混成几何距离。

“整体距离”考虑环境构象与反应中心的相容性，不等于全原子等权 RMSD，也不是关键原子预测步长的范数。指标细节和多目标分支处理见[联合学习 v2 §2](PES2TS_拓扑约束TS接近度与位移联合学习方案_v2_20261004.md#2-距离先有定义再有数值)。距离和动作采用相容的目标分支；离线 TS 分支标签不直接当作线上已知输入。

### 3.3 真实优化与选点

控制器从当前实测 q 构造下一目标，ACP/ORCA 从上一接受结构开始约束优化。模型不代替 ORCA 更新其内部优化步，也不把预测后的几何当作已验收帧。ORCA 返回完整结构及绑定观测后，进行公共验收并重新估计 d。

当前控制坐标可以推进、回退或改变协同比例；自由原子的位移由 QM 决定。小自由梯度、路径峰、很小 d 或 λ 到达终点均不等于严格 TS。几何异常、计算失败和预算耗尽分别记录，恢复动作按失败类型选择，不统一缩步。

内部维持少量合格且有差异的真实候选，同时保存所有原始帧/尝试。当前或历史帧可经冻结交接门输出 SeedProposal，无需等完整路径结束；第一代采用规则交接门，随后才检验共享表征上的校准。进入严格验证后不依据其结果继续修改当前生成路线。

下表是拟议目标及退出条件，尚未替换现行阶段定义。G0–G4 编号、G2.T 地位及 C/R/X 工作流保留。

| 阶段 | 新定位 | 核心交付 | 拟议退出证据 |
|---|---|---|---|
| G0 | 数据、来源与真值隔离底座 | 分裂清单；在线观测/离线标签隔离；方法/映射/开发暴露来源 | 新数据增量通过身份、去重、家族划分和泄漏检查；不重写已有资产完成状态 |
| G1 | 化学先验与动作空间编译 | 反应事件图、原子角色、驱动/保护模板、合法动作与洁净身份 | 边界合同与版本冻结；24 例复核闭合；原子/坐标分工可回放且范围不越权 |
| G2 | PES-C 物理闭环与数据生成 | 原生约束优化、公共验收、规则控制/选点、严格验证、全量转移与成本 | 24 条可审计终态，≥1 非参考种子生成的严格目标 TS；底座能力真实冒烟和对照通过 |
| G3 | 规模化数据与统一模型离线学习 | 1000 输入完整漏斗；距离/动作标签；共享编码器及双输出模型包；静态评测 | 标签覆盖/偏差可审计；冻结模型离线评测可复现；达到预注册的 G4 小范围接入条件 |
| G4 | 统一模型闭环导航、反馈迭代与泛化 | d/Δq 驱动搜索，在线候选/交接，外部入口，独立反应族与来源评测 | 在相同总预算和严格协议下有独立覆盖—成本增益；稳定/回退与适用域明确后再成为默认 |

### 4.1 G0：复用基础，补联合学习的数据资格

- 对反应、正逆方向、邻帧、映射/对称副本按同组划分；新增外部来源维度，来源留出与反应族留出分别报告。
- 区分状态观测、执行结果、离线距离/动作标签和最终物理成功；新增标签不直接混入 controller 输入。
- 当前帧的 E/g 等绑定同一个 geometry hash；方法、电子态、单位、偏置势及约束状态明确。
- 对已有参考数据核验其验证证据；数据集提供 TS 字段不自动代表满足本项目严格成功协议。
- 调参/尺度/损失权重和交接门使用 train 内部划分；按现行 R6，valid/test 与整族留出只用于冻结后的评测。

G0 历史完成结论保留；本轮新增字段、分裂或资产的验证单独登记。

### 4.2 G1：把图论先验变成可执行输入

1. 端点映射和全图/立体身份收口，继续使用已放行 F/B 事件范围。
2. 由编辑与事件耦合确定反应核心，按明确规则加入几何支持原子，剩余原子作为环境；角色可重叠的注解不误写成互斥自由度。
3. 输出驱动坐标及其原子支持、尺度/方向约定、可选相位、允许回退范围；未知事件时序保留未知，不从净编辑强推唯一机理。
4. 区分 monitor、guard、实际硬约束、目标身份条件。允许正常构象松弛，不冻结全部骨架或宣称图约束保证目标存在。
5. 为非支持元素/电荷/自旋/事件产生明确资格原因；小模型首版不因新名称自动扩大化学范围。

验收覆盖原子重排、正逆方向、对称映射、多事件耦合、氢伙伴及空动作集；角色/坐标变化可由输入与编译版本重建。方法相关的端点准备仍由 G2/ACP 负责，G1 不预先宣布端点在任意方法下已是极小值。

### 4.3 G2：建立所有学习方法共用的物理闭环

| 子阶段 | 拟议工作 | 交付/验收重点 |
|---|---|---|
| G2.0 装配与起点准备 | 复用装配与 origin preparation，接收 G1 原子/坐标角色 | 方法、电子态、完整身份及起点证据绑定 |
| G2.1 计划与规则控制 | 规则预测 Δq、相位/步长及停止；编译原生约束请求 | 规则与学习控制器后续共用同一动作合同 |
| G2.2 原生约束优化 | ACP 单帧能力 → continuation；从接受父帧优化 | 输入约束、最终结构/观测、失败、缓存与成本真实可查 |
| G2.3 公共验收与严格验证 | 候选档案、有效前缀交接、DFT preparation、OptTS/频率/IRC/端点 | 图/立体/氢伙伴身份、目标模态及完整来源链；标签失败分型 |
| G2.4 接口与回放收口 | controller/backend 分离、schema 适配、账本与回退 | legacy/native 身份分开，旧产物只读，所有尝试留数 |
| G2.T 四例→24例 | 固定坐标计划先比较后端，再逐项加入自适应 | 24 统一终态与≥1严格目标 TS；不把拒绝/路径完成算化学成功 |

先冻结旧投影 BFGS 的代码快照、输入、坐标计划、预算和结果；native 第一轮保持相同宏观坐标计划，区分后端收益和策略收益。自适应步长、协同相位、驱动选择和保护策略逐项消融，不在同一轮同时更换所有组件。

严格验证优先复核前次审核指出的 preparation 来源链、目标振动模式、IRC 后端点优化/极小值及完整身份、失败标签归并。现有 `passed` 字符串不单独构成新训练标签的资格证据。

### 4.4 G3：规模化与双输出模型的离线训练

| 子阶段 | 拟议工作 | 与原方案的变化 |
|---|---|---|
| G3.0 | 冻结 Classic 配方与 1000 输入队列；全帧、失败、成本；预定候选抽样验证 | 保留规模化目标，1000 是输入数，不是成功路线或充分标签保证 |
| G3.1 | 冻结距离定义；构建有限合法动作教师；距离头/动作头独立基线；审计标签与选择偏差 | 将有限教师的数据建设前移至离线阶段，不先部署学习控制器 |
| G3.2 | 共享编码器和两个输出头联合训练；静态候选评测、动作监督评测、外部适配兼容检查 | 原“独立 Rank 交付”改为统一模型包；静态排名仍是必要诊断 |

训练采用“先确认两类监督各自有效，再暖启动共享模型并联合优化”。独立头训练是诊断/初始化安排，不等于发布独立 PES-G/PES-R 模型。样本按标签掩码贡献不同损失；动作损失按有效坐标数量和尺度归一化，避免反应中心大小主导训练。

距离监督可比较尺度化几何/描述符距离、可行路线长度及有证据的偏序，按 train 内的预注册方案选定首版。其单位、目标集合、方法/分支和零点定义随模型冻结。参考 RMSD 保持现行诊断用途；未通过审计的新监督不因本提案自动获得真值访问资格。

有限教师尝试若干合法坐标动作，经真实 ORCA 松弛和公共验收取得响应。教师偏好依据冻结准则和可用的离线 train 证据，不能仅用待训练模型自评分制造“正确动作”。未尝试动作不作失败标签，多条有效方向保留分支/集合标签，不平均成不合法方向。

训练包同时报告：独立反应数、家族数、真实状态数、d 标签数、动作教师覆盖、严格验证标签数及失败/删失比例。1000 输入与大量邻帧都不保证数据足够；不足时保留规则基线，在预定预算内补 train 数据，不通过查看测试结果补样本。

G3 输出可供 G4 接入的候选版本、适用域、推理资源测量和冻结证据；离线距离/动作误差小不自动批准生产默认切换。

### 4.5 G4：闭环部署、反馈迭代与独立泛化

| 子阶段 | 拟议工作 | 控制变量及验收 |
|---|---|---|
| G4.0 | 冻结 G3 模型，小范围真实闭环；公共验收、规则交接及回退 | 固定 QC、候选门与总预算，比较规则动作与模型动作；静态指标和在线结果分开 |
| G4.1 | 仅 train 上采集新状态/教师响应，补距离与动作监督，联合更新后重冻 | 记录分布变化、模型/数据版本、拒绝与回退；共享权重改变视为联合变更 |
| G4.2 | 完整内部生成/交接与外部候选入口；整族/来源留出；发布评估 | 同预算严格覆盖—成本、外部输入资格及迁移效果、资源要求、回滚证据 |

初版接入依赖完整结构、已绑定的 E/g、原生约束优化与质量/验证，不把所有原生键级导数或完整 Hessian/曲率探针设为一律必需。新增特征或方法按实际使用能力单独验收并计费。

外部模式复用同一距离定义与特征适配；历史缺失显式处理。外部输入没有 H/结构映射/方法身份时先界定资格，不能把任意 PES 图片或无目标点云当作可直接验证的 TS 候选。静态排序通过不等于外部闭环也通过，两种能力分别登记。

## 5. 统一数据链与接口修改建议

保留主链：`ExecutionBackend → TrajectoryRecord → PathBundle → SeedProposal → ValidationResult`。PathBundle 可表示合格前缀；SeedProposal 的生产者扩为规则选点、搜索内交接、外部排序，不改变真实几何来源要求。

以下名称为拟议版本化接口，正式实施前登记新 schema 或绑定旁车，不给旧字段静默增加新语义。

| 拟议对象 | 生产者 → 消费者 | 核心内容 |
|---|---|---|
| ChemicalControlSpec | G1 → 规划/特征/验收 | H、map/graph hash、原子角色、坐标角色/单位/支持集、允许事件/相位、保护和资格来源 |
| ObservedState | ACP 产物适配 → 模型/规则 | 完整 X、实测 q、E/g、观测掩码、方法/电子态、父帧和当前结构绑定 |
| ConstrainedStepProposal | controller → 合法性检查/ACP | 原始建议、合法解码结果、坐标目标、约束版本、父状态、动作原因 |
| OptimizationTransition | 后端与验收 → 账本/离线构建器 | 实际子结构、accept/reject、响应/恢复、真实计算成本及缓存身份 |
| TSProximityEstimate | 模型 → 选点/外部 rank | d、distance kind/scale/target-method、候选 hash、输入可用性、模型版本及适用域 |
| HandoffDecision | 搜索/外部入口 → SeedProposal | 当前或历史候选、资格、冻结门版本、选择次序及剩余预算 |
| JointTrainingLabels | 隔离构建器 → 离线训练 | d/动作标签及掩码、分支相容关系、教师和严格验证来源；不进入在线状态 |
| ModelBundle | G3/G4 离线 → 两入口 | 共享权重与双头、特征/尺度/动作/距离定义、数据分裂、适用域、校准和资源测量 |

模型包中的目标定义是 H/方法/距离的语义合同，不携带在线可查询的测试 TS 几何库。训练标签的真值来源 hash 留在隔离审计层，部署输入保持真值防火墙。

候选评分与新增动作记录绑定几何、映射、方法和模型版本；模型升级后不能把不同版本保存的分数直接混排。若交接层另使用预算相关成功概率/成本，字段与 d 分开，比较时使用共同预算条件。

## 7. 对照实验与科学验收

| 实验 | 固定条件 | 要回答的问题 |
|---|---|---|
| legacy 投影 BFGS vs native ORCA | 相同起点、宏观坐标计划、验收、预算 | 优化后端迁移本身带来什么变化？ |
| 规则固定推进 vs 规则自适应 | 同后端与验证 | 反馈在学习之前是否有用？ |
| 图特征输入 vs 显式合法动作构造 | 同观测、公共质量/严格验证 | 先验执行方式能否减少无效搜索，是否损失覆盖？ |
| 距离头/动作头单任务 vs 共享双头 vs 两独立模型 | 可比数据、容量、调参及教师/训练预算 | 联合表示有收益还是负迁移？ |
| 规则候选 vs 同一 d 排序 | 完全相同候选池及精修协议 | 接近度能否选出真正可精修的初猜？ |
| 固定 d/交接门下改变动作策略 | 冻结编码/距离侧，动作适配单独变更 | 动作策略贡献如何？联合更新另报整体贡献 |
| 最后一帧 vs 历史档案；搜索内交接 vs 独立后排序 | 离线同轨迹诊断 + 在线同总预算分别做 | 在线选点是否保留覆盖并减少无效计算？ |
| 去掉环境信息/QM响应/历史 | 其余条件与成本口径不变 | 完整结构与真实反馈是否提供必要信息？ |
| 外部来源及整反应族留出 | 预先冻结模型、来源与反应组 | 是否能够迁移到未见反应族或候选分布？ |

主指标是全部冻结输入上的严格目标 TS 覆盖—总成本曲线；同时报告距离误差、候选 Top-k、动作合法/接受率、误交接、拒绝原因、回退比例及标签缺失。结构点的统计不当作独立反应数，汇总与不确定性分析以反应/反应族分组。

成本包含教师枚举、描述符补算、失败/拒绝/恢复、准备与完整验证；线上推理、离线数据/训练和冷启动/缓存成本分列。不同电子结构方法的单次梯度不按同价混算。没有严格成功时，单位成功成本标为未定义并报告总消耗，不填零。

Chemoton NT2、RMSD-PP 等基线尽可能对齐目标/端点先验、适用域和验证预算；化学信息不等时单独报告，不能把信息优势全部归因于模型。NT2 已含成断键原子对驱动；RMSD-PP 使用端点偏置；局域 QM 信息的学习型 TS 更新亦有先例。创新主张聚焦具体先验编译、双输出相容学习和真实反馈带来的可复现收益。[Chemoton](https://arxiv.org/html/2202.13011)、[RMSD-PP 官方文档](https://xtb-docs.readthedocs.io/en/latest/path.html)、[SACTS 预印本](https://arxiv.org/abs/2607.10854)

不宣称 d 是精确最短距离、−∇d 就是物理力、先验保证 TS 存在或有限教师给出全局上界。有限教师找到路线证明一个可行见证；未找到可能是覆盖/预算不足，主要评测分母不按教师成功预筛。

## 10. 可行性、资源与风险处理

| 问题 | 可行性判断与处理 |
|---|---|
| 一模型双输出 | 工程可行，先共享表示与独立头；联合学习收益需验证。负迁移时增加专属层或回退独立基线，保持对照证据 |
| 全结构观察、局部动作 | 接口清晰；全结构/环境信息可汇总，不要求输出 3N 位移。模型输入扩大是否值得，用环境消融检验 |
| TS 距离标签 | 科学定义和标签覆盖是主要研究风险；几何距离/路线距离/偏序不混用，未知标签不填零/无穷大 |
| 原生优化响应 | 可复用迁移设计，但单帧能力不等于全路径稳定；父帧分支、实际约束、响应与拒绝需要真实验收 |
| 硬化学先验 | 可减少非法动作，也可能排除必要构象/事件；同时报告覆盖损失，允许显式新 H 而非暗中放宽 |
| 距离接近与精修成功不一致 | 先验证同一 d 的选择效果；必要时在共享表示上校准交接，保持 d 与成功概率两个语义 |
| 自生成到外部候选迁移 | 方法、偏置、历史缺失、分布不同；适配/来源留出验证后再声明可用 |
| 数据及计算成本 | 教师枚举和严格验证可能主导成本；先小模型和有限动作，不预设大 RL 或全 Hessian 必需 |

预算估算先由真实试点测量：教师成本约为被选训练状态的全部合法动作尝试成本之和，验证成本为实际提交候选的完整链费用之和；不同方法、失败和重试分别累计。先冻结可用预算及采样策略，再选择状态数与动作数，不根据成功结果事后改变分母。

模型硬件需求在 G3 包冻结时测量训练峰值内存/显存、CPU/GPU 推理延迟及批量开销。CPU 推理或轻量 GPU 是待测选项，不能由“一个模型”推断无需 GPU或已满足当前机器资源。
