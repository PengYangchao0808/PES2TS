## 1. 阅读顺序与权威层级

开发宪法是唯一规范根；阶段定义负责 G0–G4 及边界；[PES-N 未来计划](PES2TS_PES-N未来开发计划_v2_20261005.md)细化算法/数据/模型；[项目开发与发布方案](PES2TS_整体开发与发布方案_v2.md)负责发布；本文件只组织流程与依赖。ADR 记录决策，台账记录归属，报告保留历史事实。

代码任务按[预测器产品模块划分](../design/PES2TS_预测器产品与G3代码模块划分_v1_20261007.md)归属。本期B0–B6全部新增业务代码在`pes2ts_core/pesn/`：离线数据/标签/训练/模型评测在offline，在线特征/模型/推理在runtime可达集；B7输出交接合同，宿主接入另批。拓扑定义许可，预测器给估计，控制器显式选择，ACP执行；系统严格验证不进入预测器训练器。

现有G0/G1基础按原证据；AB3原生4/24例已交付，G3-P1按用户说明正在实施，具体能力以各任务证据为准。文档生效不等于模型、QC或CLI能力升级。

## 2. 一条主线、两种入口

~~~mermaid
flowchart TD
  I[端点与目标化学任务] --> G1[G1：图、原子角色与合法动作]
  G1 --> C[G2：Classic候选和Chemical Shield]
  C --> QC[ACP原生约束优化与真实物理反馈]
  QC --> S[统一ReactiveState与费用/质量账本]
  E[外部单点或轨迹适配] --> S
  S --> N[PES-N共享状态/动作价值内核]
  N --> STOP[STOP：精修候选选择]
  N --> MOVE[MOVE或已验收fallback]
  MOVE --> C
  STOP --> V[准备、OptTS、Freq、IRC、端点身份]
  V --> D[隔离标签与评测]
  D --> OFF[G3监督/残差 → G4离线Q]
  T[已有IRC来源及G0/G1分裂资格] --> TP[隔离教师当前帧与标签构建]
  TP --> PRE[G3.P：进度/方向/协同预训练]
  PRE --> RF[冻结研究bundle：教师头]
  RF --> INIT[G3.1初始化对照：从零/冻结/微调]
  INIT --> OFF
  OFF --> F[冻结新版本及独立验收]
  F --> N
~~~

搜索过程自己比较 STOP 与 MOVE，保留合格历史帧档案；外部轨迹逐点评价同一 STOP。共用内核与协议，无需另建独立排名算法。严格验证结果只进入隔离评测/train 标签出口，不回流当前生成过程；学习更新离线完成再冻结。

IRC 教师支线不经过 G2 调教入口；研究 bundle 仅交接表示初始化，不能直接接管图中的 STOP/MOVE。只有相应真实标签/接入门通过的冻结版本才进入运行时内核，规范边界见宪法 §6.5 和 [ADR-0013](../design/decisions/ADR-0013-G3并行IRC预训练与模型版本体系.md)。

图定义重要反应原子/环境原子的角色和坐标支持集；“环境原子不直接驱动”不等于冻结。反应原子未受硬约束的自由度也由 QC 松弛，模型观察完整体系。Shield 包括事前合法性与事后实际结构质量，不能承诺未观察响应的绝对安全。

## 3. 阶段依赖与出口摘要

| 顺序 | 任务 | 前置与出口 |
|---|---|---|
| G0 增量 | 多来源状态、动作转移资格、来源和分裂 | 保留底座；新字段与缺失资格单独验收 |
| G1 | 化学控制模板与边界 v2 | 端点映射/事件、图身份、角色、约束与支持域；24 复核 |
| G2 | 原生优化 + Classic/Shield + 严格闭环 | 单帧→四例→24 例；全量终态/成本与≥1 非参考严格目标 TS |
| G3.P / G3-P1（并行） | 源/分裂→隔离教师标签→小编码器→研究冻结 | G0/G1 增量资格及坐标/权限；不依赖 G2 调好；首轮 `pesn-irc-v0.1.0` |
| G3.0 | 1000 输入及 STOP 标注 | G2 数据门；真实标签数单列，不把输入数当成功数 |
| G3.1 | 单点 p_seed、精修成本、Q_STOP | 协议条件化监督/校准；同池预算和跨来源选点收益 |
| G3.2 | 上下文增强、BC 与残差 | 单点不依赖上下文；动作合法与离线接入验收 |
| G4.0 | 保守离线 Q | 已知命令、相容 QC 转移；支持域/离线偏差审计 |
| G4.1 | 冻结模型闭环 | 每步真 QC；train 内采难例；真实费用与成功率门 |
| G4.2 | 外部宿主与双维泛化 | 跨生成器、整族及交叉留出；部署/校准/回滚证据 |

未来研究可在合格数据上开发原型，但发布/默认切换必须逐级通过基线门。有限动作教师是 train 数据工具并计费，不是最终科学分母；离线 Q/分类精度不能代替严格验证成功率。

按[ADR-0015](../design/decisions/ADR-0015-G2稳定底座与轻量RL研究入口.md)，近期G4研究原型可并行准备一个单步策略接缝、有限步长/候选提交和相容转移/代理奖励；不等待1000正式漏斗或IRC驻定性。受控真实试点及正式发布门分别执行，教师包不直接接管控制。[轻量计划](PES2TS_轻量控制与RL衔接计划_v1_20261007.md)细化当前顺序。

G3.P.0/.1/.2/.3 及批次工作包/版本见 [G3-P1](PES2TS_G3_P1_IRC教师预训练与模型版本计划_v1_20261006.md)。G3.P 预训练非正式 STOP 线的硬前置；若无迁移增益，G3.1 从零基线继续。G3.0 正式 1000 输入漏斗仍依赖 G2 出口。

## 4. G2 的近期关键路径

1. 冻结AB3原生底座、旧BFGS配方和24例对照；先核对全尝试费用/报告身份，修补写旁车。
2. 沿现有单步执行提取策略接缝；规则和学习共用ACP、接受父帧、有限细分、质量门、预算与trace。
3. 保持现有QC配方/驱动坐标和预算，增量限动作mask、转移/奖励合同与兼容回放；缺失梯度不追加昂贵探针。
4. 与持续实施的G3-P1并行准备规则/BC/小Q研究，先4例两策略同预算试点，不重复原生4/24交付或教师研发。
5. 持续核验preparation、OptTS、目标虚频、双向IRC及身份；人工gate保持。代理候选与严格成功分开，复杂物理研究按收益后置。
6. 全接受/拒绝/失败/删失及费用保留；正式G2.T科学出口与后续规模化按阶段定义，轻量研究不追认出口完成。

原 [G2 数学方案](PES2TS_G2_PESG收紧算法迭代方案_20261003.md) 的局部分支成立条件、质量门、图保护及 A–I 任务仍可参考；控制/实际数值优化的未来职责按 ADR-0010 与原生优化设计执行。旧本地校正不是生产 backup 的执行豁免。

## 5. G1 边界与数据资格

[G1→G2 审计](PES2TS_G1_G2边界审计与补齐任务_20261003.md) 六项任务继续保留：活动编辑单一视图；工作方法来源与准备证据；来源/评测分轨；完整图及立体身份；core/halo/interface/保护分区；按需对称注解。

183,460 scan-ready 是历史 gate 计数，不是独立无真值的能力证明；辅助映射与 IRC 预筛选的来源标记不得抹去。45 个 unassigned 继续隔离。Demo24 保留历史 split 并声明已用于开发；新独立队列承担泛化评价。

新模板区分目标事件、driver/monitor/protection、原子角色和实际硬约束；方向与允许短程回退由化学规则冻结。全图、原子序、映射、电子态、方法/单位和证据引用一致，缺失显式 unknown；不复用旧 gate 的通过位声明新资格。

状态数据分三层：物理观测、执行/成本证据、隔离标签。MD/Opt/NEB/GSM/RMSD-PP 等可提供 STOP 帧，但其相邻帧不能自动当作本环境的 Δq→约束优化转移；命令动作与实际坐标差分别存储。

## 6. ACP 能力优先级与接缝

| 能力 | 当前路线中的作用 | 验收边界 |
|---|---|---|
| 请求身份、版本与缓存 | G2 首要基础 | 新几何/方法/约束新身份；不跨任务串缓存 |
| E/g 与原生约束优化 | Classic 与真实转移的必要能力 | 正式产品、单位/原子序、收敛/残差和真实冒烟 |
| preparation + 完整 TS 验证 | 成功真值及 STOP 标注的必要能力 | 每段证据独立，不能用收敛字段替代完整结论 |
| 全量计量与拒绝记录 | 所有阶段必需 | 失败/前瞻/回退照记，内部调用不重复计费 |
| PATH/NEB/GSM 等 | 基线、外部来源或可选 fallback | 独立能力收据与预算；没有能力则拒绝 |
| 乘子、Hessian/曲率、键级导数 | 可解释特征与后续研究增强 | 可缺失；首版小模型不以全部昂贵产品为硬前置 |
| 身份桥/Workbench | 证据展示与回放 | 原产品和引用一致，不提升算法状态 |

细节沿用 [ACP 联合计划](PES2TS_G2_ACP能力补齐与联合验收计划_20261003.md)。此表调整依赖顺序，不重新宣称外部能力已完成；实况仍以正式收据为准。

## 7. 学习与系统验收

G3.P 可先在隔离 IRC 数据上预训练表示/进度/方向/协同，冻结教师研究包；正式决策线以同一精修协议构建 p_seed 和完整 STOP 成本，组合带失败惩罚的 Q_STOP；只最小化费用会偏向便宜失败。G3.1 对比预训练与从零，随后让模型提出有界 Classic 真实动作残差候选，最后才用保守离线 Q 比较 MOVE/STOP。共享模型的任务头按数据资格启用，独立模型仅作负迁移对照。

首个研究原型缩减为规则/BC后一个有限动作Q，不要求先实现连续残差或全部正式STOP头。研究奖励评价合格候选产出与全费用，不能宣称严格Y；后续以严格验证及独立家族证据判定正式能力和默认。详细数据/动作/奖励边界见[轻量计划§3–5](PES2TS_轻量控制与RL衔接计划_v1_20261007.md)。

不学习动力学时，多步 MPC 前瞻必须真实调用 QC 并计费；首版默认一步决策、执行后再观察。约束乘子/约化曲率只在局部光滑稳定分支下解释；g_perp 不直接表示几何距离。不确定性必须经校准进入缩步/probe/Classic/拒答规则。

验收同时看：目标成功率与覆盖、总 QC 费用/严格目标 TS、分支存活、接受/尝试比、各方法调用及核时、单点与批量延迟。完整决策开销包含特征、ensemble、Shield；参数/1% 开销是测量目标。

发布和回滚以 [项目发布方案](PES2TS_整体开发与发布方案_v2.md)为准。跨生成器是强制实验轴，同时保留整反应族及交叉留出；训练阶段不能使用 holdout 调参或未来真实精修成本作为输入。
