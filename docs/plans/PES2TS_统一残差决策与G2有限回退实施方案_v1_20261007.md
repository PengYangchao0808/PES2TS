## 1. 本阶段交付与优先顺序

**先在当前反应规模上接通真实 RL，再扩展数据集。一个共享模型提出逐坐标残差并评价候选动作；G2 统一执行、质量、有限回退、预算和真实响应。**

本阶段完成线是：`观测 → 合法位移候选 → Q 显式选择 → G2/ACP 执行 → 响应/奖励/费用 → 离线更新 → 冻结新包 → 新一轮真实运行`。接通后逐项检验收益、模型/注意力选择，再扩反应数。当前训练候选库很大不构成扩量前置；现有 2k 教师预训练继续保留。

“不扩量”不等于“零新数据”：RL 需要在已确认 train 资格的小批反应上补充真实动作响应。已有 IRC 标签不具有环境转移资格；Demo24 的开发暴露与训练资格分开确认。AB4 的四点/四路径实验用于工程判断，不能自动成为 RL 训练集。

范围为距离 driver 的逐坐标位移；不把步长分类作为必经阶段。STOP_CANDIDATE 先由冻结物理候选谓词触发，优化器回退由 G2 固定规则触发；两者不与连续残差相加。本阶段不训练优化器选择动作或正式 Q_STOP/p_seed，不以代理候选称严格 TS。

## 2. 算法定义：有限预算、合法动作约束的 MDP 近似

定义环境 `E=(recipe, method/state, controls, quality, recovery, budget, reward)`，版本及哈希在每轮前冻结。转移核是 G2 执行协议，不是学习得到的 PES 或另建的动力学世界模型。

状态 S 至少含：已接受完整几何/原子映射/图任务；实际 q、driver 身份/单位/尺度/范围；名义扫描相位、未完成目标队列及基准下一目标；最近命令和实际响应；已接受能量趋势及候选夹峰摘要；近期拒绝/细分记录；方法/电子态/约束/环境哈希；剩余墙钟、请求、恢复和回退配额。缺失观测显式 mask。若后端复用优化器或电子重启状态，则绑定可复现重启身份，否则冻结每次调用的初始化协议。

实际 q 与名义 lambda 分开：残差后的结构不因目标 lambda 被视为已到达该位置。状态保留所有影响下一次执行或奖励的控制器记忆，尤其剩余回退次数和已获候选奖标记。短历史不能证明严格 Markov；增加历史仍明显改变转移/收益预测时，再评估部分观测和记忆编码。

每次策略决策发出一个目标动作。内部细分/优化器回退执行冻结的恢复协议，中间接受帧、未完成目标和费用均留痕，最后返回下一决策状态。拒绝末帧不成为父结构；出现已接受中点但原目标未完成时，返回实际接受前缀及明确的 pending/终态，不伪报原目标达成。Classic 继续按原网格队列执行，学习运行使用新路径身份。

首版为有限预算 episode、gamma=1 的未折扣净费用目标。一次决策包含多个内部计算时合计增量费用；因此不以动作个数或优化周期数改变总费用的评价。冻结策略且状态充分时轨迹诱导 Markov 链；训练问题仍是带动作/奖励的 MDP。

## 3. 一个统一模型、两个新头与注意力位置

复用 SmallGraphEncoder；单一参数管理、run、checkpoint 和研究 bundle。编码一次 S 后使用两个新头：

| 部分 | 输出与用途 |
|---|---|
| 坐标交互 | driver 特征 + 全局表示 + 执行上下文；首版共享汇总，轻量坐标 self-attention 为同数据可切换消融 |
| 有界残差头 | 每个合法 driver 一个 u_j=tanh(f_j)，提出位移比例与配合 |
| 动作价值头 | Q_proxy(S, a)，输入真实候选位移向量及上下文，预测候选效率代理累计回报 |
| 保留教师头 | progress/activity 等保持原资格，teacher_direction 未通过旧门仍 disabled |

`delta_q_base = q_base_target - q(X_accepted)`，`delta_q_proposal_j = delta_q_base_j + epsilon_j*u_j`。epsilon、单位、阶段允许方向与范围由冻结 ControlSpec 给定；monitor/guard/不支持坐标不能被残差激活。零残差精确恢复基准目标；提案只读模型输出，G2 构造合法命令和绝对目标。

位移头末层可零初始化，初始候选另含已登记的合法微扰以取得非零动作响应。首轮冻结 encoder，训练新头；闭环后再比较小学习率联合微调。训练用 target 网络若采用，只是参数副本，不是另一个产品。旧教师包不原地增加动作权限；新包按研究能力声明。

注意力优先作用于关键坐标间协同，作为汇总模块的替换项；带 padding/mask 和原子重映射一致性检查，不引入真值。首版不强制 Transformer 历史编码或全图注意力改造。注意力权重不当活性概率、化学因果解释或 A(H) 合法性。

## 4. 首轮 RL：有限位移候选、保守 Q、轮次间更新

候选包括零残差、模型残差及其 0.5/1.0 缩放、少量有界单坐标正/负微扰；去重并设上限，按 A(H) 拒绝越界。微扰幅度、生成 seed、候选数、探索概率和同收益 tie-break 在 train 内预注册。绝不把所有候选都执行后只报告赢家费用。

每个候选是 k 维位移，可分别调节坐标；候选数量有限不等于只有一个步长自由度。Q 输入动作向量，不绑定会随提案版本变化的候选编号。控制器在有训练支持的合法候选中取最高 Q；无支持/能力缺失时走冻结基准或 typed 终止。候选生成器与动作范围的版本在单轮内固定。

首轮先规则采集与有界探索，生成真实 Transition；随后训练同网络 Q 头。未受监督的 Q 不能宣称已有决策能力，最初行动由冻结行为策略负责。使用小型保守 Q 目标，对合法数据外候选作保守约束；奖励和停止语义保持同协议。[CQL 原论文](https://arxiv.org/abs/2006.04779)

`R_episode = B*I(合格候选已提交) - C_all/C_ref - kappa*I(已知硬失败)`。每步扣当步实际总费用，候选奖至多一次；正常无候选到达扫描终点/预算结束及未知终态分别标记，人工中断不补失败奖惩。不奖励单纯能量下降或教师 s 下降。返回类型拆分 terminated/truncated/censored 与 bootstrap_mask，预算耗尽作为有限预算终止，人工删失不虚填完整回报。

RL 数据保留失败/恢复；只拟合已确认 train 的相容环境。Q 训练支持和数值检查通过后冻结，再成对运行。残差头随后用确实执行且具有收益支持的命令动作做受限加权模仿更新，不把实际响应当命令；未执行反事实不构造标签。每轮保存 head/encoder 更新范围和版本。在线运行不逐步更新权重。

训练数据源资格、协议/奖励单位、采集行为分布与数据外风险见宪法 R1/R5/R6、§6.5/7.3；保守正则不是无条件正确的 Q 或探索安全证明。

## 5. G2 本轮统一改造：一个执行接缝，两种冻结环境

| 改动 | 统一实现及边界 |
|---|---|
| 单步执行 | 从 classic_scan 提取请求、初猜、调用、结果/质量、恢复和计费公共函数；Classic 和学习运行共享，不复制扫描器 |
| 状态/动作 | 坐标按 atom-map/kind/unit/role/合同哈希匹配，不按位置猜测；保存 base/proposal/command/target/actual，名义 lambda 不冒充实际进度 |
| 前后检查 | driver 范围、关键原子支持、Jacobian/位移限额、碰撞、旁观键、身份、真实约束残差和能量可比性共用 |
| 有限恢复 | 细分、pending target、ORCA rescue 配额与 deadline 统一；拒绝结构不进入状态几何，所有内部接受帧和调用可追溯 |
| 路径/候选 | 固定网格完整性和新残差采样分开；候选只读取实际接受帧的同方法 E_physical，检查连续性，峰不称 TS |
| 输出/缓存 | 新结果/trace/Transition 绑定环境、策略、父几何、请求、动作、恢复和成本哈希；热缓存和冷启动单列 |

环境身份分别冻结为纯原生 E_native 和规则混合 E_hybrid。混合环境固定“原生主路径 + 有条件 ORCA 救援”，内部执行器不同已纳入同一协议；状态含救援余量和恢复记忆。纯原生旧数据与混合数据不直接拼成同一 Bellman 数据集。跨环境使用另作显式条件化与迁移评测。

AB4 未放行或 ACP 能力不可用时，RL 可在 E_native 先接通；混合能力就绪后先做规则对照并冻结 E_hybrid，必要时用该环境重采集再更新策略。比较策略收益时各组使用同一环境，不能把“RL+救援”与“规则无救援”的差异归因于 RL。

### 5.1 ORCA/xTB 救援完整承接 AB4

ACP 提供拟定公开工作流 OrcaXtbConstrainedOpt：ORCA 硬约束优化，外部 GFN2-xTB 给能量/梯度，最终几何再执行无约束势单点。PES2TS 只使用公开请求/收据，不实现 QC 进程或自写优化器。保留原固定配方、气相/电子态范围；模型 Hessian/内部准牛顿与额外计算完整 Hessian 区分。[ORCA 外部 xTB 官方接口](https://www.faccts.de/docs/orca/6.1/manual/contents/modelchemistries/semiempirical.html)、[优化与约束](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations.html)

| AB4 参数/门 | 本阶段执行口径 |
|---|---|
| 冻结点选 | 原清单 3 个几何不收敛点 + 1 个正常点，源 hash 不改 |
| 点预算 | 每引擎每点共 60 秒，含冷启动、优化、最终单点和回收；成对 8 次上限 480 秒，能力探针另记费用 |
| 扫描接入门 | 正常点通过质量/方法门，且至少 2/3 失败点真正接受；不足则不启用救援 |
| 路径对照 | 原 4 个反应，纯原生与混合规则路径成对；每条路径 900 秒，共享 120 请求等原配额 |
| 救援上限 | 每个逻辑原目标最多一次、每例最多两次；原生/ORCA/单点/恢复共同计入既定 case 预算 |
| 触发 | 原有限细分后准备因几何不收敛结束，能力/身份/预算都满足；化学拒绝、SCC、身份错误等不触发 |
| 输入 | 使用失败请求原始初猜和相同实际目标，绝不以失败末帧重启；接受中点保留原目标 |
| 能量/质量 | E_physical=最终几何同设置裸 xTB 单点；硬约束 E_effective 不适用；原 0.05 Å 接受门、0.001 Å 硬约束诊断和方法诊断门沿 AB4 |

学习运行的“逻辑原目标”用稳定 action/target ID 定义，父 target ID 跨内部细分延续，不能靠创建新 lambda/attempt ID 绕过次数上限。模型不能选择优化器或把 rescue 配额作为奖励漏洞。救援接受后下一主动作仍先走原生路径。

### 5.2 避免恢复与 RL 数据的歧义

同一决策可包含多个内部尝试；Transition 保存 decision_start、实际 accepted prefix/final_state、pending_target、child_attempt_refs、macro_cost、rescue_used、rejection 和 terminated/truncated。原生失败费、ORCA费、裸单点费及细分费各留明细，macro 与账本合计相等；内部收据不再作为同一训练 step 重复奖励/计费。

拒绝无新接受几何时 X_next=X_parent，但预算、恢复计数与失败历史变化。已接受中点又终止时，实际下一状态是中点；不把原动作命令视为已完整实现。可重放 action-mask、恢复状态和候选奖励谓词作为首轮 Markov 近似检查。

## 8. 本阶段验收与下一轮分界

工程验收包含：新旧合同兼容、原子重映射/driver顺序、单位/mask、非有限输出拒绝、目标不可达、宏步部分接受、救援计数不可绕过、deadline贯穿优化/SP、成本不重计、缓存跨环境拒绝、terminal/censor/bootstrap、在线导入隔离及执行 trace 回放。既有 Classic 对照只在改变其共用执行器时运行相关必要测试。

模型验收分三层：①实际闭环及更新可运行；②独立开发反应上的动作/位移/响应与 Q 诊断；③同环境同预算全输入候选率、连续性、拒绝/恢复、总费用与策略支持覆盖。四反应冒烟不宣称统计显著或泛化。旧 direction cosine=0.397 不自动否决新的有界残差试验，也不因新头存在而启用旧方向。

已有 2k IRC 数据可在闭环后增加定步幅位移辅助标签；先做与执行方向一致的尺度化坐标弧长标签，朝TS与R→P/P→R模式分开；未来真值仅在标签，不构造 command/Transition。监督与真实数据迁移比较采用同范围输入，超界覆盖和缺失如实报告。教师与正式调用方法不同，不能凭预训练 MAE 宣称控制收益。

扩量之前做最小对照：规则 vs 监督残差 vs Q；编码器从零 vs 当前预训；无注意力 vs 轻量坐标注意力。每次仅改变一个因素，适用性与费用不退化才保留。现有 encoder 可先复用，不因缺对照阻塞接口和真实采集。

“阶段完成”指交付单步底座、统一研究模型、真实采集/更新/冻结再运行及可审计同预算对照；AB4 单列通过/未通过。RL 无收益则仍可交付诚实负结果，默认保留规则或监督方案；不能声称“已经提高”。之后按收益扩反应数，并按原准备层/OptTS/Freq/双向IRC/身份协议小批严格验证。
