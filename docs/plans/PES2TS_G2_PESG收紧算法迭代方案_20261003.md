## 1. 总体裁决与理论目标

采用**图条件、分支感知、预算约束的路径生成与候选验证框架**。图、几何、对称分别提供化学假设、数值结构和可选先验；三者都不构成目标 TS 的存在性、唯一性或全局收敛保证。

目标是：给定映射 R/P、方法上下文、反应假设与预算，生成有证据的真实构型帧，经固定候选规则和 ACP 精修协议，尽量降低获得目标 verified TS 的总成本。`PES-G` 在本文只是本项目的算法设计名称，不声称是已验证的新方法。

三类路径方法必须分开：

1. **约束分支延续**：追踪满足物理 KKT 条件的局部约束极小点，增加历史参考、预测器和事件控制。
2. **受驱动轨迹**：RMSD-PP 偏置优化、NT2 式梯度改写；不要求每帧达到原问题的约束极小点。
3. **链式多图像方法**：NEB/string，显式耦合或共同更新多个图像；另有端点与计算预算要求。

RMSD-PP/NT2 不是第三类。路径候选、局部约束驻点、无约束 TS、IRC 是四个不同对象。

保留：G2 活动事件只有完全 formed/broken；`order_changed` 仅归档；局部 A/D 默认关闭且需来源；ACP 是唯一 QC 执行后端；G3 先 Rank 后 Gen；部分路径可独立提名；旧 `g2_path_v1` 与 191,148 条旧产物只读。

## 2. 对草案数学陈述的逐项修订

| 原陈述/操作 | 修订后表述与原因 |
|---|---|
| 根因已经确定为逐帧极小化且无耦合 | 这是待消融的假设；已有 warm-start、局部邻域控制及接受门。缓存冲突、未达驻点、秩退化、真实支路软化分别排查。 |
| 拓扑滑移 = basin separatrix / cut locus | 分开：图编辑漂移、同图构象换支、数值跳跃、允许的反应事件。流域边界与 cut locus 不是同一概念；前者还依赖优化动力学，后者涉及最短测地线失去唯一/最短性。 |
| 质量加权防止 H 滑移 | 质量范数下相同位移对 H 的罚更小；同罚允许的 H 位移反而更大。需独立的逐原子/质子伙伴门，不能把质量度规当化学保护。 |
| 测地信赖域保证不跨能垒/不换拓扑 | 距离只限制运动大小，不编码能垒；很近的构型也可能跨图阈值。它是局部性控制，不是拓扑证明。 |
| 平行移动构型点并锁死平坦自由度 | 平行移动作用于切向量；点通过 retraction/局部坐标推进。真实平坦运动不应一概锁死。 |
| 约束法向称 vertical，核空间称 horizontal | 与 SE(3) 商空间的刚体 vertical/horizontal 区分；本文称约束法空间 N、自由切空间 T。 |
| 给 Gram 矩阵加 εI 仍是严格正交投影 | 正则化逆产生有泄漏的阻尼算子，一般不幂等、不严格满足 Jδ=0；精确投影用尺度化 SVD/伪逆。 |
| SVD/正则化直接治愈 LOCALITY_LIMIT | 只能处理部分病态；信赖域边界、梯度未收敛、调度不当、分支终止也会产生该现象。 |
| Wiberg 边权位于 [0,1]，图谱保持拓扑 | 键级可大于 1，连续权重也不是离散拓扑不变量；阈值图、map 边集合与证据不确定性才用于身份判断。 |
| 核心/旁观者两个不相交子图覆盖全图 | 顶点可划分，但还存在 core–spectator 接口边；必须显式管理接口。 |
| λ₂ 趋零可靠预警骨架断裂 | 仅在明确图和连通分量下有条件意义；归一化谱对整体边权缩放不敏感，断环后仍可连通。同谱不意味着同图。 |
| -log λ₂ 或最近同构投影保证合法 | 该 barrier 只约束某种连通指标；图同构没有通用、唯一、可微的最近 Cartesian 投影。禁用此“保证”。 |
| 有 Wiberg 值就能加入恢复力 | 必须另有 ∂B/∂X 才能形成一致梯度；本期只用原生键级监测/门控，优化罚项用可微几何代理。 |
| TS 属于某 irrep，将其他梯度全部置零 | irrep 通常描述某对称参考下的振动模式；投影到反应 irrep 会丢失其他必要松弛方向，且可能保留高阶鞍点。默认不这样做。 |
| 所有侧向失稳都是 VRI | 约束 Lagrangian 失稳、图事件、特征值交叉、物理 PES 的 VRI 不等价；STEP/LOCALITY_LIMIT 均不是 VRI 证据。 |
| CNPI 基本域 = 任意 Weyl chamber，甲基旋转可镜像回去 | Weyl chamber 是特定反射群构造；标签置换去重不等于零成本实际旋转。有限势垒构象运动必须保留物理轨迹。 |
| 最小化 ∫[E+κ‖γ′‖²/2] 自动得到 MEP | 一般得到带张力的变分曲线，不满足 MEP 的垂直梯度为零条件；结果依赖参数化，可能切角/图像聚集。 |

上述修订不是判定参考软件“缺乏数学”，而是明确本项目借用启发式时的适用条件，避免把不同数学对象拼成虚假的统一定理。

## 3. 输入、身份与化学假设

输入 I 包含原子元素/同位素、固定 atom map、X_R/X_P、带来源的端点图、电子态、F/B 活动视图、归档 O、构象/装配身份和源哈希。当前中性闭壳层范围外明确拒绝；多个组分的多重度不能用 max 普遍推出总自旋。

计划 π 冻结：起点侧、硬驱动 q、有限 guard、调度 c(λ)、保护边/非边假设、可选对称先验、路径方法、工作/验证方法、预算和有限 fallback。λ 是无量纲进度，不是物理时间。

帧、量化结果、决策分别绑定：`geometry_sha256 + atom_order/map_hash + method_context + operation + effective_settings + plan/parent`。每个实际新几何有新 hash；同幂等键不同请求返回冲突。输出为同几何物理 E/g/B 与独立 bias/代理，不得互换。

按 P0 先修复 evaluation ID 命名空间：当前校正器每次调用都从 `gradient-0000` 起数，若多个 corrector 共用目录会构成冲突风险。按 `plan/attempt/frame/corrector_trial/evaluation` 分配执行身份，另以内容摘要找复用结果。冲突拒绝本身是正确保护，不应删除摘要检查“修复报错”。

## 4. 构型几何：度规、刚体自由度与投影

### 4.1 合法的局部几何模型

对没有定向外场、能量具有全体系刚体不变性的固定原子体系，可在无碰撞构型的正则部分考虑 Q/SE(3)。一般非线性构型去掉 6 个刚体自由度；线性/对称退化点需秩检测，商空间不能全局假定为单一光滑坐标图。

实际首版使用**固定 map 的全体系 proper rotation/translation 对齐 + 局部 Cartesian 切空间 + 约束回代**。禁止反射对齐抹去手性；禁止分别去掉各片段的相对平移/转动，因为这些可能正是反应运动。称作局部 retraction 近似，不称精确测地积分。

区分物理质量矩阵 M 与数值度规 W≻0。W 可选 I、M/m_ref 或经 train 标定的原子/内坐标尺度；每次局部子问题冻结 W，记录版本。若 W 依赖 X，完整梯度必须包含相应导数，首版不引入。

在 Cartesian 表示中首版限制为各原子各向同性块 W=diag(w_i I₃)，保证与整体旋转相容；若使用各向异性预条件，必须随坐标架协变或只在声明的局部 chart 使用，不能自动视为 SE(3) 商空间上的不变度规。

采用 X 的长度单位 Å，W 无量纲，g=∂E/∂X 单位 Eh/Å。真正的度规梯度是 W⁻¹g，不能把它与 Cartesian 梯度列向量混用。相同质量范数预算下，H/C 允许位移比为 √12；因此额外设置逐原子位移上限和 H 伙伴事件门。

若使用内坐标，Wilson 型矩阵 J_q M⁻¹ J_qᵀ 描述相关的逆质量/余度规结构；只有独立、正则坐标下才可适当地求逆。冗余内坐标应在有效子空间处理，不能把任意 G⁻¹ 直接称为全局拉回度规。

### 4.2 尺度化约束与精确投影

将硬约束写成无量纲残差：

\[
h(X,\lambda)=D_q^{-1}[q(X)-c(\lambda)]=0,\qquad A=\partial h/\partial X.
\]

D_q 保存距离/角度/扭转的尺度；角度按 rad，扭转在本分支局部展开，跨周期/近线性退化单独判定。归一化尺度与各坐标接受容差分别冻结。

以下公式在刚体已消除的局部坐标内成立；实际 Cartesian 实现通过共同的 W-正交基同时处理刚体和约束，不随意相乘两个不交换的投影。

\[
T_X=\ker A,\quad N_X=\operatorname{range}(W^{-1}A^T),
\]
\[
P_T=I-W^{-1}A^T(AW^{-1}A^T)^\dagger A.
\]

对选定数值秩，有 P_T²=P_T、AP_T=0、P_TᵀW=WP_T。令 Z 为自由切空间基，AZ=0、ZᵀWZ=I，则 P_T=ZZᵀW。

物理自由梯度向量与梯度协向量分别为：

\[
\operatorname{grad}_T E=P_TW^{-1}g=ZZ^Tg,
\qquad g_{T,\mathrm{cov}}=P_T^Tg.
\]

度规驻点残差可取 ||Zᵀg||₂，同时保存统一 Cartesian 单位的残差供跨方法比较。不能把 `P_T @ g` 在 W≠I 时直接当度规梯度。

对 A W⁻¹/² 做 SVD；独立秩、最小保留奇异值、被截断分量及阈值都留档。冗余但一致约束可在明确等价证书后降维；矛盾目标或失去独立物理含义不能靠伪逆吞掉。

\[
P_\epsilon=I-W^{-1}A^T(AW^{-1}A^T+\epsilon I)^{-1}A
\]

只作阻尼预测算子；必须报告 ||AP_ε||，随后再作非线性约束回代，不能作为严格驻点证明。

## 5. 约束分支为何可追踪，以及何时不再可追踪

定义物理 Lagrangian：

\[
\mathcal L(X,\mu,\lambda)=E(X)+\mu^T h(X,\lambda).
\]

在正则坐标内，物理 KKT 方程为：

\[
F(X,\mu,\lambda)=\begin{bmatrix}g+A^T\mu\\h\end{bmatrix}=0,
\quad H_L=\nabla_X^2E+\sum_a\mu_a\nabla_X^2h_a.
\]

若 E、h 在邻域足够光滑，A 满行秩，且约化 Hessian K_T=ZᵀH_LZ 正定，则该点是严格局部约束极小点；加边矩阵

\[
\mathcal K=\begin{bmatrix}H_L&A^T\\A&0\end{bmatrix}
\]

非奇异。隐函数定理于是给出**局部唯一、光滑的 KKT 解分支**。它不保证该分支延伸到 λ=1，也不保证其属于目标化学通道。

当 E 无显式 λ 依赖且 q 不随 λ 改定义时：

\[
\mathcal K\begin{bmatrix}X'\\\mu'\end{bmatrix}
=\begin{bmatrix}0\\D_q^{-1}c'(\lambda)\end{bmatrix}.
\]

这给出理论上的分支切向预测器。首版无需每帧完整 Hessian，可使用已接受帧 secant 和小步法向预测；昂贵 KKT/Hessian 探针只用于选定失败段，并计预算。

失效分型至少包括：约束秩变化、物理自由梯度不达标、局部稳定性变弱、非线性目标不可实现、优化器跨支、电子态/SCF 不连续和纯执行故障。不能将它们统一称作“拓扑滑移”。

## 6. 可实现的预测—校正—释放算法

### 6.1 预测与点/向量运输

最低 W 范数的线性法向预测为：

\[
\Delta X_N=W^{-1}A^T(AW^{-1}A^T)^\dagger D_q^{-1}\Delta c.
\]

同时核查未满足的目标分量。分支切向量 v 来自前两个接受帧的局部 secant，运输近似取对齐后的向量再投影到当前切空间，记为 T_{k-1→k}v；这是 vector transport 近似，不是对点 X_{k-1} 作平行移动。

预测位移由法向目标推进和有预算的切向 secant 组成，再通过约束回代得到 X_pred。优先保留已有回代器；非线性可行性不通过则缩步或换已冻结计划。理论分支预测器可作为后续独立消融臂。[流形运算中 retraction 与 vector transport 的区分](https://www.manopt.org/manifolds.html)

### 6.2 分支锚定是数值辅助，不是物理能量

固定本次 X_pred、W 和切向基 Z_*。在局部对齐坐标中，δ 表示从 X_pred 到 X 的局部位移近似，T_*=Z_*Z_*ᵀW。辅助目标可写成：

\[
\Phi_\kappa(X)=\frac{E(X)-E_{\rm ref}}{E_0}
+\frac{\kappa}{2\ell_0^2}\|T_*\delta\|_W^2
+\alpha\phi_{\rm geo}(X)+\beta\phi_{\rm sym}(X).
\]

约束为 h=0，并限制内部步长、距固定预测中心的累计位移以及逐原子最大位移。E₀、ℓ₀ 和罚项尺度冻结，κ、α、β 无量纲；若只提供能量值而无一致梯度，则该罚项不能进入梯度优化。

对齐变换/局部 chart 在子问题内固定；若在每次评估重新最优对齐，需正确处理其导数和非唯一性。不能只计算 penalty 值而忽略导数。P_T(X) 若实时变化也需求导；首版冻结 T_*，避免伪梯度。

锚定抑制非必要的局部漂移，但不会“消除所有自由运动”。接受前逐步减弱/移除辅助项，并用**原始物理 g**验证 h 与物理 KKT 残差。仅在辅助项帮助下稳定、释放后不驻点的帧标为 `biased_only`；可供受驱动方法候选使用，不能记为约束分支收敛。

几何 barrier 或 trust 边界若持续承担平衡力，也不能隐去其乘子。若未能恢复原问题驻点，结束该约束分支，保留有效前缀。

### 6.3 接受门与事件驱动

```text
冻结输入、电子态、工作方法、计划和全局预算
ACP 起点准备 → 图/电子态/几何证据检查
while 尚有预算:
    按冻结调度选择下一进度，计算秩与可行预测
    建立固定参考的局部子问题；通过 ACP 获取每次物理 E/g
    解约束校正；必要时辅助锚定，但独立保存偏置
    释放辅助项，检查物理 KKT、约束残差、局部性与保护谓词
    通过 → 写不可变接受帧，更新分支历史
    不通过 → 写拒绝几何、具体原因和成本
             依据原因有限缩步/提高精度/检测曲率/尝试冻结支路
    离散事件 → 结束当前连续段，决定分支或新的计划版本
从所有有资格连续段提名真实帧 → ACP 精修验证 → 隔离标签
```

驻点精度须相对于目标增量足够小；推进已落入优化噪声时返回 `PRECISION_LIMIT`。已有 `LOCALITY_LIMIT` 拆分为单次位移、累计位移、原子位移、图门、秩退化或恢复失败证据，保留上层兼容原因码。完整路径率、合格前缀率、候选可用率分别报告。

## 7. 图论层：边语义、接口与可微代理

### 7.1 边集合比两个子图更完整

从活动 F/B 构成事件核心 V_c，halo 用于立体支持；V_s=V\V_c。端点图原有 `reaction_center.core` 可包含归档 O，不能无版本直接当作活动核心。

\[
E=E_{cc}\cup E_{ss}\cup E_{cs}.
\]

分别冻结：活动编辑 A_FB；必须保留连接的 K⁺；明确禁止新接触/成键的 K⁻；只监测的 K^?。接口边属于 E_cs，不能遗漏。K⁺/K⁻ 必须与活动事件、芳香区域、端点合法变化一致；完整无意图非边集合不是自动正确的硬保护集，因为有些通道包含端点看不到的暂态成键。

映射图保护默认检验指定 map 对的连接与化学语义，不能用允许任意置换的图同构掩盖质子换伙伴。对称等价映射只有在预先授权的置换集合内比较。键级变化归档不意味着全路径保持其数值常量。

### 7.2 原生键级用于证据，几何代理用于首版优化

ACP 返回带几何/方法/SCF 身份的 B_ij。xTB 能输出 Wiberg 值并不意味着当前 ACP 产品已完整支持，也不意味着存在 ∂B/∂X；输出打印阈值省略的边不能一概补零。需要覆盖范围、阈值与稀疏缺失语义。[xTB 属性](https://xtb-docs.readthedocs.io/en/latest/properties.html)、[xTB API 键级产品](https://xtb-python.readthedocs.io/en/latest/general-api.html)

首版使用连续距离接触代理，例如 a_ij=1/(1+exp[(r_ij-r⁰_ij)/s_ij])，r⁰/s 是有单位的经验尺度；它不是电子键级。用允许区间构造：

\[
\phi_{\rm geo}=\sum_{(i,j)\in K^+}w_{ij}[\max(0,l_{ij}-a_{ij})]^2
+\sum_{(i,j)\in K^-}v_{ij}[\max(0,a_{ij}-u_{ij})]^2.
\]

平方 hinge 是 C¹ 而非处处 C²；需要二阶探针时用注明宽度的平滑版本或避开接点。极短距离另作碰撞门。使用原生 B 替换 a 时，这个式子只能作诊断分数，除非 ACP 额外提供可核验的键级导数。

不将所有 spectator 的 B 锁死为 B⁰：电子重排可引起合理键级变化。采用方法/家族校准的容忍区间、活动区豁免和歧义状态。原生键级缺失时显式进入 `distance_proxy` 证据模式，不静默冒充 Wiberg。

### 7.3 谱门的正确地位

在冻结非负边权和明确连通分量后，L=D-W 或归一化 L_sym 都可以作为补充诊断。逐边和 map 身份判定优先。初始多组分、孤点、空 spectator 分别处理；空集输出 `not_applicable`，不是通过一次虚构谱测试。

反例：两顶点一条边权 w>0，L_sym 的谱恒为 {0,2}，w 从 1 降到 10⁻⁸ 也不改变 λ₂。删除一个环边也可能仍保持连通。因此 -log λ₂ 不能保证保护某一键；同谱图也可能不是同图。

对保护谓词的强违反：拒绝并回退至上次接受点，限制步长后重新求解；“恢复”是受预算约束的几何可行性子问题，不能宣称唯一最近同构投影。灰区用 hysteresis、重复证据或局部补算处理。重复判定不能弥补系统性方法误差。

图门只证明**当前假设下**的结构合规；同图构象仍可换支，有图变化的旁路也可能是合法物理结果，应单独归档而非宣布“不可能”。

## 8. 时序、方向与可选对称先验

### 8.1 不同坐标的进度函数

\[
c_a(\lambda)=c_{a,0}+\Delta c_a S_a(\lambda),\quad S_a(0)=0,\ S_a(1)=1.
\]

所有 S_a 相同的单调变换在理想连续极限只改变参数化。不同相位/窗口才改变约束空间通道。逆向同一通道用 c_rev(λ)=c(1-λ)，不能只交换两端而保留相位。

候选仅来自无真值端点/家族规则或 train 校准；原草案 RXN_0000007104 的 0.257/0.811 以及近参考 TS 的 RMSD 属于已查看真值的开发诊断，不作为在线特征或新测试集参数依据，本次未重新验证该数值。

离散成断键事件由 B 或显式代理的双阈值/持续性判定；允许多个事件不同时发生。无峰不能直接宣布无势垒；需要中间体时记录多基元连接，不强制构造一个 R→P 单 TS。

### 8.2 群论使用条件与退出规则

指定有限参考群 H 与固定 map/同位素/电子态允许的置换-正交表示 D(h)。只有它确实保持所用能量、边界和约束策略时，才能利用其不变子空间性质。实际一般构型常只有 C₁；伪对称不是精确守恒律。

特征标投影

\[
P^{(\Gamma)}=\frac{d_\Gamma}{|H|}\sum_{h\in H}\chi_\Gamma(h)^*D(h)
\]

用于分类参考点的模式/构造候选扰动；一般是投影到对应等型分量，不保证每个简并副本单独分离。动力学问题的度规还要求群作用保持相应质量/权重。

可选软几何先验为在固定参考 chart 中 φ_sym=||Q_unwanted δ||²/(2ℓ₀²)，而不是约束 P_unwanted∇E=0。后者会涉及 Hessian，且并非几何对称约束。精确对称子空间实验必须有“解除对称”的伴随对照，并在完整振动空间检查 TS 指数。

irrep 相关表只适用于明确的群–子群关系和固定表示；近简并模式用子空间重叠追踪，不能仅按特征值序号贴标签。对称下降是允许事件，不默认回退。

甲基转动/胺反转/环翻转按周期内坐标与实际势垒处理。只有对同一无标签物理构型的允许原子重标记才可做表示规范化，必须更新 map bookkeeping；禁止通过“镜像反射”瞬间改变手性或抹掉实际扭转路径。一般 CNPI 不直接对应 Weyl chamber。

本期该层为 P2、默认关闭，只在有证据的家族做预算内消融；不阻塞首个 Classic 闭环。

## 9. 曲率、分支事件与 VRI 的证据分级

约束分支稳定性用 K_T=ZᵀH_LZ，而不是仅 ZᵀH_EZ。当前 `constrained_curvature.py` 已有固定乘子的 Lagrangian 梯度差分探针，应扩展审计而不是从零重建。

对单位自由方向 v，可通过固定 μ 的 ∇_X L 在 X±hv 的差分估计 vᵀH_Lv；这是局部导数探针，试探几何不必是约束接受帧。比较 h 与 2h、SCF 精度、刚体与映射一致性。正方向探针不能证明整个 K_T 正定；可信负方向可反证严格局部极小性，但单独不证明发生真实分岔。

VRI 的常用局部定义在选定物理坐标中要求 g≠0，存在非零 v 使 H_Ev=0 且 vᵀg=0，并需邻域地形证据解释谷/脊转变。质量加权或曲线坐标必须声明相应 Hessian 定义；它与某个人工约束面的 H_L 特征值变号不同。[Bofill–Quapp 原文](https://www.math.uni-leipzig.de/~quapp/BoQu12VRTrev.pdf)

响应级别：`soft_mode_suspected` → 多步长/邻帧复核 → `constrained_stability_loss` 或 `physical_vri_candidate`。后者也不能解释为 IRC 在任意点自动一分为二；它首先是 PES 地形性质。

有限分支探索：沿经核验软模式 ±ηv 生成子尝试，约束回代、物理校正、图/构象去重；记录父分支、方向、η 和成本。若仍需追踪在 λ 参数下折返的 KKT 分支，可另立研究子任务用 pseudo-arclength continuation；此时 λ 未必单调，须新方法/轨迹语义，不能混入现有单调路径合同。

## 10. 为什么路径峰不是 TS，以及候选该如何选择

对光滑物理约束分支：

\[
\frac{dE}{d\lambda}=g^TX'=-\mu^TD_q^{-1}c'(\lambda).
\]

多驱动峰值可以由乘子贡献抵消产生，不能据此推出 g=0。一个可计算反例为 E(q₁,q₂,z)=q₁-q₂-(q₁+q₂)²+z²，在 q₁=q₂=λ、z=0 的扫描上 E=-4λ²；λ=0 是峰，但 g=(1,-1,0)。

在理想单反应坐标 q 下，若其余 z 充分松弛、E_zz≻0，F(q)=E(q,z*(q)) 的非退化峰满足全梯度零，且

\[
F''=E_{qq}-E_{qz}E_{zz}^{-1}E_{zq}<0.
\]

由 Schur 补惯性关系，此时完整 Hessian 恰有一个负方向。这解释“驱动+横向松弛”为何能提供 TS 初猜，但其成立条件不应套用到任意多约束或有偏路径。

共同候选合同绑定真实几何、路径方法、方法对应的资格证明与物理能量。约束延续要求物理 KKT 质量；受驱动轨迹/NEB 不强制逐帧 KKT，而要求同方法定义的局部连续性、有限量化结果、无严重碰撞及明确偏置。跨方法不能误用同一个“free gradient 已收敛”前置门。

规则族：energy maximum、smoothed local peak、event-local peak、heuristic basin。非均匀 λ 用弧长/进度坐标局部拟合；原始曲线和真实帧不改。高全梯度峰可能是应变，低全梯度点可能是极小值，必须结合事件、峰邻域与必要曲率证据。

参考 RMSD-PP 作者的峰邻域插值/DFT 单点重选，可作为**独立付费候选加工策略**：合成几何先建立新身份，不能冒称原帧；后续无生成约束 OptTS、频率、双向 IRC 与端点极小值/完整身份验证由 ACP 执行。其文献 89/100 是六次运行合并覆盖，须复现预算而不是比较裸百分比。[作者论文](https://peerj.com/articles/pchem-15.pdf)、[作者实现](https://github.com/jensengroup/RMSD_PP_TS)

## 11. 两个参考方法与真正的链式对照

RMSD-PP 采用 E_work=E_low+k_R exp(-a_R d_R²)+k_P exp(-a_P d_P²)，k_R>0、k_P<0；以几何偏置引导优化。[xTB 方法说明](https://xtb-docs.readthedocs.io/en/latest/path.html)

NT2 按指定成断键对改写自然梯度并加入驱动，可在宏步间微优化；本项目若改用全局 W-约束投影，就应命名为 NT2-inspired，而非声称精确复现原实现。[Chemoton 2.0](https://arxiv.org/html/2202.13011)

二者借给本项目的是推进、松弛、选峰与有限补救思路。重试、改变电子温度/偏置、改变起点侧都形成明确 attempt/method 身份；物理能量与 biased objective 分列。

真正链式对照应单独使用 NEB/string。为避免度规含混，首版 NEB 在去刚体 Cartesian 欧氏坐标 Y 上说明：

\[
F_i^{NEB}=-[I-t_it_i^T]\nabla E(Y_i)
+k_s(\|Y_{i+1}-Y_i\|-\|Y_i-Y_{i-1}\|)t_i.
\]

邻图像定义切向 t_i，物理力保留垂直分量，弹簧用于切向分布；收敛、端点、切线及 climbing image 协议分别冻结。该组合力一般不是草案那个标量泛函的梯度。[NEB 官方理论说明](https://onetep.org/wp-content/uploads/2022/09/nudged-elastic-band-v2.pdf)

若后来采用质量或内坐标预条件，作为单独变体说明其梯度/切向定义。固定完整双端的 NEB 与开放终点单端扫描的信息集不同，不能直接混在同一成功率分母下；仅在两者均适用的输入子集比较，另报覆盖。
