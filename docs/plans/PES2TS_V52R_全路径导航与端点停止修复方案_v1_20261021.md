## 1. 目标与边界

- **任务**：Reaction-Intent-Guided **Full-Path Navigation**——Forward `R→TS→P`，Reverse `P→TS→R`；Stop 发生在**目标端点**（Endpoint Stop），TS 是必经途经点，默认负例，**never stop**。
- **接口不变**：`X, G_rxn, H → ΔX_K + Move/No-Move`；q 与 stop score 仅为辅助诊断量，不改变对外接口，不回灌为 forward 输入。
- **q 定位**：分段归一化辅助量（A=−1 / TS=0 / B=+1，reverse 取 −q）+ 全路径 directed pairwise ordering（跨 TS 构对允许）；不作为 Stop 判据。
- **Move 教师**：保留 R3 full-traversal first-contact 教师（d0=0.08 Å），无 approach-side 过滤（该方案已撤回）、无 TS 裁剪；允许且必须跨越 TS。
- **Model Stop ≠ Verified Reaction Path**：端点到达判断不等于已验证 TS/IRC 连通性；模型输出最多称 `TS_candidate` / `endpoint_reached`。
- **数据边界**：dev folds 0–2 only，folds 3/4 保持封存；V5.1b、sealed/Confirm/OOD、Fit150+ 边界不变；V5.1b/OOD/Fit150+ 不在本计划范围内做任何变更。
- **失败定性**：V5.2 已执行结果是旧 TS 邻域 Stop 任务的**有效负证据**，保留只读，不作为 Endpoint Stop 的基线或反例。

## 2. 数据与标签

新标签 schema **`pes2ts_fullpath_nav_labels_v1`**（字段级定义见合同 §7，此处只列结构）：

| 域 | 字段 | 说明 |
|---|---|---|
| Move | `move_status` / `move_target_u` | 继承 R3 full-traversal 教师与合法性 mask |
| Stop | `stop_status` / `endpoint_stop_label` / `target_endpoint` / `d_end_angstrom` | Endpoint Stop 三态标签，**含 terminal 行** |
| Progress | `q_signed` / `q_status` | 分段 q + ordering 用 |
| Legacy | `ts_stop_legacy` | 旧 TS 邻域标签，**仅 ablation**，禁止用于新训练 |

- **d_end 定义**：`d_end = RMSD_K(X, X_target_endpoint)`（Kabsch 合法刚体对齐），forward→目标端点 B(P)，reverse→目标端点 A(R)；参考端点坐标只用于离线标签。
- **窗口**：**w_pos=0.10 Å / w_neg=0.30 Å 为候选**；D1 做 0.08/0.10/0.12/0.15 敏感性，**T1 前冻结**，选择标准 = endpoint recall@precision≥0.8 且起点/TS 误正例 ≤2%，**禁止按 AUPRC 挑窗**。
- **eligibility 独立**：Stop eligibility 完全独立于 Move eligibility，`terminal(no_future_contact)` 行 **INCLUDED** 进入 Stop 数据。
- **intent 对照**：同一几何的 (X_P, H_R→P)→Stop / (X_P, H_P→R)→Move 是核心监督，不得去重。
- **退化样本**：2 个 TS/端点几何近简并样本单独 flag/mask——`RXN_0000001174` TS d_end=0.066、`RXN_0000001675` TS d_end=0.019；报告含/排两种口径。
- **审计事实（实测，12034 行 / 50 曲线）**：
  - 旧 Stop 正例 405 行 / 196 个独立 (curve,node)，全部近 TS；
  - 200 个端点行 = 92 terminal（被旧入口排除）/ 90 ok（旧标签为负）/ 18 masked；
  - 1123 个 terminal 行距最近端点中位 6 节点；
  - 0.10/0.30 → 正例 1781（14.8%）、Mask 1854、每曲线正例 9/32/90、起点误正例 0、TS 误正例 2/100；
  - q 相关性：pooled −0.147 vs approach 侧 −0.793 / 曲线内 −0.932（exploratory，双侧池化混淆所致）。
- **旧标签处置**：旧 `pes2ts_e4_labels_v1` 保留只读，用于解释已执行的 V5.2 负结果；旧符号（`TSStopHeadV3`、`ts_stop_loss_v52`、`stop_label_from_distance_v52`）标注 `LEGACY_TS_STOP`，仅用于加载旧 checkpoint，不进入新训练。
- **禁止混入**：不确定、碰撞风险、预算耗尽、局部位移过小都不是 Stop 正例；碰撞/预算属于外部控制器安全逻辑，单独记录。

## 3. 阶段矩阵（stage-gated：前一阶段不过即停）

### D0 — 任务合同与标签审计（CPU，1–2 天）

- **版本/commit 钉死**：以 git tag `v52r-base`（HEAD 94b7da9）为代码基线，补齐 run record provenance 字段。
- **端点标签构建**：实现 `pes2ts_fullpath_nav_labels_v1` 生成（d_end、三态窗口、target_endpoint、退化 flag），输出标签统计 JSON。
- **起点/TS 误正例审计**：起点误正例须为 0；TS 误正例只允许已 flag 的 2 个退化样本。
- **泄漏检查**：重点复查 48 曲线探针问题（dev folds 0–2 仅 30 条 ok 曲线，疑触 sealed folds 3/4）；本阶段全部统计只用 dev folds 0–2。
- **拓扑一致性审计**：用 target bond-edit completion 审计"几何近但拓扑未完成"样本，不一致者进 Mask。
- **Gate**：终点正例进入 Stop 表；起点 FP=0；TS FP 仅为 2 个已 flag 样本；provenance 字段齐全；`scripts/agent_ops/docs_consistency.py --strict` 通过。

### D1 — 独立 Endpoint Head + Directed Ordering（CPU，1–2 天）

- 冻结 R3 编码器，只训 head；**EndpointStopHead 输入二选一：z vs key-pooled h**（head 输入选择，非架构扩容）。
- **基线**：constant prevalence / topology-completion logistic / key-distance HGB。
- **指标**：AUROC + AUPRC + prevalence 同报；起点误停止率；TS 附近误停止率；endpoint recall@precision≥0.8；跨 TS ordering。
- 窗口敏感性 0.08/0.10/0.12/0.15 在本阶段完成比较，产出冻结建议。
- q 正式探针：dev-only、intent 分侧（避免双侧池化符号相消），directed pairwise ordering 为主目标。
- **Gate**：AUPRC 置信区间下界 > prevalence；起点/TS 误停止率低；ordering mean >0.65、跨 TS >0.6。

### D0.1 — 标签与数据审计补强（CPU，v1.1 插入；**已完成 PASS**）

- 22 个 D0 拓扑异常行逐行 S/T/D 分类（预注册决策树）：**S=0 / T=22 / D=0**，全部 T（目标键编辑未完成）→ Mask（合同 §5.3 规则 5）；dev 8 / sealed 14（sealed 仅标签 QC 计数）。
- 对称性重算 `d_end_sym`（全表 12034 行，图自同构 + proper-rotation Kabsch）：**翻转 0/1781**（0.00% < 2%）→ D0 标签统计无需以 `d_end_sym` 重述。
- terminal provenance：1123/1781 = 63.05% 复核 PASS；terminal 与 non-terminal 正例 d_end 分布 KS=0.578 → **未来 rollout 报告必须分层**。
- 证据：`outputs/pesn/v52r/d0_1/`（gate `V52R-D0.1-LABELS` PASS 7/7）。

### D2 — 输入充分性探针 P0–P5（CPU，冻结 R3 编码器，v1.1 插入；**已完成**）

- 预注册 `probe_spec.json`（sha `71130e28…`）+ `p5_spec.json`（sha `945ab443…`），运行前冻结；MME：P1/P5 ≥ +0.10、P4 ≥ +0.05（配对曲线簇 bootstrap CI 下界 > 0）。
- 结果：P2 自检 PASS（0.99998）；**P1−P0 = +0.678 [+0.587, +0.754] PASS**；**P4−P0 = −0.079 [−0.136, −0.022] FAIL**；**P5−P0 = −0.085 [−0.153, −0.008] FAIL**（P5−P4 ≈ 0：标签定义非瓶颈）；P5 有效性 5/6（TS 帧入前向 basin：RXN_0000000238/02064/02309）；冻结 z/h ≈ prevalence 下限。
- 证据：`outputs/pesn/v52r/d2/`（`D2_PROBE.md` + evidence pack；xtb QC 50 次 / 46.3 s，预算内）。

### D2-G — 门评审（v1.1 插入；**已裁定 STOP**）

- 命中矩阵行：「P1 通过但 P4/P5 不通过 → task-ref 可学、task-chem 未证 → 不训练 Stop Head；task-ref 作为独立任务重新立项」。
- **T1 不授权**；不修改输入合同；P5 标签不冻结为 schema；详见[决策记录](../reports/PES2TS_V52R_输入充分性决策记录_20261021.md)。

### T1 — Move + Endpoint + Ordering 联合训练（**未授权——D2-G 裁定 STOP；以下为预注册文本，仅在新的门评审通过后生效**）

- R3 winner（F2-bidir）初始化；分阶段：冻结编码器 head warmup → 联合加入 Move（Endpoint/Ordering 独立评估先行）。
- 梯度余弦监控（encoder gradient share 校准 λ）。
- **消融**：endpoint label vs `ts_stop_legacy`；intent-off。
- **训练顺序**：冻结编码器 head warmup → Endpoint/Ordering 独立达标 → 联合加入 Move → 可选 q（λ_q>0 才开）。
- **Gate**：**Move ≤2% 退化为硬门**（RMSE/zero 相对匹配 R3 基线；不得以 Endpoint 指标交换）。**失败分类（v1.1 修订）**：`invalid_run` 仅限数据泄漏、协议违规、哈希不符、运行时错误；训练有效但 Move 退化 >2% 或 Endpoint/Ordering 未达门 = `scientific_failure`——记录并分析，不得丢弃，也不得标为 invalid；Endpoint 不明显低于 D1；TS 不误停。

### R — 全路径 rollout（CPU + 可选 xTB 松弛）

- **预算**：`B = max(40, ceil(1.5·L_key/0.08))`；依据：rollout 步数中位 22，71% 曲线 >20 步；20 步仅作历史对照，单独报 `budget_limited`。
- **TS 跨越**：生成帧投影回参考 IRC（K-RMSD 最近节点），弧坐标越过 s_TS 记跨越（IRC projection，诊断用）。
- **端点到达**：目标端点邻域判定 + **首次 Stop 的 d_end** 分布。
- free rollout 与 physics-relaxed rollout **分开报告**；teacher-oracle 控制臂（预算与教师路径对照）。

## 4. 损失与训练

\[
L = L_{\rm move} + \lambda_{\rm end} L_{\rm end} + \lambda_{\rm ord} L_{\rm ord} + \lambda_q L_q
\]

- `L_end`：Endpoint Stop BCEWithLogits（三态标签，Mask 行不计）；
- `L_ord`：同 curve + 同 intent 的 directed pairwise ordering（**跨 TS 构对允许**）；
- `L_q`：progress Huber 为**可选辅助**，**λ_q 默认 0**；不建立 q→Stop 依赖路径；
- **统一 batch + `move_mask` / `end_mask` / `q_mask`**：terminal 行进入 Endpoint/Ordering，**不进入 Move**；
- λ 由 encoder 梯度占比校准（探索范围 2–10%），不做大网格；
- Move guard ≤2% 为硬门；破防 run 若源于泄漏/违规/哈希不符/运行时错误 → `invalid_run`，若训练有效但退化 → `scientific_failure`（记录分析，不得丢弃、不得标 invalid）（v1.1 修订）。

## 5. 验收指标表（预注册候选）

| 维度 | 指标 | 门槛 |
|---|---|---|
| 起点 | 起点误停止率 | ≤2%，理想 0 |
| TS | TS 附近误停止率 | ≤5%（双口径：含/排 2 个退化样本单列） |
| 跨越 | TS 跨越完成率 | 相对 teacher-oracle 不显著低于 R3 |
| 终点 | 目标端点到达率 | 预算内相对 R3 提升 |
| Stop 位置 | 首次 Stop 的 d_end | 中位 ≤0.10 Å，报完整分布 |
| Move | RMSE/zero、sign、dead | 相对 R3 退化 ≤2%（硬门） |
| Progress | 全路径 / 跨 TS ordering | mean >0.65 / 跨 TS >0.6 |
| Stop 分类 | AUROC + AUPRC（同报 prevalence） | AUPRC ≥2× prevalence，CI 下界 > prevalence |

- 统计单位：**cluster bootstrap by curve（1000 次）+ 3 seeds（17/29/43）**；单折/单 seed 不得晋级；Stop 阈值在 inner-val 按目标 precision 校准后冻结。
- 窗口冻结记录：`w_pos/w_neg`、选择标准命中情况（recall@precision≥0.8、起点/TS FP ≤2%）与被拒窗口的指标表一并归档，禁止按 AUPRC 事后挑窗。
- free rollout 与 physics-relaxed rollout 分开成列报告；20 步预算结果仅作历史对照列，不参与达标判定。
- 模型输出最多称 `TS_candidate` / `endpoint_reached`；报告中"TS 验证/IRC 连通"字样只允许指向 OptTS + 频率 + 双向 IRC + 端点身份确认的独立流程。

## 6. 明确不做（红线）

1. 不做 approach-side filter / TS-directed Move / TS 附近裁剪（TS clipping）——三者均已正式撤回，见 ADR-0030 §3；
2. 不用 `d_key_TS` 或 TS 邻域定义 Stop；
3. 不用 q=0 定义 Stop；
4. 不把 `terminal`（no_future_contact）等同反应终点（terminal ≠ endpoint），也不借其排除端点 Stop 行；
5. 不以 20 步 rollout 判定 full-path 失败（71% 曲线预算不足）；
6. 不触碰 sealed folds 3/4，不做 OOD/Fit150+/V5.1b；
7. D1 通过前不做任何架构变更；
8. 不把 Model Stop / q≈0 / RMSD 接近声称为 verified TS/path。

## 7. 预算与顺序

```text
0) docs gate（docs_consistency --strict）+ 本计划冻结      ← 最先执行，不过不开工
1) D0 标签与审计            CPU 1–2 天    [PASS]
2) D1 独立 Endpoint Head     CPU 1–2 天    [gate FAIL——honest negative，信号在合法几何中、不在冻结 z/h]
3) D0.1 标签与数据审计补强   CPU 0.5–1 天  [PASS]（v1.1 插入）
4) D2 输入充分性探针 P0–P5   CPU 1–2 天    [完成：P1 PASS / P4、P5 FAIL]（v1.1 插入）
5) D2-G 门评审              1 h          [STOP：T1 不授权]（v1.1 插入）
6) T1 联合训练              未授权（D2-G STOP；≤12 runs / 2 GPU-h 上限文本保留）
7) R 全路径 rollout          未启动
```

- **阶段门控**：前一阶段 gate 不过即停，禁止跳级（不跳过 D0/D1 直接 T1/R）；
- 止损规则：任一 gate 失败即停止后续投入，回写失败证据到报告而非改 gate；
- 任何语义变更必须：新 ADR + 新合同版本 + docs gate 通过，禁止静默修改。
