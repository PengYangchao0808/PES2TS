## 0. 摘要与核心决策

**一句话**：V5 不是"训练一个离线 RMSE 最低的模型"，而是一次**覆盖不同神经网络范式、统一化学监督目标、严格统计比较的 Architecture Benchmark**；用最少无效实验投入，筛出**最适合 V6 真实量化反馈环境的 1–2 个网络架构**。

**本轮六问**（实验设计围绕它们组织）：

1. **表征**：低维反应坐标是否已经足够，还是必须完整 3D 分子图编码？
2. **记忆**：预测当前反应位移需要多少历史信息——单帧、局部窗口还是长期状态？
3. **架构**：MLP / CNN / RNN / Transformer / Liquid Network / SSM 各自的优势是什么？
4. **连续性**：连续路径状态建模在非均匀 IRC 采样下是否具有独立价值？
5. **泛化**：哪些架构在未见反应家族、较大分子和扰动轨迹上更稳定？
6. **部署**：哪些模型在有限参数、CPU 单步推理条件下真正具有工程价值？

**与旧路线（V5.3–V5.4 三网络对照）的差异**：不再局限于 MLP、GRU、CfC 三选一，也不堆砌热门模型；候选扩展到**五大范式、14 类网络**，并强制三层公平对照（参数量 / 训练预算 / 部署 CPU）。

### 0.1 一个必须首先解决的数学问题

在扩展模型数量以前，先修正旧 V5 中容易被忽略的数学定义问题：

> **IRC 轨迹并不能直接告诉模型"物理上最优的步长"或"什么时候启动 OptTS 最省钱"。**

IRC 能可靠提供的是：路径上的**局部方向、构型演化、相对进度、几何曲率**等监督信息。因此 V5 的学习目标必须拆成三个科学上合法的部分：

```text
Move    = 局部运动方向与指定路径间隔下的位移
Process = 路径阶段与参考 TS 邻域识别
Trust   = 离线预测风险（不是真实 QC 成功概率）
```

真正的最优步长、回退策略与 OptTS 成功概率，**必须由 V6 的真实闭环数据标定**。V5 只做这三个目标的离线 Benchmark，避免训练标签在科学定义上出问题。

### 0.2 V5 全阶段纪律

- V5 全阶段**只使用已保存的轨迹与量化数据**，不新增在线 xTB/DFT 计算，不开展强化学习。
- V5 的验收口径是**离线预测、泛化与部署成本**，绝不把"量化闭环成功率"作为 V5 验收项（该口径属 V6）。
- 阶段严格串行：V5.5 → V5.6-A → V5.6-B → V5.7-A → V5.7-B → V5.8；后一阶段配置只能由前一轮结果决定。
- 实验记录必须可复现：训练集版本、数据与代码哈希、完整配置、随机种子、参数量、训练资源、模型权重校验值。

## 2. V5.5：冻结统一数据、输入和监督目标

V5.5 的**硬性验收**：**数据、标签、随机划分及评估脚本均能独立复现。**

### 2.1 数据结构：轨迹级数据集

把目前 V5.3–V5.4 的**逐帧训练数据升级为轨迹级数据集**，四层结构：

| 层级 | 内容 | 用途 |
|---|---|---|
| **Reaction** | 反应物/产物图、原子映射、成断键、Family ID | 独立划分与化学泛化 |
| **Trajectory** | 计算方法、路径方向、参考 TS、路径采样方式 | 序列训练 |
| **Frame** | XYZ、已有 E/Gradient、反应坐标、路径弧长 | 状态表征 |
| **Decision** | 局部切线、参考位移、阶段与风险代理标签 | 监督训练 |

**数量口径纪律**：对原始 20k / 50k / 100k 及后续更大数据集，必须先区分它们究竟代表**独立反应、完整轨迹、构型帧还是训练决策**——这些数量不能混用（对应 §附录 B 的 V5.5 清点口径）。

### 2.2 统一路径数学表示

设反应图提供 `k` 个受控反应坐标：

```text
q_t = (q_{1,t}, q_{2,t}, ..., q_{k,t})
```

令 `s` 表示参考 IRC 的**累计路径弧长**（不是物理时间），定义参考切线：

```text
v*_t = (q_{t+1} - q_t) / (s_{t+1} - s_t)
```

实际训练时应采用合适的**局部差分或平滑导数估计**，避免非均匀采样和数值噪声带来偏差。

若 Classic 控制器给出参考方向 `v_C`，则模型学习**残差**：

```text
δv*_t = v*_t - v_C

预测：  v̂_t = v_C + f_θ(S_t)
给步长： Δq̂_t = Δs_t · v̂_t
```

这就是适合 PES2TS 的 **Residual Behavior Cloning**。

**两条关键纪律**：

1. 使用**路径切线**而不是直接拟合任意相邻 IRC 帧的位移，可以减少模型把"数据采样密度"误学成"化学运动速度"的风险。
2. **方向、步长分开评估**。V5 可以用参考路径曲率构造几何步长教师，但必须标记为**人工定义的离线代理目标**，不能称为最优量化计算步长。

### 2.3 两种输入模式必须分开测试

| 模式 | 可用特征 | V5 中允许的测试 |
|---|---|---|
| **G0：Geometry-only** | 分子图、XYZ、反应坐标、历史动作、路径间隔 | 单步、OOD、无 QC 几何 Rollout |
| **G1：Cached-QC** | G0 + 已保存的能量、梯度及其历史变化 | 单步预测、历史回放、特征消融 |

> **红线**：不能在 G1 模型的自主 Rollout 中，把原始 IRC 的梯度直接赋给模型新生成的构型——两者不是相同的物理状态。
>
> **执行顺序**：所有架构先在 **G0** 下主筛选；对入围模型再做 **G1** 对照。G1 训练结果为 V6 接入实时量化反馈提供更直接的初始化。

### 2.4 固定测试集（四个互不混淆的协议）

| 测试集 | 划分方式 | 检验问题 |
|---|---|---|
| **ID** | 已见家族中的独立反应 | 常规泛化 |
| **Scaffold-OOD** | 未见分子骨架与取代环境 | 结构迁移 |
| **Family-OOD** | 未见反应家族 | 机制类型迁移 |
| **Size-OOD** | 超出主要训练分布的分子规模 | 尺度泛化 |

**划分纪律**：

- 划分之前，必须把同一反应的**所有构象、正反分支、重采样、扰动衍生轨迹**归入同一个 Group（Group split，禁止帧级随机划分）。
- 数据归一化**仅使用训练集统计量**；最终测试集在模型选择完成前**封存**。
- 不规则采样和扰动测试是上述测试集上的**额外压力条件**，不是独立测试集。
- 公开 Transition1x 只作为后续扩展来源；它主要是 NEB 路径附近的 DFT 能量/力数据，**不能把所有 NEB 中间迭代构型当按 IRC 顺序排列的教师序列**。

### 2.5 冻结三类训练标签

（与 §1.2 一致）V5.5 交付物必须包含：

- `Move`：局部切线/位移、Classic 残差标签（含无未来步 `no_future_step` 的显式标注与 mask）；
- `Process`：路径进度与参考 TS 邻域区域（几何定义，非 OptTS 成功状态）；
- `Trust`：风险代理标签（大误差、OOD、几何异常），无真值处一律 mask。

### 2.6 V5.5 验收清单

1. 数据资产清点表（文件级：路径、大小、哈希、行数/帧数、版本、生成脚本）与四层数量口径一致；
2. 标签定义文档 + 标签生成脚本 + 单测；
3. 四个测试集划分清单（reaction_id 级 Group split），含泄漏审计（同一组不得跨 split）；
4. 评估脚本可在固定种子下独立复现同一批指标；
5. 归一化统计量仅由训练集计算并冻结（含 SHA256）。

## 3. V5.6-A：广覆盖的模型架构筛选

### 3.1 完整模型候选矩阵（五大范式 / 14 类网络）

| 编号 | 模型 | 代表范式 | PES2TS 测试价值 |
|---|---|---|---|
| M01 | Stateless MLP | 无记忆网络 | 单帧基础下界 |
| M02 | Window-MLP | 固定窗口映射 | 历史特征是否已足够 |
| M03 | Causal TCN | 时间卷积网络 | 局部历史和多尺度特征 |
| M04 | GRU | 门控递归 | 轻量历史记忆 |
| M05 | Time-aware GRU | 时间感知递归 | 显式不规则路径间隔 |
| M06 | LSTM | 长短期记忆 | 经典状态记忆对照 |
| M07 | xLSTM | 新型门控记忆 | 更强记忆结构的收益 |
| M08 | CfC | 闭式连续状态网络 | 非均匀采样与连续状态 |
| M09 | LTC | 连续时间 ODE 网络 | 连续动力学归纳偏置 |
| M10 | Latent Neural ODE | 隐状态微分方程 | 连续隐状态演化 |
| M11 | Tiny Causal Transformer | 自注意力 | 全历史上下文 |
| M12 | Diagonal Selective SSM | 轻量状态空间 | 选择性记忆 |
| M13 | S4D | 结构化状态空间 | 线性状态动力学 |
| M14 | Mamba-2 Small | 选择性 SSM | 现代状态空间结构 |

**说明**：补充 TCN / LSTM / xLSTM / S4D 是有意义的——分别提供卷积记忆、传统门控、增强门控、线性状态空间的独立对照。xLSTM、Mamba-2 的方法论文优势不能直接推断为对 PES2TS 更优。CfC / LTC / Neural ODE 检验三种不同连续状态建模方式；Neural ODE 必须单独记录**内部函数评估次数**与实际 CPU 延迟。

### 3.2 不进入主力矩阵的架构

| 架构 | 不进入 V5.6-A 的原因 |
|---|---|
| SNN | 适合后续独立研究事件决策；V5 缺真实回退/失败事件标签，不宜承担核心 Move/Process Benchmark |
| FNO | 更适合有明确函数场表示的问题；少数反应坐标 + 单条序列不构成其天然优势场景 |
| Flow Matching | 属输出分布建模/生成方法，应在 **Move Head 消融**中单独比较，不能与 GRU/CfC 当作同层网络对照 |

> 本轮广泛测试的是**记忆核心**，不是把每种机器学习技术都拼接成完整模型。

### 3.3 两级筛选机制

| 级别 | 规模 | 说明 |
|---|---|---|
| 初筛 | **14 架构**（覆盖五大范式） | 统一 Encoder + 约 0.1M 参数 Core + 相同 Heads；30–40% 反应子集（覆盖全部训练家族）；每种架构一个固定种子 |
| 正式入围 | **8 架构 × 3 seeds** | 完整训练集、三种子复现；确保不同范式都有代表 |
| 深度优化 | **4 架构** | 进入多容量及消融（V5.7/V5.8） |

**纪律**：

- 上面是**建议实验规模，不是已有训练结果**；初筛结果只用于选择值得进一步测试的网络，**不能作为正式架构排名**。
- 第一轮筛选的不只是验证 Loss，还包括：能否正常收敛、是否支持变长轨迹、能否保存隐藏状态并执行单步 CPU 推理、是否有不合理的额外运行依赖。
- 第二轮保留 6–8 个架构，完整训练集 + 三个随机种子复现；应确保不同范式都有代表，而不是因为筛选噪声提前淘汰整类方法。

### 3.4 深度 Benchmark 的公平性协议

| 对照方式 | 固定的条件 | 研究意义 |
|---|---|---|
| **参数量公平** | 相近 Core 参数预算 | 比较参数利用效率 |
| **训练预算公平** | 相同训练 token / 计算预算 | 比较获得性能的训练成本 |
| **部署公平** | `batch=1`、相同 CPU 环境 | 比较实际控制器推理效率 |

**统一训练纪律**：

- 统一 AdamW 主流程、相同超参数搜索次数、相同 early-stopping 规则；
- 为所有网络提供**同样可用的历史路径间隔信息**；
- 有状态模型：隐藏状态只在**同一轨迹内部**延续，禁止跨反应继承；
- Transformer：严格使用**因果注意力掩码**；
- **CfC 必须与 Time-aware GRU 对比**（而不只是普通 GRU），否则不能证明其优势来自连续状态机制，而可能只是多获得了一个路径间隔特征。

## 4. V5.7-A：架构确定后的四组关键消融

回答"模型为什么有效"：

| 消融专题 | 具体测试 | 核心结论 |
|---|---|---|
| **Encoder** | 低维反应描述符 / StarEGNN v2 / 局部反应子图 | 是否需要完整 3D 信息 |
| **Memory** | 历史长度 1 / 4 / 8 / 16 / 32 / 64 | 最小有效历史范围 |
| **Representation** | 绝对位移 / 方向+步长 / Classic Residual | 先验是否降低学习难度 |
| **Heads** | Move-only / Move+Process / Move+Process+Trust | 多任务学习是否提升 Move |

**附加消融**：独立的 `Δs` 消融——固定路径间隔 / 真实几何弧长 / 质量加权弧长；所有序列架构必须获取相同可用信息。

**重点检查 Classic Residual Learning**（与"化学规则限定合法动作、神经网络修正决策"的产品哲学契合）：

> 若最简单的 **MLP + Classic Residual** 已接近复杂 CfC 或 Mamba-2，说明关键收益可能来自**化学归纳偏置**而非复杂时间序列网络——这本身就是有价值的研究结论。

## 5. V5.7-B：真正区分架构的五项压力测试

模型最终选型以**泛化能力**而非单步平均 RMSE 为中心。

### 5.1 测试矩阵

| 实验 | 测试条件 | 主要评估 |
|---|---|---|
| **T1：单步预测** | ID 与 Family-OOD | Move RMSE、方向余弦 |
| **T2：历史依赖** | 1–64 帧历史 | 性能—历史长度曲线 |
| **T3：不规则采样** | 稀疏、随机间隔、历史缺失 | 误差恶化比例 |
| **T4：多步 Free-run** | 5 / 10 / 20 / 50 步 | 累计路径偏离、几何异常 |
| **T5：反应泛化** | Scaffold / Family / Size OOD | 反应级统计性能 |

### 5.2 多步测试的两条独立赛道

| 赛道 | 定义 | 边界 |
|---|---|---|
| **R0：低维反应坐标 Rollout** | 模型持续更新 `q_t`，不从参考 IRC 获取未来状态 | 检验模型能否稳定延续低维路径决策 |
| **R1：运动学几何 Rollout** | 固定非量化几何映射，把关键坐标变化转成 XYZ，再更新几何特征 | 只回答离线几何稳定性；**不能称为 xTB 约束松弛，不能宣称物理可靠** |

> 对 Cached-QC 输入的模型，可单独做 Teacher-forcing 回放；但禁止把参考路径的未来梯度当作模型预测构型的真实反馈。

### 5.3 最值得制作的三张核心图

| 图 | 横轴 | 纵轴 | 判读 |
|---|---|---|---|
| **Figure A** | CPU 单步延迟 | Family-OOD Move 误差 | 架构性能—CPU 成本 Pareto 前沿 |
| **Figure B** | 累计预测路径长度 | 标准化反应坐标误差 | 多步 Rollout 误差累积差异 |

## 6. V5.8：训练规模、轻量化与最终选型

### 6.1 容量与数据规模

对最有竞争力的 4 个模型增加参数容量比较：

```text
N_Core ∈ {0.03M, 0.1M, 0.5M}
```

对最终前两名增加**数据规模**比较；数据子集按**独立反应数与反应家族覆盖**构建，禁止简单随机抽取 20k/50k/100k 帧。

### 6.2 完整训练任务预算（建议上限 122 次）

| 实验阶段 | 训练组合 | 新增运行数 |
|---|---|---|
| V5.6-A | 14 架构 × 1 seed | 14 |
| V5.6-B | 8 架构 × 3 seeds | 24 |
| V5.7 容量 | Top 4 × 2 个额外容量 × 3 seeds | 24 |
| V5.7 Encoder | Top 3 × 2 编码器 × 3 seeds | 18 |
| V5.7 消融 | Top 2 × 4 项关键配置 × 3 seeds | 24 |
| V5.8 Scaling | Top 2 × 3 个数据子集 × 3 seeds | 18 |
| **合计** | **完整建议实验上限** | **122** |

**执行纪律**：不建议一次性启动全部训练；后面的配置由前一轮结果决定；重复配置应复用已冻结的权重与实验记录。

### 6.3 最终选型原则

**不要**简单加权平均分。选型顺序：

1. 先以 **Family-OOD 与多步 Rollout** 设定准确性门槛；
2. 在符合门槛的模型中比较 **CPU 性能、稳定性、维护成本**；
3. 选出 **Pareto 前沿**上的候选，给出进入 V6 的 1–2 个模型。

### 6.4 值得重点关注的结论模式

| 现象 | 判读 |
|---|---|
| MLP 与 GRU 接近 | 当前任务可能不需要复杂路径记忆 |
| GRU 显著优于 MLP | 历史状态对路径预测有实际价值 |
| CfC 优于 Time-aware GRU | 支持连续状态归纳偏置的独立贡献（仅对比普通 GRU 不够） |
| SSM 长路径稳定、短路径无优势 | 应判断实际 PES2TS 搜索是否真的需要长历史 |
| StarEGNN v2 提升有限但推理明显更慢 | 低维化学描述符可能更适合作为部署主线 |

## 附录 A · 术语表

| 术语 | 含义 |
|---|---|
| **CfC** | Closed-form Continuous-time network，闭式连续时间网络 |
| **LTC** | Liquid Time-Constant network，液体时间常数网络 |
| **SSM** | State Space Model，状态空间模型（S4D / Mamba-2 属此类） |
| **TCN** | Temporal Convolutional Network，时间卷积网络（因果卷积） |
| **xLSTM** | 扩展 LSTM（sLSTM/mLSTM 系列门控记忆结构） |
| **DAgger** | Dataset Aggregation，交互式模仿学习纠偏（V6 使用，V5 不进行） |
| **Teacher-forcing** | 用真实历史/参考标签喂入的教师强制推理方式 |
| **Open-loop Rollout** | 模型自回归延续、不回灌参考未来状态的自由运行测试 |
| **`C_valid`** | V6 有效 TS 定义下的验收指标（V5 不产出） |
| **Fixed-k / Step-RL / Subspace-RL / Joint-RL** | V7 四类受限/分层 RL 策略（本方案不涉及） |
| **Pareto 前沿** | 准确性—成本权衡下不可同时改进的候选集合 |
| **G0 / G1** | Geometry-only / Cached-QC 两种输入模式 |
| **R0 / R1** | 低维坐标 Rollout / 运动学几何 Rollout 两条离线赛道 |
