## 1. 目标、计数单位与完成定义

按用户承接上一轮建议的语境，本方案采用“IRC 20,000 个独立训练反应，RL 新采集 2,000 个独立训练反应的主 episode”口径。独立性按 canonical reaction group 去重；正逆反应、映射/对称副本和同反应构象不增加独立反应计数。若实际意图是帧/转移/参数更新次数，另行修订规模及预算，不能沿用本计划混计。

| 项目 | 本阶段数量目标 | 单独报告，不能替代目标的计数 |
|---|---|---|
| IRC | train_fit 中 20,000 个合格、去重训练反应组 | 轨迹分支、帧、方向有效帧、每 epoch 抽样次数、更新步数 |
| RL | 2,000 个新训练反应组，各执行一个有真实收据、到达明确终态的主 episode | 有效转移、非零命令、配对分支、重复运行、训练更新 |
| 开发评测 | 独立于拟合的 200 个反应组；中间仅使用固定 50 个子集 | 不计入 2,000 个训练反应 |
| 封存评测 | 暂定 200 组：100 IID 新反应 + 100 整族留出 | 不计入训练规模，样本量不构成功效保证 |

“完整运行”指尝试过程有闭合终态及账本，包含 complete、partial、failed、censored_budget 等，并不要求完整路径或严格 TS 成功。运行后的物理失败计入 2,000 次真实尝试，不能换题补成成功集。预检拒绝/未运行单独计数，不冒充已运行；不足 2,000 如实留缺口。旧 258 条转移可审计复用，但不计入本阶段新采集目标。

完成分三层：①数量与数据资格达标；②模型训练、冻结和可用能力证据齐备；③独立真实收益达标。①②成立、③不成立时，交付研究数据/模型及未达标报告，不能宣称控制效果改善。

## 3. 数据集合与防火墙设计

### 3.1 一张全局用途清单

S0 先冻结组身份、父 split、用途与排除清单，再读取新增教师真值或运行计算。沿既有隔离访问器与资格流程操作，不为达到规模放宽来源权限。当前 Demo24 是开发暴露材料，保留回归用途，不能成为封存独立评测。

| 集合 | 规划规模/用途 | 隔离要求 |
|---|---|---|
| IRC fit | 20k；2k/5k/10k/20k 嵌套子集 | 只从已有合格 fit 中取；原 2k 需重新核验后继承 |
| IRC dev | 固定现有 250 组 | 全程相同评测规则；不参与拟合/normalizer/支持阈值 |
| RL fit | 2k 新组；50/200/500/1000/2000 嵌套子集 | 可与 IRC fit 重叠，重叠关系公开，不因此成为独立教师泛化证据 |
| RL dev | 200 组；固定 50 子集用于前四次检查 | 不进入 IRC fit、RL fit、registry 或优势标签拟合；可与 IRC dev 同组 |
| calibration | 既有 calibration 用途集合 | 不自动改作 fit；支持容差使用 fit 内独立校准子集 |
| sealed IID/family | 暂定各 100 组 | 整组/整族从所有教师预训练、RL、校准和选择中排除 |

现有旧教师如已训练过拟选 RL dev/test 组，则重选集合或登记为暴露回归，不能通过更名恢复独立性。IRC 单任务 sealed 评测沿原教师方案另列，主预算不默认覆盖。

### 3.2 选择规则

依据已有端点/图/坐标资格分层，覆盖当前放行的反应类型、单/多 driver、原子数和端点制备难度；不看参考 TS 来挑“容易成功”或“接近 TS”的运行。每组主 episode 用确定性抽样表指定方向/起点，不将多个方向计为多个独立反应。

选择种子建议 42，模型确认 seeds 42/43/44。冻结选中集及候补顺序。候补仅用于计算前发现的资格缺口，追加事件和原因；已运行失败不替换，原选择分母始终保留。若某类型资格不足，不改支持范围硬凑比例，报告缺口。

产物：cohort_manifest、group_split_reference、cross_task_exclusions、development_exposure、rejections、source_hashes。每阶段报告 selected/precheck_qualified/attempted/terminal/complete_path/strict_success 全漏斗。

| 阶段 | 工作和数量 | 推进条件 | 核心产物 |

| S3 覆盖扩展 | IRC 10k；RL 累计200组；开发50×3 | 跨反应支持研究方案通过fit内校准和开发冒烟；无收益明显退化 | irc10k、rl200、support_transfer_report |

S1 的1+4冒烟共最多5个 episode，不计入 RL2000 主队列。S1/S2 未取得可重复的动作优势时，暂停策略扩训、诊断候选与监督；IRC 扩训可以继续。S3 不能跨反应适用时，先停止扩大 Q rollout，不能以全零回退结果宣布“RL2000已生效”。行为数据扩量如另有覆盖诊断价值，单独记录目的及批次，不混作 Q 验收。

S1/S2的状态采集有交接：先完成补修和5例冒烟，再启动S2主50的冻结行为采集及开发50的rule_zero分支以捕获真实完整快照；这些运行已经计入主采集/开发预算。随后完成S1配对与优势门，再训练S2的BC/Q并执行开发剩余两组。不能从缺必要历史的旧记录猜快照，也不额外重复同一批基线以制造配对起点。

## 6. 动作支持与跨反应适用：扩量的关键前置

现 registry_v1 以同反应/ControlSpec严格匹配，预算context容差1e-6、几何约0.001147 Å。增加反应数不会自动让陌生反应候选获得支持，历史自查询不能当泛化证明。

建议分两层研究，旧 v1 的含义和历史包保留：

1. **同反应局部支持**：用于修复验证、历史真实状态与独立分支比较。对新fit反应先以Classic/已有合格有界探索采集行为数据，轮间离线构建新registry再冻结；不在episode内在线更新支持域或权重。
2. **跨反应支持候选**：拟新版本，按有序driver类型、编辑模板、单位/尺度、方法/电子态、归一化目标和预算上下文及因果图/几何特征匹配。几何/动作坐标对应、旋转/原子重排处理先验证；不能仅删reaction_id/spec_hash或用模型embedding近邻代替物理相容性。

跨反应校准在fit内留反应/留模板子集，阈值只从fit校准；RL dev是冻结规则的诊断集，不反向成为邻居/阈值拟合集。拟用编码器特征时绑定encoder/feature/normalizer hash，换encoder先重建并复验registry。

验收至少包括同语义换原子顺序不变、不同driver/尺度/电子态/恢复条件拒绝、陌生组不误入训练、TD和执行同规则、距离/邻居/接受原因留痕及真实QC局部收益。对未覆盖状态保持明确Classic回退；有界行为探索按独立已验收规则执行，其记录可供以后学习，不能假称当前Q已支持。

每次真实运行报告：合法候选数、有限Q数、支持候选数、具有合法非零候选的决策数、非零被支持/被选中/实际执行数、失败/回退原因。开发中有非零候选的决策若≥90%仍全被支持门过滤，触发诊断暂停，不能强制提高非零比例。90%是本方案诊断阈值，不是支持有效性保证或优化目标。

## 7. IRC 20k 训练配方与资源小试

### 7.1 数据与规模对照

2k/5k/10k/20k固定嵌套fit集合，同一个250组dev、标签定义、反应权重与模型结构。轨迹各分支/方向/近TS/中段/末端分层；长轨迹不增加反应权重。TS/未来邻帧只存在隔离教师观测/标签侧，不用于在线控制起点、特征或RL转移。

按现有平均约116帧/反应粗估，20k可能导出约230万fit帧；实际以标签资格和manifest为准。采用分片/惰性读，测NPZ解压、float64展开、缓存/prefetch和峰值内存，不能按磁盘文件大小估RAM。

### 7.2 第一条基线配方

沿现有独立配置：hidden64、3层、basis16、cutoff5 Å；batch_reactions8、frames_per_reaction12、pairs8、margin0.05；lr3e-4、weight_decay1e-4、clip1、max_epochs50、patience8；任务权重s1/d0.5/rank1/direction0.5/activity0.2/symmetry0.1。不同时改标签/损失/容量。

先seed42完成各规模学习曲线；2k与20k候选再用42/43/44确认，最多8个主训练run（4档seed42+2档额外两seed）。规模对照从同一种初始化规则独立训练，旧2k既有包作为历史参考；2k→20k继续训练可另作warm-start实验，不混入纯规模收益。教师epoch抽样约20k×12=24万次帧使用，不能称24万个独立反应。

如新增动态重采样/方向类平衡，单独版本；现固定分层采样不能假称所有230万帧每epoch全部使用。开发指标按反应等权，掩码、有效反应数及95%组级区间一并报告。

### 7.3 资源冻结

先选合格fit内200组试读，再2k一个真实epoch测吞吐、峰值RAM/VRAM、I/O和训练恢复。20k同配方约2500个batch/epoch、最多125000个更新；初估 T20k ≈ 10×T2k_epoch×实际epoch数，仅为同硬件/采样下的推算，开发评估与读取另外计时。

旧记录无可靠训练耗时/资源，不能给出确定“几小时完成”。WSL已有pes2ts环境及torch 2.14.1+cpu是此前证据，启动前重新探测版本/设备；Windows默认环境不能直接当训练环境。GPU可用性未知，不承诺GPU加速。

资源小试冻结cpu/gpu小时、内存、磁盘和run数上限。建议峰值内存不超过可用资源70%，数据/检查点剩余磁盘≥预估新增量20%裕量；达限先调整加载/batch并记录公平性影响，不触发无限重试或自动安装环境。训练/构建不新增QC的前提是使用已有合格IRC源；缺轨迹不默认新算20k条DFT IRC。

## 8. RL2000：真实采集、配对监督和轮间更新

### 8.1 采集批次

累计目标50/200/500/1000/2000，对应新增50/150/300/500/1000组。每批先冻结行为策略、模型包、支持registry、环境/奖励、候选/探索seed和实际预算，再采集。新组无Q支持时以规则/已有合格探索产生数据并显式标行为来源，不把fallback归因于模型。

首批沿epsilon0.1 Å、探索概率0.25、最多8候选、模型缩放0.5/1.0的已核验配方；实际尺度符号及合法范围由ControlSpec决定。首两批不加大探索幅度或增加候选以硬凑非零。失败、拒绝、恢复和预算删失都保留；非法或身份错误记录隔离，不进入学习。

在fit主运行中按冻结观测规则留困难状态：多driver耦合、反复拒绝、细分、恢复、预算紧张。采样依据当时观测，不读取未来轨迹或参考TS。相同模板不过度重复；每反应/每episode/每失败类型平衡采样权重，报告长轨迹占比。

### 8.2 成对动作证据

S1 fit32状态，每状态零动作+2个合法非零；8个状态追加零动作重复，共104宏步。dev16状态同样三动作，4个追加重复，共52宏步。合计156个诊断分支，源状态不足则报告缺口。

条件绑定包含几何/原子映射、pending逻辑目标、剩余预算、恢复队列、规则/环境/奖励及执行种子。分支各自费用单列；主运行共享起点制备只计一次。先按完成/质量/推进量判断，再比较全恢复费用；差异未超过零动作重复波动视为平局。

配对fit只用于优势监督；配对dev只用于早停/诊断。单步诊断、分支与主episode具有不同身份，不默认把它们拼入Bellman后继。新增配对实验超出156时另开预算清单。

### 8.3 离线训练与模型冻结

基线hidden64/3层、batch16、lr3e-4、max_epochs60、patience8、CQL alpha1、imitation_weight0.5、target_sync4沿用纠错配方；编码器先冻结。每档在同一数据/支持/环境上训练真实BC与CQL；Q专属参数及编码器前后变化、optimizer参数、epoch/更新、训练资源完整留证据。

正模仿优先有真实成对优势且合法的命令；失败/劣势可供Q学习，不全部丢掉；旧41条受限BC数据不能补写优势标签。优势旁车与原reward分别版本化，改变reward不无条件混训旧转移。

episode索引采用round/episode/branch/decision完整身份；预算截断、自举资格与next_context按实际记录处理。TD与执行用同一冻结registry，不支持的后继候选不参加max，终止/无有效候选原因留痕。

每档seed42做BC/Q两run，共最多10个主run；1000/2000档的候选再用43/44确认，最多额外8个离线run。额外seed不默认增加真实QC对照；如要验证运行seed稳健性，单列资源。扩数据不自动增加epoch，先看反应等权dev和梯度/TD稳定性，任何batch/loss改动单独对照。

## 9. 表示迁移与容量调整顺序

在固定同一份RL数据上比较：旧2k encoder冻结、新20k encoder冻结、新20k encoder小学习率微调。先做离线/配对dev诊断，选择一项进入下一批；建议encoder_lr为head_lr的1/10起步，但当前接口需显式实现参数组与验证，不能写配置后假设已生效。

数据规模主线保持hidden64/3层。仅当20k仍欠拟合、方向能力低且学习曲线/迁移诊断支持时，条件增加hidden128/3层；不能直接把64维旧权重载入128维模型。重新预训练相容encoder并统计实际参数和资源。attention/第4层各自作为后续单因素实验，不与宽度/标签同时改变。

宽度/attention、更多seed和encoder迁移真实QC都不包含主预算；新增消融先做最多两run小试、固定fit内选择，实测后登记预算。默认不扩到百万级模型。IRC指标变好、下游控制未改善时，优先诊断动作监督、状态、候选和支持覆盖。

以下性能数值为预注册研究目标，沿上一轮建议，不是效果承诺；正式出口始终引用宪法。硬正确性门不能因指标好看而放宽。

| 指标 | 当前值/口径 | 本阶段目标/判定 |
|---|---|---|
| IRC fit独立反应 | 2000 | 合格去重20000；报告帧/标签缺失，不用重复采样凑量 |
| IRC direction cosine | 0.39726，反应等权dev | ≥0.55；有效反应数、方向/类型/位置分层及区间 |
| IRC activity F1 | 0.55371 | ≥0.65；PR-AUC同时披露，正负率/阈值按既有规则冻结 |

| RL 主运行规模 | 新批0 | 2000组有真实尝试终态；失败算尝试，不算路径/TS成功 |

支持率/非零比例仅诊断，不设“非零越多越好”。同时报告无非零合法候选的决策，不能通过改变分母提高覆盖。

停止规则：任意身份/用途/合法性硬门失败立即停该子批并保留结果；预算或资源到限停止；开发真实失败率明显增加或完整率下降先暂停查因；连续两档在预注册主要指标（开发配对排序、全输入费用）均无超出波动的改善，停止继续RL扩量。IRC连续两档学习曲线无改善则暂停更大规模训练，先诊断标签/采样/优化和容量，不重读sealed调参。

S0在读取新增结果前冻结最小实际改善量、重复波动容差和严格成功率非劣界δ；首批开发可用于估计方差/样本量，之后每批配置在运行前冻结。不得根据sealed结果调整阈值、样本定义或模型再测。

## 11. 评测设计与归因

开发检查：50、200、500、1000累计档各在固定dev50跑rule_zero/真实BC/residual_Q；2000档在完整dev200跑三组。每组相同起点、方法、Shield、预算和恢复规则，调用顺序交错；缓存/冷启动披露。模型在每批内冻结，不逐步更新。

主线上每档只选一个BC和一个Q候选参加真实评测，其他seed先做离线确认。教师数据、RL数据、策略与模型同时变化时报告联合系统变化；要声称某组件贡献，固定数据/协议做单因素对照，不将阶段前后差自动归因于IRC或参数量。

S7固定最终三组，在sealed暂定200组跑一次，IID100与family100分开报，不只报混合平均。提前以开发方差、最小节约及非劣δ做样本量设计；200是预算起点，不保证95%区间能判定收益。可先封存更大候选池；不足功效时在看sealed结果前调整n和预算，否则如实写证据不足。

按canonical组配对重采样，提供费用比与严格成功率差的95%区间，统计失败/删失；单seed完整系统结果不能替代多seed稳健性。若严格链未放行/预算未落实，仅报告扫描proxy与gated，不宣称正式G4收益。

严格验证沿现有ReviewRecord/准备层/ACP能力门，不能因RL尝试数达到2000自动执行。需要完整记录受限DFT preparation→OptTS→目标模态Freq→双向IRC→端点极小值/身份；未运行项为unattempted/gated，不算验证失败。若只严格验证预筛少量候选，不能把未验证输入当负例推断全输入严格成功率非劣。

## 14. 研究依据与适用边界

[CQL原论文](https://proceedings.neurips.cc/paper/2020/hash/0d2b2061826a5df3221116a5085a6052-Abstract.html)支持关注离线数据/策略分布差异与保守估值；本项目额外的状态/动作支持与跨反应语义仍需自己的真实证据。[RL统计评测研究](https://arxiv.org/abs/2108.13264)支持区间和稳健汇总；本计划按反应组而非帧作独立统计单位。论文不保证化学控制迁移，20k/2k数量本身不保证达到研究目标。
