## 1. 用户目标与研究判断

用户希望减轻规则对学习和探索的限制，使拉伸过程自主形成反应路径，最终与 IRC 相符。建议研究“目标反应条件下的自适应路径生长”：模型决定当前节点下一步往哪走、走多远，物理优化决定垂直于推进方向的松弛，鞍点与 IRC 由真实验证给出。

本方案将自由度从“固定扫描目标上的小残差”提升为“局部生长方向和步长”。先研究已知反应物/目标产物图的定向导航；仅给反应物的未知产物发现另立任务，不混用成功分母。

不主张立刻删除全部门并运行原离线 Q。当前 Q 的数据、动作定义和支持域都属于旧环境，关闭过滤不能使未经训练的值函数自动可信。

## 3. “自然生长出 IRC”的科学含义

IUPAC 将 IRC 定义为质量加权坐标中的最小能量反应路径，经 TS 连接反应物与产物。常规验证从 TS 沿目标不稳定模态向两个方向微扰，再沿梯度下降检查连接关系。[IUPAC](https://goldbook.iupac.org/terms/view/IT07057)、[ORCA IRC](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/irc.html)

因此交付分三层：

1. **自主生长轨迹**：没有预先规定每一步距离目标的连续轨迹。
2. **候选低横向力路径**：节点经局部横向松弛，具有可审计的力与费用；这仍不能宣称是 IRC。
3. **严格验证链**：候选精修到一阶鞍点、目标虚频模式、双向 IRC、端点极小值/目标 R/P 身份。只有这层确认反应连接。

在极小值处梯度接近零，自由几何优化不会自行爬出反应物盆地。搜索阶段仍需要推进方向、路径约束或鞍点算法。生长路径可以先上坡再下坡，不能把能量上升本身作为失败，也不能把高能峰作为成功。

对于多步反应，允许发现中间体；各 elementary step 分别找 TS/IRC，不要求一个鞍点连接整个多步总反应。初期聚焦绝热、单一电子态与现有方法覆盖；跨自旋/非绝热过程不套用同一验证口径。

## 4. 规则逐项处置

| 当前机制 | 新分支提议 | 原因与检验 |
|---|---|---|
| 固定 21 点 lambda 与端点距离插值 | 用实际已接受节点构成路径，按局部状态选下一动作 | 检验固定路线是否迫使分子走高应变支路 |
| 多 driver 按同一进度同步变化 | 各距离独立、也可联动；允许有预算的小幅反向和回退 | 允许异步成键/断键及构象调整 |
| 只在规则目标上加残差 | 直接给出下一步局部坐标增量和步长 | 模型获得路径形状的决定权 |
| 同 reaction_id 历史支持作为探索准入 | 新 on-policy 探索入口不以历史相同反应为准入条件 | 新动作通过真实计算产生经验；不复用旧 Q 冒充可信策略 |
| 不确定即全回退规则 | 可在小信赖域内花显式预算探测；高不确定性限制步长/增加观察 | 未知不等于非法，但探测不是免费 |
| 所有非 driver 变化都严格拦截 | 初始冻结反应中心及合理邻域的活动范围；非必要局部变化先诊断/软罚 | 氢转移、配位或构象运动需相应活动变量；副反应保留并标 wrong_target |
| 固定共价图作为所有中间帧的判据 | 目标图用于终点身份；中间帧允许连续键变与过渡配位 | 原始图不得成为把真实 TS 拒掉的理由 |
| 原子映射、元素/电子态、单位、数值有限性、灾难性重叠 | 保留独立检查 | 使动作与真实计算结果有确定含义 |
| QC 失败、预算和收据身份 | 保留并累计计费 | 防止无限重试和失败样本消失 |
| 参考 TS/IRC 真值隔离与严格科学验证 | 保留 | 目标是发现并验证路径，参考答案不作为在线导航输入 |

每次规则消融记录：proposal、修改/拒绝原因、实际执行动作、原规则在同节点会怎样判定。先统计每种门造成的损失，避免一次关闭所有约束后无法归因。上述改变均为新研究环境，实施时沿宪法 §12/版本接口审查，不原地改变旧 registry 语义。

## 5. 新环境：模型推进，物理松弛

### 5.1 观测

状态包含当前几何/目标反应图、真实同层级能量和梯度、前 2–3 个已接受节点与切线、独立坐标值、已用预算和拒绝/恢复历史。全路径摘要用于标记循环及已访问状态。该观测仍是对历史的有限表示，先视为 MDP 近似，检查同输入不同历史是否导致不同后继；必要时加入显式路径记忆。

当前能量/梯度是当次 QC 观测，不是隔离参考轨迹标签。不同理论层级能量/梯度不混合成一个连续 PES，方法变化建立新环境。

### 5.2 初期动作空间

从反应编辑与当前结构定义约 4–12 维低维内坐标空间：先支持独立距离及其联动，再验证角/二面角。活动区与候选坐标由非真值输入生成并冻结规则；活动区外原子可以物理松弛，不等于冻结 Cartesian 坐标。

动作由 `advance(方向, 步长)`、`relax`、有限 `rollback`、`propose_seed`、`stop` 组成。方向不要求与端点直线平行。第一版使用离散局部方向候选的随机策略，便于准确保存采样概率；之后才评估连续策略。

距离步长暂以 0.02/0.05/0.10 Å 作小试候选，不作为已校准默认。角度/二面角另设单位与尺度，不能复用 Å 阈值。实际 Cartesian 位移、原子最小间距和信赖域另核验；坐标雅可比退化时做 rank 检查并拒绝/缩小动作。

### 5.3 一步执行

1. 模型根据当前观测采样下一方向和步长。
2. 在物理信赖域内构造几何预测，记录提议与实际位移。
3. 用临时路径切向约束固定本次推进量；其余方向由真实梯度松弛，而不是把所有 driver 锁到旧端点插值值。
4. 接受后新增节点，更新切线、活动状态与预算；失败保留原因和费用，可按策略缩步/回退，不能重置 episode。
5. 有足够 TS 候选证据时提交种子；独立精修与 IRC 验证决定是否成功。

数学示意：去掉整体刚体自由度后的质量加权坐标为 y，单位切线为 t，真实梯度为 g_y。候选的横向梯度为

\[
g_\perp=(I-tt^\top)g_y.
\]

推进后，在本次局部横截面和信赖域内减小横向梯度。多约束情形用相同度规下的秩感知投影，不能把阻尼逆称为精确投影。切线更新、曲率和内部坐标映射都需要实际验证；g_perp 小不保证全梯度为零、不证明已找到 TS，也不保证全局最小能垒路径。

这借鉴 growing-string 的逐节点增长与路径松弛思想，但加入的 RL 决策需独立对照验证；不是声称已实现某个文献算法。[单端 GSM 原论文](https://doi.org/10.1002/jcc.23833)

### 5.4 路径后处理与验证

冻结生成轨迹后，可以选择独立的 string/NEB 路径精修，再取候选做 TS 优化。后处理对所有对照组同配方、同预算，分别报告原始路径与精修路径，不能把后处理的收益全部算给 RL。[ORCA NEB](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/neb.html)

低成本 PES 的轨迹与高层级 DFT IRC 可以不同。低成本阶段找种子，高层级阶段重新精修和验证；分别报告层级。多条合理路径/分岔时不强迫匹配唯一参考序列。

## 6. 学习路线与奖励

### 6.1 算法选择

旧 CQL/registry_v1 保留作冻结对照；不直接把旧权重用于新动作空间。新分支采用低维、分批 on-policy actor–critic，PPO 作为第一项待比较实现：批内策略固定，收集真实轨迹后更新，再冻结下一批。PPO 的采样/优化机制见[原论文](https://arxiv.org/abs/1707.06347)，其机器人基准结果不保证化学任务性能。

第一步先把路径环境做通，并运行无 RL 的同动作随机/自适应控制。若这些已显著改善，先量化环境改动贡献，避免误归因给 RL。首批 605 转移只在相同语义下用于诊断或表征初始化，不能按新奖励/新动作无条件混训。156 配对中 fit 分支可以构建局部偏好初始化，dev 分支不进入拟合；局部宏步优势不自动等于长程成功优势。

策略预测每个合法方向候选的 logit，经 softmax 得到采样概率；熵项帮助保留探索。合法候选没有历史同反应记录仍可被采样，但会实际消耗 QC。记录采样前/后 mask、原始提议、执行动作及 log-probability。若宿主修改动作，要么重建明确的执行分布，要么将该样本隔离，避免 PPO 概率与执行动作不一致。

### 6.2 奖励草案

采用“任务结果 + 局部进步 − 实际成本 − 无效行为”的分层目标。草案为

\[
r_t=\beta\,I_{\text{strict target verified}}-\lambda_c C_t
+\eta[\Phi(s_{t+1})-\Phi(s_t)]
-\lambda_l L_t-\lambda_f F_t.
\]

其中 C 为冻结单位的累计计费增量，L 为重复/停滞成本，F 为数值失败或错误目标事件；Phi 是仅用当前和历史可观察量构建的有界潜势。潜势可研究目标拓扑进展和局部松弛质量，权重/尺度只用 fit 校准。终态潜势统一置零并正确处理回退，防止奖励循环；不宣称有限预算、部分观测、近似优化下必然策略不变。

局部质量不依赖未来参考 IRC、不只奖励能量下降、不按弧长/高能峰给持续正奖励。检查零步、往返、跳过困难目标、过早停止等反例，避免以少走路换低成本。

严格验证昂贵：先用明确标为 proxy 的局部奖励和独立配对偏好调试；进入成功学习阶段，预先冻结训练种子提交/严格验证策略，所有符合提交规则的训练提议均按同一预算核验，不能只验证少量好看的结果再把未验证样本当失败。验证费用计入对应 episode 的完整成本；未验证记 unknown，验证预算耗尽记 censored，不编造正/负标签。proxy 阶段不称已学到 IRC/严格成功价值。

可额外比较严格验证成功率固定预算最大化与代理奖励两种目标，不把奖励改动收益混在控制器消融中。

## 7. IRC 数据怎样使用

- 现有合格 IRC 数据仍只在隔离离线侧用于结构编码、局部切向方向等监督；任何新标签先核对已登记来源/用途。
- 训练反应与开发/封存按 canonical group 隔离，教师预训练也排除相应独立集合。
- 同一理论层级的生成路径与事后 IRC 比较端点身份、对齐/弧长重参数化后的路径偏差、切向一致性及能量轮廓；全部属于诊断，不能替代严格连接验证。
- DFT 教师到 xTB 的迁移单列，沿目标方法真实梯度判断局部松弛，不把 DFT 参考坐标或能量在线反馈给 xTB 搜索。

## 8. 实施顺序与首个小包

本表是新的研究预算建议，不是现有流水线执行命令，不因本次文档开始消耗。

| 顺序 | 工作 | 交付/推进条件 |
|---|---|---|
| 1 | 门诊断与新环境合同 | 原始失败归因、独立坐标/动作语义、分支/预算/方法身份；架构决策与新版本登记 |
| 2 | 无 RL 路径生长 + 梯度接缝真实小试 | 新轨迹能推进、回放和预算可核对；尚不要求收益 |
| 3 | 12 个 fit 反应 × 2 次探索 | 获得实际新动作响应；合格失败保留；fit 配对偏好初始化 |
| 4 | 分批 on-policy 训练，离线 3 个初始化种子筛选 | 训练/动作概率一致；与同环境无 RL 控制对比，dev 不调奖励 |
| 5 | 8 个 dev 反应 × 4 组 × 2 个运行种子 | 原始方法、无 RL 自适应、同空间随机、新 RL 的配对比较 |
| 6 | 严格验证与路径诊断 | 验证策略和预算在看结果前冻结；目标 TS/双向 IRC 与成本齐备后考虑扩量 |

第一批预算建议：

| 子批 | 运行数 | 每运行上限 | 串行包络/请求上限 |
|---|---:|---|---|
| 接缝小试：4 fit × 自适应/随机 | 8 | 180 秒、60 请求 | 24 分钟 / 480 |
| 新策略探索：12 fit × 2 | 24 | 900 秒、120 请求 | 6 小时 / 2880 |
| 开发四组：8 dev × 4 × 2 | 64 | 900 秒、120 请求 | 16 小时 / 7680 |
| 以上合计 | 96 | 到任一限额结束并留终态 | **22 小时24分 / 11040 请求** |

训练、起点制备、路径后处理、TS/Freq/IRC、Hessian/数值导数另列实际预算并纳入总成本；表中不是全任务成本或日历预测。一个数值梯度/优化/Hessian 内含多个后端计算时不能靠包装成一个请求隐藏费用，需同时核对原始工作量、wall 和 ACP 收据。小包实测后冻结后续上限。

上述 fit/dev 从现有合格用途名单中预先选定、按困难程度分层；运行失败不换题，不用只有完整的反应挑测试集。不得使用最终 sealed 作快速迭代。初步 8 个 dev 只是诊断样本，不能证明广泛泛化；确认阶段再扩大并做组级区间。

## 9. 对照、验收和停止判断

四组共享起点、理论层级、实际总预算与后处理：

1. 原固定网格/现有残差冻结基线。
2. 自适应路径生长、没有 RL 的物理/几何控制。
3. 与 RL 相同合法动作空间和松弛器的随机策略。
4. 新 RL 策略。

组 1→2 估计解除路径限制的贡献，组 3→4 估计学习贡献。候选产生、回退、物理松弛、严格验证协议固定；探索方差通过运行种子单列。若补充 NEB/GSM 文献算法比较，保证实现与费用口径可核验，不能拿未运行的理论数值作基线。

报告完整漏斗：selected/prepared/attempted/accepted nodes/wrong target/seed proposed/strict attempted/strict success/unknown/censored。完整扫描率换为路径任务的对应指标后，不与旧 21 点覆盖率直接混比。

主要结果为固定总预算下严格目标成功数/率和达到相同质量的全输入费用；同时报告原始路径/精修后路径质量、横向梯度、无进展/循环、规则拒绝率、动作分布与探索覆盖。对每个分子按反应组配对汇总，不能把节点当独立实验。成功率差与费用比的最小有意义改善和非劣界在看开发结果前按 fit 小试冻结，不预设 8 个 dev 有统计功效。

若自适应组改善而 RL 没改善，结论为路径环境改进，不宣称 RL 有效；若增加自由度主要增加副反应/预算耗尽，先诊断活动子空间、松弛质量与目标，不继续盲目扩量。若 RL 仍无动作多样性，检查执行 mask 与概率，而非强行增加非零奖励。

至少一例完整严格链可以证明工程链路，但不是普遍收益证据。只有独立评测和全费用支持时才声明收益，仍沿宪法 R2/R5。

## 10. 代码落点与依赖

- `generation/planning`：新增自适应路径宿主、活动坐标与状态/方向/横向松弛逻辑；复用质量检查/回放/成本机制，但重新审查旧固定 manifold 的假设。
- `pesn/contracts/models/inference`：新路径状态/动作合同、候选随机策略和价值头；保持纯推理，不承担 QC 或化学裁决。
- `pesn/offline`：新 on-policy 轨迹与 log-prob loader、fit 偏好构建、actor–critic 训练、分组评测及导出。
- `integration/acp`：复用已存在的 ORCA gradient request/transport 和真实梯度收据；现有文件存在不证明新松弛环境已冒烟。
- ACP 侧能力核查：GFN2-xTB 能量/梯度、所需临时切向或内坐标约束、TS/Freq/IRC、方法/电子态/原子序和缓存摘要一致。缺什么登记接缝依赖，不直接启动另一个 QC 后端绕过。
- 旧包、旧奖励和轨迹不覆盖；新状态/动作/支持与环境身份在实施前版本化。新方向按现有导航职责研究，若转成独立 Cartesian TS generator 或通用反应发现器，则另作架构决策，不默认扩大产品定位。

## 11. 近期建议

优先做固定网格与 driver 同步规则的消融，并将同反应支持限制从新 on-policy 探索入口移开；先验证无 RL 的自适应生长是否已有改进。随后用新采集和 fit 配对证据训练策略，以独立严格连接/全费用检验。近期 RL 扩量先服从这条研究结果，不把新分支失败/配对/重复计成 RL2000 的新独立主反应。

目标是形成“自主生长路径 → 物理松弛 → TS 候选 → 严格 TS/IRC”的证据链；不能承诺解除规则后轨迹必然等于 IRC。
