## A. 统一后的项目结论

当前主线为：**无序 A/B 双端点拓扑条件 → 完整 A→TS / B→TS 教师 → 逐点真实 xTB E/g → 规范化 EGNN → BC → 相容环境 IQL**。目标是向 TS 推进；A/B 为身份编号，不代表天然正逆方向。SAC 保留为 G4.1 后续条件任务，本阶段不启动。

项目总体仍沿 G0–G4，不另建阶段。教师拟合、无参考纠正的自由运行、严格成功分开验收。严格成功仍依 OptTS、目标模态频率、双向 IRC 和无序目标端点对身份确认；DFT 参考 TS 不是自动的 xTB 鞍点。

本文 A–H 负责项目进度、依赖、归属和版本衔接；§I 保存用户确认的完整技术规格。接口字段与隔离边界登记在[合同 v2 草案](../contracts/PES2TS_双端TS教师与相容转移合同_v2.md)，规范适用见宪法 §6.7。旧计划未冲突的资源保护、ACP、严格验证接缝可参考，旧任务的超参/终止/门槛不自动继承。

## I. 用户确认的完整技术规格（原文保留）

以下为本次输入的技术规格原文。其“尚未修改代码、重建数据或启动补算”适用于该技术版本；本次新增的是上文的进度映射及文档登记。

本阶段最终采用 **“无序 A/B 双端点拓扑条件 → 完整双侧向 TS 教师数据 → 逐点 xTB 观测 → 规范化 EGNN → BC → 相容环境下的 IQL”**。

A/B 仅为端点身份编号，不表示反应物、产物或天然正逆方向。模型的运动策略由**当前结构、拓扑任务和物理观测**共同决定；“向 TS 推进”是本阶段的学习目标。

以下作为最终实施规格。尚未修改代码、重建数据或启动补算。

---

**1．阶段目标与交付物**

本阶段完成四项交付：

| 交付物 | 内容 |
|---|---|
| 双端教师数据集 v2 | 完整 A→TS、B→TS 路径及动作、辅助标签 |
| 物理观测与特征规范 v2 | 节点级 xTB E/g、单位、身份、归一化和缺失规则 |
| BC v2 | 能在独立反应上预测合理动作与方向的冻结模型 |
| IQL v2 | 在动作、后继、奖励和终止语义一致的环境中检验策略改进 |

明确区分三种结果：

- **教师拟合**：模型能否模仿参考路径。
- **自由运行**：不用参考下一帧纠正，模型能否持续产生合理结构。
- **严格成功**：候选经精修、频率、双向 IRC 和端点身份验证。

训练损失下降不能替代后两类结果。

---

**2．反应身份：采用无序 A/B 端点对**

一个反应定义为：

\[
\mathcal R=
\left(
\{G_A,G_B\},
\text{原子映射},
\text{电子态},
\text{任务约束}
\right)
\]

必须满足：

\[
\{G_A,G_B\}=\{G_B,G_A\}
\]

交换 A/B 名称，不改变反应身份、数据分区或相同物理状态下的策略预测。

每个反应保留以下层级：

| 层级 | 用途 |
|---|---|
| `reaction_group_id` | 去重、划分和独立样本统计 |
| `reaction_id` | 原始来源追溯 |
| `branch_id` | 两侧教师序列追溯 |
| `episode_id` | 起点、预算、动作和终止记录 |
| `state_id / transition_id` | 节点观测及显式后继关系 |

A/B 分支编号只用于管理和评估，**不作为具有物理方向含义的网络输入**。

两侧路径、逆向副本、映射副本和扰动样本必须跟随同一反应组进入同一分区。50 个反应即使形成 100 条分支 episode，仍然只有 50 个独立反应组。

---

**3．拓扑表示：对称编码完整端点图，独立执行动作约束**

通过原子映射比较两端：

\[
G_A=(V,E_A),\qquad G_B=(V,E_B)
\]

保存：

- 两端完整连接关系和键级；
- 连接变化与键级变化；
- 原子元素、映射及可判定立体信息；
- 电荷、自旋及允许的化学动作范围。

不再给全局编辑永久指定“形成／断裂”的方向。对某对原子，记录其两端键状态；具体移动怎样影响该连接，由当前结构和任务决定。

**对称化不能破坏完整端点关系。**不能只把每条边的两个键级各自排序，随后丢掉它们属于哪个完整端点图的信息。建议使用共享端点编码器及对称融合，并保留一致原子对应关系。

同时区分：

| 层面 | 职责 |
|---|---|
| 神经网络拓扑条件 | 帮助模型理解相关原子、连接变化和允许任务 |
| 独立动作检查 | 拒绝数值非法、尺度越界、灾难性重叠及已明确禁止的化学动作 |

拓扑信息本身不保证唯一运动方向，也不能简单冻结所有现有键或全部非核心原子。协同响应仍需允许。

**4．数据重建：完整保留 A→TS、B→TS 两侧教师序列**

由原始 IRC 布局和 TS 身份构建：

\[
A=X^A_0\rightarrow X^A_1\rightarrow\cdots\rightarrow X^*
\]

\[
B=X^B_0\rightarrow X^B_1\rightarrow\cdots\rightarrow X^*
\]

两侧统一动作定义：

\[
a^b_t=X^b_{t+1}-X^b_t,\qquad b\in\{A,B\}
\]

固定处理流程：

1. 核验原子映射、分支布局、电子态和 TS 帧。
2. 分离两侧，并分别排列为端点→TS。
3. 去除整体刚体漂移，核验坐标、位移和向量标签同步变换。
4. 分支内部重采样，明确保留 TS 边界。
5. 超出动作范围时插入节点，不裁剪动作后保留旧后继。
6. 生成全部合格教师动作与辅助标签。
7. 补齐所需物理观测。
8. 分别导出教师样本与环境转移。

必须取消旧搜索规则对教师集的截断：

- 不因 100 步预算删除后段；
- 不因旧产物距离势“无进展”删除后段；
- 不因旧连接代理命中提前删除后段；
- 不跨 TS 把两侧串成一条动作。

计算批次可以切片，但**切片不改变轨迹的科学边界**。

缺失分支、映射错误、几何质量不足等情况分别登记；不能静默补造或剔除反应分母。

**5．教师标签：局部动作是主标签，TS 差与剩余弧长是辅助标签**

每个节点生成三类监督：

| 标签 | 定义 | 用途 |
|---|---|---|
| 局部动作 | \(a_t=X_{t+1}-X_t\) | 主策略监督 |
| TS 剩余位移 | \(d_t=X^*-X_t\) | 辅助几何预测、诊断 |
| 剩余路径弧长 | \(\ell_t=\sum_{k=t}^{T-1}\|X_{k+1}-X_k\|_M\) | 辅助进度预测 |

一致性检查：

\[
d_t-d_{t+1}=a_t
\]

但不强制：

\[
a_t\parallel d_t
\]

路径可能弯曲，不能让模型把“直线冲向 TS”当成唯一正确行为，也不要求 TS 直线距离每步严格下降。

TS 处记为教师端点；零动作不参与方向余弦损失。

参考 TS 坐标、真实 \(d_t\)、真实 \(\ell_t\)、未来帧和参考路径序号只存在于离线标签区，不能进入策略输入。

**6．逐点 xTB 观测：全覆盖、可复用、可审计**

现有 3,612 条转移的状态记录已检查到能量和梯度完整、有限，但它们只覆盖旧截断片段。新双端完整路径需要重新生成覆盖清单。

每个物理观测至少绑定：

- 原子元素、映射和实际坐标；
- 电荷、自旋；
- 方法、软件及计算配置；
- 能量 Hartree；
- 梯度 Hartree/Å；
- 完成状态、单位转换及 ACP 收据；
- 内容摘要、缓存复用和真实费用。

复用以完整计算身份匹配为条件。新增插值几何必须取得相应真实观测，不能用插值梯度冒充计算。

同一结构反向使用时：

- E/g 不因运动方向改变而变号；
- 动作按新序列重算；
- 相对能量以该 episode 的实际起点为参考：

\[
\Delta E_t=E(X_t)-E(X_0)
\]

教师几何来自 DFT IRC、观测来自 xTB，应保留双重方法身份；参考 TS 不自动成为 xTB 鞍点。

本阶段优先使用 E/g。原子电荷、键级和 Hessian 等另行评估，不默认对完整路径全部计算。

缺失统一记为 `null + reason`，禁止补物理零值。

**7．特征规范：适配 EGNN，保持对称性、等变性和物理尺度**

建议策略输入为：

\[
s_t=
\left(
Z,X_t,\{G_A,G_B\},
g_t,\Delta E_t,
q,M,\text{方法},
\text{部署可得任务状态}
\right)
\]

不再输入 `origin_side`，也不沿用未经重定义的旧产物命中和无进展字段。

| 特征 | 规范 |
|---|---|
| 元素 | 类别 embedding |
| 完整端点拓扑 | 交换对称编码 |
| 坐标 | Å，去整体平移，保留相对几何 |
| 距离 | 固定展开，与长度单位一致 |
| 梯度 | 共同正标量尺度，保持方向及相对幅度 |
| 能量 | 相对实际起点，再使用冻结尺度 |
| 电荷、自旋、方法 | 显式条件或明确限制支持域 |
| 预算、必要历史 | 仅使用环境实际需要且部署可得的信息 |
| 缺失状态 | 显式 mask |

梯度采用：

\[
\tilde g_i=g_i/s_g
\]

不能分别对三个轴使用不同尺度，也不能只保留单位方向而丢掉幅度。

所有统计参数只在 fit 上拟合，随模型冻结；monitor、test 和部署复用同一份参数。完整路径重建后重新测量分布，不能直接永久沿用旧截断片段的尺度。

输入维数变化时同步更新网络输入层，禁止静默截取或补零。

**8．动作合同：严格区分潜变量、有界动作和物理位移**

统一：

\[
u_i\in\mathbb R^3
\]

\[
z_i=\tanh(\|u_i\|)\frac{u_i}{\|u_i\|}
\]

\[
a_i=a_{\max}z_i
\]

| 表示 | 使用位置 |
|---|---|
| \(u\) | 高斯分布及潜变量运算 |
| \(z\) | 无量纲动作密度 |
| \(a\)，Å | 实际推进、几何检查、Q 的动作几何编码 |

保留已修复的：

\[
\sigma=\sigma_{\min}+\operatorname{softplus}(\mathrm{raw})
\]

重新检查 σ 下限是否妨碍近静止原子的尺度拟合。

第一轮保持 \(a_{\max}=0.1\) Å 作为对照起点；0.2 Å 属于单独版本。不要在同一次比较中同时更换任务、步长、网络和损失。

采样后若增加刚体投影或其他动作变换，必须重新核验概率密度，不能继续默认原 log-prob 有效。

**9．BC：先验证动作可学，再比较训练配方**

先在少量 fit 反应上分别验证：

- 两侧单独拟合；
- 两侧共同拟合；
- 显著移动原子；
- 近 TS 区域；
- A/B 交换一致性。

若少量轨迹都不能拟合，不扩量。

正式比较：

| 配方 | 组成 |
|---|---|
| BC-NLL | 修复后的概率基线 |
| BC-A | NLL＋确定性动作误差 |
| BC-D | NLL＋动作误差＋幅度加权方向损失 |

\[
\mathcal L_{\mathrm{BC}}
=
\mathcal L_{\mathrm{NLL}}
+\lambda_a\mathcal L_a
+\lambda_{\mathrm{dir}}\mathcal L_{\mathrm{dir}}
\]

近零真实动作降低方向权重，避免放大数值噪声。TS 剩余位移、弧长辅助头在基础方向学习通过后单独消融。

当前向量通道和 μ 输出存在正门控结构，需要检查表达能力。若过拟合失败，再比较有符号向量权重或更充分的向量消息，不能将方向弱完全归因于 NLL。

模型选择先冻结动作／方向质量要求，再依据 monitor 指标选择；不能仅选 NLL 最低的模型。

**10．统一采样、归约和训练计数**

BC 与 IQL 的主比较统一采用：

**反应组均衡 → 两侧分支均衡 → 分支内按冻结规则抽样。**

分支内可按弧长区间分层，保证端点、中段、近 TS 均被覆盖。采样规则和权重随数据版本保存。

主 log-prob 归约：

1. 每步对有效原子维度求和；
2. 分支内平均；
3. 反应内对可用分支平均；
4. 跨反应组平均。

每原子 NLL 单独报告，不与主损失混用。不同数据资格造成的覆盖差异必须报告，算法对照需增加相同数据子集上的匹配实验。

epoch 采用唯一解释：每个反应组被抽到一次，组内抽样数量明确记录。同时报告更新次数与实际样本曝光量，避免“50 epochs”含义再次混淆。

**11．IQL：先修物理语义，再启动价值学习**

本次必须先修复以下实现问题：

- Q 接收无量纲潜变量，却按物理位移处理；
- 动作与坐标、梯度存在单位混用；
- actor 未加载对应 BC；
- 未执行计划中的 Q/V 预热；
- 当前索引不能直接支持每反应多 episode；
- BC/IQL 的采样和 log-prob 归约不同；
- checkpoint 与内容身份记录不充分。

Q 应接收明确的物理动作，再构造规范化几何特征，例如：

\[
\|\tilde a_i\|,\quad
\tilde a_i\cdot\tilde g_i,\quad
\tilde a_i\cdot\hat r_{ij},\quad
\Delta d_{ij}
\]

动作必须与具体原子和任务边联合编码，不能主要依赖平均动作长度。候选几何可由 \(X+a\) 构造，但未计算的候选 E/g 不能伪装成真实观测。

训练顺序：

1. 加载相同 seed、特征及动作版本的 BC actor。
2. 独立初始化 Q1、Q2、V。
3. 先 2,000 次 Q/V 更新，冻结 actor。
4. 再最多 20,000 次联合更新。
5. 冒烟运行另记实际阶段长度。

采用明确冻结的 IQL 目标、目标网络和权重公式。起始候选沿用已有计划：expectile 0.7、优势温度 3、权重上限 100；有限选择只使用 fit-monitor。

不能为了降低 ESS 而人为放大权重差异。

**12．IQL 数据与终止：教师边界不自动变成成功**

新搜索环境明确区分：

- `MOVE`；
- `STOP_AND_REFINE`；
- `ABORT`；
- 已验收的回退动作。

STOP 单独建模，不作为零位移 MOVE。

| 情况 | 数据语义 |
|---|---|
| 到参考 TS 帧 | `teacher_endpoint`，教师边界 |
| 精修验证完成 | 根据实际协议结果形成终端标签 |
| 任务预算耗尽 | 冻结环境规定的失败终态 |
| 外部超时、取消、计算缺失 | 删失，不伪造失败 |
| 文件或训练切片结束 | 数据边界，不自动终止 |
| 明确几何非法 | 按环境规则处理 |

预算依据 fit 数据进行一次冻结，不按每条参考剩余路径长度定制。教师集仍保留完整路径。

奖励优先采用明确的逻辑动作成本和真实终局结果。旧产物距离势停用；参考 TS 距离可做独立 oracle 诊断，不与部署奖励混训。

尚无相容后继或终局标签的数据继续保留为 BC 教师数据，不为启动 IQL 补写成功、失败或完整回报。

随后逐步增加：

1. 完整双侧专家转移；
2. 不同步长但重新取得后继的动作；
3. fit 内受控扰动；
4. 冻结 BC 的真实偏离、恢复、失败及 STOP 尝试。

Q、V、actor 分别定义样本资格。恢复时保存目标网络、优化器、采样器与 CPU/CUDA RNG、训练阶段和规范化参数；哈希字段必须是实际内容摘要。
