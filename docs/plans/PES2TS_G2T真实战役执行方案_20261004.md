## 6. 预算外推（2026-10-04 S2 v3cal 实测回填；证据 outputs/g2t_campaign_logs/T16-01-extrapolation.log）

口径声明（冻结，逐字执行）：

- 每梯度尝试均值 = Σcpu_seconds / ΣN_gradient（聚合值，**不称中位**）。receipt/账本**无逐评估（per-evaluation）计时**，仅 attempt 级 `cpu_seconds`（`costs.json` ledgers）与 `origin.duration_seconds`。
- 逐例墙钟（任务口径）= `costs.aggregate.cpu_seconds + origin.duration_seconds`。注：账本 `aggregate.cpu_seconds` **已含 origin 条目**（`cost_id=...:origin:0000`，`cpu=origin.duration_seconds`），任务口径 `+origin duration` 会重复计入 origin；下表两者并列。
- 外推系数：**1.5，统一**。
- 分批 = 同一冻结 manifest 多次 `--case` 子集调用（单 root 单身份；不另建多 manifest）。
