# PES2TS 第二轮修改最终方案：仅完全成键与完全断键

> 状态：参考（已并入 R 工作流 R0–R4）
> 层级：工作流 R（generation 核心研究）/ G2 攻坚
> 取代关系：作为 R 工作流的范围与验收来源；R 的统一序列见 [PES2TS_整体开发与发布方案_v2](PES2TS_整体开发与发布方案_v2.md) §5。

日期：2026-10-02。状态：最终实施设计，尚未实施代码改造或启动新版计算。

本方案替代上一份 v2 中关于键级变化可提升为几何驱动的规定。用户本轮明确要求：键级变化作为其他键形成/断裂的衍生行为处理，只关注完全成键和完全断键位点。以下为本轮统一范围和验收标准，不推广为所有化学反应的通用机理断言。

## 1. 冻结范围

1. 化学事件集合仅含 `formed`、`broken`；这两个类别依据映射端点图中边的存在/消失确定。
2. `order_changed` 保留在完整图编辑档案，作为被动衍生记录；不生成 driver、guard、独立事件、调度分组或必要覆盖要求，不再保留“必要时提升为驱动”的例外。
3. 不为键级变化专门增加扫描坐标、约束、相位、计算任务或扫描成功门。完整输出结构自然包含它们的几何变化；已有键级观测可作为解释附件。
4. 核心反应中心只由完全成断键端点定义。局部不变邻居可作支持原子，但不成为新增事件位点。
5. 默认只使用完全成断键距离硬约束。立体辅助控制仅允许来自这些位点局部邻域的少量 A/D guard，且必须有必要性和可行性证据；不得通过辅助控制重新引入键级变化距离约束。

最终 TS/IRC 与化学身份验证仍保留。未给衍生行为独立扫描任务，不意味着约束距离达标就足以证明机理正确。

## 2. 从端点图确定唯一的活动编辑视图

在统一原子映射、显式氢、电荷及芳香表示后，令 R/P 的边集合为 \(E_R,E_P\)：

\[
F=E_P\setminus E_R,\qquad B=E_R\setminus E_P.
\]

本轮驱动与事件覆盖的依据统一为：

\[
\text{required\_connectivity\_edits}=F\cup B.
\]

\(E_R\cap E_P\) 中的键即使键级不同，也不属于本轮活动编辑。不能使用 `bond_order_R != bond_order_P` 来定义 required。

“完全”指端点图中的键存在性变化，不是要求扫描中每一步具有整数键级或一步断完。几何仍连续推进；成键判读使用端点图和适配的验证规则，不由一个普适距离单独定义。

完整归档与执行视图分离：

```text
完整 ReactionEditGraph
  ├─ formed / broken → ConnectivityEventView → driver / event coverage
  └─ order_changed  → derived_changes_archive
```

事件耦合、方向提名、候选枚举、覆盖验收和批次构建必须消费同一活动视图。不可只在 ORCA 编译的最后一步过滤，否则早期事件分组和覆盖拒绝仍受键级变化影响。

没有任何 F/B 的纯键级变化反应：返回 `OUT_OF_SCOPE_NO_CONNECTIVITY_EDIT`，保留原数据并报告本轮不适用；不得制造距离驱动。R-only 探索模式则使用明确提出的新增/删除边事件，不凭空生成未知 P。

## 3. Demo24 的新规划基线

本次只读核查 `outputs/demo24_acp_geometry_audit_20261001/RXN_*_graph.json` 的结果：

| 类别 | 编辑数 | 第二轮用途 |
|---|---:|---|
| 完全成键 formed | 40 | 活动化学事件、距离驱动 |
| 完全断键 broken | 31 | 活动化学事件、距离驱动 |
| 键级变化 order_changed | 44 | 衍生档案，不进入执行覆盖 |
| 活动成断键总数 | 71 | 覆盖分母 |

24 例均至少含一个 F/B 编辑。旧初始计划按全部 115 个编辑生成驱动；新版必要编辑集合收敛为 71 个。本数字是整批独立化学编辑数，不等于量化任务数、每次尝试约束数或必须在同一段同时驱动的数量。

每个反应仍保持一个逻辑主身份。相关成断键可共用一维 lambda；已有证据或冻结规划允许分段时，每段有独立的活动 F/B 子集和父计划身份。某段的覆盖分母只能是该段明确选定的 F/B，不能用删去必要编辑的方式伪装完整反应完成，也不能为覆盖全图而强迫所有多基元事件同步。

RXN_0000155302 原始完整 R/P 的组分间重叠仍属于输入问题；减少约束不能修复起点碰撞。列作输入异常验证例，物理合格起点的统计分母另报。

## 4. 坐标角色的最终规则

| 角色 | 本轮允许来源 | 执行作用 |
|---|---|---|
| `driver` | 活动 F/B 原子对 | 唯一化学驱动，距离 B 坐标 |
| `monitor` | 活动位点距离、局部立体、碰撞和电子态 | 被动记录，不形成硬约束 |
| `guard` | F/B 位点及稳定局部支持邻居的 A/D | 条件启用的辅助立体控制，不计化学事件覆盖 |
| `target_test` | F/B 的连接身份与段落终点 | 事件达成与连接验证 |
| `derived_changes_archive` | 键级变化 | 非执行档案，不提名或补足上述角色 |

对一个多驱动集合，距离 driver 原子对必须恰好匹配本段活动 F/B 集合；不能缺失、不能混入键级变化对或其他辅助距离。原子顺序、映射和 driver ID 保持稳定。

氢转移按供体–H 的完全断键和受体–H 的完全成键处理，保留两个独立距离；D–H–A 可为局部 monitor/guard。键级变化独立地留给电子结构及自由几何松弛响应。

guard 默认关闭。出现可诊断的局部立体漂移时，启用预先冻结的候选 guard 方案；每个事件首轮最多从 0–2 个独立 A/D 起测。支持原子不得按键级变化差值提名，不添加远端构象控制，不引入额外非 F/B 的 B 距离硬约束。

启用前检查几何定义、周期性、Jacobian 独立性、共同可实现性和松弛自由度。不能固定反应所需的平面化或环运动。guard 变更必须使用新计划/候选版本并计入预算，禁止在执行中静默添加。

## 5. 起点与方向

先进行完整结构和电子态检查，再以活动 F/B 评价方向：

1. 优先从关键驱动键已经成键的一侧开始拉伸；
2. 优先减少反应片段的相对摆放自由度；
3. 比较活动位点局部构象和几何条件；
4. 证据相近时，预算内保留备用方向。

已知有效 P 的双分子环加成通常优先 P→R；并非所有反应固定 P 优先。端点能量只作同方法辅助信息，不能越过输入质量门。

F/B 标签固定相对于 R→P 定义，执行动作按方向转换：

| R→P 编辑类别 | R 起步 | P 起步 |
|---|---|---|
| formed | 缩短距离 | 拉长距离 |
| broken | 拉长距离 | 缩短距离 |

存在多个 formed/broken 时仍允许协同多距离推进，不退回每反应仅选一条键。键级变化数和变化幅度不参与方向评分。

## 6. 同步一维目标函数

只为活动 F/B 距离定义独立主调度。保留同步线性对照和现有 smoothstep；新增归一化 sigmoid 可在对照之后启用。有限候选为同步、事件组 A 领先、事件组 B 领先，事件组由 F/B 活动视图组织。

\[
c_k(\lambda)=c_{0,k}+(c_{1,k}-c_{0,k})S_k(\lambda),\quad k\in F\cup B.
\]

不为键级变化设置任何 \(c_k\)、激活相位、陡峭度或端点距离目标。共享同一 S 时仅改变采样参数，不能直接称异步机理。

反向目标函数按 \(c^{rev}(\lambda)=c^{forward}(1-\lambda)\) 转换；新 lambda 节点重新验证活动距离与启用 A/D guard 的联合可实现性。参考几何见证若使用已知 TS/IRC，必须保持参考引导标签；新版主改进对照应优先使用相同 F/B 目标信息，避免混入教师信息差异。

## 7. 单端在线执行器

流程固定为：

```text
有效起点准备
  → 上一 accepted 帧预测
  → 活动 F/B + 可选局部 A/D guard 非线性投影
  → ORCA 硬约束松弛
  → 完整验收
      ├─ 通过：保存 checkpoint，继续/触发独立 landing probe
      └─ 未通过：记录原因，重试/步长折半/预算终止
```

每次只由上一已接受结构暖启动；参考几何不能覆盖在线种子。预测用当前实际 q 到新目标的残差，并做有限次非线性回代。距离 driver 和辅助 guard 分开保存、分开验收。

接受门：量化正常结束、电子结构与几何收敛、有限物理能量、全部活动约束残差达标、整体 proper-Kabsch RMSD≤0.30 Å，以及同一次整体对齐下最大原子位移≤0.60 Å。保留既有距离 0.01 Å、角/扭转 0.5° 工程残差门，正式冻结后不随失败放宽。

碰撞、旁观骨架异常和电子态异常另作物理质量门。未知完全成断键事件出现在探索区时保留分支证据，经新计划处理；键级衍生变化不作为额外驱动需求。

连续两次全部通过且校正温和后才增大步长；拒绝后清零平滑计数。设置最小实际步长、每点 attempts、总 attempts、帧数及时间预算。不能在最小步长永久循环，也不能以最终结构正确为由接受跳跃帧。

失败类型区分约束不可行、坐标退化、SCF、优化、连续性和预算耗尽；步长耗尽不自动证明分岔。返回部分有效路径与诊断，拒绝结果不进入有效曲线，但全部归档和计费。

## 8. 候选排名、沉降与验证

GENERATION 输出已验收路径及证据，RANKING 从内部局部峰区间提名候选。只对活动 F/B 判读反应推进；键级变化不生成独立峰候选、不用于驱动覆盖评分。

排名继续遵守：约束优化的投影梯度是松弛质量门；峰值及无约束物理梯度、可用曲率和峰值包围证据共同筛选 TS 候选。多驱动零路径斜率和调度平台零斜率不构成驻点证明。物理梯度缺失明确标 unknown。

事件达成/峰后条件触发独立释放约束优化，区分返回起点、新极小值候选、新连接分支和失败。lambda 达上限不自动说明得到中间体。

正式 TS 结论仍需 OptTS、一个相关有意义虚频、双向 IRC 和相邻势阱身份确认。中间体需自由优化和稳定性证据。完整化学身份可以记录电子与键级情况，但不由此恢复键级变化驱动或改变本轮 F/B 覆盖分母。

## 10. 实施顺序与验收

### S0：范围与计划迁移

新增版本化 F/B 活动视图与合同；生成 24 份新版规划草案，重新核对整批 40 formed、31 broken、44 derived。不就地修改旧冻结计划，不重标旧结果合格状态。实际准备之后才统计物理有效起点数量。

退出条件：所有新计划的主 driver 对精确等于本段活动 F/B；O 对进入 hard B、driver、required 或事件调度均被拒绝；纯 O 例明确不适用；氢转移两距离不丢失。

### S1：在线执行闭环

相同 F/B 目标、计算方法、起点和总预算下，比较固定步长上一帧启动与预测/投影/自适应启动。先不加 guard、不改相位，隔离执行器收益。

代表例：RXN_0000007104 为已通过基线；RXN_0000017762、RXN_0000187964 为困难例；RXN_0000026256、RXN_0000077619 为单驱动压力例。真实能力探针与状态机负例先通过，再进行代表例计算。

退出条件：没有无限循环、拒绝帧污染或恢复重复执行；所有接受帧满足冻结门；完整目标区间覆盖和部分停止分别报告。不能只通过缩短路径获得表面连续成功。

### S2：方向、少量 guard 与协同调度消融

图核实后选择适用的环加成/环闭合反应，分别比较 R/P 起点；无 guard/少量局部 A/D；同步/A 领先/B 领先。匹配总预算，不一次做完整候选笛卡尔积，不为 O 单独创建任何对照。

### S3：排名与机理验证

对有限候选验证物理梯度接口；比较能量基线与证据排名的 OptTS 和 IRC 成功率。未知中间体由独立 landing probe 验证，再决定是否开启下一段。代表例证据满足后才扩批。

必需回归负例：双→单/单→双误分类、芳香表示差异、O 被提升、O 改变事件分组或覆盖、局部 guard 偷带非 F/B 距离、纯 O 伪造驱动、单驱动被多驱动选择条件漏掉、反向 F/B 动作错误、约束不可行、最小步长无限循环、NaN/缺失能量、断点污染、调度伪峰与无势垒情况。

## 11. 统计口径与本轮交付

规划统计：完全成断键覆盖率、O 被动归档率、非范围例与输入异常例数量、guard 数和来源。

执行统计：同方法有效起点数、完整区间覆盖率、连续性、部分路径、拒绝原因和全部 attempts 成本。

科学统计：候选 TS 精化成功率、相关一级鞍点比例、IRC 连接确认率、稳定中间体确认率。阈值和分母冻结，分别报告参考引导/端点知情/单端事件探索。

新计划删除 O 后属于新的科学协议。旧 3/24 连续性结果保留为历史证据；不能复用旧能量、重新筛帧后当作新版重算结果。若研究减少 O 约束的影响，对照只按全协议版本比较，不创建 O 单独驱动分支。

本轮最终交付范围：F/B-only 图论与合同改造、在线延续执行器、少量局部 A/D guard 的受控接口、有限调度/方向消融、排名与验证对接。跨反应训练、全局环构象锁定、键级变化驱动及大规模 AFIR/NEB/GSM 集成不列入本轮交付。
