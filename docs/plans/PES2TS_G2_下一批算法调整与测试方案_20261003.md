## 3. 核心算法主张（与宪法一致，不夸大）

1. **分支可追踪是条件性事实**：在 A 满行秩、约化 Hessian `K_T=ZᵀH_LZ` 正定的邻域内，KKT 解分支局部唯一光滑；该分支**不保证**延伸到 λ=1，也不保证属于目标化学通道（PES-G §5）。
2. **分支控制是"数值辅助 + 释放核验"，不是物理能量**：辅助项只约束内部步长/累计位移/逐原子位移；接受前必须释放辅助并用**原始物理自由梯度** `‖Zᵀg‖` 与约束残差复核；只在辅助下稳定、释放后不驻点的帧标 `biased_only`（PES-G §6.2）。动作必须落在 `A(H)` 内（R4）。
3. **缓存身份修复不是"删摘要检查"**：同幂等键不同内容必须显式冲突（P1 + AGENT §5）；修的是命名空间与内容寻址。
4. **路径完整性与候选可用性分开**：部分连续路径可独立提名候选（PES-G §5/§10）；"完整路径率"与"有效候选被验证率"是两个分母；生成侧标签 = **basin entry**（弱），PES-R 侧标签 = **verified TS**（强），禁止混用（宪法 §6.3）。
5. **landing 几何标签 ≠ 化学身份证明**：化学身份只有 ACP OptTS/频率/双向 IRC 能产生（R2）。
6. **决策层可回放，QM 不要求逐位**（P3）：给定后端版本 + seed + config hash + 输入 hash，决策层可复现；`generated_at` 为唯一允许的易变键。

## 4. 工作包（实现 + 测试 = 一个工作包）

### WP-1（P0，G2.1）— 执行身份命名空间与内容寻址的梯度复用

**现象/根因**：`correct_local.sample` 每次调用从 `gradient-0000` 起编号并用它当目录名；同一 attempt 被重放（resume/重试/`warm_start` 改初猜或初始曲率）时新几何复用旧目录名 → `request_sha256` 不符 → `CACHED_GRADIENT_INPUT_MISMATCH`。执行身份（运行期）与内容身份（几何+映射+方法+电子态+收敛+操作）混用。

**代码改动点**
| 文件 | 改动 |
|---|---|
| `generation/planning/local_corrector.py` | `evaluation_id` 改为 `trial-<NNNN>/eval-<content16>`；`content = digest(canonical(geometry, coordinates, targets, method_context, operation))`；`evaluate` 契约不变 |
| `integration/acp/gradient_backend.py` | receipt 目录按新 `evaluation_id`；同键不同 binding → typed `IDENTITY_CONFLICT`（含两者 `request_sha256`）；record 增 `evaluation_identity` |
| `integration/acp/orca_gradient_request.py` | 冻结 canonical JSON（浮点/几何序列化规则）；`request_sha256` 绑定 geometry+atom_order+method/state/operation |
| `generation/planning/continuation.py` | attempt 记录携带 `evaluation_identity_prefix`（`plan/attempt/frame/trial`） |

**测试**：`tests/test_local_corrector.py`（同内容复用、异内容重算、伪造同键异内容 → `IDENTITY_CONFLICT`）；`tests/test_acp_orca_gradient_transport.py`（假 ACP 下复用/重算）；新增 `tests/test_execution_identity.py`（跨 attempt 不串目录）。
**验收门 V0**：上述测试全绿；无任何既有 cache-check 断言被删除或放宽。
**对齐义务**：冲突拒绝保留（P1/P3）；测试替身须标注且不得进生产路径（R3 例外）。

### WP-2（P0，G2.2）— 相对上一接受帧的分支约束、释放与分级局部性

**现象/根因**：`correct_local.within()` 只相对 `reference=guess`（预测器）限运动；首个 `project_geometry` 即可移动起点；接受帧仅在 `continuation.geometry_quality` 事后相对上一帧检查（`rmsd_limit=.30`/`atom_step_limit=.60`），**跨帧累计漂移无上界**；`LOCALITY_LIMIT` 不分型；无 `biased_only` 记录。

**代码改动点**
| 文件 | 改动 |
|---|---|
| `generation/planning/local_corrector.py` | 新增 `BranchPolicy`（`branch_rmsd_radius`/`branch_atom_radius`/`cumulative_rmsd_radius`/`bias_kappa`/`release_iterations`，全部 `TODO: calibrate`）。以**上一接受帧 + 预测器**冻结局部参考 `T_*`（首版冻结切空间基，避免伪梯度）。逐试探同时核验 `within(predictor)` 与 `within(previous_frame)` 与累计位移门。引入**可释放的数值锚定**（trust 边界），**不向电子能量加罚项**（`restraint_energy_added` 保持 false，另记 `numeric_anchor_active`）。接受前释放并用原始物理自由梯度与约束残差复核，未过则 `biased_only` 并给 released 证据 |
| `generation/planning/continuation.py` | `geometry_quality` 增 `branch_rmsd_angstrom`/`cumulative_drift_angstrom`；`LOCALITY_LIMIT` 拆为 `LOCALITY_STEP/CUMULATIVE/ATOM/BRANCH/RANK`（保留兼容上层码）；接受帧记 `branch_reference_frame_id`、`convergence_mode ∈ {physical, biased_only}` |

**算法调整**：冻结参考的预测—校正—释放；锚定抑制非必要局部漂移但**不消除所有自由运动**；动作必须落 `A(H)`（R4）。接受门始终以原始物理量为准。

## 5. Preparation Layer 诚实声明（宪法 §8）

宪法 §8 规定 xTB 帧与 DFT OptTS 之间**必须**插入 constrained DFT preparation，**当前不存在**，落地前不得声称已具备。

- 本批 WP-3 的 **origin preparation 不是**该 preparation layer：前者是"方法起点准备/一致性证据"，后者是"在 DFT PES 上短暂固定 `q_reactive` 让其余 DOF 再适应"（需 ACP 约束 DFT 能力，属另批）。
- WP-4 的验证入口必须以 typed 字段显式标注 `preparation_layer_status = absent`；报告不得把"xTB 帧 → DFT OptTS 直连"描述为宪法 §8 链。
- 消除该缺口登记为**后续批次（依赖 ACP-G2-04/05）**，不在本批伪造。
