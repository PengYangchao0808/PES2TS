## 1. 目标与核心选择

采用“IRC 专家动作预训练 → 同一 MDP 的离线 IQL → 真实 xTB 交互 SAC 微调 → 冻结独立评测”。模型直接提出协同原子位移，规则不再预设固定 21 点网格、端点距离插值或 driver 同步路线。现有 Classic、BC 残差和 CQL 留作历史基线，旧 Q 不迁移为新动作价值。

第一环境选择纯位移/观测：X_next = X + displacement；随后经 ACP 对该几何计算同层级能量和梯度，不做默认几何优化。如此 IRC 帧差就是动作，参考邻帧就是此环境的几何后继，无须逐帧额外约束优化。它是搜索控制环境，不宣称生成节点本身构成 xTB IRC。

若后续加入横向物理松弛，登记为另一环境版本；松弛后的实际几何才是后继，不能沿用纯位移教师后继训练该版本的 Bellman 目标。

每步状态压缩必要执行信息，先按 MDP 实现，不引入 RNN/Transformer 历史编码。模型参数不是本次 episode 的历史记忆。

## 2. 同一 MDP 的状态、动作与转移

### 2.1 状态

s = (X, Z, atom_map, goal_graph, charge, spin, method_id, E_relative, gradient, budget, step_remaining, event_state)。

能量采用固定同方法相对参考，原点参考纳入可回放上下文；梯度来自当前节点真实计算。目标条件同时明确反应方向，不能仅以无方向反应图代表 R→P。节点序号、参考 TS 距离、未来 IRC 帧、教师切向和真值能量不进入部署输入。达到目标与候选检测若需有限摘要，将其定义为显式状态。单点观测失败提供有效性 mask/typed 状态，不填造梯度零值。

预算终止是有限任务真正终止，bootstrap=0；人工中断或外部暂停不自动伪造任务失败。训练数据的数据边界与物理终点分开记 terminal_reason/continuation_known。

### 2.2 直接原子位移与随机策略

输出所有原子的协同位移 ΔX；去除任意整体平移/转动，保持原子身份、旋转等变和排列一致性。目标反应图作为条件；不能用教师轨迹构造在线动作基。第一版不硬锁非 driver 原子、不要求中间离散图恒定。

BC/IQL/SAC 共享可计算 log_prob 的策略族。候选实现为：用当前状态构造等变、质量度规正交、固定秩的去刚体位移基 B(s)，在其 k 维系数空间采样 z，解码 ΔX = B(s) z。策略为有界可逆变换高斯，记录标准化单位、尺度及变换雅可比。基仅去掉刚体自由度时覆盖全部内部位移；若降秩，作为额外消融并量化教师动作重构残差，不能默认为无损。

BC 标签由同一编码器将参考 ΔX 变为 z，校验重构与范围。基连续性、秩变化、分子大小批处理、旋转/排列协变需要实施验证；这是设计候选，不视为现有能力。备选为有明确 gauge 和密度的等变 flow 策略。

SAC 熵定义在登记的内部动作系数空间，不能对投影/归一化后的 Cartesian 位移套用投影前高斯密度。避免采样后无记录地裁剪/缩步；拒绝可作为明确自环或终止转移，并记录采样动作、费用和原因。原子位移阈值为数值信赖域，不作为扫描路线。只移除危险重叠、非有限数值等动作；被拒绝经验留存。

### 2.3 转移

合法动作：计算 X'=X+B(s)z，再通过 ACP 获得 E'/g'，更新预算与任务事件。非法动作：按合同定义自环/终止，扣除检查或已发生费用。真实单点失败：保留请求与收据，按 typed 终态处理。能量/梯度观测不直接定义 TS 或成功。

纯位移的坐标后继可由数据构造；补算 xTB 能量和梯度使状态方法一致。DFT IRC 的几何可以作为 xTB 状态，但其路径形状不自动成为 xTB 最小能量路径。

## 3. IRC 数据制备与资格

1. 先冻结 canonical reaction-group 与整族分裂；所有教师、节点、逆向副本、扰动和真实探索继承父反应用途。
2. IRC 方向按目标 R→P 定向；拼接双向支路，处理 TS 重复节点，校验原子顺序/映射。
3. 对整条路径采用一致坐标框架，去除刚体漂移；按质量加权弧长重采样。不得逐邻帧独立对齐后破坏连续方向；记录对齐变换、单位和插值方式。
4. 按同一方法、电子态、溶剂等配置，经 ACP 对保留节点计算 xTB 能量和梯度，缓存绑定几何及方法哈希；缺失观测另记，不跨缺口假连转移。
5. 构造 expert_direct_displacement 转移，包含原始帧、后继、动作系数、终态、奖励分解、方法/环境/映射/split 身份、单点费用来源。
6. 专家数据的步长覆盖部署动作域；超出范围采用重新采样/分段后重算新节点观测，不能仅裁剪动作而保留原后继。
7. 优先反应组均衡采样，再抽节点；正负方向、TS 附近与端点分层，但每类权重公开，避免长轨迹占据损失。

单点制备费用是数据制备费用，不伪称旧 IRC 的完整物理搜索费用。离线步费用可以使用标明来源的固定/校准请求成本代理，不能把未来部署墙钟当已观测真值。在线保存全部实测成本。

## 4. 奖励与离线/在线一致性

第一版共同优化“目标条件下的路径连接代理＋查询费用＋数值/化学异常”，成功名称使用 goal_connected_proxy，严格 TS 标签独立。

r = B_goal * I(first goal event) - c_query - c_step - c_invalid + η(γΦ(s') - Φ(s))。

Φ 仅基于可部署的当前几何与目标图，例如连续目标键距离误差，能垒允许上升；不对所有增能节点处罚、不以低梯度作为唯一进展、不强制单调靠近产物。有限任务终态势取 0；势函数和边界固定后才引用 potential-shaping 结论。γ=1 为有限预算首版；γ<1 只作明示改变目标的消融。

代理连接终点由当前端点图、几何/电子态质量定义；端点松弛若参与终点检验，作为登记的执行操作纳入费用与状态。参考 IRC 完成、参考峰和真值 TS 标签不被写成 xTB 严格成功。

教师切向/参考路径距离作为 BC 辅助损失或单列的教师奖励实验，不能只在 IQL 存在而在 SAC 消失。IQL 与 SAC 共用相同代理奖励字段；若使用校准成本代理，两阶段保持相同代理奖励定义，同时另报真实墙钟，不静默替换奖励尺度。

严格 OptTS/Freq/IRC/RP 验证用于最终独立指标。若将严格结果加入训练奖励，另建 reward_version，离线未知结果留 unknown 并补标签，不把专家路径结束冒充严格成功。

## 5. BC：建立可 rollout 的随机动作模型

模型：等变图编码器＋目标条件＋随机内部动作分布，解码协同原子位移。能量/梯度及预算是输入，不拟合替代 PES。目标：L_BC = -E_D[log π(a_expert|s)]，另记方向余弦、位移重构与步长误差。方差设下界/上界，不能由单一专家样本学到近零方差后直接开启 SAC。

训练先离线，然后冻结 BC 在 fit/dev 独立起点自由 rollout，部署不读取参考后继。报告 teacher-forced 与 free-rollout 的区别。只用专家邻点不能学习所有偏离恢复；补充扰动节点时先定义实际动作与后继，计算观测，不能把随机扰动的后继凭空标成参考帧。

出口：动作编解码/等变/概率密度验证通过；独立开发 rollout 的危险拒绝、停滞、目标代理连接与费用有完整记录。具体阈值在 fit 小试后预登记，不用看到 dev 后调整。

## 6. IQL：离线价值与优势加权策略提取

使用 π、双 Q 和 V；保持新动作/环境/奖励合同。IQL 不通过 max Q 查询未观测候选，这适合专家为主的离线数据，但不保证发现数据之外的新路径。

令 q=min(Qbar1(s,a),Qbar2(s,a))，δ=q-V(s)。

L_V = E_D[|τ-I(δ<0)| δ²]。
L_Qi = E_D[(Qi(s,a)-(r+γb V(s')))²]。
A = stop_gradient(q-V(s))。
w = clip(exp(A/T_A), 0, w_max)。
L_actor = -E_D[w log π(a|s)]。

τ 是 expectile，不是分位数；τ>0.5 对高于 V 的样本施加更大回归权重。温度 T_A 控制优势选择强度；权重、V/Q 标签均 stop-gradient。双 Q/目标网络为本方案实现选择，不称为 IQL 定义的必要组成。

建议 fit 内小网格 τ={0.7,0.9}、T_A={1,3}、w_max={20,100}；起始 lr=3e-4、batch=256、目标软更新系数0.005 是小试候选，先核对奖励尺度与有效样本量。预算与选择损失/训练步上限预冻结。

关键诊断：advantage 分布、ESS=(sum w)^2/sum(w²)、权重饱和比例、双 Q 分歧、MC 回报校准、按反应分层的 rollout。单一路径每状态只有一个动作且回报相似，IQL 可能近似 BC；不以 loss 降低宣称策略改进。

若优势区分不足，优先补充 fit 反应的不同步长跳帧、多个合格路径及小规模真实偏离动作/失败。跳帧只有在登记动作范围和一步成本下才是纯位移转移；额外干预计算费用计入数据预算。不额外要求重跑专家整条约束优化。

出口：冻结 IQL 与同动作 BC 在开发集同预算比较，有有效优势权重且无明显退化；若无法优于 BC，保留结果，不阻断小规模 SAC 探索，但不宣称 IQL 必然有益。

## 7. SAC：真实交互微调与独立评测

SAC 是 off-policy 真实交互训练；冻结评测与训练采集分离。用 IQL actor 初始化同策略族，双 critic 可 warm-start，但先做 critic 校准：IQL 的普通回报与 SAC 的熵正则回报不同。

初期冻结 actor，以有限 fit 真实转移和兼容专家数据 warm-up soft critic；温度从低探索水平开始，评估固定初值与自动调温。不得声称 warm-start Q 已是校准 soft Q。

a'~π(.|s')。
y=r+γb[min(Qbar1(s',a'),Qbar2(s',a'))-α log π(a'|s')]。
L_Qi=E[(Qi(s,a)-y)²]。
L_actor=E[α log π(a|s)-min(Q1(s,a),Q2(s,a))]。

随机采样使用重参数化和正确变换密度。α>0，自动温度围绕登记的内部动作熵目标；按有效动作维数处理分子大小差异，不能只用全批统一 3N Cartesian 熵。标准差受控，但不通过隐藏动作裁剪改变采样分布。

Replay 只混同环境/奖励兼容转移；初始 expert:online=50:50 作为小试候选，在线覆盖增加后逐步下降。短期 BC/KL 锚定是可选 SAC+anchor 变体，单列消融，不称纯 SAC。第一批每新真实转移最多1次梯度更新作为预算候选，后续上限由 fit 校准；防止过度重复拟合少量真实数据。

fit 反应真实交互更新；dev 仅冻结 checkpoint 比较，不更新；sealed iid/family 最后一次冻结评测。episode 内冻结行为参数便于回放，可在 episode/批次之间更新，仍属于 off-policy SAC，不要求逐 QC 调用更新。

第一批建议：4 fit 环境接缝；12 fit×2 episode 训练；8 dev×BC/IQL/SAC/同动作无学习基线×2 seed，训练上限预冻结。原22小时24分小包预算不能直接沿用：新每步至少含新节点观测，严格验证与制备另计；按真实单点延时×请求上限给出包络后再扩量。本文件不启动计算。

## 8. 评测与“ML 实际改变路径”的证据

至少比较 Classic、同动作空间几何基线、BC、BC→SAC、BC→IQL、BC→IQL→SAC；受预算限制先 fit 筛选，正式对照共享独立起点、方法、全预算与严格后处理。

区分：teacher-forced 下一步误差；自由 rollout 的目标代理连接；严格目标 TS 成功。主要科学指标为严格验证成功/全输入、全费用、unknown/失败漏斗；路径偏差、切向一致、横向力与峰值只是诊断。成功之外的代价同样保留。

路径自由度证据：相对 Classic 的实际位移方向、构象变化、异步键变化、拒绝/改写比例、非零动作、动作协方差谱、停滞/循环。单纯残差非零或策略熵增大不算发现更好路径。

统计单位为独立反应组；报告配对差、按反应 bootstrap 区间、训练种子与探索种子。教师训练也排除 sealed/family，不能把邻点当独立样本宣称有效 N。

## 10. 理论来源与不能声称的结论

- IQL：[Kostrikov et al., Offline Reinforcement Learning with Implicit Q-Learning](https://arxiv.org/abs/2110.06169)。Expectile、数据内价值学习、优势加权策略提取；论文效果不构成本项目验收。
- SAC：[Haarnoja et al., Soft Actor-Critic Algorithms and Applications](https://arxiv.org/abs/1812.05905)。最大熵 off-policy actor–critic 与温度调整；昂贵 QC、变维等变动作与有限预算需要本项目单独验证。
- 势奖励：[Ng et al., Policy Invariance under Reward Transformations](https://www.cs.utexas.edu/~shivaram/readings/b2hd-NgHR1999.html)。应用前核对 Markov状态、折扣与终态边界，不把任意路径奖励称为保持最优策略。

本方案不保证 BC→IQL 必然改进、不保证 SAC 必然优于冻结 IQL、不保证 DFT IRC 几何就是 xTB IRC、不把一步可行或路径连通代理称为严格 TS 成功。
