## 0. 一句话

PES2TS 是**反应意图驱动的低维 PES 搜索与几何控制系统**：

\[
\boxed{
\pi_\theta(X_t,G_{\rm rxn})
\rightarrow
(\Delta X_{K,t},\hat q_t,\hat m_t)
}
\]

- \(X_t\)：当前唯一三维构型；
- \(G_{\rm rxn}\)：有方向的反应意图（source/target、键变化、CV、规则）；
- \(\Delta X_{K,t}\)：关键原子下一步位移；
- \(\hat q_t\)：当前 IRC 进度（TS=0，有符号）；
- \(\hat m_t\)：是否停止并进入 TS/端点验证。

**没有 branch，没有单独 direction token。**

## 1. 曲线中心的数据模型

```text
irc_curve
  curve_id, canonical_irc_id
  G_src, G_tgt, K, CV spec, rules
  ts_index, progress[]
  nodes[]

irc_node
  curve_id, node_index

sample_view
  sample_id=(curve_id,node_index,intent_id,d0)
  target_first_contact (node/alpha)
  target_action u
  target_progress q
  stop_label
  disposition
```

旧 branch 只作为曲线上的两段，**不进入模型、split 或身份系统**。

## 2. 三个产品模式

| 模式 | 输入 | 输出 |
|---|---|---|
| **Known-B Growth** | A + \(G_{\rm tgt}\) | A→TS→B 路径、TS |
| **TS-only Growth** | A + 反应中心/CV | A→TS 路径、TS |
| **Unknown-B Discovery** | 仅 A | Top-k 产物候选、路径、置信度 |

**From Any Point** 是核心能力：

- 从曲线任意节点出发；
- progress head 预测 q；
- 方向由 \(G_{\rm rxn}\) 的 source→target 规定；
- 不额外输入 direction token；
- q≈0 起点返回两侧或要求目标。

**Unknown-B 不承诺唯一产物。**

## 3. 架构

```text
X_t, G_t, G_rxn
      │
      ├─ Geometry Encoder (SE(3)-equivariant EGNN)
      ├─ Intent Encoder (signed graph edits + CV spec)
      └─ Current CV Encoder
      │
      ├─ CV Head / Jacobian Lift -> ΔX_K^(0)
      ├─ ML Correction -> ΔX_K^ML
      ├─ Progress Head -> q̂
      ├─ Stop Head -> m̂
      └─ Endpoint Head (Unknown-B)
      │
Constrained Relaxation (protect CV advance)
      │
Path Memory / Controller
      │
Verifier (TS/IRC/endpoint)
```

### 3.1 三种动作生成

| 臂 | 方法 | 用途 |
|---|---|---|
| Classical CV | \(\Delta X_K^{(0)}=J_K^\top(J_KJ_K^\top+\epsilon I)^{-1}\Delta\xi\) | 可解释基线 |
| Direct EGNN | \(X_t,G_{\rm rxn}\to\Delta X_K\) | R3 主路线 |
| Hybrid | \(\Delta X_K^{(0)}+\Delta X_K^{\rm ML}\) | V5.2+ |

### 3.2 为什么不是单独 direction token

方向已经由 \(G_{\rm rxn}\) 规定：

```text
C–Br 断裂 -> Δr_CBr > 0
C–O 形成  -> Δr_CO < 0
```

再加 token 是重复条件，可能冲突。

## 4. PREDICT → ACTION → RELAX → UPDATE

```text
PREDICT:
  ΔX_K, q̂, m̂ = policy(X_t, G_rxn)

ACTION:
  ΔX_K = trust_region_clip(ΔX_K, q̂)
  X_prop = X_t + ΔX_K

RELAX:
  X_next = relax(X_prop, G_rxn, protect CV advance)
  # 不允许松弛直接撤销反应坐标推进

UPDATE:
  update path memory, q̂, TS/endpoint checks
```

停止：

- TS-only：q≈0 停止；
- Full curve：TS 是途经点，继续到端点；
- 端点：graph match / endpoint head；
- 预算/停滞：控制器停止。

---

## 5. 方向语义

### Relabel

交换端点名字，物理任务不变：

\[
\pi(X,\mathrm{Relabel}(G_{\rm rxn}))
=
\pi(X,G_{\rm rxn})
\]

### Reverse

真正反转反应目标：

\[
\pi(X,\mathrm{Reverse}(G_{\rm rxn}))
\ne
\pi(X,G_{\rm rxn})
\]

小步长切向近似相反，但不要求有限步长严格互为负数。

| 阶段 | 能力 |
|---|---|
| **V5.1-R3** | `intent_directed_irc_step`：完整 IRC、两种有向 intent、first-contact 单步；无 progress/stop |

损失：

```text
L_step = Huber + cosine
L_q    = Huber + monotonicity + TS sign
L_m    = BCE
L_path = endpoint + TS + barrier + cost
```

## 7. 评估

```text
step: RMSE/zero, cosine, SRE, sign, dead-zone
progress: q MAE, monotonicity, TS sign
stop: precision/recall
growth: TS pass, endpoint success, IRC connected, path RMSD, barrier error
cost: QC calls, wall time
semantics: relabel invariance, reverse sensitivity, rotation/permutation equivariance
```

三层成功：

1. 生长成功；
2. TS 成功；
3. IRC 成功。

---

## 8. MVP 与边界

MVP：

- Known-B；
- 从 A 或 B 任一端；
- progress + stop；
- PREDICT-ACTION；
- TS/端点验证；
- 失败显式返回。

MVP 不含：

- Unknown-B；
- 多产物发现；
- RL；
- 全自动机理解释。

不承诺：

- 唯一产物；
- 最低能垒路径；
- 低维扫描路径等于 IRC；
- 未验证的 TS/端点。

---

## 9. 一句话

**PES2TS 学习的是：在给定有向反应意图下，把低维反应坐标推进转化为关键原子三维位移，并预测 IRC 进度与停止位置。方向来自反应意图，不来自 branch，也不需要额外 direction token。**
