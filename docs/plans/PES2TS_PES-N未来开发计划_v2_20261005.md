## 1. 项目身份与本版裁决

PES2TS 解决的是：已知目标化学转化后，利用真实低成本电子结构观测，持续判断当前状态、是否精修、下一步计算什么，在保持目标成功率的条件下减少全部计算费用。PES-N 是其中可独立嵌入工作流的反应状态决策内核：

**chemistry-constrained, physics-in-the-loop, reactive-state decision model。**

PES-N 是 search closure model 的操作性设计：将当前可观测信息映射为指定搜索/精修协议下的决策价值。“闭合”不声称局部观测能唯一确定全局路径，也不意味着已建立精确的物理降阶模型。

本版采用一个共享内核及多种条件输出：p_seed、预测完整精修成本、Q_STOP，之后扩展 Q_MOVE、策略相关 J 与不确定性。D_perp/D_parallel、直接 Δq 仅作有标签时的辅助任务或残差候选生成。G/R 为 navigation/ranking 使用方式，PES-N 是核心名；不新增工程阶段。

**训练顺序：可信 Classic 数据 → STOP 监督学习 → 模仿/残差 → 保守离线 Q → 冻结模型的真实闭环与 train 内反馈迭代。**

## 2. 物理基础与需要收紧的数学表述

### 2.1 TS 真值与局部松弛面

对指定电子态/PES，严格目标 TS 的证据仍为无生成约束的驻点、去除平移/转动后振动空间内一个显著负曲率/相应虚频、正确目标模态、双向 IRC 及端点极小值/完整身份。非线性孤立分子通常有 3N−6 个内部自由度，线性分子等特殊体系另处理。

以 G 表示化学任务图，q=φ_G(X)，y 表示其余局部坐标。真实局部优化通常产生依赖初猜的分支：

\[
y^*_\ell(q)\in\operatorname{local\,argmin}_y V_L(q,y),\qquad
U_{G,\ell}(q)=V_L(q,y^*_\ell(q)).
\]

因此记录分支/历史，不能默认 y*(q) 是唯一全局极小解，或所有外部瞬时结构均在该面上。MD/未收敛 Opt/NEB image 可以供 STOP 评价，不自动具有约束驻点资格。

令 B=∂φ_G/∂X，采用 L=V_L+λᵀ(φ_G−q)，在光滑独立约束、收敛 KKT、局部稳定且持续同一分支的条件下：

\[
\nabla_X V_L+B^T\lambda=0,\qquad
\nabla_q U_{G,\ell}=-\lambda^*.
\]

这里 −λ 是约化能量梯度；若 generalized force 定义为负梯度，则力为 +λ。尺度化坐标、角度单位及额外 guard/锚定约束都影响乘子解释；释放辅助项后再解释物理响应。原生乘子不可用时可由 E/g/约束几何作经审计重建，但需标明非引擎原生、秩与误差，不能假定 ACP 已支持。

在有效的非冗余局部 (q,y) 坐标、H_yy 正定可逆、同一光滑分支下，由隐函数微分得到：

\[
\nabla_q^2 U_{G,\ell}=H_{qq}-H_{qy}H_{yy}^{-1}H_{yq}.
\]

H 是在该坐标系中的完整二阶导数；非线性坐标变换含额外导数项，在 Cartesian 约束形式下使用一致的 Lagrangian 二阶结构。不能把任意原子子块直接代入此式；刚体零模、退化或分支失稳时关系失效，伪逆/阻尼只能作为另行声明的近似。首版不要求逐帧完整 Hessian。

### 2.2 可解释特征与距离边界

对可定义且已对齐的轨迹切线 t，有 g_parallel=(g·t)t、g_perp=g−g_parallel。它们是对**指定切线**的梯度分解，g_perp 的单位是力而不是长度；它不直接测量到未知反应流形的距离，局部极小点也可使它很小。g·t≈0 只说明该方向导数小，不证明 TS。

约束自由梯度 `(I−B⁺B)g` 与一维轨迹法向梯度不同；使用尺度化坐标、去刚体/选定度规及导数资格时分别记录定义。无可靠切线、近邻或曲率时记缺失，单点模式仍可工作。

`D_TS=(D_perp,D_parallel,D_basin)` 保留为解释框架；前两者只有明确 train 标签/代理定义后才加入输出。`−log p_seed` 是无量纲决策代理，不是几何距离，概率裁剪与校准另记录。完整结构观察不等于全原子等权 RMSD。

## 3. Seedability、成本与 STOP/MOVE 的统一定义

### 3.1 协议条件化的 seedability

令 ρ 固定 preparation、OptTS 初始模式/Hessian 规则、目标方法/电子态、频率、IRC、端点优化/身份和失败恢复；b 是预算，ν 是显式扰动/随机性协议，T_G 是满足目标身份的 TS 集合：

\[
p_{\rm seed}^{\rho,\nu,b}(s)
=P_\nu\bigl[Y_\rho(X+\epsilon,G;b)=1\bigr].
\]

多 TS 目标按已声明的身份/分支集合接受，不预设唯一参考结构。确定性协议且 ε=0 时，单次真实收敛是 0/1 事件；网络给出的是条件化的预测概率。未实施扰动重复试验时，不把网络/ensemble 输出解释为已测的扰动稳健概率。参考 TS 在线隔离仍按宪法 R1/R2。

成本头分开预测 OptTS-only 与完整 STOP 链的追加费用；排序主成本使用完整链，含 preparation、失败、超时和端点验证。未运行、执行故障、验证缺失、预算删失与已验证非目标保留七态，不相互替换。

### 3.2 避免“最便宜的失败”成为最优策略

仅最小化累计费用会偏向立即失败/放弃。主研究目标为：在预注册的目标成功率下限/相对 Classic 的非劣界限和总预算条件下，改善全输入覆盖—成本，并报告每个严格目标结果的总费用。

首版学习使用可审计的有限预算代理：

\[
J_\Lambda^\pi(s,b)=\mathbb E_\pi[C_{\rm total}/C_{\rm ref}+\Lambda(1-Y)],
\qquad \Lambda>0.
\]

Λ、成本单位、预算和成功率约束在 train 内预注册/选择；该代理不是比率指标的精确等价变换，不保证某个 Λ 自动满足成功率门。另报 p 与 C，避免单一 Q 掩盖失败率上升。

将预算、剩余决策/重试次数、计算方法/协议、必要历史/分支和候选档案加入决策状态；首版同时设最大步数，避免零费用拒绝/缓存循环。以 γ=1 的有限时域写：

\[
Q_\Lambda(s,\mathrm{STOP},b)=\mathbb E[C_\rho/C_{\rm ref}]+\Lambda[1-p_{\rm seed}^{\rho,\nu,b}(s)],
\]
\[
Q_\Lambda(s,\mathrm{MOVE}(\Delta q),b)=
\mathbb E[c_L/C_{\rm ref}+J_\Lambda(s',b-c_L)],
\qquad J_\Lambda=\min_{a\in\mathcal A_G^{\rm allowed}}Q_\Lambda(s,a,b).
\]

STOP 是终端操作，包含完整链费用，之后不再加一次 terminal cost；失败/预算或步数耗尽/ABORT 终端保留 Λ 惩罚。FALLBACK 是有具体版本、费用和终止条件的策略选项，不是免费重新开始。既有沉没成本只入总账/剩余预算，不在候选评分中重复扣除。

实际训练一般先估计行为策略下的 J^π/Q^π；固定轨迹的剩余费用不等于 J*，成功轨迹子集不足以训练无偏最优价值。有限历史未必满足 Markov 性，本模型按近似信息状态处理；宏观优化动作亦可作半马尔可夫选项。无条件“严格 MDP/已学 Q*”不作为声明。

### 3.3 Ranking 与 navigation 的边界

- 单次选点：在相同 G、ρ、预算、代价单位及校准下，比较各候选的 Q_STOP。
- 导航：显式比较合法 MOVE、STOP、FALLBACK；无合格动作时拒绝/终止，并记录费用。
- 搜索内档案：STOP(i) 可以选择一个合格历史帧，档案是控制状态的一部分；不要求最终帧最佳。
- 多 seed 验证序列：静态 Q_STOP 排序是基线，不自动最优；候选相关性、去重、失败后的条件更新另建预算协议。首版可预定序列，但严格验证结果不返回当前生成重新规划。

seedability、精修成本与目标分支可信度共同支持 STOP；几何距离不再承担主要排序语义。

## 4. 完整控制栈与首代模型

~~~mermaid
flowchart TD
  G[Chemical Planner：目标事件与合法动作] --> C[Classic动作及有界残差候选]
  X[完整结构、真实E/g、q、方法、质量] --> N[PES-N：p_seed、成本、Q、可校准不确定性]
  C --> S[执行前Chemical Shield]
  N --> A[显式比较STOP、MOVE与FALLBACK]
  S --> A
  A -->|MOVE或已放行fallback| P[ACP → 真实QC/ORCA优化]
  P --> Q[执行后物理与化学质量验收]
  Q -->|接受更新；拒绝留父帧与反馈| X
  A -->|STOP| V[DFT准备、OptTS、Freq、IRC、端点身份]
  V --> L[隔离标签、全量费用、离线训练]
  L -->|train内训练后冻结新版本| N
  EXT[外部单点或轨迹 → 统一状态适配] --> X
~~~

共享内核包括图/状态编码、轻量特征、p/C/Q 输出与不确定性估计。独立任务头可分批训练，模型容量和多任务负迁移通过对照决定；不要求第一代同时拥有所有诊断头，也不另外复制 G/R 模型。

图定义反应原子和允许坐标，模型观察完整体系；未被直接驱动的原子仍影响判断并由 QC 松弛。原子化学角色与本次实际硬约束支持集分开，反应原子未约束的自由度仍然可动。

Residual-first 仅用于连续 MOVE：

\[
\Delta q^{\rm cand}=\Delta q^{\rm Classic}+\delta q_\theta.
\]

残差按坐标尺度限幅，再进行全部合法性检查/重新解码；STOP/FALLBACK 是离散动作，不能和向量相加。候选包含原 Classic 动作及少量残差/缩步变体，由 Q 显式选择；选后的动作仍经过执行门。早期无可信 MOVE-Q 时只做离线残差模仿，不用 STOP 分数冒充远期动作价值。

Chemical Shield 前置检查方向/允许回退、尺度、坐标秩、可实现性初检、电子态及已知几何限制；后置验收碰撞、拓扑/氢伙伴、位移、连续性、收敛和数据身份。只有真实优化后才知道的违规不能由前置层保证排除。形成键的总体事件方向不等于每步只能单调缩短；合法的恢复/回退由冻结规则说明。

不确定性参与 `Q_risk=μ_Q+βσ_Q` 的费用最小化，但这是校准后的风险启发式，不是自动有效置信界。train 内冻结低/中/高风险分层：正常选择、缩步或有预算的 QC probe、同样过 Shield 的 Classic、极端 OOD 拒答。报告错误接受/错误拒绝和覆盖率。

Classic 策略及历史数值基线长期保留；生产 backup 仅调用已通过 ACP 能力和真实验收的操作。NEB/GSM 是可选注册 fallback，不是默认可用；旧本地优化器也不借 backup 名义重新绕过 ACP。

## 5. 滚动决策与真实计算预算

默认每步用 Q 比较有限候选，只执行选中动作，再观察真实响应。G4 以后可检验 1–3 步滚动时域；该长度是实验范围，不是普适充分条件。

若多步候选需真实状态，使用 ACP 做前瞻，所有分支计算、被弃分支和恢复费用计入。不能在“不学转移模型”的设定下假装免费预测未来 QC 状态；没有可查询前瞻时仅做 Q 引导的一步选择，不称为完整 MPC 求解。

PES-N 使用已知可调用的物理环境；离线 Q 学习本身可以是 model-free，调用物理求解器作前瞻才构成规划部分。重新观测可减轻偏差，但不保证递归可行、全局收敛或错误不累积。[MPC 理论参考](https://sites.engineering.ucsb.edu/~jbraw/mpc/)

## 6. 统一状态、轨迹适配与数据资格

`PESNTrajectory` 是不同来源的状态容器，不是把所有来源宣布为同一个动力学环境。`ReactiveState` 最少含完整 X/元素映射、目标 G/H、q/角色、来源/目标方法与电子态、绑定 E/g、可用性/质量及预算协议标识。

| 数据层 | 可以使用的来源 | 学习用途 |
|---|---|---|
| 单点状态 | 资格合格的 PES/Opt/MD/NEB/GSM/RMSD-PP/外部 XYZ+E/g | 经同一精修协议取得标签后训练 STOP；未标注点仅用于明确声明的无监督任务/覆盖诊断 |
| 上下文状态 | 合法近邻、切线、相位/历史 | 增强 STOP 或当前决策；与单点模型分别评测 |
| 相容动作转移 | 已记录命令 Δq、父子状态、成本、验收、同一环境合同 | MOVE-Q、行为模仿、残差训练 |
| 不同环境转移 | MD 积分步、NEB 全链更新、其他优化器步 | 先补齐速度/温控/全链/优化器状态及其环境条件，或只使用单点层；不混作同一 MOVE |

实测 `q_next−q_now` 是响应，不能无条件反推出生成它的动作命令。离线失败轨迹也是有价值记录，但无终端证据/被截断时不能凭空填完整回报。

单点模式不依赖轨迹切线/未来邻帧；“XYZ＋梯度可评价”还以目标图、元素映射、电子态、方法/单位和必要 E 可用为条件。缺字段可补算并计费，或使用已训练验收的缺失模式；无法定义目标时不输出目标 seedability。

保留 generator/source provenance、偏置势与物理 E/g 区分，避免错误抹平方法差异；默认不靠 generator-ID 捷径预测。静态完整轨迹可用双侧上下文，在线只能用决策时已知前缀，两种条件分别标注和评测。

所有原始点、选择概率/抽样机制、失败和费用留存；只验证模型高分点会造成选择偏差，G3 采用 train 内预定分层抽样补标签。整反应族、正逆方向/邻帧/映射副本隔离继续执行，另做跨生成器留出及二者交叉实验。

## 7. G0–G4 新开发路线与验收

| 阶段 | 目标与任务 | 交付及出口 |
|---|---|---|
| G0 | 复用数据底座，增补 ReactiveState 来源、标签/转移资格及交叉分裂 | 历史完成状态保留；新增数据通过身份/防泄漏门；不把所有邻帧当可用 transition |
| G1 | graph→合法动作；反应原子/支持/环境角色及 driver/monitor/guard | 化学控制合同、分支/回退范围、边界复核；目标不由网络改写 |
| G2 | 原生约束优化、独立 Shield、Classic/backup、严格验证与费用 | 单帧→四例→24例；24 可审计终态＋≥1非参考严格目标 TS；不提前启用学习默认 |
| G3.0 | 冻结 Classic 和 1000 输入漏斗，多源状态适配、精修抽样 | 全量成本和可信 STOP 标签；状态数/反应数/有效标签数分列 |
| G3.1 | 单点 p_seed、完整精修 C、Q_STOP 的监督学习与校准 | 固定候选池规则/小模型对照，独立来源与反应族评测，单点库 API；尚不声称全局 J* |
| G3.2 | STOP 基线通过后，增加可选上下文、已支持动作的 BC/有界残差 | 冻结共享内核；有效动作支持/风险校准；只具 STOP 数据时不虚报 MOVE-Q |
| G4.0 | 相容转移上的保守离线 value/Q，Classic/residual 候选显式比较 | 对行为策略、残差和独立模型的离线对照；OOD 动作限制、Shield/backup 与接入门 |
| G4.1 | 冻结模型真实 xTB/QC rollout，默认一步重规划，train 内难例采集后离线更新 | 同预算覆盖—成本、拒绝/回退/决策费用；需要时才验证短时域 probe；不逐步在线更新网络 |
| G4.2 | 全系统与跨生成器泛化、独立内核宿主适配/发布 | 目标成功率门下总成本收益、单点/上下文分列、整族及来源留出、资源与可复现包 |

离线 Q 对未覆盖动作可能产生不合理乐观费用，先限制在数据支持的合法候选并检验保守估计；采用 reward 形式文献时注意转换为 cost 形式后的符号。保守离线 RL 是候选工具，不意味着可直接继承他人最优性保证。[CQL 原论文](https://arxiv.org/abs/2006.04779)

G3 的监督 STOP 成果可以先作为排序能力交付；它仍属于同一 PES-N 内核，不重新建立独立 PES-R 学习产品。G4.0 若数据不足或不优于模仿/规则，则保留较简单模型，不为了进入 RL 扩预算或降低验收门。

### 7.1 首代模型与训练任务

首代先建立图定义的低维物理特征基线，再与小型图编码器比较：坐标及目标偏差、约束残差、梯度投影/范数、核心—环境局部描述、观测掩码、方法与电子态。几何特征满足刚体旋转/平移与原子重排一致性；原子角色作为条件，不能删除环境影响。绝对总能量不能直接跨组成/方法比较；相对能量必须注明同体系参考，单点无参考时使用缺失模式及其他特征，归一化只拟合 train。

| 训练任务 | 标签与训练方式 | 接入限制 |
|---|---|---|
| p_seed | 固定协议/预算的成功事件；分类损失及 train 内校准 | 同一目标/协议语义；选择偏差、无标签和基础设施故障单独处理 |
| C_full / C_OptTS | 全部已完成尝试的追加费用；可用稳健或对数尺度回归 | 截尾样本用删失方法或明确子集，不把截尾观测当完整费用 |
| Q_STOP | 首版由 p 与 C 按冻结 Λ/C_ref 组合 | 若后续直接训练 Q 头，必须检查与组成量的一致性，不能各头各用预算 |
| 残差/行为模仿 | 相容动作轨迹、train 内有限动作教师，学习命令相对 Classic 的差 | 多个可行动作可保留分布/候选，不把平均动作当必然合法；全部过 Shield |
| MOVE-Q / J | 相容转移、费用与终端，有限时域 Bellman/行为回报及保守约束 | 行为回报是 Q^π 证据；无覆盖动作不虚报最优值，先离线再真实对照 |
| 不确定性/辅助距离 | ensemble/校准残差；有明确来源的辅助标签 | σ 从第一代 STOP 起评测；距离无合格标签则不启用 |

“预算内成功”若协议确认预算已耗尽且无目标结果，是该预算下的未成功事件；对无限预算成功与完整费用仍属删失。日志中断、任务状态不明不等于已知未成功。七态原标签保留，派生训练标签必须记录协议与资格，不能直接把所有非 verified_target 行压成负例。

共享编码器分阶段扩头；扩展残差/Q 时可冻结或受控微调表示，重复检查已冻结的 STOP 基准及校准，防止负迁移。损失权重在 train 内确定；独立 G/R 模型只作必要消融或经证据支持的回退，不预设共享一定更优。训练/标注/部署硬件在首个原型上实测，不能由参数量推断 GPU 必需或不必需。

## 8. 接口、软件边界与发布

### 8.1 小内核、多适配器

PES-N 内核只处理图/观测、特征、轻量模型、价值估计与候选建议；宿主负责编排、真实 QC、Shield 接线、预算及验证。PES2TS 是第一参考宿主，未来 ASE/Chemoton/Sella/其他脚本可使用各自宿主适配器。PES2TS 内任何正式计算仍经 ACP，不将引擎适配直接放进内核。

建议内核先落在受审的 `pes2ts_core/pesn/`，在线推理不导入 truth_reader、调度器或 QC 二进制；离线标签构建仍在隔离训练/评测侧。未来提取独立包以同合同验证为门，不在本轮建立新仓库、发布包或迁移目录。

### 8.2 待实施的版本化合同

| 合同 | 关键语义 |
|---|---|
| ChemicalControlSpec | G/H、反应/支持/环境原子、坐标与支持集、目标/回退、Shield 规则版本 |
| ReactiveState | X/E/g/q、方法/电子态、物理/偏置区别、历史与观测掩码、身份与来源 |
| PESNTrajectory | 状态列表、静态/因果上下文、generator provenance、独立转移资格，不替代旧 PathBundle |
| Action / Transition | MOVE 命令或 STOP/FALLBACK/ABORT，实际执行动作、响应、环境/成本、终端/删失；拒绝动作不冒充已执行 |
| SeedProtocol / SeedOutcome | 完整准备/精修/验证、目标集合、预算/扰动/恢复版本、七态及费用 |
| DecisionEstimate | p_seed、C_OptTS/C_full、Q_STOP/Q_MOVE/J^π、单位/失败惩罚/预算、σ及校准，分输出 availability |
| ShieldDecision / DecisionTrace | 候选、规则拒绝、风险分层、最终动作、backup 版本、预/后验与全部开销 |
| PESNModelBundle | 数据/分裂/特征/协议/尺度/目标/模型/校准版本，支持输出、适用域、总参数与硬件测量 |

合同先登记存在性与语义，再写具体 schema/fixture；旧产物不改字段。保留 `ExecutionBackend→TrajectoryRecord→PathBundle→SeedProposal→ValidationResult`，新增旁车绑定原 hash。外部点通过明确来源适配，不伪造内部生成记录。

公共接口建议分为 `evaluate_point`、`evaluate_context`、`evaluate_actions`；仅 STOP 已训练时动作接口显式 unsupported，不以零值填缺失 Q。单点库不触发 QC；PES2TS 宿主需要补算时通过 ACP 的显式操作实现。

## 9. 评测、预算与小模型约束

北极星指标采用总实际费用/严格目标成功数，并与成功率下限及覆盖—成本曲线一起报告。默认每个冻结反应目标最多计一次成功；若另报不同 TS 数，冻结去重身份口径，避免重复收敛同一个 TS 增大分母。零成功时该比值未定义，报告总费用和零覆盖。

总费用包括全部生成、拒绝/失败/恢复、教师枚举、前瞻、准备/OptTS/Freq/IRC/端点。生产单次、离线训练/数据和摊销情景分别报告；不能只平均成功轨迹，也不能把计算调用次数视为不同方法下等价费用。

验收矩阵包括：单点 vs 上下文；规则峰/事件峰 vs Q_STOP；Classic vs 有界残差 vs Q选择；共享 vs 独立模型；无/有不确定性规则；全结构 vs 无环境；一步 vs 付费短前瞻；相同生成器/跨生成器；整族留出及交叉留出。主要结论基于真实严格结果，离线 Q/分类精度只是接入前证据。

支持域、成功率非劣界限、费用改进门、统计单位、置信区间方案、调参预算在 train 内冻结。测试失败如实报告，不对已查看的 valid/test 反复调参。样本不够时扩大的是预定 train 证据，不是把测试数据挪回训练。

首代参数目标约 10^5–10^6，扩容到少量百万需有增益证据；树模型另报体积和复杂度。ensemble 报单成员及总参数。理想 `T_decision/T_low-cost-workflow<1%`，测量包含图/特征处理、全部成员推理、Shield 与选择，分别报告冷启动、暖态、单点和批量、CPU/GPU及体系大小。廉价 QC很快时达不到该比例属真实结果，不据此隐去开销或承诺无需 GPU。

## 10. 十五项原则的工程落点

| 原则 | 开发落点与证据 |
|---|---|
| TS 真值 | G2 严格证据链，G3 标签资格；模型分数不进入成功判据 |
| 化学先验 | G1 图编译为合法动作，支持集/事件版本可追踪 |
| 低维控制 | MOVE 仅 Δq；环境/反应原子未约束自由度真实松弛 |
| 真实物理闭环 | G2/G4 实际动作经 ACP/QC，父子几何与费用绑定 |
| 闭合函数 | p/C/Q 绑定精修协议；局部特征不声称确定全局真值 |
| 显式决策 | 合法候选上比较 Q，直接动作头仅提候选 |
| STOP 即 Ranking | G3 单点 STOP API 与 G4 STOP/MOVE 同语义 |
| 最小计算成本 | 成功率门＋全部费用；带失败惩罚而非只优化便宜结束 |
| 安全分层 | pre-Shield/post-quality/backup 独立，承认未观测响应边界 |
| Residual-first | Classic＋有界 δq，原动作保留；连续/离散分开 |
| Offline-first | STOP监督→BC/残差→离线Q→冻结模型rollout |
| 轨迹无关 | 多源状态统一；不同动力学不伪装同一转移 |
| 不确定性优先 | 训练内校准、风险动作/拒答、跨域错误接受评测 |
| 小模型 | 总参数、单点延迟及完整决策开销作为发布证据 |
| 模块独立 | PES-N 纯推理内核＋宿主适配；PES2TS 内 ACP 边界不变 |
