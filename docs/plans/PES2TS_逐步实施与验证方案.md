> **历史资料。** 本文保留 2026-09-25 的思路，不再作为项目定位、路径默认方法或规模顺序的执行依据。当前方案见 [PES2TS 双项目开发与 Demo 方案](PES2TS_双项目开发与Demo方案.md)：PES generation 负责生成可审计的近似路径，PES ranking 负责路径质量判断和真实帧排序，合并后才是 PES2TS。首轮以 [24 条待复核反应](../demo/PES2TS_demo24_反应挑选与复核方案.md)形成 Demo。

下文的“中性、闭壳层”“默认双端 GFN2-xTB PATH”“先训练帧排序模型”和旧规模里程碑，均已被新版方案修正；请勿将历史措辞用于新的接口或成果表述。

## 1. 已确定的项目决策

PES2TS 是独立项目，先完成通用反应识别、廉价路径生成与帧排序验证，再通过稳定接口接入 RPH。项目分为两个工作流：

```text
数据生成：Reaction-QM → 通用 S0 → 双端 GFN2-xTB PATH → 逐帧能量与质量检查 → 标签
训练拟合：有效路径 → 启发式基线与 oracle gap → 帧排序模型 → Top-k TS 初猜
                                                    ↓
最终验证：同预算 OptTS → 频率 → 双向 IRC → 目标 R/P 连通性
```

| 决策 | 第一版采用 | 暂不纳入第一版 |
|---|---|---|
| 化学范围 | Reaction-QM 的中性、闭壳层小分子基元反应；RPH 环加成作外部对照 | 金属催化、多自旋、仅从反应物预测产物 |
| 输入 | 已映射 R/P 反应图及对应几何 | 未映射反应自动原子映射 |
| 路径 | 对齐后的 R/P 双端 GFN2-xTB PATH；必要时反向尝试 | 将 RPH 单端 PEB 强行用于所有反应 |
| 能量 | 全量 GFN2-xTB；分层验证子集补齐整条路径的 B97-3c 单点能 | 全量高层级 DFT 路径 |
| 模型 | 对已有路径帧排序，输出 Top-k 候选 | UniTS 式直接生成 TS、DeePEST-OS 式完整势能面模型 |
| 严格成功 | 收敛的一阶鞍点，并经双向 IRC 连回目标 R/P | 仅凭能量峰、TS 几何接近或一个虚频宣称成功 |

**术语边界。** 此处“PES 曲线”是沿采样反应路径得到的近似能量剖面，并非完整多维势能面。路径生成完成不等于 PES2TS 训练完成；得到一个高能帧也不等于找到正确 TS。

## 2. 为什么需要重建 S0 与路径生成

现有 RPH V4 的 S0 从可信 CSV 读取预先标注的 `mechanistic_forming_bonds`，要求恰好两条形成键；S2 主要从产物结构沿形成键距离做单端扫描。这个合同适合当前环加成工作流，但不能直接覆盖纯断键、键级变化、氢迁移、不同成断键数量及多组分反应。RPH 当前可用的约 20 条反应和相应路径可作对照，不能充当通用模型训练集的规模上限。

Reaction-QM 提供原子映射反应 SMILES、R/P/TS 几何及 DFT IRC。其 HDF5 中分子可按 `R0/R1/...`、`P0/P1/...` 分组，坐标顺序必须通过映射显式转换，绝不可假定各组分与完整反应共用同一 XYZ 索引。**DFT TS/IRC 仅供标签和评估，不得用于拼装端点、引导廉价路径或生成模型输入。**

两篇参考工作的可借鉴点：UniTS-Gen 从二维反应图及反应位点生成 TS 初猜，提示通用 S0 必须输出可靠反应中心；DeePEST-OS 以半经验计算为物理先验学习反应势能面，提示应重视路径覆盖、力/能量质量与物理验证。PES2TS 第一版仍聚焦“已有路径帧的选点”，不直接复制两者的模型任务。

## 3. 数据生成：按关卡实施

### G0 · 数据入口与固定划分

1. 从 Reaction-QM 的反应信息 CSV 与 `B3LYPD3_TZVP.h5` 读取反应 ID、映射 R/P SMILES、R/P 几何、原子序数、电荷、自旋及来源版本。`B3LYPD3_TZVP_IRC.h5` 和 DFT TS 几何进入独立的只读真值区。
2. 在任何路径生成或调参前，按反应而非帧划分训练/验证/测试；排查重复映射、逆向反应及高度相似反应跨集合泄漏。保存划分清单、源文件摘要和随机种子。
3. 首批 100–200 条做接口与质量试验；约 1,000 条按成断键数、键级变化、元素与 R/P 分子数分层，建立选点上界。通过后再扩至约 10,000–20,000 条有效训练路径。

**关卡：** 每条记录可追溯到唯一反应 ID；真值文件不会被路径生成进程读取；任何被剔除的反应都有机器可读原因。

### G1 · 通用 S0：反应键变化与统一索引

1. 将映射 R/P SMILES 解析为保留显式氢的分子图，验证映射号唯一、两侧原子及元素相符、总电荷和自旋一致；对芳香键采用一致的规范化表示。
2. 在**原子映射空间**计算 `formed = E_P − E_R`、`broken = E_R − E_P`，并对两侧均存在的键记录键级变化；反应中心是所有变化键的端点并可加一圈邻域。分别标记邻接变化、键级变化及氢迁移，不设置固定“两个形成键”假设。
3. 为每个 R/P 组分构造 `map number → 本地 XYZ 下标 → 全局 0 基下标`，用元素序列与映射关系交叉验证；对称性导致多个合理置换时保存候选及歧义状态，不任取一个。
4. 输出版本化 `reaction_change.json`，包含反应 ID、映射摘要、形成/断裂/键级变化、反应中心、R/P 组分与索引转换表、校验状态、失败原因和数据来源。

**关卡：** 纯成键、纯断键、成断键并存、键级变化、氢迁移、多组分及歧义用例全部通过；无效索引不能进入 QC。抽样人工核对反应中心，并按类别报告覆盖率。

### G2 · R/P 端点准备与廉价路径

1. 先完成单分子 R→P；随后扩展多组分。保持映射原子顺序一致，利用未变化的共同结构对齐端点；多组分在反应中心约束下生成数个确定性初始摆放，记录装配方案和几何冲突检查。不得借用 DFT TS/IRC 坐标摆放片段。
2. 用相同电荷、自旋和 GFN2-xTB 设置运行双端 PATH。正向结果若端点不符、拓扑漂移、能量缺失或路径不连续，再尝试反向并统一输出方向。失败保留 XYZ、日志、参数和状态，不能默默替换为一条看似完整的曲线。
3. 对每帧计算/保存 xTB 能量、几何、变化键距离、路径弧长和拓扑质量。分层子集可对所有有效帧补做 B97-3c 单点能，不能只给候选帧补能量后再比较曲线。
4. 输出版本化 `path_manifest.json`、统一原子顺序的 R/P XYZ、逐帧 XYZ/能量表及完整计算溯源。有效路径须达到目标端点、具有足够内部帧、能量完整且无严重非反应中心碰撞。

**关卡：** 路径有效率、反向补救率、各类失败率按反应类别公开；仅有效路径进入训练，所有原始反应仍留在覆盖率分母。

### G3 · 标签与数据封存

在统一映射下，将每个廉价路径帧与 DFT TS 比较反应中心 RMSD、变化键距离误差及最近帧排序；DFT IRC 只检查该路径是否连接同一目标反应。标签、训练输入和来源摘要分开存储，训练器只读取显式白名单特征。先计算“最接近 DFT TS 的 oracle 帧”与简单基线的差距；若路径本身没有可用候选，应修复 G1/G2，而不是继续训练。

## 4. 训练拟合与候选输出

1. 在**同一条 GFN2-xTB 路径**上先固定基线：全局能量最高帧、内部局部峰、knee+shift；RPH 现有选点器仅在兼容反应上运行，ORCA ScanTS 仅在适用的一维扫描子集上对照。oracle 最近 DFT TS 帧是不可部署的上界。
2. 训练轻量帧排序器，以路径内候选相对优劣为目标；输入只含可在推理时获得的路径能量、几何和 G1 反应中心特征。训练/模型选择仅使用训练与验证集，冻结模型后一次性评估测试集，并报告三个随机种子。
3. 推理接口接收 `reaction_change.json` 与 `path_manifest.json`，返回有序 Top-k 帧 ID、XYZ 路径、分数、模型版本和拒绝原因；路径无效时拒绝推理，不伪造 TS 初猜。

**训练成功的定义：** 未见反应上的 Top-1 反应中心距离或 Top-3 近邻覆盖率，须经配对置信区间证明优于最佳适用启发式。训练损失下降、模型能运行或训练集分数高都不单独算成功。

## 5. 四级效果验证

所有方法在同一批反应上配对比较，使用相同路径、相同候选预算、相同 OptTS/频率/IRC 理论级别、Hessian 策略、硬件资源、超时和重试规则。主比较为 **Top-1 对 Top-1**；Top-3 对 Top-3 另报。Reaction-QM 验证采用与参考数据一致的 B3LYP-D3/TZVP 条件；RPH 外部验证保持其自身 S3/S4 协议。

| 里程碑 | 需要回答的问题 | 主指标 | 防止误判 |
|---|---|---|---|
| V1 拟合有效 | 模型是否学到可泛化的选点规律？ | 未见反应的 Top-1 反应中心 RMSD；Top-3 覆盖率 | 以反应分组划分，不按帧随机划分；禁止 TS/IRC 真值泄漏 |
| V2 初猜获取 | 从 R/P 输入到交付候选是否更快？ | `T_seed = T_mapping + T_endpoint + T_path + T_energy + T_select`；有效初猜率 | 另列已有路径上的 `T_select`；ML 推理本身不会自动缩短 PATH 时间。若总耗时下降，需说明是否来自省去 B97-3c 等流程改变 |
| V3 后续优化 | 选中的帧是否让 OptTS 更快、更稳？ | OptTS 核时、迭代/梯度/Hessian 次数、重试数、收敛率 | 同时报告成功作业耗时和包含失败/超时的受限平均成本；不只挑成功例子 |
| V4 正确 TS | 是否得到目标反应的一阶鞍点？ | OptTS 收敛 + 恰好一个显著虚频且模态涉及反应中心 + 双向 IRC 连接目标 R/P | IRC 端点允许方向互换，但必须用映射连通图和几何核对；“一阶但错误模态”记为失败 |

最终主结果使用两个共同指标：

```text
目标成功率 = 通过 OptTS + 频率 + 目标 R/P IRC 的反应数 / 全部测试反应数
每个正确完成反应的成本 = 全部方法尝试的 QC 核时 / 通过严格验证的反应数
```

另报从 R/P 输入到**首个正确 TS＋IRC**的完整耗时、队列等待时间、失败/超时分布，以及“最高点在端点”子集。失败和超时的消耗必须计入总成本；队列等待单列，不混入算法核时。对配对差异进行反应级 bootstrap，报告 95% 置信区间。

**预设‘效果很好’的研究目标：** 相比最强适用基线，目标 TS＋IRC 成功率至少增加 **10 个百分点**，且每个正确完成反应的总核时至少减少 **20%**；两项改善的 95% 配对置信区间均不跨越零改善。未达某项时如实报告，不用其他里程碑替代。

## 6. 实施顺序与交付物

| 阶段 | 建议规模 | 交付物与转段条件 |
|---|---:|---|
| A · 合同试验 | 100–200 条 | S0 映射/键变化检查、单分子与多组分端点样例、完整失败分类；修复任何静默索引错误 |
| B · 路径与 oracle gap | 约 1,000 条 | 分层路径有效率、基线和 oracle 差距；仅当有效路径存在可提升的选点空间时进入训练 |
| C · 排序训练 | 约 10,000–20,000 条有效路径 | 冻结的数据划分、模型、配置、Top-k 接口和独立测试结果 |
| D · 物理验证 | 至少 300 条独立反应；必要时扩至预留的 1,000 条 | 等预算 OptTS/频率/IRC 对照、配对置信区间、失败案例报告 |
| E · RPH 对接 | 现有环加成外部集 | 版本化候选 XYZ/反应中心适配器；RPH 保留 QC 执行、清单和恢复职责，训练代码留在 PES2TS |

现有 RPH 基准中的 `valid_target_ts` 是频率/模态层面的分类，多个记录的 IRC 状态为 `not_run`；不能把它直接当作 V4 的严格成功率。外部对照须重新按本方案完成双向 IRC。
