## 0. 一页结论

PES2TS 的重新定义：

> **从 IRC 曲线上任意一点出发，在给定拓扑约束下，预测下一步关键原子移动，以及当前点在曲线上的位置；通过 PREDICT → ACTION → RELAX → UPDATE 闭环，生长出整条曲线，经过 TS，最终到达另一个端点。**

这条定义里没有 branch：

- 一条 IRC 是一个**曲线对象**；
- 曲线上的每个节点是一个**状态**；
- 走法只有**行进方向** \(d\in\{+1,-1\}\)，它是瞬时选择，不是数据身份；
- 模型不学习 branch embedding，也不预测“我在 R 半支还是 P 半支”；
- 模型学习的是曲线上的**局部流场**：下一步位移 \(u\)、进度 \(q\)、停止概率 \(m\)。

\[
\boxed{
\text{PES2TS}(X_t,G_t)
\rightarrow
(\hat u_t,\ \hat q_t,\ \hat m_t)
}
\]

- \(\hat u_t\)：下一步 key-atom 位移；
- \(\hat q_t\)：当前点在 IRC 上的有符号进度（TS=0）；
- \(\hat m_t\)：是否到达 TS/端点，是否停止。

## 1. 曲线中心的数据模型

### 1.1 一条 IRC = 一个对象

```text
irc_curve
  curve_id / canonical_irc_id
  method, charge, multiplicity
  endpoint_A, endpoint_B
  ts_index
  nodes[0..N-1]         # 按 A -> TS -> B 排序
  progress[0..N-1]      # 0 -> 1，ts 处为 tau_TS
  energies[], gradients[]
  quality_status
```

### 1.2 节点与边

```text
irc_node
  curve_id, node_index
  xyz, graph
  energy, gradient
  progress
  is_ts, is_endpoint
  gauge_status, quality_status

irc_edge
  curve_id, i, j
  delta_xyz, delta_progress
  direction (+1/-1)
  quality
```

### 1.3 训练样本视图

```text
sample_view
  sample_id = (curve_id, node_index, travel_direction)
  state: xyz, graph
  target_next_node
  target_progress q
  stop_label
  quality/disposition
```

**没有 `branch_id`。**

- 旧 branch 数据只作为曲线上的两段；
- 数据质量诊断可以保留 `segment_quality`，但不进入模型输入；
- split 按 `curve_id` / canonical IRC，不按 branch；
- 同一条曲线的所有节点、两个方向、所有 d0 在同一 fold。

## 2. 进度与方向：没有 branch，但仍有方向

### 2.1 有符号进度

定义：

\[
\tau \in [0,1],\quad \tau_A=0,\quad \tau_{TS}=\tau_{\rm TS},\quad \tau_B=1
\]

\[
q = \tau-\tau_{\rm TS}
\]

- \(q<0\)：A 侧；
- \(q=0\)：TS；
- \(q>0\)：B 侧。

模型预测 \(\hat q_t\)。这是**输出**，不是输入；推理时从当前几何/拓扑预测。

### 2.2 行进方向不是 branch

行进方向：

\[
d_t \in \{+1,-1\}
\]

默认从起点决定：

\[
d_0 = -\mathrm{sign}(\hat q_0)
\]

含义：朝 TS 走。

- 起点在 A 侧，\(q_0<0\)，\(d_0=+1\)；
- 起点在 B 侧，\(q_0>0\)，\(d_0=-1\)；
- 起点在 TS，\(q_0\approx0\)，方向歧义，返回两个方向或要求用户指定。

**关键：方向在起点 latch，之后不因 q 过零而反向。**

```text
d = d0
while not stop:
    u = step_head(state)
    q = progress_head(state)
    X = relax(X + u)
    if q crosses 0: record TS
    if endpoint_match or budget: stop
```

这样从任意一侧出发，都会经过 TS，再继续到另一侧端点。

### 2.3 TS 穿越

- TS 前：q 从负到 0，或从正到 0；
- TS 处：q≈0，位移应很小，stop head 可触发；
- TS 后：q 变号，但行进方向 \(d\) 不变，继续到另一侧端点；
- 全曲线模式下，TS 只是途经点，不是终点；
- TS-only 模式下，q≈0 即停止并验证。

## 3. 三个预测头

### 3.1 Step Head：下一步 key-atom 位移

\[
\hat u_t \in \mathbb{R}^{K\times 3}
\]

- 目标：\(X_{t+d,K}-X_{t,K}\)；
- 输出可用 trust region 裁剪；
- 推理时由物理松弛接受/回滚；
- 第一版不要输出全原子坐标。

### 3.2 Progress Head：当前 IRC 位置

\[
\hat q_t \in \mathbb{R}
\]

或输出分布/区间。

用途：

- 判断在 A 侧还是 B 侧；
- 决定起点方向；
- 调整步长：离 TS 远可大步，近 TS 小步；
- 判断 TS 穿越；
- 判断端点接近；
- 产品报告“当前在曲线哪里”。

训练标签：

- 弧长归一化进度；
- TS 处为 0；
- 端点处为 \(-1\)/\(+1\) 或 \(-\tau_{TS}\)/\(1-\tau_{TS}\)。

损失：

- Huber / 分位数损失；
- 沿曲线单调性；
- TS 附近符号准确率；
- 端点附近误差。

### 3.3 Stop Head：TS / 端点停止

\[
\hat m_t \in \{0,1\}
\]

- TS candidate；
- endpoint reached；
- budget/stagnation 由控制器处理，不由模型学习。

训练标签：

- TS 邻域；
- 端点邻域；
- 远离 TS/端点的硬负样本；
- 不把所有接近 TS 的帧都标成停止。

### 3.4 可选：Endpoint Head（Unknown-B）

- 图编辑候选：断键/成键/键级/质子转移；
- 候选端点图 + 置信度；
- 只在 Unknown-B Discovery 模式启用；
- 不要求唯一 B。

## 4. PREDICT → ACTION → RELAX → UPDATE 闭环

```text
INIT:
  encode X_0, G_0
  q_0 = progress_head(state)
  d = -sign(q_0)   # toward TS; if q≈0, return both/require goal
  latch d

LOOP:
  PREDICT:
    u_t = step_head(state)
    q_t = progress_head(state)
    m_t = stop_head(state)

  ACTION:
    u_t = trust_region_clip(u_t, q_t)
    X_prop = X_t + u_t

  RELAX:
    X_next, E, g = physics.relax(X_prop, G, tangent)
    if invalid or not accepted:
        rollback(); shrink_step(); continue

  UPDATE:
    state = encode(X_next, G, memory)
    q_next = progress_head(state)
    memory.add(...)
    if q_t * q_next <= 0: record TS crossing
    if m_t and mode == ts_only: stop
    if endpoint_match or |q_next| >= endpoint_threshold: stop
    if budget/stagnation: stop
```

### 4.1 步长控制

\[
\text{step\_scale} = f(|\hat q_t|)
\]

- 远离 TS：步长大；
- 接近 TS：步长小；
- 端点附近：步长小；
- 物理拒绝：缩小步长；
- 不自动重置 episode。

### 4.2 回滚

- 几何非法；
- 图非法；
- 能量/梯度异常；
- 物理松弛失败；
- 连续失败 N 次 → stop with reason。

### 4.3 循环检测

- 图/几何哈希；
- 弧长停滞；
- q 停滞或震荡；
- 重复节点；
- 触发回滚/停止。

## 5. 训练

### 5.1 数据采样

对每个曲线节点 \(i\)，生成两个方向：

```text
(i, +1) -> target i+1
(i, -1) -> target i-1
```

- 不把方向当 branch；
- 方向只是 sample 的 travel_direction；
- 同一节点两个方向可以同时训练；
- TS 节点特殊处理：两个方向都指向两侧，不作为普通单步目标，或单独标 stop。

### 5.2 损失

#### Step

\[
L_{\rm step}
=
\mathrm{Huber}
\left(
\frac{\|\hat u-u^*\|}{a_{\rm ref}}
\right)
+
\lambda_{\cos}(1-\cos(\hat u,u^*))
\]

#### Progress

\[
L_q
=
\mathrm{Huber}(\hat q-q^*)
+
\lambda_{\rm mono}L_{\rm mono}
+
\lambda_{\rm sign}L_{\rm TS\_sign}
\]

- 单调性：沿固定方向，q 应单调；
- TS 符号：TS 两侧 q 符号正确；
- 端点：|q| 接近 1。

#### Stop

\[
L_m
=
\mathrm{BCE}(\hat m,m^*)
\]

- TS/端点正样本；
- 远离 TS/端点负样本；
- 类别不平衡用权重/焦点损失。

#### 路径级（rollout 后）

\[
L_{\rm path}
=
L_{\rm endpoint}
+
\lambda_{\rm TS}L_{\rm TS}
+
\lambda_{\rm barrier}L_{\rm barrier}
+
\lambda_{\rm cost}L_{\rm cost}
\]

#### 一致性

- 正反方向预测应相反：

\[
\hat u(x,+1) \approx -\hat u(x,-1)
\]

- 端点交换不变；
- 旋转/平移等变；
- 原子重编号等变；
- 可选 cycle consistency：正向走再反向走回到起点。

### 5.3 训练阶段

1. **Teacher forcing**：单步 BC；
2. **Scheduled sampling**：模型自己的状态 + 教师纠正；
3. **Rollout fine-tune**：多步路径级损失；
4. **Physics-in-the-loop**：真实松弛；
5. **RL**：只在 BC/闭环稳定后。

### 5.4 不输入未来

- 不输入下一帧、TS 坐标、IRC progress、端点几何；
- `progress` 是预测目标，不是输入；
- `travel_direction` 是采样变量，不是模型输入（推理时由 q 或用户指定）。

## 7. 推理模式

### Mode 1：Known-B

输入 A + B 图；从 A 出发，d=+1；经过 TS，到 B；端点图匹配停止。

### Mode 2：Known-B Reverse

输入 B + A 图；从 B 出发，d=-1；经过 TS，到 A；用于反向一致性。

### Mode 3：TS-only

输入 A + 反应中心；从 A 出发，q 到 0 停止；输出 TS 候选。

### Mode 4：Unknown-B Discovery

输入 A；Endpoint Head 提议多个 B 候选；对每个候选生长；Top-k 返回。

### Mode 5：From Any Point

输入曲线中间点；progress head 预测 q；方向由 q 或用户指定；生长到两侧端点。

**From Any Point 是产品核心能力，但要先有 Known-B/TS-only 的可靠 stop。**

## 10. 产品边界

MVP：

- Known-B；
- 从 A 或 B 任一端；
- progress + stop；
- PREDICT-ACTION 闭环；
- TS/端点验证；
- 失败显式返回。

MVP 不含：

- Unknown-B；
- 多产物发现；
- RL；
- 全自动机理解释。

不承诺：

- 唯一产物；
- 最低能垒路径；
- 代理模型结果等于 IRC；
- 未验证的 TS/端点。

---

## 11. 一句话

**PES2TS 不学 branch，也不学生成一条静态曲线；它学习 IRC 曲线上的局部流场：下一步位移、当前进度、是否停止。用 PREDICT → ACTION → RELAX → UPDATE 闭环，从任意一点出发，经过 TS，生长到另一个端点。**
