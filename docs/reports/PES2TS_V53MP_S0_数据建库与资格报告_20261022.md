## 2. S0-B 经授权提取与教师建库（硬门 = 无未授权访问）

- 路径：`truth_source.stream_scoped_irc_frames`（范围检查先于打开归档；confirm 永不请求）+ `truth_reader.load_ts_table`（一次批量审计读 charge/multiplicity/原子序）。`data/manifests/truth_access_log.jsonl` 逐反应记录；本 build 的日志切片随产物归档（`data/truth_access_log.jsonl`）。
- 归档布局（实测）：frame 0 = TS；其后两段方向分支（`ts_first_dual_branch`）。规范曲线 = `[seg_R 反转] + [seg_P[1:]]`，单一共享 TS；连续帧规范门（2°/0.1 Å）失败即 masked（`gauge_unresolved_excluded`），绝不静默重定向。
- 方向判定：比较型键编辑方向分数（全部有符号键编辑 × 两个分段端点）为主判据，G1 `orientation` 字段交叉核验；**0 例 G1 冲突被接受**（18 例冲突排除）；226 例方向歧义排除。
- 结果：26,600 候选 → **建成 26,038 曲线 / 5,958,548 样本**（ok 5,079,851 / terminal 514,831 / masked 341,902 / conflict 21,964）；quality：ok 24,560 / gauge_unresolved_excluded 1,478。排除 562（方向歧义 226、分段断裂 144+4、能量缺失 138、TS 能量非最高 28、G1 冲突 18、过短 4）。
- 产物：`data_manifest.json`（dataset_sha256 `4034db20…`）、`teacher_manifest.json`、`extraction_manifest.json`（逐反应 sha256）、`build_ledger_r3v53mp.json`（逐曲线证据：方向/连续性/冲突审计/能量）。

## 7. 声明边界与遗留

- 本阶段产物是**教师建库**，不构成任何 TS/IRC 科学验证；`verified TS` 主张仍须 OptTS+频率+双向 IRC+端点身份独立确认。
- `irc_node.energy` / `irc_curve.energy_a/b` 为 B3LYP-D3/TZVP 溯源值，**不作模型前向输入**（feature payload 从不含能量/梯度）。
- 方向判据的比较型分数在 200 反应种子审计中与 G1 方向 198/200 一致、0 冲突；2 例歧义排除。
- 已知遗留：S1 前的 λ 校准探针（gradient-share）尚未跑（arm B/C 在 config 中仍为 null，driver 拒绝启动，fail-closed）；S1 的 ≤1 GPU-h 是资源上限而非完成保证。
