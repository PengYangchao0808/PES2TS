| 轨道 | 冠军 | 确证性效应（inner-val，3 seed） | dev 复现（589 曲线一次性） |
|---|---|---|---|
| MOVE | **M1 Residual MLP**（37,272 参） | rmse_zero **+4.77%** 相对改善（95% CI [+4.60%, +4.95%]，p=1/10001）；direction@3 +0.47pp（p=0.0008） | rmse_zero **−6.1%**、dead −27%、sign +3.9pp、direction +2.4pp |
| PROCESS | **P3 Latent Graph-GNN**（36,210 参） | endpoint AUPRC **+0.283**、q MAE 相对 **+0.351**（双端点 p=1/10001） | AUPRC 0.437→**0.901**、q MAE 0.614→**0.233**、ordering 0.804→**0.993**、Brier −68%、ECE −80% |

- BMP（双冠军集成）在 dev 上为两轨改善的**精确并集、零干扰**——轨道隔离合同的最终实证。

## 6. 关键技术事实与裁决（均已入档）

1. **BOND_SCALE 换算冻结**（ADR-0034 §10 v1.1 ①）：forward ΔB = pair_edit/3.0；不改 builder/监督。
2. **A0 checkpoint 双形态**（v1.1 ②）：legacy 43 键（冻结 mapping）与 V542 A0 45 键双写已物化（identity 45→45）；strict=False 从未存在。
3. **三 seed bootstrap 配对修复**：per-seed inner-val 样本交集仅 37 曲线；evaluator 新增 multiseed 模式（每 seed 独立重采样 + per-draw seed 平均）后确证功效恢复为 3×~1,024 曲线；基线刷新后指标逐位不变（`--compare-to` 硬断言）。
4. **M1/M2 实现偏差**（方案 §6.3 宽度为设计起点）：M1 的 u0/a_ref 原始笛卡尔分量改为与 key_v 的不变内积（否则旋转等变必 fail）；M2 投影零初始化 + gate=1（双零初始化梯度全死）。
5. **CPU-bound 训练**：方案 §8.4 的 43–55 min/run 估计按 GPU 假设；实际 CPU 单 run ~2.4h、18-run 合计 ~43h——同环境纪律优先，未改 frozen trainer。
6. **文档不一致记录**：主方案 §2 F6 的 A0 q_corr 0.9988 vs V542 执行口径 0.99682（V543 evaluator 重算值为准）；parity 证书模板 43/45 双计数口径对 45 键形态的适用性说明。
