## 2. 单端方案的科学定位

“从一个初始结构出发、沿给定事件方向逐步生成新节点”是成立的算法定位。但每一步仍求解非线性约束优化，不是分子动力学，也不是自动沿物理力场积分得到的唯一轨迹。驱动选择、目标函数、初始构象和电子态都保留了先验。

GSM 同时存在单端和双端版本；单端 GSM 的文献已明确以一个结构和驱动坐标逐步生长节点，并在生长后继续优化路径和 TS。因此研究价值应放在在线验收、失败诊断、预算可复现和与现有 PES2TS 数据合同的整合，不能建立在“GSM 必须给产物”这个前提上。[Zimmerman, 2015](https://onlinelibrary.wiley.com/doi/10.1002/jcc.23833)，[作者维护的 GSM 项目](https://zimmermangroup.github.io/molecularGSM/)。

建议区别三个信息级别：

1. 参考引导延续：固定原有教师目标函数，用于隔离执行算法的改进。
2. 已知事件、未知终点：只给 R 和局部事件，如靠近、拉长、质子转移；不输入 P 的坐标或完整编辑图。
3. 反应事件自动发现：还需要枚举/学习驱动事件、方向、构象和电子态，并在预算内探索多分支。单条延续本身没有覆盖这部分。

## 3. 预测器：公式可用，但不是精确满足非线性约束

给定 \(J=\partial q/\partial X\)，建议公式

\[
\delta X=M^{-1}J^T(JM^{-1}J^T)^+\Delta c
\]

求解的是

\[
\min_{\delta X}\frac12\delta X^TM\delta X,
\quad \text{s.t.}\ J\delta X=\Delta c,
\]

前提是右端在 Jacobian 的可达空间。质量为正且单位处理一致时，这是有效的质量加权最小位移预测。其度量是质量加权位移，不是普通欧氏笛卡尔位移；希望普通位移最小时取 \(M=I\)。质量权重应作为可对照的选择，不是保证化学正确的必要条件，也不代表动力学。

实际有

\[
q(X+\delta X)=q(X)+J\delta X+O(\|\delta X\|^2).
\]

所以一步更新通常只在一阶满足约束。当前预测器的一个三原子、双距离数值例：目标 1.10/1.20 Å 时，未裁剪的一步预测得到 1.104536/1.201041 Å；小目标变化 1.01/1.02 Å 时则得到 1.010050/1.020012 Å。这说明小步长有效，但“精确满足”仍需额外投影。

首版建议：

1. 计算到新目标的实际残差 \(r=c(\lambda_{next})-q(X_{accepted})\)，而不只用 \(c(\lambda_{next})-c(\lambda_k)\)。否则已有残差会累积。
2. 距离用 Å，角/扭转在求解端转换为弧度；周期扭转展开；按允许残差做行缩放。
3. 对缩放后的 Jacobian 做 SVD，记录有效秩、奇异值和不可达残差。伪逆不会使矛盾约束变得可行。
4. 多次重新计算 Jacobian 和残差，进行有限次非线性回代；每次有信赖域和残差下降验收。
5. 当预测所需位移超过限额时，优先缩小 lambda 步长并重新求解。仅裁剪位移再将完整目标交给 ORCA，会把剩余冲击转移给校正器。
6. 对接近线性的角/扭转使用稳定替代坐标；首次可沿用已验证的 B/A/D 后端能力，不假定自定义坐标能直接写成 ORCA Constraints。

ORCA 自身也说明内部坐标到笛卡尔坐标的变换非线性、需迭代回代；约束初猜应接近目标。[ORCA 几何优化文档](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/optimizations.html)。

这只是“可行几何预测器”。严格的约束驻点分支切向还涉及能量曲率。若

\[
\mathcal L=E(X)+\nu^T(q(X)-c(\lambda)),
\]

则在独立约束、去除刚体自由度等正则条件下：

\[
\begin{bmatrix}H_{\mathcal L}&J^T\\J&0\end{bmatrix}
\begin{bmatrix}X'\\\nu'\end{bmatrix}
=\begin{bmatrix}0\\c'\end{bmatrix}.
\]

首版不必引入昂贵的精确 Hessian。可先使用质量加权可行性预测，加上已接受帧的对齐割线来估计非驱动方向，再重新投影；曲率模型作为后续升级。接近奇异分支时，更好的几何伪逆不能替代曲率诊断。

## 4. ORCA 校正：工程可行，速度与分支保持需实测

现有真实 ORCA 6.1.1/GFN2-xTB 探针已验证混合 B/A/D 逐点硬约束与五距离约束；可复用约束编译与结果恢复。每个新点从预测器输出启动，全部目标同时施加。

几何暖启动不会自动复用 SCF 波函数或优化 Hessian。若增加波函数/Hessian 重启，需要分别验证方法、原子顺序、电子态、约束集合和文件有效性；失败尝试的重启数据不得覆盖上一已接受状态。

“5–15 步必定收敛”应改为待测的性能目标。约束曲率、质子迁移、SCF 分支和初始状态都可能增大成本。每次校正需要验证计算正常终止、电子结构收敛、几何收敛、有限能量与全部驱动残差。

ORCA `Trust`/`MaxStep` 控制单次优化更新，并不保证最终结构离上一帧足够近。普通硬约束优化允许未约束自由度发生远距离松弛；在线拒绝是必要的。若以后加入到上一帧的总位移限制或近端正则化，必须区分物理能量与辅助项，并确认得到的是物理约束极小值而非被正则项固定的非驻点。[ORCA 几何优化文档](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/optimizations.html)。

## 5. 连续性验收与步长折半

建议保留现有整体 proper-Kabsch RMSD ≤ 0.30 Å，增加同一次整体对齐下的最大原子位移 ≤ 0.60 Å。前者容易被大量不动原子稀释，后者能发现局部跳跃；同时输出反应中心与重原子 RMSD。

原子身份固定、只允许共同 proper 刚体变换；不能分别移动独立组分，也不能为了降低 RMSD 重排原子。反应中心单独对齐可作为补充诊断，不能代替共同对齐下的相对位置检查。两个阈值是工程门槛，不是化学连续性的充分证明。

还应记录：

- 全部目标残差及投影梯度证据（后端可提供时）；
- 校正量 \(\|X_{opt}-X_{guess}\|\) 与实际接受位移；
- 保护键变化、非成键碰撞、必要立体信息；
- 量化计算迭代数、电子态与可用的自旋指标；
- 物理能量和按实际非均匀 lambda 计算的斜率。

拓扑门要区别“旁观骨架保护”和“探索区事件”。无条件禁止非驱动成断键会禁止未知质子迁移或级联事件。严重碰撞和明确保护骨架异常可拒绝；探索区新事件应保留为分支证据，经过复算、释放约束及新计划版本处理。共价半径只是初筛，需滞回阈值和多帧确认；可用时结合键级。距离门不能单独定义键级变化。

折半机制的正确承诺是：拒绝不合格点污染主轨迹，并在有限预算内尝试更小步长。它不能保证局部极小值分支永远存在。

到达最小步长仍失败，至少可能是：约束不可行、坐标退化、SCF 不收敛、优化迭代不足、输入问题、真实极小值分支失稳或控制坐标遗漏。必须输出原因和最后已接受状态，不能直接宣布“已确认分岔”。如果投影 Hessian 的软模趋近零，才增加失稳诊断依据。

步长只在连续两次通过全部门、位移较小且校正温和时放大；拒绝后清零平滑计数。lambda 的数值依赖目标参数化，因此 0.001/0.005 不能跨反应直接解释为相同几何精度。联合控制 \(\Delta\lambda\)、缩放的 \(\Delta c\) 和预测位移；另设 accepted_frames、attempts、wall_time 和每点重试预算。40 帧可作为预算上限，触顶时返回部分路径与预算终止，不能为了补齐终点放过坏帧。

伪代码中的 `max(d_lam / 2, d_lam_min)` 在反复失败时会永久停在最小步长。应检查下一实际步长和重试预算后显式终止。最终剩余区间若小于最小步长可尝试一次；失败后按预定规则终止。SCF 错误先分类处理，永久性后端错误直接终止，不能全部靠几何步长折半。

进一步的伪弧长延续可处理以 lambda 参数化的折叠，但可能跟踪到失稳驻点；它不保证继续保持局部最小，更不能自动把路径认定为真实机理。应作为后续分支诊断工具。

## 6. 能量峰与 TS 候选

在上述拉格朗日符号约定、相同电子态和收敛的可微约束驻点分支上：

\[
\frac{dE}{d\lambda}=-\nu^Tc'(\lambda).
\]

若后端没有可靠乘子输出，不应假设能从普通日志直接获得；首版使用非均匀节点的有限差分、局部拟合与峰值区间加密。若能导出未投影物理梯度，可在满秩/条件合适时估计乘子，并核查 KKT 残差、单位及符号。

**多驱动共用一个 lambda 时，导数为零不意味着全空间梯度为零。** 例如两个约束方向的乘子贡献可以相互抵消：\(\nu=(1,-1)\)、\(c'=(1,1)\) 时 \(\nu^Tc'=0\)，但 \(\nabla E=-J^T\nu\) 仍可非零。这在现有多坐标架构中尤其关键。

一个独立标量约束且 \(c'\ne0\) 时，精确 KKT 条件下零导数会使乘子为零，这是更强的特殊情况；仍需 Hessian 和连接验证，不能据此推广到任意多驱动路径。

因此：接受的能量局部峰 → 候选区间 → 加密和曲率诊断 → 无约束 OptTS → 频率确认一个相关虚频 → 双向 IRC 和端点优化、身份确认。虚频应对应目标反应运动。分支跳跃、电子态切换和无有限能量的点不能参加峰值判定；允许无势垒、多个峰和不完整峰的结果类型。[ORCA TS 搜索](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/optimizations_TS.html)，[ORCA IRC](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/irc.html)。

## 7. 中间体沉降与停止条件

C–C ≤ 1.54 Å 仅可作特定驱动的试探触发，不能证明跨过势垒。这个距离可能过短、排除异步成键或只由外力压缩产生。用事件类别和元素适配的窗口、多帧趋势及峰后下降证据触发；无势垒反应设单独规则。

释放约束优化作为独立 landing probe：保留原 accepted checkpoint，不能用探针输出直接覆盖主轨迹。探针有四类结论：

1. 回到原 R 的势阱：这次沉降未发现新的中间体，可在预算内继续驱动；
2. 新稳定候选：确认电子态、拓扑与构象去重，并保存来源；
3. 新的意外事件分支：保存探索证据，按规则形成派生计划；
4. 优化/电子结构失败：返回失败证据，不产生中间体结论。

自由优化收敛可用于暂定候选；正式局部极小值结论需梯度与频率/曲率支持，排除有意义的虚频，并将近零数值模单独判读。证明与 R 经所选 TS 相连仍需 IRC。它可能沉降到任一可达势阱，不保证唯一或最“自然”的下一中间体。

搜索停止状态至少区分：确认新中间体、无势垒终点候选、事件范围耗尽、预算耗尽、电子结构失败、约束不可行、连续性无法恢复。lambda 达上限本身不构成找到中间体。多基元探索从确认的 I 开始新一段，重新选择事件；保留分支、父路径与状态身份。

对自由基/双自由基，多重度与同一自旋面内 SCF 解仍需跟踪。几何连续不能保证电子态连续；不同自旋面的穿越需独立处理，不能由这个几何循环代替。

## 8. 建议的新执行合同与状态机

新模式建议命名 `single_ended_continuation`，保留旧同步参考模式。冻结输入应含：完整 R、原子映射、元素、charge/multiplicity、计算级别、局部驱动及其来源、目标函数版本、监控/保护区、步长/阈值/预算和停止策略。未知终点模式不要求 P 或预先完整 lambda 表。

即使不给 P 的坐标，若驱动仍由 P 的图编辑或已知 TS/IRC 提取，也必须标为已知事件/参考引导，不能声称反应事件盲发现。

将冻结的生成规则与动态执行结果分开：

- `AcceptedFrame`：frame_id、lambda、X、物理能量、电子态、全部目标/实测残差、父 accepted ID、质量证据；
- `Attempt`：attempt_id、父 accepted ID、新 lambda、步长、种子来源/哈希、量化文件、拒绝原因与耗时；
- `Checkpoint`：最后已接受帧、电子结构重启引用、下一步长、平滑计数、总预算；
- `TS/IntermediateCandidate`：候选来源、后续验证状态及关联作业；
- 终止结果：状态、部分有效路径及剩余未证实事项。

状态转移：

```text
INPUT_CHECK → PREPARE_R → ACCEPT_INITIAL
ACCEPT_INITIAL / ACCEPT → PREDICT → PROJECT → CORRECT → VALIDATE
VALIDATE → ACCEPT → PEAK/EVENT_CHECK → NEXT / LANDING_PROBE
VALIDATE → REJECT → CLASSIFY → RETRY / HALVE / STOP_WITH_EVIDENCE
LANDING_PROBE → NEW_CANDIDATE / RETURNED_TO_R / BRANCH_EVIDENCE / FAILED
```

只有通过完整门的点更新 checkpoint。被拒绝点不进入有效能量曲线，但保留文件、记录和成本。每个反应保持一个逻辑主任务，帧和尝试为其子记录；恢复运行先按 attempt 身份检查已有产物，避免重复执行和帧污染。新增控制坐标属于计划变更，应按新版本处理，不在 G2 静默修改冻结 G1 驱动。

原始 R 不一定是当前方法下的驻点。先做输入检查和同方法无约束准备，保留原始 R 与准备后的 R0 两份结构、哈希和电子态；若预优化改变反应身份则拒绝或单独判读。以 R0 为分支起点，原始 R 可保留为来源节点；不要把一次大幅起点松弛计成反应推进。

## 9. 分阶段实现与验证

### 第一阶段：接通执行闭环，隔离算法收益

复用现有约束后端，新增在线预测/投影、完整验收、折半、预算和 checkpoint。固定相同 R0、GFN2-xTB、电子态与目标函数，对比：逐点参考启动；上一帧启动且固定步长；上一帧预测并自适应步长。三组使用相同连续性门和可比较的总计算预算。先不新增控制坐标，避免把坐标设计收益误记到执行器。

代表例包括：RXN_0000007104（已通过基线）、RXN_0000017762、RXN_0000187964（多驱动困难例）、RXN_0000026256、RXN_0000077619（单驱动困难例）。RXN_0000155302 用于输入异常拒绝，不参与有效机理成功率；其准备修复效果另行统计。

首阶段无固定 P 的终点合同有变化。比较重点是同一驱动区间的覆盖和连续性；达到门槛但提前停滞只计部分路径，不能通过取消末端验收宣称超过旧模式。参考引导对照也不能变为盲发现证明。

### 第二阶段：事件驱动未知终点

新增单端合同、冻结事件目标函数、landing probes 和候选去重；生成侧禁读 P/TS/IRC。验证器可独立读取保留真值来评价，但该信息不得回流到本次搜索策略。先测试已知事件、未知 P；事件自动提出作为后续独立任务。

### 第三阶段：科学验证与分支诊断

对候选做 DFT 或适当层级的 OptTS、频率和 IRC；校验得到的新极小值身份与相邻连接。GFN2-xTB 上的成功不自动迁移到高层级能量面。对持续折半压力例增加投影软模/分支分析，再评估少量额外控制或伪弧长方案。坐标、模式和能量层级变化需单独记录。

### 必要测试与实际指标

必要负例：非线性预测残差、不可达目标、角度退化、周期跨界、末端剩余步长、最小步长重复失败终止、SCF 永久失败、缺失/NaN 能量、约束残差失败、接受后分支跳跃、拒绝点污染 checkpoint、恢复重复提交、无峰/多峰、landing 回到 R、异常 R、真值生成泄漏。

实际指标：有效起点数、完整区间完成率、部分路径比例、拒绝原因、accepted/attempts、最大整体/中心/原子位移、约束残差、总 wall time、SCF/优化迭代、landing 新势阱比例、候选 TS 精化与 IRC 成功比例。统计所有失败尝试、R 准备、landing 与验证成本；上轮剩余 18 例的 518 秒不含此前全部修复成本，不能据此承诺新版速度。

首阶段的退出条件是有限预算可终止、拒绝点不污染状态、全部接受点满足冻结质量门，并在同信息/同预算对照下观察到覆盖与成本的收益。允许明确失败；不要求算法以不真实的“100% 连续完成”来通过验收。

## 10. 推荐决策

优先实施“上一已接受帧暖启动 + 非线性可行性投影 + 在线多门验收 + 有限折半与失败分类”。这是当前证据直接支持的改进。随后增加未知终点合同、事件触发沉降和独立 TS 验证。质量加权、割线预测、分支曲率诊断及伪弧长按实测收益升级。

本方案有实质可行性与科研价值；其可靠性来自可复核的路径连接和候选验证，而不来自对唯一终点、100% 连续性或固定计算步数的保证。
