## 摘要

PES2TS 已经形成一条可执行的“物理生成 + 离线学习 + 冻结评测”工程链：G0/G1 数据与拓扑层、G2/G2.T xTB–ACP 执行层、G3.P PES-N 离线数据/模型/训练/评测层，以及贯穿全链的执行身份、真值隔离、typed refusal 与内容寻址冻结。当前代码规模约 **10.4 万行**（`pes2ts_core/`，272 个 Python 文件），测试代码约 **6.4 万行**（179 个测试文件），另有约 2.3 万行实验/驱动器脚本（108 个 Python 文件）。

本轮 V4.2–V4.7 完成了五项新的工程能力：

1. **原生重连数据版本**：剔除 399 个插入节点，重建 50 组/100 分支/5,568 个原生动作；全部身份、单位、后继唯一性与标签恒等硬门通过。
2. **无界 Cartesian 位移头**：取消 `0.1·tanh` 动作上限，直接回归 Å 位移；旧 radial-tanh 头保留为 D0/D1 对照。
3. **战役训练协议 `campaign_v1`**：AdamW、warmup+cosine、EMA、u5k/u10k/u20k 独立检查点、曝光账本、完整断点恢复。
4. **三口径冻结评测**：`legacy_full` / `native_full` / `common_unchanged`，在看任何模型预测前冻结；四项门 1.0 / 6-of-8 / 0.30 / 0.40 原样保留。
5. **可恢复战役驱动器**：预检、测速标定、阶段晋级、预注册裁剪、预算删失、失效 run 归档与重跑。

**最新训练结果是一个明确的负结果：** V4.7 FINAL 在完整 fit50 上训练三种子（20261017/18/19），以 `native_full` 主口径的三种子中位为 **MSE/零动作 1.132、优于零动作组数 0/8、整体 cos 0.180、near-TS cos 0.248**，四项全部低于冻结门；三种子没有任何一个通过四项门。`legacy_full` 与 `common_unchanged` 给出同方向结论。全部筛选臂（D0–D3、H2、E1/E2、V1、W96/W128）也都未过门；H1 因物理先验 `Δs_fit=0` 被预注册门判 `prior_not_supported`，V2 因接触边实现 0.43 steps/s 按预注册顺序裁剪，40k 延长门判 `STAY_20K`。

**最重要的科学判断：** 失败不是“训练链路没跑通”，也不是“单纯容量不足”。本轮 fit 侧误差持续下降（E1 的 fit MSE/零动作 = 0.706，W128 = 0.681，V1 = 0.516），但 dev 侧 MSE 反而升到 1.26–1.49、组数降到 0；说明当前 50 组数据、单帧 5 通道观测、全原子位移目标与 20k 训练预算的组合，存在严重的**跨反应泛化缺口**。同时，fit45 内存在 **342 对近似相同输入但教师方向冲突**的样本，单纯“加大模型/延长训练”没有证据支持。下一步应优先解决输入可辨识性、训练时长协议与数据覆盖，而不是继续堆容量。

## 一、项目定位与阶段边界

### 1.1 项目目标

PES2TS 是一个化学约束、物理在环、成本感知的过渡态搜索工作流。其共享 PES-N 内核面向两类决策：

- **排序（ranking）**：评估一个反应状态是否值得 `STOP_OPTTS`；
- **导航（navigation）**：比较 `STOP`、图定义 `MOVE` 与经过验证的回退动作。

Classic 扫描仍是基线与兜底控制器；ACP 负责真实 ORCA/xTB 执行；G3.P 负责从合格 IRC 教师数据中学习反应状态与位移；G4 的 IQL/SAC 闭环仍处于停靠状态。

### 1.2 阶段状态

| 阶段 | 当前实现 | 证据状态 | 不能据此声称 |
|---|---|---|---|
| G0 数据入口 | fetch/inventory/quarantine/dedup/DRFP audit/split freeze/cohorts，幂等 8 阶段 | 有真实数据与冻结收据 | 不代表所有族/用途资格已闭合 |
| G1 拓扑与真值层 | bond-change 文档、P1 映射、P2 分类、v2 排他编辑、扫描计划 propose/verify/freeze | 有 gate 与真实产物 | 拓扑可扫描不等于 TS 可确认 |
| G2 Classic / G2.T | 图论选点、ACP/xTB 原生约束扫描、24 例战役、四类终态、成本账本 | 24 例真实终态与成本证据 | 正式 validated=0；未切生产默认 |
| G3.P PES-N | 双侧教师、特征 v3/v4、EGNN/PaiNN、BC/IQL、V4.2 战役、三口径评测 | 本轮新增大量真实训练证据 | 未过研究门；无生产模型 |
| G4 RL 闭环 | 控制合同、宏步环境、critic/控制头、离线 trainer、`g2t-control-round` | fixture 与规划级证据 | 真实闭环、收益与 SAC 未验收 |

### 1.3 证据纪律

本轮延续项目宪法与既有冻结件：

- **真值隔离**：教师标签、TS/IRC 原始真值仅经 audited bridge 读取；`utils/truth_guard.py` 做 AST 静态扫描与 allowlist。
- **执行身份**：每次 ACP 调用有 `execution_id`/`attempt_id`；失败、重试、预算删失分别记账。
- **内容寻址冻结**：协议、阈值、划分、数据 manifest、物理先验均绑定 sha256；训练开始后不可修改。
- **typed failure**：缺失依赖、模型不兼容、预算耗尽、裁剪、先验不放行都写机器可读代码；不静默截断、不伪造结果。
- **报告只读**：新报告不修改历史门审、协议、模型、阈值或冻结记录。

## 三、V4.2–V4.7 新增实现

### 3.1 原生重连数据 `pesn_dual_ts_features_native_v1`

**规则**（`dual_ts_native_rebuild.py`）：

1. 按 `gaps_registry_observed.json` 的 `inserted_state_id` 全集剔除插入节点；
2. 原生后继 = 原生序列中的下一个节点；`action_delta = X_next − X` 使用已配准坐标，**不重新配准**；
3. 逐态特征从 v3 npz 原样继承；`s_g`/`s_delta_e` 沿用 v3 冻结值；
4. `remaining_arc_length` 在原生链上按同一质量加权度规重算；
5. 395 个超限动作与 399 个插入节点的差额逐条解释，解释不了即 hard fail。

**硬门结果**（`native_reconnect_audit.json`，`all_passed=true`）：

| 门 | fit | monitor |
|---|---|---:|
| 原生状态数 | 5,668 | 931 |
| 原生动作数 | 5,568 | 915 |
| 教师端点数 | 100 | 16 |
| 标签恒等最大误差 | 0.0 Å（≤1e-10） | 0.0 Å |
| 未变步恒等最大误差 | 8.7e-16 Å | 8.3e-16 Å |
| 弧长重算最大误差 | 7.1e-15 | 3.6e-15 |
| 唯一后继 / 双侧排序 / map+单位 | 通过 | 通过 |
| E/g 定点抽查 | 20 态，最大 5.0e-11 | 20 态，最大 5.0e-11 |
| 最大原子动作 P50/P90/P95/P99/max (Å) | 0.0120 / 0.0375 / 0.0518 / 0.0896 / 0.2078 | 0.0129 / 0.0400 / 0.0543 / 0.0959 / 0.2379 |

**解释**：`0.1 Å` 上限只影响 **<1%** 的原子动作（P99 = 0.0896 Å < 0.1 Å，最大 0.2078 Å），不是本轮失败的主因。这个结论修正了“取消 0.1 Å 就能解决”的直觉。

E/g 来源登记为 **GFN2-xTB（ORCA EnGrad 包装）**，`basis=""`（xTB 无基组，显式空而非缺字段），`charge=0`，`multiplicity=1`，`solvent=unrecorded`；`g=∇E`，单位 Ha/Å。**不得默认它与教师 DFT IRC 势能面同源。**

### 3.3 物理先验与梯度基线

**公式**：

```
b_i = (g_i / m_i) / sqrt(Σ_j ||g_j||²/m_j + eps_g²)
a_phys,i = Δs_fit · b_i
Δs_fit = max(0, Σ w (b·a*) / Σ w ||b||²)
```

- `a_s = 0.0119204 Å`（fit45 非零原子动作中位，正尺度，不是上限）；
- `eps_g = 4.0941e-5`、`tau_g = 4.0941e-8`；
- 梯度质量范数中位 0.04094；原生质量加权步长中位 0.16540 Å；
- 5,046 态 / 79,401 非零原子。

**放行门结果（H1 未入夜）**：

| 判据 | 值 | 结果 |
|---|---:|---|
| `Δs_fit` 正且有限 | **0.0** | 否 |
| fit5_dev 组中位 MSE/零动作 < 1 | — | 否（先验幅值为 0） |
| 整体 cos > 0 | 先验方向 +g：dev −0.0202 / full +0.0242 | 否 |
| near-TS cos | +g：dev 0.1180 / full 0.2044 | 弱 |
| H1 放行 | `prior_not_supported` | **未跑 H1** |

**含义**：在 fit45 上，xTB 质量加权反向梯度与教师原生位移的线性投影为零（非负最小二乘截断到 0）；`+g` 的方向 cos 只在 full 上略正、dev 上为负。跨方法（xTB vs 教师 DFT IRC）与单帧切线近似不足以支撑“物理先验”作为强 baseline。**这不是数据错误，而是先验不适用的负结果。**

**可辨识性**：在 0.05 Å 输入阈值内，fit 中存在 **342 对**近似相同当前帧但教师方向冲突的样本（已排除原子置换/重复身份/精确重复坐标）。这给出单帧 5 通道输入的信息上限：一部分“误差”不是模型容量能消除的，而是同一输入对应多路径/多后继。后续若继续单帧 BC，必须把这一类样本显式处理（多路径标签、历史/曲率输入或 pair 目标），否则门不可达。

### 3.4 模型与目标

| 版本/臂 | 编码器 | 头 | 动作 | 关键开关 |
|---|---|---|---|---|
| D0/D1 | DualTSEGNN 5ch | `DualTSPolicy` radial-tanh | 0.1 Å 上限、log-Jacobian | 旧 `legacy_v41` preset |
| D2/D3 | DualTSEGNN 5ch | `DualTSDisplacementPolicy` | 无界 Å 位移 | `campaign_v1` |
| H1（未跑） | 同上 | 同上 + frozen `a_phys` skip | 无界 | `use_prior_skip=True` |
| H2 | 同上 | 同上 | 无界 | `L_xyz + λ_dir L_dir + λ_mag L_mag` |
| E1 | DualTSEGNN 7ch 边 | 无界 | 无界 | `features_v4` |
| E2 | 同上 + keypair wrapper | 无界 | 无界 | `keypair_condition=True` |
| V1 | `DualTSPaiNNEncoder` 16 向量通道 | 无界 | 无界 | `encoder=painn` |
| V2（裁剪） | PaiNN + 接触边 | 无界 | 无界 | 5 Å、16 近邻、平滑 cutoff |
| W64/96/128 | DualTSEGNN | 无界 | 无界 | hidden 64/96/128，`light=False` |

**无界位移头**：`a_hat = gate(h) ⊙ v`，gate 为有符号线性读出，无 tanh 上限、无 inverse-tanh/log-Jacobian；同时报告 residual/skip 范数与比值（零分母 NaN）。E2 的 keypair conditioner 与 E1 的 7 通道边特征均在训练器中注册参数。

### 3.5 训练协议 `campaign_v1`

- AdamW，峰值 lr=3e-4，wd=1e-5；warmup 前 5%，余弦衰减到 1e-5；梯度裁剪 1.0；
- batch=64 states；20k updates = 1,280,000 次状态抽样；
- EMA decay=0.999，warmup 后启动；raw 与 EMA 同存；
- 检查点 `u5000/u10000/u20000/{raw,ema}.pt` 独立路径；
- dev 评估在 5k/10k/20k；记录 fit 诊断、曝光、近 TS 比例、逐组/分支 draw 分位；
- 非有限 loss/action/grad 立即停臂；断点恢复保留同一臂身份与 RNG/采样器/曝光状态。

**曝光**：fit45 可抽取 5,046 态，coverage=1.0，repeat_rate≈0.996，near-TS 抽样占比 0.1806（与总体 0.1773 接近，无偏）；每次 20k run 约 229–253 epochs（legacy 数据 236，native 253，FINAL 229）。

### 3.6 三口径评测与晋级

| 口径 | 标签/分母 | 用途 |
|---|---|---|
| `legacy_full` | 原 monitor8 v3 特征、全部细分动作、原组名单与方向/near-TS mask | 历史四门回归；对新原生动作模型存在**目标口径不匹配**，只能作交叉检查 |
| `native_full` | 原生重连 monitor8、全部原生动作、8 组 | 新任务主口径；四门阈值沿用但标记 `new_protocol=true` |
| `common_unchanged` | 两库共有、未被细分、后继/动作/mask 一致的转移交集 | 同题比较；不套四门，只报告差值与缺失分母 |

`protocol_freeze.json` 在任何模型预测前写一次，payload sha256 `e7b11a44…`；live reference digest 必须与冻结一致，否则拒绝评测。

**§9.1 晋级规则**：对每个配对种子，子臂必须同时满足整体 cos +0.01、near-TS cos 下降 ≤0.01、组中位 MSE 比值上升 ≤0.01、优于零动作组数不减少、pooled 比值上升 ≤0.02、near-zero RMSE 上升 ≤10%；否则保留父臂。多候选按组中位 MSE ↓ → cos ↑ → 参数少排序。

**§9.2 40k 门**：仅当入选配方两种子 10k→20k 的 dev 组中位 MSE 比值各下降 ≥0.01、整体/near-TS cos 各不下降 >0.01、near-zero RMSE 不增加 >10%，且三种子 40k 含评估能放入 95 min 时，才允许 40k；否则统一 20k。

### 4.3 指标定义

- **MSE/零动作**：逐组 `MSE_model / MSE_zero`，再取 8 组中位；零动作 = 预测全零位移；
- **优于零动作组数**：比值 <1 的组数（门要求 ≥6/8）；
- **整体 cos**：在 `||a*||≥0.01 Å` 的方向有效原子上，按 |a*| 加权后取组中位；
- **near-TS cos**：剩余弧长位于近 TS 20% 的状态上的同定义；
- **near-zero RMSE**：`||a*||<0.01 Å` 原子的绝对位移 RMSE（Å）；
- **α**：`|a_hat|/|a*|` 的逐原子中位；近零真值显式未定义；
- **关键对**：`changed_flag=1` 的并集边端点；报告距离变化符号准确率与预测后距离误差。

### 5.5 切片：错在哪里

以 FINAL seed20261019 / `native_full` 为例：

| 切片 | 指标 |
|---|---|
| 重原子 cos | **0.314** |
| 氢原子 cos | **0.109** |
| 长步 P99 cos | **0.111** |
| 旁观原子 cos | 0.116 |
| 关键对 cos | 0.299 |
| 关键对距离 MAE | 0.0201 Å |
| 关键对距离变化符号准确率 | **70.2%** |
| near-zero 原子绝对 RMSE | 0.0102 Å |
| α 中位 / p10 / p90 | 0.274 / 0.036 / 1.279 |

**解读**：

1. **重原子骨架方向明显好于氢**：0.314 vs 0.109。氢转移/氢长步是主要失败来源，与化学直觉一致，也解释了 near-zero 与长步切片差。
2. **长步（P99 >0.096 Å）方向 cos 仅 0.111**：模型对大幅位移几乎无方向能力；这直接关系到后续 IRC 追踪，不能用“平均 MSE 接近”掩盖。
3. **关键对符号准确率 70.2%**：高于随机，但远不足以驱动约束优化；距离 MAE 0.02 Å 对 5 Å 尺度看似小，但对成/断键方向判断仍会累积错误。
4. **α 中位 0.274、p90 1.279**：整体仍收缩，但尾部已出现幅度过冲（p90 >1）；不是单纯“步长太小”。p10=0.036 说明大量近零/难样本仍被强烈压缩。
5. **per-group 极不均匀**：`RXN_0000010293` 的 MSE 比值 7.11、cos −0.00；其余 7 组比值 1.01–1.33、cos 0.11–0.41。组中位 1.13 掩盖了单组灾难。该组必须单独审查（长步/曲率/原子数/教师质量），不能只报总中位。

### 5.7 失败归因（按证据强度排序）

1. **跨反应泛化缺口（强证据）**：fit MSE/零动作 0.52–0.78，dev 1.26–1.49；容量越大 fit 越好、dev 越差。45 组 fit 对 10 万–38 万参数模型明显不足。
2. **单帧可辨识性上限（强证据）**：342 对近似相同输入/冲突教师方向；已排除置换、重复身份与精确重复坐标。单帧 5 通道无法区分部分路径。
3. **训练时长/终点选择冲突（强证据）**：多数臂 dev 在 5–10k 最好，20k 退化；预注册只读 20k 终点，导致“最佳 dev 模型”不进入定稿。40k 门也因此判 `STAY_20K`。
4. **目标/幅度权衡（中等证据）**：无界头把 α 从 0.15 提到 0.27，方向改善，但 MSE 更差；旧头 α 0.08–0.12、MSE 更低。方向与幅度尚未同时闭合。
5. **物理先验不适配（强负结果）**：Δs_fit=0、dev cos 负；xTB 梯度与教师 DFT IRC 势能面不同源，单帧切线近似不足。
6. **辅助损失校准失败（强负结果）**：H2 的 λ_dir=16,311.87、λ_mag=56.20 使 fit 与 dev 同时恶化；该一次性梯度范数校准规则不适用于本任务。
7. **结构增强未转化为泛化（中等证据）**：E2 keypair、V1 PaiNN、W96/W128 均未在 dev 上超过 E0；V1 的 fit 最好但 dev 最差之一，说明容量/表达不是瓶颈。
8. **接触边实现性能（工程负结果）**：0.43 steps/s，纯训练 20k 约 12.9 h；不是模型效果失败，而是逐状态构边实现不可接受；按预注册裁剪。

### 5.8 不能声称什么

- 不能声称“BC 原理不可行”或“数据已足够”；本轮只证明当前数据/输入/目标/预算组合未达门。
- 不能声称“原生化/无界头失败”；它改善了方向，但没有通过四项门，且与训练时长、数据覆盖混杂。
- 不能声称“signed messages/PaiNN/keypair 有效”；均未在严格规则下晋级。
- 不能把 `legacy_full` 的 FINAL 结果当作与 v4.1 完全同题比较：FINAL 在原生动作上训练，`legacy_full` 标签是细分动作，存在目标口径不匹配；同题证据看 `common_unchanged`/`native_full`。
- 不能把 monitor8 当外部确认；它是历史回归集，confirm8/test/family holdout 未触碰。
- 不能把“优化收敛”或“动作接近 TS”当作真实 TS 成功；严格成功仍需 OptTS + 正确虚频 + 双向 IRC + 端点身份。

| V4.4 接线偏差 | 执行 E1-vs-E2 头对头，未先做 E1-vs-E0(父) 检验 | 归档 off-chain V1/V2；回滚 `stage_decisions.pre_chainfix.jsonl`；按 §9.1 重跑 |
| V1 错基座 | `_resolve_arm` 父基座查空，V1 以 v4 特征错基座重生 | 归档 `V1_wrongbase_v4`；修别名链并清除过期 configs；重跑 |
| V2 裁剪 | 接触边 0.43 steps/s，20k 投影 12.9 h | 按预注册顺序裁剪；`pruned_arms.json` + typed decision 留账 |
| 评测脚本与 checkpoint 布局不同步 | 训练写 `checkpoints/u20000/raw.pt`，旧 eval 只找平铺文件/旧头 | 修 loader/头识别/`load_state_dict`；W128/E1/FINAL 等实测 `status=ok` |
| 评测产物重名 | 三种子 FINAL 共用 `arm_id=FINAL`，后写覆盖前写 | eval 的 `arm_id` 追加 `_seed<seed>`；重跑全部正式 run，保留逐 seed JSON |
| 自动汇总纳入 archive | `render_v42_summary.py` 递归读 `run_records_archive`，把失效 run 计入汇总 | 改为只读 `run_records`，跳过 TIMING/SMOKE；旧草稿移至 `superseded_render_20261018.md` |
| E2 评测 skip | keypair wrapper 未在 eval 中重建 | 以 `SKIP_KEYPAIR_WRAPPER_UNSUPPORTED` typed skip 记录；E2 只有训练/dev 证据，无 monitor 证据 |

## 七、风险与限制

1. **数据规模**：50 组 fit 对当前模型过大；500/2k 扩量在 WP0 前置（144 个 identity partner 补绑定、family 审计、重定价）闭合前不应启动。
2. **单帧输入**：342 对冲突样本表明部分路径不可辨识；继续单帧 BC 会在信息上限处停滞。
3. **教师与观测不同源**：教师为 DFT IRC，E/g 为 GFN2-xTB；跨方法先验弱，不能把 xTB 梯度当精确切线。
4. **monitor8 复用**：长期用于调参/选择/诊断，不是独立测试；confirm8 未运行。
5. **训练时长**：20k 终点不是最优；5–10k dev 峰值与 20k 退化需要独立协议。
6. **评测缺口**：E2 keypair 无 monitor 证据；`legacy_full` 对新原生模型存在目标口径不匹配；H1 未运行。
7. **无真实闭环**：本轮零 QC、零 rollout；G4 IQL/SAC 仍停靠，bundle 契约未闭合。
8. **工作树状态**：大量未提交研究代码/文档；不能按发布版本或可复现实验包对待，需在发布前冻结提交。

## 八、下一步建议

### 8.1 立即（本轮收口）

1. **登记负结果**：V4.2–V4.7 注册门 `BELOW_GATE`，FINAL 不晋级、不部署、不扩量；保留 FINAL 三 seed 与全部筛选臂收据。
2. **冻结证据包**：把 `campaign_manifest.json`、`run_records/`、`protocol_evals/`、`dev_split.json`、`physical_prior_spec.json`、`native_reconnect_audit.json`、`gradient_baseline_audit.json` 与 `protocol_freeze.json` 打成一个内容寻址包；补 E2 的 typed skip 说明。
3. **修工具链**：eval 支持 keypair wrapper 与 H1 prior skip；统一 run identity/检查点布局；把 `render_v42_summary.py` 的归档过滤与 seed 去重纳入测试。

### 8.2 科学上（按优先级）

1. **训练时长协议（最高优先，低成本）**：单独预注册 5k/10k/20k 早停规则，在 dev 上选 checkpoint，再在 monitor8 上复核；不能再事后挑 5k 权重，但可以把“训练多久”作为正式因子。当前证据强烈支持这一步。
2. **输入可辨识性**：针对 342 对冲突样本，评估多路径标签、历史帧/曲率输入、或多假设预测；先做一个只读诊断臂，确认能否把冲突样本的 near-TS cos 提升，而不是直接上大模型。
3. **数据扩量**：只有在 WP0 前置闭合后，按 500/2k 分阶段扩量；优先新增**独立反应族**，不是同一 IRC 加密。扩量前先固定“组数 vs 参数”比例，避免继续 45 组训 38 万参数。
4. **目标重定义（备选）**：若单帧全原子位移仍不可辨识，转向“关键对 Δd + xTB 约束松弛”环境；这是新的动作/转移合同，需独立 pair 头、真实松弛后继与教师，不能把本轮 BC 成绩直接当闭环验收。
5. **物理先验**：Δs_fit=0 已判不适配；除非能证明梯度源/符号/质量度规/配准有误，否则不要重跑 H1。若继续，先做跨方法 PES 差异与质量加权切线诊断。
6. **辅助损失**：H2 的 λ 规则失败；若仍要做方向/幅度辅助，改用 loss-scale 归一化或不确定性加权，并在 fit45 上做短 canary，不得直接复用 16311.87/56.20。

### 8.3 不建议

- 不建议继续加宽/加深（W128 参数 38 万、dev 更差；V1 fit 最好但 dev 最差之一）。
- 不建议直接扩到 500/2k 并期待自动解决；数据扩量不能修复单帧不可辨识与训练时长选择问题。
- 不建议降低四项门或改用 pooled 指标“过门”；本轮 pooled 与组中位同向失败。
- 不建议把 `legacy_full` 的单一数字当作新旧模型同题比较；必须同时报告 `native_full` 与 `common_unchanged`。
- 不建议在真实 TS 成功未验证前宣传“预测器可用”；当前只是研究级离线模型。
