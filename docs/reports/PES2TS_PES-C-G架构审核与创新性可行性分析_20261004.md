## 1. 审核结论

**方向可行，建议保留“坐标控制器 + ACP/ORCA 优化器”的架构；v1 可以作为实施起点，但尚不足以直接切换生产主链或证明科学增益。**

用户希望的“几何结构初猜输入器”，建议精确定义为：

> PES-C/G 是基于当前已接受几何与量子计算反馈的逐步初猜及约束目标提议器。它每步向 ACP 提交完整初猜结构和有限关键内坐标目标；ORCA 求解该目标下的几何响应；公共验收器决定是否接受；接受结果经观测编码后进入下一次提议。

首版完整初猜可以直接等于上一接受结构，不要求模型先生成一个改变后的 XYZ。改变约束目标本身就能指示 ORCA 推进。若以后引入几何预测，只承担有限、无能量优化的初猜构造，不能悄悄恢复 PES2TS 自己的 BFGS/线搜索。

这保留了结构反馈控制的实质。若把“输入器”理解为只输出一次 XYZ、之后不读取优化结果，则无法实现用户要求的逐步预测。

| 判断项 | 审核意见 | 依据或限制 |
|---|---|---|
| 职责拆分 | 合理 | 决策与数值优化可以分离，ACP 继续承担执行 |
| ORCA 单帧可实现性 | 有基础证据 | 已有混合约束和五距离小步探测；尚非完整迁移验收 |
| PES-C 几何反馈闭环 | 工程上可实现 | 已有接受/拒绝外循环，但策略、λ、结果格式尚耦合 |
| PES-G 复用同后端 | 可行 | 需新增状态/动作/特征/模型/离线训练，不是参数替换 |
| 严格 TS 闭环 | 当前存在优先修复缺口 | preparation、端点身份、标签归并等见 §2 |
| 创新性 | Classic 单独偏弱，学习控制组合有研究价值 | 需排除既有扫描/事件选峰/RL 概念，实验证明泛化与成本收益 |
| 广泛成功率、加速比、硬件结论 | 尚无充分证据 | 本轮没有进行新计算或模型部署测量 |

原方案已正确写明：畸变不是完成、路径峰不是 TS、不得静默回退、生成/排序分离、真实成本、真值隔离和反应族测试。以下建议主要补齐可执行语义及实际接缝，不重复把这些已写内容当成“缺失”。

## 2. 优先审核发现

本节的 P1 表示落地或科学计分前优先解决，P2 表示进入下一扩展前解决；不是新增工程阶段。

### F1 · P1：现有“严格验证”不能原样继承为最终科学标签

**证据：**

- [stage_results.py](../../pes2ts_core/integration/acp/stage_results.py) 的 _match_endpoint（约 320 行）按原子顺序保持的 Kabsch RMSD 选择 R/P；collect_irc_evidence（约 346 行）据此给出 matched。
- 同文件 collect_batch_ts_frequency_evidence（约 250–278 行）确认模式数量和单虚频，并绑定正常模式文件，但该结果判定没有显式核验虚频是否沿目标事件方向。
- [validation.py](../../pes2ts_core/integration/validation.py) 的 build_validation_result（约 115–257 行）主要聚合四阶段状态；没有要求端点自由优化、端点极小值及完整图/立体身份的独立证明。

**影响：** 全局 RMSD 可将局部错误氢迁移稀释，也可把同一化学身份的不同构象误拒。保留正常模式文件不等于已检查目标模态。不能把现有 passed 原样解释成迁移方案要求的全部物理证据。

**建议：** 新验证合同逐项绑定 OptTS、频率与目标模态、双向 IRC、两端优化与极小值证据、原子映射及完整化学身份。目标身份至少覆盖键连通/必要键级、氢伙伴、组分、电荷/自旋与必要立体信息；共振、芳香性、对称原子和可接受构象等价规则预先版本化。RMSD 保留为诊断，不承担身份判据。

对无明确端点极小值证据、IRC 未到达有效端点或模态证据缺失的结果返回 validation_incomplete。低频数值噪声的容差规则冻结，不能通过事后删掉虚频凑成“一阶鞍点”。不要求所有反应的虚频都能由某个单键长变化唯一描述；目标模态检查要结合完整事件，最终连接由 IRC 验证。

### F2 · P1：失败原因正在被压成错误的化学负例

[campaign.py](../../pes2ts_core/generation/campaign.py) 的 attach_validation_result（约 730–756 行）把所有 failed 映射为 verified_non_target，把 passed 映射为 verified_target；默认 preparation_layer_status 为 absent。

本轮隔离提取该纯函数，用合成输入复现，未执行任何计算：

| 合成输入 | 当前输出 | 问题 |
|---|---|---|
| status=failed，optts.status=failed | verified_non_target | 优化失败没有证明找到另一个反应 |
| status=passed，未提供准备层证据 | verified_target，preparation=absent | 科学标签未受完整新协议约束 |

**建议：** 终态由阶段原因和证据推导，不由顶层 failed 二分。OptTS 未收敛 → optimizer_failed；进程/传输故障 → execution_failed；缺频率/IRC/端点证据 → validation_incomplete；未运行和预算删失分别保留；只有得到充分验证、但连接非目标身份的产物时才记 verified_non_target。

这不是说这些失败对机器学习没有价值。固定协议内“未得到目标 TS”可以成为任务效用的失败观测，但必须保留失败/删失原因，不能将它们伪装为已证实的非目标化学。PES-R 与教师训练需要分开处理。

### F3 · P1：DFT preparation 需要新的结构来源链，不能只插入一次计算

[stage_cli.py](../../pes2ts_core/integration/acp/stage_cli.py)（约 185–224 行）直接把 proposal 几何写入 TS 任务，使用 BatchOptimize 的 opt_freq；[validation.py](../../pes2ts_core/integration/validation.py)（约 224–240 行）明确标记 preparation_layer_status=absent。

**建议：** 显式建立：

~~~text
candidate_geometry_hash
  → preparation_input_hash / recipe / method
  → preparation_output_hash
  → optts_input_hash
  → optts_output_hash
  → frequency / IRC source hash
  → endpoint-optimization hashes / identity evidence
~~~

保留 source_candidate_frame_id 表示候选来源，同时要求 optts_input_hash 等于 preparation_output_hash。不能为通过旧的候选结构绑定检查而把准备后的几何仍标成原帧。冻结准备层约束集合、目标值、收敛/失败行为、约束释放和 Hessian/模式初始化来源；其耗时和失败计入精修成本。

准备层可改变局部构象和后续收敛分支，不能声称总能提高成功率。避免先做一次释放约束的普通极小化、再寻找 TS，那可能已使候选落回反应物谷底。

### F4 · P1：当前接缝能换优化器，但还不能完整替换生成策略

[continuation.py](../../pes2ts_core/generation/planning/continuation.py)（约 339–367 行）仍以 while λ<1、target_values(plan,next_λ) 产生动作，默认 predictor_enabled=true；接受后确实用 ORCA/旧 corrector 的 output 更新 x（约 419–434 行）。[campaign.py](../../pes2ts_core/generation/campaign.py)（约 288–319 行）仍把 production_backends 直接接到 ORCALocalCorrector。

**结论：** 当前已经有“接受几何进入下一步”的基础，缺的是通用 policy.propose/observe 和无 λ 依赖的终止/候选合同。第一轮可只替换 make_corrector；自由多坐标学习器则不能止步于该替换。

**建议：** 将现有 target_values 调度封成一种规则策略；native 首版显式使用父帧初猜。新结果保存 q_target 与 q_observed；学习动作基于 q_observed。固定扫描则继续以冻结绝对目标为权威，不因数值误差偷偷改写基线。多坐标动作以坐标向量和事件状态控制终止，λ 只作为可选展示字段。

### F5 · P1：反馈信号和教师评分可能在“完整约束优化”后失去区分力

原方案提出使用自由梯度和约束误差。对每帧已充分收敛的硬约束优化，它们通常已被验收压至阈值附近；driver 的实际值也接近提交目标。只看这些量，策略很难区分“反应在有效推进”和“每次都完成同样的扫描”。

**建议：** 除当前结构外，重点加入非驱动 monitor 的响应、局部角度/氢伙伴、能量变化、约束广义力、优化迭代及真实调用成本、结构跳变、拒绝历史、剩余预算。具体定义见 §4–5。

不要奖励单步能量下降或单纯“离产物更近”：跨越能垒往往需要升能；目标距离达成也可能靠错误分支实现。也不要把教师简单定义为“本步最容易收敛”的动作，否则可能系统性学到极小步长或不推进。

### F6 · P1：权威文档存在会影响实施的数学和评测冲突

[开发宪法](../PES2TS_开发宪法_v1.md) §6.2 把显式 ΔX_pred + ΔX_⊥ 写入核心公式；§6.3 将有限 Oracle 称作可达上限，并要求仅在 Oracle 找到路径的子集比较；同节 basin entry 的操作定义使用 verified target TS，却又称其为较便宜、较弱标签。

这些不能仅在 v1 设计中另写一句话解决：

1. 用抽象受约束 QM 转移定义主接口，显式几何预测降为可选实现。若 J=∂q/∂X 为 k×3N，Jᵀg 不可直接相乘；若采用相反定义，J⁺Δq 又不相容，需统一符号，见 §5。
2. 有限搜索“找到合法路径”是可达性的见证；“没有找到”不能证明不可达，更不构成未知最优策略的严格上限。
3. 全部冻结输入作为主分母，Oracle 找到的子集仅作附加诊断，避免选择偏差。
4. 冻结精修器成功域是“该精修协议的吸引域/可成功集合”，不是已证明的普适物理 basin。弱标签和严格标签分开命名、分开来源。
5. 宪法 R6 同时限制 valid/test 调参。若需要模型选择，应另设 train 内部调校子集；要让 validation 承担常规调参功能，先正式澄清其权限，不能在实施中自行放宽。
6. [阶段定义](../plans/PES2TS_阶段定义_G0-G3.md) §2 的 G4 前置条件含键级导数和曲率探针；首版仅用距离/几何/最终梯度的学习器未必需要这些能力。建议按状态/动作实际依赖拆门，同时澄清 G2 规则自适应与 G4 L-G1 的研究范围。

本报告提出修订建议，不自行覆盖规范。ADR-0006 后续应具体列出这些受影响条款及正式替代文本。

### F7 · P2：现有候选诊断仍绑定单一 λ

[gradient_evidence.py](../../pes2ts_core/generation/planning/gradient_evidence.py) 的 force_evidence（约 45 行）从 target_values(plan,λ±ε) 重建能量斜率；[candidate_selection.py](../../pes2ts_core/generation/planning/candidate_selection.py)（约 38–105 行）使用该斜率、λ≥0.1 等规则。

自由多坐标策略没有唯一 λ，切换 driver/guard 时更不能沿用旧斜率。建议增加按实际相邻动作/路径弧长计算的量，或直接用广义力与实际 Δq 的内积；约束集合变化时不跨切换点机械计算导数。事件邻域、多样性候选和部分前缀保留，但同一事件不必位于固定 λ。

### F8 · P2：不能将所有拒绝归为“缩步重试”

原方案已有 typed rejection，但恢复表还应细化：碰撞/过大结构变化可以缩步；SCF、约束秩退化、方法不支持、缓存冲突、身份不匹配、预算耗尽需要不同动作。

物理几何保持父帧时，历史与已耗预算仍应更新；否则策略重复相同错误。失败的部分结构可作诊断观测，不能悄悄成为下一接受初猜。切换初猜/计划只能作为显式新分支，带独立身份和共享总预算。

## 3. 建议采用的共同闭环

~~~mermaid
flowchart TD
  A[当前已接受结构与事件状态] --> B[观测编码：实际坐标、QM响应、历史、预算]
  B --> C[PES-C规则 / PES-G冻结策略]
  C --> D[有限坐标动作提议]
  D --> E[动作校验与初猜构造]
  E --> F[ACP：ORCA原生约束优化]
  F --> G[公共证据与化学验收]
  G -->|接受并持久化| A
  G -->|拒绝：记录原因和成本，几何保持父帧| B
  C -->|计划完成 / 提名停止 / 预算停止| H[合格帧与有效前缀]
  H --> I[固定候选选择 / PES-R]
  I --> J[DFT准备、OptTS、频率、IRC、端点优化、身份]
  J --> K[隔离标签与评测]
~~~

角色边界建议：

| 组件 | 拥有的决策/计算 | 输出 |
|---|---|---|
| 化学编译器 | 事件、允许顺序、坐标角色、端点与映射来源 | 冻结化学计划 |
| PES-C/G 策略 | 本次推进目标/相位/停止建议 | ActionProposal |
| 初猜构造器 | 父帧复制，或明确批准的纯几何预测 | 完整 X_seed、构造版本、来源 hash |
| 验收器 | 坐标可行性、结果质量、证据和身份 | 接受/拒绝及原因 |
| ACP/ORCA | 任务执行与完整几何优化、最终证据 | 结构、E/g、收敛、成本 |
| PES-R | 固定候选池中的精修价值排序 | SeedProposal |
| 验证器 | 最终物理证据解释及目标判定 | 分阶段状态和严格标签 |

“彻底成为初猜输入器”应约束 PES-C/G 组件，不宜把整个 PES2TS 缩减为文件写入器；公共验收、候选管理及化学身份判断仍有独立必要职责。

宏步 t 是一次约束目标提议；ORCA 在该宏步内部执行自己的优化微步。每轮 ORCA 返回后才作下一次策略决策。不要为“逐步预测”重新接管 ORCA 每个 BFGS 微步。

## 4. 状态、动作和接口的具体补充

### 4.1 状态

建议 StateV1 至少包括：

- 身份：reaction/branch/state/frame ID、几何与 atom-map hash、方法/电子态、策略/特征版本。
- 几何：当前已接受 X、实际 q_observed、最近 q_target、与目标范围的余量、局部反应环境。
- 事件：各事件未开始/进行/完成的观测、事件先后关系、当前 driver/guard mask；避免把阈值抖动当多次成断键。
- QM：相对能量、真实最终梯度资格、自由梯度残差、可重建的广义力；键级为能力可用时的可选证据，缺失有掩码。
- 响应：monitor 的变化、局部/逐原子移动、优化周期/调用数、最近接受与拒绝。
- 控制：剩余预算、连续拒绝次数、当前步长及策略记忆。

对不同分子不要直接比较绝对总能量；使用同一方法/电子态及同一分支内的相对量。仅靠几个距离可能不能辨识不同构象分支，因此保留必要局部几何。是否足够近似 Markov 状态需通过消融检验，不能由符号 s_t 自动保证。

### 4.2 动作

首版 ActionProposal 建议限定为：

~~~text
parent_state_id / parent_geometry_hash
coordinate_ids + role_mask
absolute_targets + per_coordinate_units
proposal_mode = fixed_schedule | relative_to_observed
delta_from_observed
seed_mode = previous_accepted
phase_id / continue_or_stop
policy_version / raw_proposal_hash
~~~

规则扫描和学习器可以共用 absolute_targets，但目标来源不同且须记录。第一代学习器使用有限动作目录，如保持相位小/中步、成键先行、断键先行、协同推进、提名停止；只选择化学计划允许的动作。

允许集合更准确地写为 A(H,s_t,b_t)：它还依赖当前结构可行性和预算。这个集合可能含离散相位、启用 mask、连续目标和边界，未必是处处光滑的单一“流形”。局部使用微分工具时单独给出光滑及秩条件。

首版不同时学习优化精度、QC 方法、driver 列表和验收阈值，避免模型用改变执行环境掩盖策略收益。

### 4.3 请求与结果

在 v1 草案基础上补充：

| 对象 | 建议新增/明确 | 原因 |
|---|---|---|
| Request | parent_geometry_hash 与 seed_geometry_hash 分开 | 将来纯几何预测会改变初猜 |
| Request | 全部实际硬约束集合的 hash；guard enforcement 类型 | post-check guard 不等于 ORCA 硬约束 |
| Request | 方法实现标识、电子温度/溶剂等有效参数 | GFN2 方法名相同不一定执行条件相同 |
| Request | 允许重试/重启规则、剩余额度及预算语义 | 防隐藏增加 MaxIter 或多轮尝试 |
| Result | q_target/q_observed、优化器/SCF/约束/梯度分项状态 | 防“一次 success”遮盖证据不足 |
| Result | 最终几何/E/g/电子态共同绑定 | 轨迹末项未必对应导出的最后结构 |
| Result | 核时与调用计量、缺失原因、缓存/重启来源 | 拒绝与补算也有成本 |
| Decision | 原提议、实际执行、接受原因、提交状态 hash | 回放并区分物理状态与控制状态 |

计算缓存摘要应覆盖所有影响计算结果的输入；策略 ID 等审计身份另行绑定。是否允许不同策略对完全相同物理请求复用缓存要预先规定，benchmark 另报冷启动成本，不能靠跨方法共享缓存制造速度优势。

## 5. 数学定义、验收和可学习反馈

令 X∈R^(3N)，本步实际硬约束为 c(X)=u。c 包括 driver 与确实编译给 ORCA 的硬 guard，不包含 monitor 和仅用于事后检查的 guard。

\[
X^{trial}_{t+1}=\mathrm{LocalConstrainedOpt}_{QM}(X^{seed}_t;c(X)=u_t).
\]

首版 X_seed=X_t。接受后 X_(t+1)=X_trial；拒绝后 X_(t+1)=X_t，但历史和预算改变。约束误差按坐标自身单位验收，二面角差使用周期处理；接近线性角度的奇异性另作拒绝或坐标切换原因。

令 B=∂c/∂X∈R^(m×3N)，g=∇_X E。欧氏 Cartesian 度量下：

\[
P=I-B^+B,\qquad g_\perp=Pg.
\]

采用约束行尺度化 SVD/伪逆处理秩与阈值；若加入整体刚体模式，要与现有投影定义一致。混合距离/角度先规定单位和尺度，角度导数用弧度。Cartesian 冻结或环境条件存在时，不能无条件剔除所有整体刚体模式。质量加权是另一度量，不能和欧氏阈值混用。

对 L=E+νᵀ(c−u)，满足有限容差 KKT 时：

\[
g+B^\top\nu\approx0,\qquad
\frac{\partial E^*}{\partial u}\approx-\nu.
\]

可用最小二乘重建 ν，并明确其来源不是 ORCA 原生输出。只有约束局部独立、同一光滑分支、自由残差足够小时，才把它解释为约束值变化的局部能量响应；依赖约束下乘子不唯一，不能直接逐坐标学习。一般情况下不能拿 B g 或含糊的 Jᵀg 直接替代该广义力。

可用 −νᵀΔu 表示小动作的局部一阶能量变化估计；它只是反馈特征，不是保证下降的奖励。路径上 dE/dλ≈−νᵀdu/dλ=0 可以由多坐标抵消产生，不能据此推出 g=0 或 TS。

建议优先采用以下可辨识反馈：

| 反馈 | 用途 | 边界 |
|---|---|---|
| 约束误差、自由梯度 | 验收和数值难度 | 收敛后接近零，通常不是唯一策略信号 |
| monitor/局部角度/氢伙伴的 Δ值 | 看未被强制的自由度如何响应 | 几何变化不自动等于真实机理 |
| 广义力、相对 ΔE | 识别强阻力、事件前后变化 | 能量升高不能自动拒绝 |
| 优化周期、真实 E/g 次数 | 预测本动作代价和缩步需求 | 同时受优化配方影响，需冻结 |
| 对齐后局部最大位移、轨迹异常 | 识别分支跳跃及畸变 | 全局 RMSD 只能辅助 |
| 多次拒绝、剩余预算 | 决定缩步/停止/显式备用计划 | 不能伪造“已进入目标 basin” |

收敛帧资格还应验证电子态和方法一致。固定总电荷/多重度不保证始终处于同一 SCF 解；方法可提供时记录相关电子态诊断。首版限定已核准范围，不承诺单势能面算法能处理自旋交叉或多参考困难。

## 6. 化学边界和失败恢复

**关键坐标控制能限制动作，不能保证正确通道。** 少量距离不能唯一决定进攻方向、质子接力、构象翻转或配位模式；图编辑也不能推出唯一机理。

建议把首版能力范围具体写成“已审核原子映射、固定电子态、当前 F/B 白名单、预期为基元反应的输入”。多步骤净反应不能强迫用一枚 TS 的两端 IRC 直接连接总 R/P。发现稳定中间体或多个独立事件时，保留分段候选并标记需分步解释；要正式支持多步机理，再定义中间体节点和逐边严格验证合同。

| 原因 | 建议处理 |
|---|---|
| 外层动作过大、局部位移超限、碰撞 | 从同一父帧缩小动作，在总预算内重试 |
| 约束秩退化/目标几何不相容 | 拒绝该动作；只在冻结策略允许时选备用坐标/计划 |
| 优化未收敛 | 分类保留最终诊断；按固定恢复配方重试，不直接接纳 |
| SCF/电子态异常 | ACP 执行受控恢复，记录新尝试和有效方法；不一律缩 Δq |
| 错误图/氢伙伴/立体变化 | 拒绝；重复出现说明计划或保护可能不适用 |
| 引擎/版本/缓存身份冲突 | blocked 或 execution_failed；不消耗无意义缩步循环 |
| 连续最小步拒绝/预算耗尽 | partial + 明确原因，保留既有合格候选 |
| 无活跃 driver 后执行普通 Opt | 标明动作性质，防止无意识回到极小值 |

硬 guard 只保留有明确化学目的的必要项。把所有保留键和惰性原子固定会消除必要弛豫，也可能制造高能假峰。只做最终检查又不能阻止优化中间跳支，故轨迹可检查性与失败成本需在能力验收中体现。

## 7. 与 Chemoton / RMSD-PP 的算法差异

比较对象需要先分层：Chemoton 是网络探索框架，NT1/NT2 是其中基元反应试探算法；RMSD-PP 是端点驱动路径方法；PES-C/G 是目标条件的生成控制组件。不能把整个 Chemoton 网络枚举成本与已知目标事件的一次扫描直接相比。

| 维度 | 本方案 PES-C | 学习型 PES-G | Chemoton NT2 | RMSD-PP |
|---|---|---|---|---|
| 信息条件 | 已知 R/P、映射、事件和坐标计划 | 同左，另有冻结策略 | 通常从起始结构/复合物及选定成断键对发起单端试探 | 给定反应物与产物几何 |
| 驱动对象 | 关键内坐标目标 | 根据反馈选下一目标/相位 | 反应原子对的人工驱动及梯度修改 | 对 R/P 的 RMSD 偏置 |
| 一步的语义 | 完成一次局部硬约束优化 | 同左，外层动作由模型决定 | 受修改梯度驱动的扫描步，可配微迭代 | 在带偏置能量上优化并作路径处理 |
| 优化自由度 | 约束之外全部允许自由度 | 同左 | 反应原子梯度分量受修改，微循环可固定选定原子 | 偏置影响整体优化，没有本方案的逐坐标硬目标合同 |
| 帧资格 | 按冻结标准的约束优化证据 | 复用同标准 | 按受驱动轨迹资格解释 | 按偏置路径资格解释 |
| 下一步自适应 | 规则 | 学习策略 + 相同验收 | 既有物理反馈和规则，不应称“无反馈” | 偏置/试跑/路径精修规则，不是单纯线性插值 |
| 自带目标保证 | 无 | 无 | 无 | 无 |
| 公平最终比较 | 同目标、同成本协议下的严格验证 | 同左 | 同左；明确 NT2 版本 | 同左；不能按硬约束 KKT 淘汰其路径 |

NT2 的关键区别是对选定原子对相关自然梯度作处理，再加人工力；它允许协同成键/断键，微循环可固定反应原子。本方案改为给出显式约束值，再让 ORCA 完成局部优化。因此是与 NT2 有共同化学表示的不同推进算子，不能称为“ORCA 版 NT2 复现”。[Chemoton 2.0 原论文 §3.2](https://arxiv.org/html/2202.13011)

Chemoton 2024 已将候选提取改为结合键级事件：优先事件前的局部峰，特定情况下取事件后峰，缺事件证据时另行回退。因此“事件附近取峰”和“化学规则引导”已有先例；比较应纳入该更新，不能只比较 2022 的最高局部峰规则。[Steiner 与 Reiher，2024](https://www.nature.com/articles/s41467-024-47997-9)

RMSD-PP 在反应物附近施加排斥偏置、在产物附近施加吸引偏置，并尝试不同偏置组合；它既不等于坐标直线插值，也不等于把 RMSD 作为最终成功标签。本方案的区别在于事件坐标可分配独立相位和角色。由此推断，本方案可能更容易表达局部协同策略，但也更易受遗漏坐标影响；RMSD-PP 的整体几何偏置则可能对端点构象敏感。二者谁更有效需同协议实测。[xTB 官方路径文档](https://xtb-docs.readthedocs.io/en/latest/path.html)

v1 引用的 Chemoton 118/145 个参考反应及不同试算量，与原论文表格相符；它们属于该探索协议，不能转成 PES2TS 的预计成功率。本报告不据这些数值推算性能。

## 8. 创新性评估

### 8.1 已有方法成分与可能的新贡献

| 内容 | 判断 |
|---|---|
| 图识别成断键、选关键距离 | 成熟思路，单独创新性弱 |
| 多约束松弛扫描、ORCA 接管优化 | 工程整合有价值，不能作为新算法主张 |
| 当前优化结果作为下一帧初猜 | 常规延续思想 |
| 自适应步长、拒绝缩步 | 常规控制/数值策略 |
| 事件局部峰、IRC/频率验证 | 已有相关工作，属于应具备基线 |
| 有状态的低维事件控制表示 | 有研究空间，需证明其表达能力与跨反应泛化 |
| 真实 QM 响应下学习协同相位/推进/停止 | 有潜力，但“序列决策 + QM”本身不是首次 |
| 相同优化器/验证器下，学习控制降低严格 TS 总成本 | 可检验且有价值的核心贡献 |
| 成本感知排序与完整失败账本 | 可形成可靠系统与评测贡献，需证明排序收益 |

ORCA 原生支持键长、角、二面角及 Cartesian 约束，因此将这些能力作为执行后端是合理工程选择，不是新物理方法。[ORCA 6.1 优化手册](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/optimizations.html)

已有 actor–critic 研究将原子结构动作用于 TS/MEP 搜索；另有催化反应的第一性原理相关 RL 导航框架。因此不能写“首次把 TS 搜索转成序列决策”，也不能仅以“不学习 PES”宣称独占创新。本方案更具体的研究空间在事件条件动作、完整受约束松弛后的反馈、独立族泛化和全流程效用。[Barrett 与 Westermayr，2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10788951/)、[HDRL-FP 原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11282263/)

React-OT 则属于从 R/P 生成 TS 结构的学习方法。与其比较时，本方案的动作控制链和多次在线 QC 是不同成本结构；不能只对比模型推理时间。是否加入这类方法为后续外部基线，取决于适用元素/训练重叠/输入和实现可用性。[React-OT 作者预印本](https://arxiv.org/abs/2404.13430)

### 8.2 建议提出的三个可证伪假设

1. **结构反馈价值：** 相同输入、后端、预算下，使用当前优化响应的规则策略优于固定计划；打乱/移除反馈后收益下降。
2. **学习控制价值：** 模型在未见反应族上优于最强冻结规则，并接近有限教师的效果，同时明显降低在线教师枚举成本。
3. **全链价值：** 固定 PES-R 和严格验证器后，生成策略改进提高固定预算覆盖，或在预先约定的覆盖条件下减少总核时/梯度成本。

可用于未来论文的审慎表述是：“研究一种由反应事件约束、以真实量子计算松弛响应为反馈的低维生成控制策略，并评估其在独立反应族上的严格目标 TS 覆盖与计算成本。”在实验完成前使用“提出/研究/待验证”，不使用“首次/保证/显著提升”。

本轮检索用于判断主要先例和比较边界，并非穷尽全球文献的唯一性或专利检索。

## 9. 教师、训练和停止策略

有限动作 Oracle 建议从同一个已接受状态复制 K 个合法动作，执行相同后端和验收。记录所有动作，包括失败、未运行和预算删失，而不只保留 winner。若有多步 horizon，其长度、总预算和分支数提前冻结。

教师可先采用词典序或冻结多目标评分：先满足执行/化学资格，再考虑事件响应、异常风险、推进效果与成本。小自由梯度只是约束优化合格性之一，不能独占评分；即时“更接近目标”也不能代替最终可精修性。

离线训练有两类来源：

- 在线可观测代理：几何/QM响应、代价和失败原因，可训练动作可行性及成本。
- 隔离 train 精修结果：训练长期精修价值，不能回流当前 valid/test 控制。

从有限 Oracle 得到的 a* 只是该动作目录、horizon、预算和评分下的选择，不是全局最优真值。必要时学动作排序/分布而非单一标签，保留近似等价动作。

模仿学习部署会访问教师轨迹之外的状态；可在 train 范围收集模型访问状态再求教师、逐轮冻结，避免只在干净教师轨迹上评测。测试阶段不增加教师调用，否则不能称为纯学习策略成本。

停止建议只能表示“按冻结规则已有足够候选/值得精修”或“预算应停止”。模型不能在线宣称 verified TS basin 已知；真正标签来自后续验证。

首版建议用事件级标量特征的小 MLP/树模型或小局部图网络，加入缺失掩码和动作合法性约束。CPU 推理是合理候选，仍需测量实际运行时、内存、依赖、延迟和 QC 总成本占比；不能先承诺无需 GPU 或硬件完全不变。

原五步顺序总体合理，建议增加两项：**提前修补标签/验证合同；把单帧物理问题对照与整条路径闭环对照分开。**

| 顺序 / 归属 | 工作包 | 出口 |

| 3 / G2.2 R/X | 接 native backend，保留固定规则 policy | 父帧输入、接受更新、拒绝不污染结构、恢复和缓存通过 |
| 4 / G2.3 R/X | preparation 来源链、严格端点/模态验证、标签修复 | 一次完整真实链路有可审计证据，失败亦正确分型 |
| 5 / G2.T R | 四例开发 → 24 例固定协议 | 全量终态/成本；满足原 G2 出口才宣布闭环 |

| 7 / G3 R/X | 固定生成和候选池，建设 PES-R | 标签子集质量/偏差明确，排序有同预算收益 |
| 8 / G4 R | 规则反馈 → 有限 Oracle → 模仿学习 | 独立族测试、固定 ranker/验证器的增益 |

### 10.1 现有探测能证明什么

[receipts.json](../../outputs/acp_synchronized_capability_20261002/receipts.json) 记录 ORCA 6.1.1 / GFN2-xTB 的混合 B/A/D 和五距离约束探测。距离目标总变化约 0.02 Å，角/二面角约 0.5°；抽查 mixed_BAD 的末帧输入和输出，可见同步约束及优化收敛标志。

这是有价值的局部能力证据，但变化较小；不能证明跨成断键全过程、分支保护、约束失配/超时恢复或正式 ACP 生产合同已经验收。mixed_BAD 是探测标签，不代表该记录实际失败。

下一步真实单帧验收建议同时覆盖：合理的小步和较困难但化学有效目标、多约束共享原子、秩退化、错单位/索引、正常退出但未收敛、E/g 对错帧、优化中途取消、重试和缓存冲突。不为让冒烟通过而放松身份门。

### 10.2 比较设计

| 对照 | 固定与变化 | 解释范围 |
|---|---|---|
| 单帧 legacy vs native | 相同父结构、初猜、约束目标、方法和验收；旧 bias/anchor 另列 | 比较求解同一局部问题的差别 |
| 路径 legacy vs native | 同一起点、固定目标表/预算/候选；分别运行闭环 | 比较整体可靠性和成本，允许轨迹不同 |
| native 固定 vs native 自适应 | 固定优化与验证，只改变一步策略 | 控制反馈价值 |
| 自适应 vs Oracle vs imitation | 固定动作域、ranker、验证、预算与分裂 | 学习价值及教师在线成本 |
| NT2 / RMSD-PP 外部基线 | 相同输入适用域、电子结构条件、最终验证及总预算 | 外部方法效果；保留各自合法帧资格 |

仅“保持关键目标相同”还不足以称为纯后端对照：若同时关掉预测器、移除锚定、改变梯度门和起点方法，效果有多个来源。资源有限时至少把不可等价项列为复合迁移，并通过少量正交对照拆分主要因素，不强行宣称优化器单独贡献。

全部方法的方向、构象、备用计划和重复运行计入同一输入预算。NT2 使用真实版本并记录设置；自建 NT2-like 不代表 Chemoton 严格复现。RMSD-PP 若使用不同温度、GFN 实现或溶剂，分列差异，不暗中让基线更弱。

## 11. 指标、成本和可行性

### 11.1 推荐主指标

\[
\mathrm{Coverage}(B)=\frac{\sum_{r=1}^{N}
1[\text{输入 }r\text{ 在总预算 }B\text{ 内得到严格目标 TS}]}{N}.
\]

N 是冻结的全部输入，包括失败和预算删失。路径完整率、约束通过率、候选数是诊断，不能替代 Coverage。

\[
C_{\mathrm{total}}=C_{\mathrm{origin}}+C_{\mathrm{generation}}
+C_{\mathrm{ranking}}+C_{\mathrm{prep}}+C_{\mathrm{OptTS}}
+C_{\mathrm{Freq/IRC/endpoints}}+C_{\mathrm{failed/retry}}.
\]

实现计账时各项互斥，避免把失败/重试已计入阶段成本后再重复加一次。报告总核时/梯度等成本向量、每输入成本分布、相同预算覆盖，以及全体成本之和除以严格成功数；零成功时后者记不可定义，不写零。

xTB 与 DFT 的一次梯度不等价；既报分层调用数，也报实测 core-hours/墙钟和资源条件。Oracle 训练成本单列，并给部署多少次可摊薄的情景分析，不能只报模型推理毫秒数。

推广门在实验前设定：覆盖不劣容限、成本改善幅度和证据完整性。24 例用于开发和回归，不足以给可靠普适统计结论。规模化评测按反应/反应族做配对统计或分组重采样，不能把同一路径上很多邻帧当独立样本。

PES-R 标签若只来自旧排序器挑中的少数候选，会有选择偏差。建议在 train/校准数据中预设分层抽样精修预算并记录候选被选择的方式；测试用相同冻结候选池和验证预算。未精修帧不直接写负标签。

### 11.2 可行性与主要不确定性

| 方面 | 评估 | 决定因素 |
|---|---|---|
| native 优化后端 | 较高工程可行性 | ORCA 已有能力，难点在 ACP 合同、证据、成本与失败恢复 |
| 逐步 PES-C | 较高工程可行性 | 复用现有外循环，拆出策略/观测及结果适配 |
| TS 成功覆盖提升 | 中等且待实验 | 坐标/起点/分支/模型误差可能比优化器更关键 |
| PES-R | 可实施，受标签质量约束 | 先修 F1–F3，再积累足量独立标签 |
| PES-G 小模型 | 可原型化，泛化不确定 | 教师质量、动作域覆盖、反馈区分力和分布偏移 |
| 大规模训练/部署 | 当前无法量化承诺 | 缺真实批次耗时、有效标签率、模型测量及资源配额 |

若跨后端频繁启动单点作业开销大，native Opt 将多次调用包在一次任务里可能节省执行开销；但每步完整收敛、外加最终梯度补算和更保守约束可能增加物理计算量。旧优化器的曲率复用也可能丢失。是否允许绑定几何/约束/版本的 ORCA 重启或 Hessian 复用，应作为单独配方验证。

不建议现在给精确开发天数或固定加速比。可先用四例测得接受帧成本、拒绝率、DFT 各阶段耗时和标签产生率，再按计划动作数、重复次数和验证比例估算 24/1000 输入资源，并给失败情景范围。

建议实施优先级为 **F1–F3 科学证据/标签 → F4/F6 接口与规范对齐 → ACP 单帧与固定策略迁移 → F5/F7/F8 自适应及学习准备**。前两组可以在同一批次分别推进，实际生产切换仍依赖共同验收。

本轮结论支持该架构方向，也明确其当前性质：它是一条可实施、可逐步研究的生成控制路线；Classic 的工程迁移尚不能证明学习创新或严格 TS 成功率。完成上述优先修补和分层实验后，才具备对外作这些声明的证据基础。
