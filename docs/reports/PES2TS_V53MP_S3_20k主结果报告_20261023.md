## 7. 风险与诚实警示

1. **C 臂 endpoint 头 seed 间不稳定**：s29 的 τ_end=0.219 远低于 s17/s43（0.58/0.71），其 dev 起点/TS 误停率高达 0.63/0.62（s17/s43 均 ≈0）。τ 校准在 inner-val 达成目标精度 0.9，但 dev 上稳定性不足——**训练资格 ≠ 部署资格**的实证；No-Move 在线控制权只在独立校准、误停率与闭环验证通过后才可启用。
2. **endpoint 监督整体仍是中等信号**（AUROC≈0.60）：相对 prevalence 有稳定超出，但距部署判据尚远；报告中不夸大。
3. **guard 语义**：Move guard 的"负退化"是相对 R3 zero-shot 基线的改善，不构成对新化学反应的泛化保证；confirm 集全程封存未触碰。
4. S3 跨 4 个训练相关 commit（prefetch/COW 修复与两次 cap 提额），五 sha 绑定（config/data/teacher/features/split）全程未变，run 间可比性不受影响。
