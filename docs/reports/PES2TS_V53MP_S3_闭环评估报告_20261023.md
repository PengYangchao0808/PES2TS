## 0. 一句话结论

864 个无物理闭环 episode（24 dev 曲线 × 双向 × 3 臂 × 3 seed × 双预算）如实显示：**20k 模型的纯几何闭环仍主要是一个压力测试**——0.10 Å 正窗端点到达率 A 1.4% / B 0% / C 0%，TS 候选跨越率 ≤4.9%，多数 episode 出现碰撞；**C 臂在线 No-Move 停呈 seed 分裂**：s17/s43 保守（停 6–10/96）而 s29 过度停（82/96，τ=0.219 过低），与 dev 误停率互为印证——No-Move 在线控制权维持"未授予"状态。

## 1. 设置与纪律

- **曲线集**：冻结 split 的 dev 子集（589）中按 `sha256("v53mp-rollout|17|<curve_id>")` 升序取前 24（规则与清单 sha256 记录于 manifest）；confirm 封存未触碰、pool（训练集）不用。
- **双预算（结构上分离，永不合并成功率）**：
  - `reference_normalized`：B = max(40, ⌈1.5·L_key/0.08⌉)，L_key = 参考 IRC 弧关键原子路径长（实测 L_key 2.64–9.88 Å，中位 5.11；B 50–186，中位 96）——离线教师诊断口径；
  - `autonomous`：固定 200 步，只用当前合法信息——正式自主导航口径。
- **在线停**：仅 C 臂（`sigmoid(endpoint_logit) ≥ τ_end`，τ_end 为各 run inner-val 冻结值）；A/B 无法定停止信号（q 为 never_stop_criterion），恒跑满预算。在线停只作诊断——训练资格 ≠ 部署资格。
- **声明纪律（机检）**：`check_claim_discipline` 对 864 条记录 + manifest 强制 `claim_scope=TS_candidate_only`，`verified_ts_claim=forbidden`；TS 候选须独立物理验证（OptTS + 单虚频 + 双向 IRC + 端点身份）方可升级，本报告不升级任何 TS。
- **引擎**：CPU 纯几何 rollout（无物理调用）；trust region 0.20 Å/原子；碰撞阈 0.5 Å；checkpoint 经 metrics↔文件 sha256 双重核对；episode 级 seed=17 固定。

## 3. C 臂 per-seed 分解（在线停的 seed 分裂）

| seed | 在线停/96 | 端点到达(0.30Å) | 对应 dev 误停率（起点/TS） | τ_end |
|---|---:|---:|---|---:|
| C_s17 | 10 | 8 | 0.0 / 0.0009 | 0.582 |
| C_s29 | **82** | **0** | **0.631 / 0.622** | **0.219** |
| C_s43 | 6 | 7 | 0.0 / 0.0 | 0.706 |

- C_s29 的 τ_end=0.219 使 endpoint 头在闭环中几乎到处停（85% episode），且停止位置距端点尚远（全部 0 到达）——离线误停率与闭环行为互为印证，**该 seed 的 No-Move 头不可用于任何控制**。
- C_s17/s43 停得保守且少，但即使停得少也未换来 0.10 Å 到达——闭环精度瓶颈在 Move 端（纯几何、无物理校正），不在停止头。

## 4. 负迁移检查（闭环口径）

- 同评估集 Move 离线指标（主报告 §3）：C vs A +1.95%、C vs B +0.13%——轻微。
- 闭环口径：B/C 的 0.30 Å 到达率（6.9%/4.9%）低于 A（16.7%）、碰撞 episode 更少（98–106 vs 128–138）与 arc-progress 形态差异共同提示：联合监督的 policy 在长程闭环中更"保守"（步幅/方向更谨慎），到达更弱但非法几何更少。两种口径一致支持"负迁移轻微、以到达率换稳定性"的读法；不合成单一分数。

## 5. 限制与声明

1. 无物理 rollout 是 policy 压力测试，**不是受控反应路径**；所有 TS 记录均为 `TS_candidate`，本报告不做任何 verified TS / verified path 声明。
2. 到达率窗口（0.10/0.30 Å）与 TS 接触窗（0.15 Å）均为记录诊断口径，与标签规范一致。
3. 闭环曲线集为 dev 的 24 曲线确定性子样本（非全量 589）；结果用于臂间比较与诊断，不作绝对成功率外推。
4. C 臂在线停仅为诊断运行；**No-Move 在线控制权仍处未授予状态**，需独立校准 + 误停率 + 物理验证后才可启用。
5. B_s43/C_s17 为外部中断后的断点续跑完成（attempt 账目见主报告 §4）；其 checkpoint 参与闭环前已通过 sha 三方一致核对。
