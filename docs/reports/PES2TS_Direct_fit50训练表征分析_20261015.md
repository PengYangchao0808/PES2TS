## 0. 范围与状态纪律

本报告分析 fit50 规模的表征训练产物：**不是正式配方结果**（正式为 fit500 冒烟 → fit2k 三 seed；IQL 正式为 22,000 更新）。这些运行的价值是配方正确性、可学习性信号与缺陷发现。相关运行均落在 `outputs/pesn/direct_egnn_v1_20261015/{bc,iql}/`，全部可从 checkpoint + 脚本复现。

## 1. BC：两次运行暴露的关键缺陷与修复

| 运行 | 配置 | 结果 |
|---|---|---|
| `bc_fit50_char_seed42`（修复前） | 50 epochs、σ 硬钳位参数化 | NLL 在 **42.23 处完全平台化**（= N(0,I) 先验基线 42.91） |
| `bc_fit50_sigmafix_seed42`（修复后） | 50 epochs、σ=σ_min+softplus | NLL **−66.71**，单调下降 |
| `bc_fit50_sigmafix_long150`（延长） | 150 epochs（表征外延） | NLL **−78.35**，仍未饱和 |

### 1.1 缺陷诊断（`scripts/diagnose_direct_bc.py`，`diagnosis.json`）

**根因 A（实现缺陷）**：log σ 头采用硬钳位 `clamp(min=log 0.02, max=log 1.0)`。检查点实测 pre-clamp 值 1.78–1.93，**994/994 节点全部超出上限** → 钳位饱和区梯度恒为 0 → **σ 头权重/偏置梯度精确为 0.0**，σ 永久钉死 1.0（模型退化为先验，且永不恢复）。过拟合实验（2 反应 × 400 步）证明机制本身可学：σ 一旦经编码器漂移解锁，损失发生相位跃迁（+2.73 → −3.83/原子）。

**修复**：`σ = σ_min + softplus(raw)`（永不饱和、梯度恒非零）+ 负偏置初始化（σ₀=0.1）。回归测试 `test_sigma_gradient_never_saturates` 锁定。

### 1.2 修复后状态（`h1/h2` 证据）

- σ 有效范围 0.027–0.193（均值 **0.069 ≈ 数据最优尺度 0.056**），无饱和；
- 梯度全面流动：σ 头 37.4、μ 门 5.76、编码器 1.80（修复前 σ 头为 0）。

### 1.3 拟合质量与理论下界

| 量 | 每原子 log-density（越大越好） |
|---|---|
| N(0,I) 先验基线 | +2.72 |
| **实测 150-epoch 模型** | **+4.99**（占可学习空间的 52%，仍在上升） |
| μ=u、σ=1 oracle | +2.72（μ 在此动作尺度可学空间仅 0.005/原子 = 0.2%） |
| σ*、μ=u oracle | +7.10（σ 路径是主要可学空间） |

**结构性结论**：fit50 专家动作的潜变量半径均值仅 0.098（每原子每步 ≈0.01Å），NLL 的可学信号几乎全部在方差路径；μ/方向路径的密度梯度空间天然微弱。

### 1.4 方向指标（分层）

| 指标 | 值 |
|---|---|
| 方向余弦（质量加权全原子） | 0.163 |
| 方向余弦（单步位移 >0.02Å 的原子，约 1.6 个/样本） | 0.129 |
| 位移误差（Å） | 0.0055（= a_max 的 5.5%） |

方向余弦显著低于 1，且移动原子的方向同样未学到——**确定性动作方向在当前 NLL 目标下未被有效训练**。这不是实现缺陷而是目标函数性质：σ 吸收了全部可学信号。计划 §7.1 已预登记"需要辅助损失时另建配方版本"——本报告为**辅助方向损失版本提供登记依据**（不在此静默改配方）。

### 1.5 按终态分层

goal 路径 NLL −73.5 < no-progress 路径 −64.6：到达目标的路径每步更确定（密度拟合更好），失败/平台路径更嘈杂。对后续按终态重加权/再平衡有参考价值。

## 2. 静态 RL（IQL）fit50 表征

运行：`iql_fit50_char_seed42`，50 反应、256 批量、**3,000 更新**（正式配方 22,000）。

| 指标 | 值 | 判读 |
|---|---|---|
| loss_q（末） | 0.010 | twin Q 拟合 Bellman 目标收敛 |
| loss_v（末） | 0.0004 | expectile 残差小，V≈Q 上分位自洽 |
| loss_pi（末） | −5.77（首值 +5078） | AWR 目标收敛 |
| **AWR ESS** | **255.9 / 256** | 优势权重接近均匀 → **本轮策略更新≈普通 BC，重加权无信号** |
| V vs MC 校准 | V 均值 −0.163 vs MC −0.725，MAE 1.37 | V/Q 自洽但不追踪 MC 均值——只有有限自洽意义，如实报告 |
| Q/V 有限性 | 全部有限 | Gate-IQL 基础条件满足 |

**判读**：证据是"管线正确 + 训练动力学可运行"，不是"静态 RL 有收益"。优势信号在 fit50×3k 更新规模下退化（Q≈V 常数），ESS 指标正确地把它暴露出来；正式规模（fit2k、22k 更新、3 seed）与 Gate-IQL 分层校准是本结论的检验场。

### 2.1 训练器性能修复

初版每 update 对 256 样本逐个重建特征（0.5–1.5 s/update，3000 更新 >1h 超时）；改为启动时物化样本+特征缓存后 **~0.07 s/update（约 7×）**，3000 更新约 4 分钟。

## 3. 登记结论与后续动作

1. **（A）σ 参数化修复**：已入代码+回归测试；后续所有训练（BC/IQL/SAC）生效。
2. **（B）BC 方向学习**：NLL 目标下不可得（§1.4）→ 若研究需要方向质量，按 §7.1 登记**辅助方向损失版本**（如 +λ·(1−cos) 或流匹配项），不改默认配方。
3. **（C）σ_min=0.02 底限**与数据处理端动作下界需在 fit500 校准中复查（低 r 原子的最优 σ 可低于底限）。
4. **（D）正式训练门**：以上修复进入正式配方前，fit500 冒烟需要复跑（本报告的表征运行不替代正式配方验收）。
5. **（E）a_max 决策**保持前报告结论：0.2Å 候选（几何可达 54%）待评审重建。
6. 所有产物：`bc_fit50_*`（3 个 run）、`iql_fit50_char_seed42`、`diagnosis.json`、`eval_fit50.json`；脚本 `evaluate_direct_bc.py`、`diagnose_direct_bc.py`、`train_direct_iql.py` 可复现。
