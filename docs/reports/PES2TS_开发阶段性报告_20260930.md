## 三、项目定位与阶段总览

### 3.1 双项目定位

PES2TS = **PES generation**（从端点生成可审计的廉价近似反应路径与能量剖面）
+ **PES ranking**（在已计算路径中筛选、排序可提交 TS 优化的真实几何帧），
两者通过版本化 `PathBundle` 合同连接，可分别开发、替换与评价。

成功终点：从 R/P 输入出发，以固定预算得到 OptTS 收敛、频率确认目标模态的一阶鞍点、
双向 IRC 连回目标 R/P 的结构。**几何接近参考 TS、能量峰或一个虚频只是中间证据。**

### 3.2 统一阶段顺序（S0–S8，来源：`PES2TS_统一开发顺序与阶段验收.md`）

共同合同 → 数据隔离与样本复核 → 最小 G1 计划 → ACP 执行适配与 G2 最小路径 →
独立 ranking 与基础展示 → 单反应物理验证 → 复杂路径扩展 → 24 条冻结 Demo → 分层试点与模型决策。

里程碑：**M1** 标准数据包（S0–S2）；**M2** 单反应完整闭环（S3–S5）；**M3** 24 条可复核 Demo（S6–S7）。

方向与时间表 → 后端能力校验 → 冻结候选。登记 11 个主策略
（`LOCAL_CONNECTIVITY`、`H_TRANSFER`、`H2_EVENT`、`RING_COUPLED`、`NETWORK_PATH` 等），
坐标角色分离（driver/monitor/guard/target_test），
输出 `StrategyProposal` 与 `ExecutablePlan v2` 分离，含 14 类冻结失败码。
Demo24 的设计分配：6 条单坐标、15 条多坐标一维、3 条双端路径优先（**设计分配，非计算成功数**）。
实施阶段 P0（输入与图）→ P1（单坐标选择器）→ P2（多坐标闭环）→ P3（路径与分段）。
已列出与 `planning.py`/`adapter.py`/`trajectory.py`/`quality.py` 的接口缺口。
