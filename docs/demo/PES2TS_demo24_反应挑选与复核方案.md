# PES2TS 首轮 24 条反应：候选名单与复核规则

> 2026-09-29。对应可筛选表格：[pes2ts_demo24_candidates_v1.csv](../../data/manifests/pes2ts_demo24_candidates_v1.csv)。这是**待人工确认的 demo 候选队列**，不是已经完成 PES、TS 或 IRC 验证的反应名单。

本名单服务于当前的 [PES generation + PES ranking 双项目开发方案](../plans/PES2TS_双项目开发与Demo方案.md)；两条开发线共用这批反应，但分别报告路径生成与同路径选点结果。

## 选样目标

首轮用少量反应分别检验两个项目：

1. **PES generation**：从 G1 键编辑出发，能否为简单和复杂机制生成质量可检查的廉价路径；失败原因是什么，回退增加多少成本。
2. **PES ranking**：在已有路径中，最高能帧、局部峰和化学进度规则是否产生不同的 TS 初猜；不同路径来源能否共用选点接口。

本队列为**机制覆盖型、有意包含困难例子的开发集合**，不能用 24 条的总体成功率估计整个 Reaction-QM 数据集的成功率。

## 硬条件和信息隔离

- 候选须在现有 G1 v2 `scan_ready` 中，且属于官方 `train` 或 `valid`；本轮不用 `test`，也不用 45 条 `unassigned`。
- 原子数 8–20；元素限 C/H/N/O/F/Cl；R/P 总电荷均为 0；库存记录 `multiplicity_max=1`；R/P SMILES 均能由 RDKit 解析。
- R/P 已存坐标有限且任意两原子距离 ≥0.45 Å。这个下限只排查严重重叠，**不代表**多组分相对摆放已适合路径计算。
- 只用 R/P、互斥键编辑、H 伙伴变化、芳香编辑、G1 分类、组分数、split 和既有 DRFP 做挑选。`endpoint_match`、`orientation`、TS/IRC 坐标、能量和真值标签不得进入选样评分、扫描计划或 ranking 特征。
- 当前 P1 原子映射是 `truth_assisted_p1`，G1 `scan_ready` 关卡也参考过 IRC 证据；因此这是加速工程开发的队列。正式泛化评测需以端点独立映射重建或把真值辅助条件明确列为限制。现有导出还包含 IRC 派生状态，接入 PES generation 前须隔离。

`multiplicity_max=1` **不等于**各端点都没有局域自由基或形式电荷。表格另外列出 RDKit 解析的自由基电子和带电原子数；这些样本需单独核对电子态。

每类两条 train、一条 valid。valid 在首轮输入复核后锁定，不用于改扫描阈值或排序规则。

| C. 取代 | F1B1 双向锚点；一条 train 为 2→2 组分 | `RXN_0000053132`, `RXN_0000155302` | `RXN_0000171675` |

## 进入计算前的逐条人工复核

在 CSV 的 `review_status` 改为 `accepted` 前，两名复核者应独立核对：

1. 反应中心、H 迁移、环/芳香变化与 R/P 图一致；是否像单个基元步骤，还是明显的多步反应。
2. 原子映射和元素顺序正确；对称映射样本 `RXN_0000079731` 的等价选择是否影响扫描键。
3. 端点的形式电荷、局域自由基、预期总自旋和化学合理性；不能仅凭 `multiplicity_max=1` 判作闭壳层。
4. 多组分的相对位置与碰撞风险、所需预装配；尤其 C/F/H 层。
5. 至少一个成键锚点有合理键长和拉伸窗口；所有非驱动编辑能被定义为观察量。无合适 1D/同步候选时，明确标为双端路径候选。

**替补规则**：只允许在任何 PES/OptTS 结果出现之前替换，保持原来的层和 split，并记录拒绝原因。替补从相同过滤池按固定哈希顺序提出，再做同样的端点复核；不能因试算失败而换成更容易成功的反应。

可复现的同层替补池在上述硬条件之外再按以下规则定义：A 为 `H_transfer=1, F1B1, O≤1, R/P 均单组分`；B 为 `F+B=1, O≤1, 无 H/H₂ 事件`；C 为 `F1B1, O≤2, 无 H/H₂，substitution`；D/E 分别为 `F2/F3, B≤2/3, O≤2, 环合/开环/重排, R/P 单组分`；F 为 H₂ 特殊事件且两侧组分数均≤2；G 为芳香编辑>0、F/B≤2、两侧单组分；H 为 F>3 或 B>3。先按 `sha256("demo24_v1:" + reaction_id)` 升序提出，再按端点结构、电子态和几何逐条复核。主名单经过了这一步人工取舍，因此它本身不代表概率抽样。

## 建议的实验顺序与记录

先跑 A–E 的 15 条，形成扫描路径与统一 `PathBundle`；再跑 F–H 的 9 条来暴露装配、H₂ 和回退问题。对每层至少保留一条路径来源对照；不要求所有 24 条都跑昂贵的 NEB。Ranking 先比较最高能帧和局部峰/键进度规则；选择少量同反应的候选帧送入相同 DFT OptTS、频率及双向 IRC。

分别报告 `24 → 输入可构造 → 路径完成 → 路径化学有效 → 可选初猜 → 正确 TS` 的分母、每一步拒绝原因、核时/壁钟时间。开发队列完成后，再另做 200–1000 条分层随机试点，用于估计总体覆盖率、oracle gap 与泛化能力。
