# 命名与编号规则（99_meta/naming_rules）

> **状态**：Canonical（档案树元规则）
> **层级**：L3 元数据
> **取代关系**：无
> **上游依赖**：ADR-0035、归档方案 v2.0 §6.2
> **下游消费者**：条目作者
> **当前版本**：v1.0 @ 2026-11-21

1. 目录：`NN_p<期号>_<主题>_<起YYYYMMDD>_<止YYYYMMDD>/`，NN 为 10 递增。
2. 条目：`E##_<主题>.md`；`E01`–`E17` 一经分配不复用；横切层为 `X0`（`00_global/`）。
3. 不按版本号命名目录：版本会随取代链漂移，时间不会。
4. 条目冻结后只追加“后续指针”；新增语义 → 新条目，不改旧条目。
5. 文件引用一律用反引号 inline code；不写 markdown 链接（链接门禁扫描）。
