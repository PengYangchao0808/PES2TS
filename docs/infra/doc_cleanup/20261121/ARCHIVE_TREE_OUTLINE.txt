PES2TS 开发档案树 —— 拟建 docs/archive_tree/ 文件树草案（task-6, 2026-11-21）
================================================================================
设计原则：
  1. 只新增、不移动：docs/archive_tree/ 是"压缩后的时间线叙事层"，不是目录搬家区；
     既有 docs/plans|design|reports|contracts|agent_runs|infra|archive|superseded 全部原地保留。
  2. 分区依据 = 7 期（P1–P7，ARCHIVE_TREE.md §1 有边界证据）；每期含 1–4 个条目文件；
     条目编号 E01–E17 一经分配不复用；横切常青层编号 X0。
  3. 命名：目录 NN_p<期号>_<主题>_<起YYYYMMDD>_<止YYYYMMDD>/；文件 E##_<主题>.md。
  4. 冻结规则：条目冻结后只可追加"后续指针"，不可改写；档案树自身变更登记 CHANGELOG.md。
  5. 本树不进入 docs/reports/（只读证据区），不进入 docs/archive/（快照区）。
  6. md 内文件引用一律用反引号 inline code（链接门禁扫描），不写 markdown 链接。
