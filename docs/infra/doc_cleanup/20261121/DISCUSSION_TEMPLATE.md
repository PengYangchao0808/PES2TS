## 2. FAQ 模板（复制即用）

> 铁律：FAQ 不得被引用为执行依据；答案有规范效力时，必须升格为 ADR/合同/计划（见 `MAINTENANCE.md` §3.1 ④）。

- **答案**：<≤5 行，直接可执行；命令用代码块>

- **维护者**：<角色>　**复审日**：YYYY-MM-DD

**收录门槛**（满足任二）：同一问题被问第 2 次；答案跨会话可复用；答案能挡住一次返工。
**淘汰规则**：季度审计时，连续两季无人引用或依据已变 → 标记"已失效"或删除条目（删除需在台账登记一行）。

### 3.3 该示例与五类落点判定树的对照（为什么不是 ADR / 合同 / FAQ 主落点）

| 判定问题 | 回答 | 结论 |

| 0. 只是可复用问答？ | 不是：涉及状态机条款落地 + 冻结纪律边界 | 不进 ④ 主落点（FAQ 为附带） |

| 是否需要规则级裁决先例？ | 是（"冻结件不改 vs 状态头可改"边界） | 写入本 DISC 记录并登记台账，**将来可升格 ADR-0035 附件条款**（避免每次新建 ADR） |
