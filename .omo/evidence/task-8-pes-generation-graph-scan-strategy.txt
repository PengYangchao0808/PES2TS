- cross_component_R/P = bundle component-id inequality per side; same_component_* = negation.
- distance_R_A/distance_P_A = round(math.dist(...),6) from caller-supplied map->xyz (bundle stores only geometry SHA256; coords come from review-case geometry aligned to atom_map_id).
- endpoints evidence block: n_components, cycle_rank (|E|-|V|+C), charge, multiplicity (case-level via EndpointElectronic), rdkit_formal_charge_sum / rdkit_charged_atom_count / rdkit_radical_electron_count (from bundle AtomNodes) — all seven keys per side.
- Ring grouping (plan failure scenario 两根不相交新键仍识别为同一环化): formed→P-graph / broken→R-graph ring region = 2-edge-connected component containing the edge (None if bridge); union-find links edits with intersecting regions (shared_ring_region) or same-kind intersecting support-path atom sets (support_path_overlap). Cross-kind edits never merge on shared atoms alone (H transfer stays out of RING groups). order_changed excluded.
- Ring sizes = deterministic BFS-tree fundamental-cycle multisets, NEVER the sole classification: in_cycle (membership in a >=3-atom biconnected block), biconnected blocks (bridges appear as size-2 blocks — standard decomposition), classic bridges, cycle_rank per component + total, 2-edge-connected components ship alongside.
- bridge_edges_R/P = task definition (edge present on one side whose endpoints differ in the other side's component structure); classic graph bridges stored in SideTopology.bridges.
- Aromatic regions = connected aromatic-atom clusters; aromatic_boundary = non-aromatic atoms bonded into a region; aromatic_periphery = region-edge aromatic atoms.
- Spectator components = bundle components with no edit atoms (tuple-of-tuples).
- context_radius default 2 (config/defaults.yaml scan_strategy.context_radius); context_radius_from_config falls back to 2 on invalid values; radius 1 vs 3 proven not to change support paths, cross flags, endpoints block, ring groups, bridge edges (shells only grow).
