DESIGN §11.2 FOUR INDEPENDENT TIERS (never collapsed)
1. execution_complete — job/files complete (report.complete, n_frames>0,
   no incomplete_frame_indices).
2. numerically_usable — per-frame convergence, residuals within
   constraint_tolerance (default 0.05 Å), consecutive frame indices,
   scan-energy channel complete and method-comparable.
3. target_path_compatible — terminal-frame target edits realized by
   CONTINUOUS bond length (Cordero radius sum + tolerance), regions
   reached, stereo labels match product, path continuity (no frame jumps).
4. validated_ts — requires typed evidence references ONLY:
   optts_ref + first_order_imaginary_ref + irc_forward_ref + irc_reverse_ref.
   Missing artifacts are listed per key in tier.missing_evidence.

HARD RULES (test-pinned)
- Technical usable ≠ chemical completion: numerically usable path with
  unfinished formed-bond target (2.8 Å end distance, bonded upper ~1.97 Å)
  → numerically_usable=achieved, target_path_compatible=not_achieved
  (plan failure scenario).
- Bond labels continuous, never forced binary: formed ≤ radius_sum+0.45;
  broken ≥ radius_sum+0.45+0.5 (transition width); middle zone labelled
  unknown/transition with CODE_BOND_INCOMPLETE. order_changed bonded at
  both ends still needs electronic_order_evidence (else
  bonded_order_unverified + ORDER_EVIDENCE_MISSING).
- validated_ts absent without all four evidence refs; partial evidence
  lists exactly the missing keys; evidence refs are opaque strings.
- No-internal-peak / monotonic association-dissociation paths and
  endpoint-max energy profiles never grant validated_ts and never set
  ts_candidate_from_path_shape; reason codes ENDPOINT_MAX_NOT_TS /
  NO_INTERNAL_PEAK_TS_SEED recorded as diagnostics.
- Stereo: final_label==p_label achieved; ==r_label → STEREO_AT_REACTANT;
  None → STEREO_LABEL_MISSING. Region member bonds reuse continuous
  bond labels; electronic-only regions need region_evidence.
- Mapping inputs (report.to_doc() / target definition dicts / evidence
  dicts) round-trip identical to dataclass inputs.
