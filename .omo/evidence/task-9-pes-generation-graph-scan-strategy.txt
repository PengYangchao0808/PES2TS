== API ==
build_event_coupling_graph(bundle, edit_graph, context) -> EventCouplingGraph
hydrogen_events_from_bundle(bundle) -> tuple[dict,...]        # golden {from,from_state,h,kind,to,to_state}
aromatic_regions_from_bundle(bundle) -> dict[str, list[list[int]]]  # golden {region_id: [[a,b],...]} | {}
EventCouplingGraph: events / coupling_records / strong_components / weak_links / membership /
                    hydrogen_events / aromatic_regions / events_by_type() / component_of() /
                    membership_map() / to_doc()

Event node types (design §4.3): H_TRANSFER, H2_EVENT, CONNECTIVITY_EXCHANGE, RING_REORGANIZATION,
DELOCALIZED_REGION, SHARED_CENTER (leftover shared-centre groups + inter-event strong rule);
CONTEXT_NEAR = weak link only (never merges).
Rule ids return rule_id/support_atom_maps/support_edges/evidence_level on every CouplingRecord.

== OWNERSHIP / MEMBERSHIP ==
Primary priority: H (transfer/release/capture; HH_EVENT_KINDS->H2 dedup by H-H pair cluster)
  > CONNECTIVITY_EXCHANGE (formed+broken sharing non-H centre) > RING (todo-8 ring_groups)
  > DELOCALIZED (v2 aromatic region with edits) > leftovers
Leftovers: >=2 sharing edit-degree>=2 atom -> SHARED_CENTER event; single order_changed ->
DELOCALIZED_REGION singleton (rule order_change_singleton); single formed/broken ->
CONNECTIVITY_EXCHANGE singleton (rule connectivity_single).
Multi-membership -> typed justifications (aromatic_region_membership / ring_group_membership /
h_partner_change / shared_center) + shared_edit_membership strong link between co-member events.
Strong components = union-find over strong links ONLY (shared_edit_membership + shared_center).
CONTEXT_NEAR weak links listed separately; NO transitive closure over weak links.
