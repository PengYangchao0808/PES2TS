SEMANTICS (test-pinned)
- Targets come from the todo-19 CompiledRequest schedule-λ per-point values
  (parsed todo-20 targets are the fallback when the compiled table does not
  cover that frame index). Actuals come from the todo-20 MulticoordFrame.
  Residuals are computed target − actual for EVERY driver — never first-only.
- Incomplete marking: a frame missing ANY driver residual (target or actual
  absent) is marked incomplete and listed in incomplete_frame_indices —
  never silently passed. missing_driver_ids keeps todo-20 semantics.
  Backend constraint_residuals are carried in a separate channel and do NOT
  rescue a frame whose actual is missing.
- Energy channels separated: scan / single_point rows per frame; both-missing
  collapses to a single energy_channel="none" row. Values never merged.
- Monitors: coordinate-pool records (B/A/D, map-keyed) measured from
  per-frame geometries (B=distance, A=bond_angle_deg, D=dihedral_deg from
  geometry_feasibility); without geometry rows stay explicit (measured=false).
- Non-target contacts: nonbonded atom pairs below threshold (default 0.8 Å,
  g2.validity semantics — distinct from quality.py collision 0.45) that are
  not subsets of any driver coordinate's maps.
- Electronic-state diagnostics: explicit placeholder structured channel
  (status="not_recorded", charge/multiplicity from compiled.recipe when int,
  spin_contamination=None).
- PathBundle extension additive-only: extension frames carry OLD single-
  driver field semantics (target_coordinate / actual_coordinate /
  constraint_residuals, first-driver derived — unchanged when only 1 driver)
  plus NEW named fields (all_driver_targets / all_driver_actuals /
  all_driver_residuals / monitors / contacts / energy_channels / ...). Old
  and new name sets are disjoint (semantics.additive_only=true).
- Driver-mismatch refusal: result.driver_ids must equal compiled driver ids
  (driver_id_for per coordinate); mismatch -> FrameRecoveryError
  DRIVER_MISMATCH. Runtime tripwire _assert_all_drivers_covered raises
  DRIVER_COVERAGE_INCOMPLETE if any output map omits a driver.
