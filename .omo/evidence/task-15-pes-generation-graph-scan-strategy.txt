SELECTION SEMANTICS (the only mechanism)
----------------------------------------
compare_directions(r_profile, p_profile) -> DirectionComparison
  L1 hard gate: both sides must carry has_usable_target_definition
               (else layer1_eligible=() -> all candidates NO_USABLE_ENDPOINT, not ready)
  L1 preference: exactly one side with completed electronic+geometry review wins
  L2 (driver_bonded_at_start + reduces_fragment_dof, 0-2)  >  L3
     (configuration_ok + orientation_ok + undriven_event_coverage_ok, 0-3)
  F/B totals NEVER enter the comparison
  Full tie -> bidirectional=True; start enumeration fixed ("R","P") order

Demoted five-rule anchors (hybrid_rule_ids_for(FBCounts)):
  F==B              -> hybrid_rule_tie_geometry
  max(F,B)<=3       -> hybrid_rule_more_bond_default
  max>3, 1<=min<=3  -> hybrid_rule_fewer_bond_evaluated
  else              -> hybrid_rule_representative_or_path
  always (applicable strategies) -> hybrid_rule_minimal_constraints
Applicable only when route_strategy_id in {LOCAL_CONNECTIVITY, CONNECTIVITY_EXCHANGE}
(ANCHOR_APPLICABLE_STRATEGIES, constants single-sourced from registry.py).
Guardrail test: F>B prior points at P but layer-2 favours R -> only R candidate emitted;
prior recorded in anchor_reason(layer="prior", endpoint="P") but NOT applied.

Cheap priors (recorded, never hard rules):
  F>B -> PRIOR_FB_STRETCH_FROM_ANCHOR endpoint=P; B>F -> endpoint=R; F==B -> PRIOR_FB_NONE
SPLICE_POLICY = "reverse_curves_never_spliced_without_verification"
Every candidate record: equivalence_claimed=False (this module never claims curve equivalence;
splice accounting is todo 28's job).

ASSEMBLY POLICY
---------------
Kabsch rigid alignment reuses g2/endpoints.place_single (import clean; g2 does not import
scan_strategy; truth_guard green). Anchor = largest component (-n_atoms, tag asc).
Cross-side shared-map BFS placement; unplaced components keep stored coords + frame_ambiguous.

ASSEMBLY_FRAME_MISMATCH (typed, never silently accepted):
  (1) HARD failure: bonded pair (R∪P union) inside one component stored farther than
      radius_sum + bond_tolerance + frame_mismatch_tolerance (default 1.5 A) ->
      source file wrote the component across independent physical frames -> ready=False.
  (2) Disconnected group with no rigid link: typed record; edit-bearing groups rely on
      approach configurations (not auto-blocking); no-edit groups = spectators,
      preserved + flagged (CODE_SPECTATOR_PRESERVED; design §7 default keep).

Approach configurations: cross-component B drivers -> translate non-anchor fragment along
the pair axis to policy.approach_target_distances (default 2.5/3.0/3.5 A, ascending);
ids asm-<side>-000-cfg-000..; deterministic enumeration (driver-set order, bond order,
distance asc); per-config collision check.

Collision: nonbonded pair < g2.validity.collision_min_distance (default 0.8) ->
ASSEMBLY_COLLISION -> not ready (spectators included).

Readiness blockers = L1 failure ∪ start-side assembly failures ∪ target-side assembly
failures (scan end values require BOTH sides to assemble; a broken R side blocks both
directions — locked by test).

EQUIVALENCE PROPERTIES (locked by tests)
----------------------------------------
- Rigid endpoint motion (90 deg z + translation): same candidates, ready flags,
  blocker codes, config counts, min_nonbonded_distance (distance invariants).
- Template R/P swap (profiles + sides + F/B swapped consistently): same decided_layer,
  rule_trace, readiness, anchor reason codes; winner assembly geometry identical;
  docs equal after stripping direction labels (ids/endpoints/label-bearing prose).
- F=B tie -> bidirectional candidates (both directions, R then P order).
- Assembly failure -> not ready with typed reason (ASSEMBLY_FRAME_MISMATCH /
  ASSEMBLY_COLLISION); target-side failure also blocks.
