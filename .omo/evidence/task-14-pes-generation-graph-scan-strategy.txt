SCHEDULE KINDS (single source contracts_v2.SCHEDULE_KINDS)
----------------------------------------------------------
- linear:       s_j = λ (shared uniform λ grid, N from FeasibilityReport.n_points)
- event_A_early / event_A_late: windowed smoothstep on exactly two event groups
  (group A = min event id; early window (0,0.5), late window (0.5,1); drivers
  outside the two groups stay linear). Generated ONLY when the candidate's
  drivers span exactly 2 event groups (design §8.1: not per-bond permutations).
- smoothstep:   s = 3u²−2u³, u=clip((λ−a)/(b−a),0,1), window (0,1):
  s(0)=0, s(0.5)=0.5, s(1)=1, monotone.
- ALL drivers share ONE λ list per schedule (invariant, test-locked).
- No arbitrary non-uniform λ lists; custom-list/Simul_Scan compilation is
  todo 19 and is NEVER produced here (requires_backend_smoke=True on
  SCHEDULED_1D + multi-driver linear; doc contains no %geom/%pal markers).

REFINEMENT TREE (pre-frozen, design §8.3)
------------------------------------------
- RefinementRule{max_refinement_count=2 (TODO: calibrate),
                 kinds=(doubling, local_interval)}
- doubling: N→2N−1 midpoint halving, endpoints preserved exactly
- local_interval: one midpoint per adjacent λ pair (closed set: N−1 options)
- refinement_options returns the full closed set from any node; empty when
  depth ≥ max_refinement_count. Runtime never invents new schedules.
- Optional config key scan_strategy.max_refinement_count read when present;
  defaults.yaml NOT modified (todo-2 file frozen in practice).

DOUBLE-DISTANCE INTEGRITY (design §8.1 hard rule)
--------------------------------------------------
- assert_schedule_integrity raises ValueError("SCHEDULE_INTEGRITY_VIOLATION: ...")
  on: unresolved driver ids, role/kind/arity mismatch, duplicate driver ids,
  n_drivers != len(driver_coordinate_ids), any pool coordinate whose origin
  geometry_kind/note claims difference/delta/relative/d1_minus (forbidden),
  or two hydrogen partner/hh DRIVER records sharing (event, H map) with
  duplicate atom_maps (collapsed double distance).
- Target_test companions sharing atom_maps with their driver are LEGITIMATE
  and excluded (role filter) — first version flagged them, fixed.
- Real H-transfer pipeline test: donor(2,4)+acceptor(1,4) remain separate
  drivers into ScheduledCandidate; driver ids unchanged.
