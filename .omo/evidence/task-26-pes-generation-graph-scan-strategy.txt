## PathRequest API (给 todos 27-31)

- `make_path_request(bundle, materials, config, image_chain_params, *, reaction_id=None) -> PathRequest`
  - bundle: EndpointGraphBundle（实例；RebuiltEndpointGraphBundle 子类可过）
  - materials: EndpointMaterials 或映射 {r_coordinates/p_coordinates 或 r/p}，
    可选 `atom_map_ids`（冻结原子序声明——非 map 排序合法，双端几何都按它对齐）
  - config: scan_strategy 段（读 max_total_candidates.path_neb 与可选
    path_request.deep_intermediate_threshold；数值字符串接受——YAML 1.1 quirk）
  - image_chain_params: int | {"n_images", "spring_constant"?, "neb_backend_id"?} |
    ImageChainParams
- `PathRequest` 冻结 dataclass：atom_rows（冻结序）/ n_atoms / elements /
  endpoint_geometries{reactant,product}（**双端同行序 = atom_rows**）/
  image_chain / method_kind="NEB" / recovery_protocol / method_channels / policy；
  `to_doc()` / `to_path_candidate(candidate_id, ...)` / `request_json()`
- `path_request_from_doc(doc)` 往返重建；`flag_intermediate_minimum(energies, *, deep_threshold=None)`
  → IntermediateMinimumFlag（interior min → NEB_INTERMEDIATE_MINIMUM；
  depth≥threshold → DEEP_INTERMEDIATE_MINIMUM + adjacent_segment_required=True；
  恒 single_elementary_process_guaranteed=False；next_stage=
  "intermediate_evidence_staging" = todo 27 接缝）
- 拒绝码（PathRequestError.code，全部 typed，绝不伪造坐标）：
  ENDPOINT_GEOMETRY_MISSING / ATOM_ORDER_MISMATCH / IMAGE_CHAIN_INVALID /
  MATERIALS_SCHEMA_INVALID / BUNDLE_INVALID / PATH_REQUEST_INVALID
- 方法通道（NEB/Scan 分算）：CHANNEL_NEB/CHANNEL_SCAN；`enter_neb_channels()`
  = 进入 NEB 时 NEB.n_entered=1 + 双通道 branch=native_scan_branch_exited；
  `record_channel_outcome(channels, method_kind, succeeded=...)` 只改被寻址通道
  （测试钉死 NEB 成功不加 scan 成功）；n_cpu_hours 恒 0 直至后端实测（§13.4）
