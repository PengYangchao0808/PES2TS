== Semantics ==
- effective_capability(engine, adapter, deployment, *, registry=None):
  args are registry entry ids (layer-checked) or inline CapabilityEntry.
  Declared fields intersect strictly; enabled_modes additionally requires a
  pass probe receipt on EVERY layer covering the mode at that layer's
  engine_version (receipt.adapter_version matched when present; mode must be
  in receipt.modes; empty modes = evidence only; any fail receipt disables).
- UNKNOWN = NOT ENABLED. Shipped baseline: enabled set empty everywhere.
- assert_mode_supported(cap, mode, kinds, n_coords) raises
  BackendCapabilityError code=BACKEND_CAPABILITY_MISSING on structural
  violation OR non-enabled mode.
- capability_check(...) -> {status: pass|fail|unknown, missing: [...]} for
  proposal-stage capability_check fields (todo 17). Declared-but-unprobed =>
  "unknown"; unsmoked combinations can never yield ready.
- method_element_coverage: strict three-way intersection (method must be
  declared by every layer; elements intersected).
- Validation on load: each entry's capability payload projected through
  make_backend_capability(entry_id, "active", **payload) — reuses contracts_v2
  validator exactly; envelope issues (duplicate ids, bad layer) local.
- Disabled reasons formatted as "entry_id [state]: detail" (state in
  {unprobed, fail}).
