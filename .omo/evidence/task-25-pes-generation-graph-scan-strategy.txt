### Phase coverage (one test function per phase, per task spec)

1. `test_coupled_and_scheduled_compile_from_selector_outputs`
   - Real selector (`propose_strategies`) on synthetic EXCHANGE reaction with
     injected passing Simul_Scan probe receipts (todo-16 `_smoke` stack) →
     2-driver COUPLED_1D candidate → `compile_orca` (todo 19):
     both drivers present (`{(1,2),(2,3)}`), `Simul_Scan true` fragment,
     aligned λ (values[i] = q_start + λ_i·Δ, schedule_values ≈ λ within
     6-dp compile rounding), `total_points == len(lambda_values)` (no
     implicit grid), point hashes recorded.
   - Synthetic SCHEDULED_1D non-uniform candidate (selector-output shape) →
     per-point recipe: `len(point_input_sha256) == total_points == 4`,
     distinct hashes, BOTH drivers in every `%geom Constraints` fragment,
     non-uniform per-driver schedule lists preserved.

2. `test_per_frame_all_driver_recovery_marks_missing_driver_frame_incomplete`
   - Synthetic multicoord result (2 drivers, 3 frames, driver-02 actual
     missing at frame 1) → `parse_multicoord_result` (todo 20) →
     `recover_frames` (todo 21): complete per-frame target/actual/residual
     traces for both drivers on healthy frames; frame 1 marked
     `incomplete=True`, `missing_driver_ids=("driver-02",)`,
     `incomplete_frame_indices=(1,)` — never silently passed.

3. `test_target_quality_layer_records_tiers_and_unfinished_target`
   - Recovered complete frames → `assess_target_path` (todo 22): all four
     tiers recorded independently (`execution_complete` achieved,
     `numerically_usable` achieved, `target_path_compatible` NOT achieved
     with `TARGET_PATH_INCOMPLETE` for the unfinished C–C formed bond,
     `validated_ts` absent listing all four missing evidence refs).
   - Technical usable ≠ chemical completion (design §11.2 plan failure).

4. `test_plan_freeze_valid_document_and_failure_tree_replayable`
   - Freeze-ready 2-driver COUPLED proposal + real CompiledRequest →
     `freeze_generation_plan` (todo 23): `validate_v2_document == []`,
     `verify_generation_plan == []`, frozen candidate carries BOTH drivers,
     `extensions.freeze.compiled_request.coordinates` has both entries.
   - Failure tree replayable: `FAILURE_PREDICATES == FAILURE_TREE_CODES`,
     `active_failure_codes` computable (GATE_REFUSED / BUDGET_EXHAUSTED /
     multi-code), `is_failure_code` rejects free text ("效果不好"),
     `assert_failure_code` raises `FAILURE_CODE_UNKNOWN`.

5. `test_explicit_refusals_capability_missing_unsupported_and_no_implicit_grids`
   - Inject test: COUPLED request on shipped default registry →
     `compile_orca` raises `BACKEND_CAPABILITY_MISSING`; adapter
     `multicoord_request_payload` refuses with the same code and is an
     `ACPMappingError` subclass.
   - Unsupported A/D on current adapter (registry: B only) → compile AND
     adapter refuse with `BACKEND_CAPABILITY_MISSING`.
   - No implicit grids: COUPLED and SCHEDULED compiled totals equal the
     schedule grid (`total_points == len(lambda_values)`, per-point hash
     count == total_points).

6. `test_no_first_driver_projection_across_every_chain_artifact`
   - Both drivers appear in EVERY artifact down the chain:
     compiled.coordinates, payload coordinates + metadata (n_drivers=2,
     driver_ids), recovery frames (targets/actuals/residuals per driver),
     PathBundle extension (`all_driver_*` per frame), frozen plan candidate
     drivers, and the sealed compiled-request binding.

7. `test_p2_gated_smoke_status_is_explicit_passed_or_blocked`
   - `_p2_gated_smoke_status()` returns `passed` or `blocked`; in this tree
     (env absent) → `blocked` with missing env var names — matches env
