# data/ storage policy

This directory is **data, not source**. Only small, human-readable manifests are
versioned; raw data, parquet caches, truth logs and large derived reports stay
local and are re-generated from the frozen inputs when needed.

## Versioned

- `data/manifests/*.json` — small manifests (target: each file < 1 MB).
- `data/interim/g2_needs_review.json` — the small G2 review list.
- `data/README.md` — this policy.

## Not versioned (local only)

- `data/raw/**` — Reaction-QM / IRC source data.
- `data/interim/**` — `inventory.parquet`, fingerprints, class summaries and
  other derived tables (hundreds of MB).
- `data/manifests/truth_access_log.jsonl` — append-only truth audit log
  (~200 MB); rotate/compress it locally, never commit it.
- `data/manifests/g1_cluster_report.json` — 74 MB derived cluster report
  (regenerated by the G1 audit/classification commands).
- `data/interim/g2_eligible.json`, `g2_scan_ready.json` — multi-MB derived ID
  lists (regenerated by the G2 preparation commands).
- `data/ground_truth/**` — quarantined truth.

## Regeneration

Large derived files are produced by the stage CLIs. Use the command help for the
exact flags, e.g.:

```bash
python bin/pes2ts g1 --help
python bin/pes2ts g1 classify --help
python bin/pes2ts g1 v2-gate --help
python bin/pes2ts g2 prepare --help
```

The frozen inputs (`data/raw`, source manifests) are the authority; never
hand-edit a large derived file to make a test pass.

## V5/V6 campaign data

V5 teacher shards, resampled paths and pre-relaxed frames are **not** committed:

```text
data/manifests/v5/*.json      # small split/audit/frame/feature manifests: versioned
data/interim/v5/**            # teacher labels, shards, parquet: local only
outputs/pesn/v5/**            # run outputs, rollouts, checkpoints: local only
```

Only the small manifests and SHA-256 hashes are versioned; see
`docs/design/PES2TS_G_V_MAPPING_v1_20261018.md` for the G/V campaign map.
